### Шаблон

Перебор с возвратом (backtracking) строит решение по шагам: на каждом шаге пробует все допустимые варианты, для каждого рекурсивно продолжает, а после возврата **отменяет** сделанный выбор.

```python
def backtrack(state):
    if решение_готово(state):
        сохранить(state)
        return
    for choice in варианты(state):
        if допустимо(state, choice):
            сделать(state, choice)
            backtrack(state)
            отменить(state, choice)
```

Сложность — число узлов дерева перебора, обычно экспоненциальная. Поэтому перебор применяют, когда n маленькое (обычно до 10–20), или когда отсечения сильно уменьшают дерево.

### Правильные скобочные последовательности

Задача из официальной статьи Яндекса об алгоритмических секциях: вывести все правильные скобочные последовательности длины 2n в лексикографическом порядке (`(` меньше `)`).

Состояние — текущая строка и число открытых и закрытых скобок. Допустимость: открывающую можно поставить, если открытых меньше n; закрывающую — если закрытых меньше, чем открытых.

```python
def gen(n):
    res = []
    def go(s, opened, closed):
        if len(s) == 2 * n:
            res.append(s)
            return
        if opened < n:
            go(s + "(", opened + 1, closed)
        if closed < opened:
            go(s + ")", opened, closed + 1)
    go("", 0, 0)
    return res
```

Сначала пробуем `(`, потом `)` — поэтому результат автоматически в лексикографическом порядке.

**Типичная ошибка из той же статьи:** изменить строку `current += "("` и передать её дальше, а потом в следующей ветке дописать `")"` к уже изменённой строке. Здесь строка передаётся как новый объект `s + "("`, поэтому «отмена» не нужна. Если же состояние — изменяемый список, после вызова обязателен `pop()`:

```python
def gen_list(n):
    res, cur = [], []
    def go(opened, closed):
        if len(cur) == 2 * n:
            res.append("".join(cur))
            return
        if opened < n:
            cur.append("("); go(opened + 1, closed); cur.pop()
        if closed < opened:
            cur.append(")"); go(opened, closed + 1); cur.pop()
    go(0, 0)
    return res
```

Число последовательностей — число Каталана C(n): 1, 2, 5, 14, 42… Для n = 10 это 16 796.

### Все подмножества

Для каждого элемента два варианта — брать или не брать:

```python
def subsets(a):
    res, cur = [], []
    def go(i):
        if i == len(a):
            res.append(cur[:])        # копия! иначе все элементы res — один и тот же список
            return
        go(i + 1)                     # не берём a[i]
        cur.append(a[i])
        go(i + 1)                     # берём
        cur.pop()
    go(0)
    return res
```

2ⁿ подмножеств, O(2ⁿ · n) с копированием. Ошибка `res.append(cur)` без копии — классика: в конце все элементы `res` окажутся пустыми списками.

**Перебор по битовым маскам** — без рекурсии:

```python
n = len(a)
for mask in range(1 << n):
    subset = [a[i] for i in range(n) if mask >> i & 1]
```

Бит i маски говорит, взят ли элемент i. Удобно для «выбрать подмножество с лучшим значением» при n ≤ 20.

### Перестановки

```python
def permutations(a):
    res, cur, used = [], [], [False] * len(a)
    def go():
        if len(cur) == len(a):
            res.append(cur[:])
            return
        for i in range(len(a)):
            if not used[i]:
                used[i] = True; cur.append(a[i])
                go()
                cur.pop(); used[i] = False
    go()
    return res
```

n! перестановок — годится до n ≈ 8–10. С повторяющимися элементами: отсортировать и пропускать `a[i]`, если `a[i] == a[i-1]` и `a[i-1]` не использован в текущей ветке. На контесте — `itertools.permutations`.

### Сочетания и комбинации с суммой

Сочетания из n по k: в цикле начинаем со следующего индекса после последнего взятого — так не будет повторов в другом порядке.

```python
def combinations(n, k):
    res, cur = [], []
    def go(start):
        if len(cur) == k:
            res.append(cur[:]); return
        for i in range(start, n + 1):
            if len(cur) + (n - i + 1) < k:     # отсечение: не хватит элементов
                break
            cur.append(i); go(i + 1); cur.pop()
    go(1)
    return res
```

«Комбинации с заданной суммой» (каждое число можно брать много раз): после выбора `a[i]` рекурсия продолжается с того же `i`; если текущая сумма превысила цель — отсекаем.

### Отсечения

Отсечение — ранний выход из ветки, которая заведомо не даст ответ:

- сумма уже больше цели (при положительных числах);
- оставшихся элементов не хватит до нужного размера;
- текущий результат уже хуже лучшего найденного (метод ветвей и границ);
- симметрия: не рассматривать варианты, отличающиеся только порядком.

Хорошие отсечения превращают «невозможный» перебор в быстрый. На контесте часто проходит перебор с отсечениями там, где «правильного» алгоритма вы не знаете.

### Генерация в лексикографическом порядке

Если варианты на каждом шаге перебираются по возрастанию, результаты выходят отсортированными. Это важно, когда условие требует порядок вывода, и экономит сортировку.

### Где встречается

- генерация всех объектов: скобки, подмножества, перестановки, разбиения числа на слагаемые (задача «Сумма» из бэкенд-сезона CodeRun);
- головоломки: судоку, N ферзей, раскраски;
- поиск при маленьких ограничениях: выбрать подмножество людей, задач, предметов с условием;
- комбинации букв телефонной клавиатуры.

## Самопроверка

### Сколько правильных скобочных последовательностей длины 6?
- [ ] 3
- [x] 5
- [ ] 6
- [ ] 8
> Число Каталана C(3) = 5: `((()))`, `(()())`, `(())()`, `()(())`, `()()()`.

### Что выведет код?
```python
res, cur = [], []
def go(i):
    if i == 2:
        res.append(cur)
        return
    go(i + 1)
    cur.append(i)
    go(i + 1)
    cur.pop()
go(0)
print(res)
```
- [ ] `[[], [1], [0], [0, 1]]`
- [x] `[[], [], [], []]`
- [ ] `[[0, 1], [0, 1], [0, 1], [0, 1]]`
- [ ] Ошибку
> В `res` добавлялась ссылка на один и тот же список `cur`, который к концу опустел. Нужно `res.append(cur[:])`.

### Что выведет код?
```python
def gen(n):
    res = []
    def go(s, o, c):
        if len(s) == 2 * n:
            res.append(s)
            return
        if o < n:
            go(s + "(", o + 1, c)
        if c < o:
            go(s + ")", o, c + 1)
    go("", 0, 0)
    return res

print(gen(2))
```
- [ ] `['()()', '(())']`
- [x] `['(())', '()()']`
- [ ] `['(())']`
- [ ] `['()()', '(())', ')(()']`
> Сначала пробуется открывающая скобка, поэтому последовательности идут в лексикографическом порядке.

### Что такое отсечение в переборе?
- [ ] Удаление дубликатов из ответа
- [x] Досрочный выход из ветки, которая заведомо не приведёт к ответу
- [ ] Ограничение глубины рекурсии
- [ ] Сортировка вариантов
> Например, если сумма уже превысила цель при положительных числах, продолжать ветку бессмысленно.

- [ ] Через словарь
> Бит i маски отвечает за элемент i: `mask >> i & 1`.

## Вопросы на собеседовании

### Сгенерируйте все правильные скобочные последовательности длины 2n.
Перебор с возвратом со счётчиками открытых и закрытых скобок: добавляем `(`, если открытых меньше n, и `)`, если закрытых меньше открытых; при длине 2n сохраняем строку. Отсечения гарантируют, что генерируются только правильные последовательности, поэтому работа пропорциональна их числу — числу Каталана C(n), умноженному на длину. Главная ловушка — изменяемое состояние без отката.

### Как сгенерировать все перестановки массива с повторяющимися элементами без дубликатов?
Отсортировать массив и перебирать с массивом `used`; на каждом уровне пропускать элемент, если он равен предыдущему и предыдущий не использован в текущей ветке. Так одинаковые элементы берутся строго в порядке следования, и одинаковые перестановки не повторяются. Альтернатива — перебирать уникальные значения через `Counter`, уменьшая счётчик.
