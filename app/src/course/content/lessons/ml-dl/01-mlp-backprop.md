### От линейной модели к нейросети

Логистическая регрессия — это один «нейрон»: взвешенная сумма признаков и нелинейность σ. Полносвязная сеть (MLP) — несколько слоёв таких нейронов:

```text
h₁ = f(W₁x + b₁)
h₂ = f(W₂h₁ + b₂)
ŷ = g(W₃h₂ + b₃)
```

W₁ — матрица размера (число нейронов слоя) × (размер входа). f — функция активации внутри сети, g — на выходе под задачу.

**Зачем нелинейности.** Без них композиция линейных слоёв — снова линейная функция: W₂(W₁x) = (W₂W₁)x. Сколько слоёв ни добавляй, модель останется линейной. Нелинейность между слоями позволяет сети приближать сложные зависимости: по теореме об универсальной аппроксимации сеть с одним скрытым слоем достаточной ширины приближает любую непрерывную функцию на компакте. Глубина при этом нужна не для выразительности в принципе, а для эффективности: глубокие сети выражают сложные функции гораздо меньшим числом параметров.

### Функции активации

| Активация | Формула | Производная | Замечания |
|---|---|---|---|
| Сигмоида | 1/(1 + e^(−z)) | σ(1 − σ), не больше 0.25 | Насыщается, градиент затухает; выход не центрирован |
| tanh | (eᶻ − e^(−z))/(eᶻ + e^(−z)) | 1 − tanh² | Центрирована, но тоже насыщается |
| ReLU | max(0, z) | 1 при z > 0, иначе 0 | Дёшево, не насыщается при z > 0; «мёртвые» нейроны при z < 0 всегда |
| Leaky ReLU | max(αz, z) | 1 или α | Нет мёртвых нейронов |
| GELU | z·Φ(z) | гладкая | Стандарт в трансформерах |

По умолчанию во внутренних слоях — ReLU или его варианты, в трансформерах — GELU.

### Выход и функция потерь под задачу

| Задача | Выходной слой | Потеря |
|---|---|---|
| Регрессия | Линейный | MSE, MAE, Huber |
| Бинарная классификация | 1 нейрон + сигмоида | Бинарная кросс-энтропия (logloss) |
| Многоклассовая | K нейронов + softmax | Кросс-энтропия |
| Много меток одновременно | K нейронов + сигмоида у каждого | Сумма бинарных кросс-энтропий |

На практике сигмоиду и softmax объединяют с потерей (`BCEWithLogitsLoss`, `CrossEntropyLoss` в PyTorch принимают логиты) — так численно устойчивее.

### Число параметров

Полносвязный слой из n входов в m выходов: m·n весов + m смещений. Сеть 784 → 256 → 10 (классификатор MNIST) — 784·256 + 256 + 256·10 + 10 = 203 530 параметров. Посчитать параметры — частый короткий вопрос.

### Обратное распространение ошибки

Обучение — градиентный спуск по всем весам. Считать производную по каждому весу отдельно дорого. **Backpropagation** — это правило цепочки, применённое к вычислительному графу в правильном порядке:

1. **Прямой проход**: вычислить все промежуточные значения от входа к потере и сохранить их.
2. **Обратный проход**: от потери к входу, для каждого узла получить градиент потери по его выходу и превратить его в градиенты по его входам и параметрам.

Для слоя z = Wh + b, a = f(z), если известен δₐ = ∂L/∂a:

```text
δ_z = δₐ ⊙ f'(z)          поэлементно
∂L/∂W = δ_z · hᵀ          внешнее произведение
∂L/∂b = δ_z
δ_h = Wᵀ · δ_z             передаётся в предыдущий слой
```

Стоимость обратного прохода — порядка стоимости прямого. Именно поэтому обучение глубоких сетей вообще возможно: градиент по миллионам параметров за один проход назад.

Пример — сеть с одним скрытым слоем, сигмоидами и MSE на одном объекте:

```python
from math import exp

def sig(z):
    return 1 / (1 + exp(-z))

def step(x, y, W1, b1, w2, b2, lr):
    # прямой проход
    z1 = [sum(W1[j][i] * x[i] for i in range(len(x))) + b1[j] for j in range(len(b1))]
    h = [sig(z) for z in z1]
    out = sum(w2[j] * h[j] for j in range(len(h))) + b2
    loss = (out - y) ** 2
    # обратный проход
    d_out = 2 * (out - y)
    g_w2 = [d_out * hj for hj in h]
    g_b2 = d_out
    d_h = [d_out * w2[j] for j in range(len(h))]
    d_z1 = [d_h[j] * h[j] * (1 - h[j]) for j in range(len(h))]
    g_W1 = [[d_z1[j] * x[i] for i in range(len(x))] for j in range(len(h))]
    # шаг — только после подсчёта всех градиентов
    W1 = [[W1[j][i] - lr * g_W1[j][i] for i in range(len(x))] for j in range(len(h))]
    b1 = [b1[j] - lr * d_z1[j] for j in range(len(h))]
    w2 = [w2[j] - lr * g_w2[j] for j in range(len(h))]
    return W1, b1, w2, b2 - lr * g_b2, loss
```

Обратите внимание: `d_h` считается по **старым** w2 — веса обновляются только после полного обратного прохода.

Современные фреймворки делают это автоматически (**автоматическое дифференцирование**): PyTorch записывает граф операций при прямом проходе, `loss.backward()` проходит его в обратном порядке. Но на собеседовании ждут, что вы можете выписать backprop для двух слоёв руками.

### Затухающие и взрывающиеся градиенты

Градиент первого слоя — произведение множителей всех следующих слоёв. Если множители в среднем меньше 1 (производная сигмоиды не больше 0.25), градиент экспоненциально **затухает** с глубиной, и первые слои почти не учатся. Если больше 1 — **взрывается**, веса улетают в бесконечность.

Решения:
- ReLU-подобные активации — производная 1 на активной части;
- правильная **инициализация**: Xavier/Glorot (дисперсия весов ~ 2/(вход + выход)) для tanh и сигмоиды, He (~ 2/вход) для ReLU — чтобы дисперсия активаций не росла и не падала от слоя к слою;
- **нормализация** слоёв (BatchNorm, LayerNorm);
- **остаточные связи** (residual): h_{l+1} = h_l + F(h_l) — градиент проходит по «короткому пути» без затухания; на них стоят ResNet и трансформеры;
- **обрезка градиента** (gradient clipping) против взрыва — стандарт для RNN и трансформеров.

**Почему нельзя инициализировать нулями**: все нейроны слоя получат одинаковые градиенты и останутся одинаковыми — симметрия не нарушится, и слой будет эквивалентен одному нейрону.

### Типичные ошибки

- Забыть нелинейность между слоями.
- Softmax в модели и ещё раз внутри `CrossEntropyLoss`.
- Обновлять веса слоя до того, как по ним посчитан градиент предыдущего слоя.
- Инициализировать все веса нулями или одним числом.
- Сигмоиды во всех слоях глубокой сети.
- Путать число нейронов и число параметров.

### Как спрашивают на Яндексе

## Вопросы на собеседовании

### Объясните, как работает обратное распространение ошибки.
Нейросеть — композиция функций, потеря зависит от весов через цепочку слоёв. При прямом проходе вычисляем и сохраняем промежуточные значения всех слоёв. Затем идём от потери назад и по правилу цепочки получаем градиент потери по выходу каждого слоя: для слоя z = Wh + b, a = f(z) градиент по z — это градиент по a, поэлементно умноженный на f'(z); градиент по W — его внешнее произведение с h; градиент по h, который уходит в предыдущий слой, — Wᵀ, умноженная на градиент по z. Так за один обратный проход, по стоимости сравнимый с прямым, получаем градиенты по всем параметрам.

### Почему ReLU популярнее сигмоиды?
Производная ReLU на положительной части равна 1, поэтому градиенты не затухают через много слоёв, тогда как производная сигмоиды не больше 0.25 и почти ноль при больших |z|. ReLU дешевле вычислять и даёт разреженные активации. Минус — «мёртвые» нейроны, которые при отрицательном входе на всех объектах перестают обучаться; его закрывают Leaky ReLU, GELU и аккуратная инициализация. Сигмоида остаётся на выходе для вероятностей и в гейтах LSTM.

### Что такое затухающие и взрывающиеся градиенты и как с ними бороться?
При backprop градиент первых слоёв — произведение якобианов всех следующих слоёв. Если их нормы в среднем меньше 1, градиент экспоненциально затухает с глубиной, и ранние слои не учатся; если больше 1 — взрывается. Борются активациями без насыщения (ReLU), инициализацией, сохраняющей дисперсию (Xavier, He), нормализацией (BatchNorm, LayerNorm), остаточными связями, которые дают градиенту прямой путь, gradient clipping против взрыва и гейтами в рекуррентных сетях (LSTM, GRU).
