### Вероятность и условная вероятность

P(A) — вероятность события, P(A | B) — вероятность A при условии, что B произошло:

```text
P(A | B) = P(A и B) / P(B)
```

События **независимы**, если P(A и B) = P(A)·P(B), то есть знание B не меняет вероятность A. Независимость — сильное предположение: наивный Байес предполагает независимость признаков при известном классе, и почти всегда это неправда.

**Формула полной вероятности**: если B₁, …, B_k — разбиение на непересекающиеся случаи, P(A) = Σ P(A | Bᵢ)·P(Bᵢ).

### Формула Байеса

```text
P(B | A) = P(A | B) · P(B) / P(A)
```

Классическая задача: болезнь встречается у 1 % людей, тест находит 99 % больных и ошибочно срабатывает у 5 % здоровых. Тест положительный — какова вероятность болезни?

```text
P(+) = 0.99·0.01 + 0.05·0.99 = 0.0099 + 0.0495 = 0.0594
P(болен | +) = 0.0099 / 0.0594 ≈ 0.167
```

Всего 17 %: здоровых так много, что ложных срабатываний больше, чем верных. Это та же история, что с precision при редком классе: ложные срабатывания на большом классе съедают точность. Интервьюеры любят эту задачу, потому что интуиция подсказывает «99 %».

Термины: P(B) — **априорная** вероятность, P(A | B) — **правдоподобие**, P(B | A) — **апостериорная**.

### Случайные величины, матожидание, дисперсия

- **Матожидание** E[X] = Σ x·P(X = x) — среднее значение. Линейно всегда, даже для зависимых величин: E[X + Y] = E[X] + E[Y], E[aX] = a·E[X].
- **Дисперсия** Var X = E[(X − E X)²] = E[X²] − (E X)². Var(aX) = a²·Var X. Для **независимых**: Var(X + Y) = Var X + Var Y.
- **Стандартное отклонение** — √Var, в тех же единицах, что X.
- **Ковариация** cov(X, Y) = E[(X − EX)(Y − EY)], **корреляция** — ковариация, делённая на произведение стандартных отклонений, от −1 до 1. Корреляция меряет только линейную связь: для Y = X² при симметричном X она ноль, хотя Y полностью определяется X. И корреляция не означает причинность.

Линейность матожидания решает много задач «сколько в среднем»: ожидаемое число неподвижных точек случайной перестановки — сумма n индикаторов с вероятностью 1/n каждый, то есть 1, без всякой комбинаторики.

### Распределения, которые надо знать

| Распределение | Где встречается | E | Var |
|---|---|---|---|
| Бернулли(p) | Клик/не клик, метка класса | p | p(1 − p) |
| Биномиальное(n, p) | Число кликов из n показов | np | np(1 − p) |
| Геометрическое(p) | Число попыток до первого успеха | 1/p | (1 − p)/p² |
| Пуассона(λ) | Число событий за интервал: заказы в час | λ | λ |
| Равномерное [a, b] | Случайные числа, инициализация | (a + b)/2 | (b − a)²/12 |
| Нормальное N(μ, σ²) | Шум измерений, средние больших выборок | μ | σ² |
| Экспоненциальное(λ) | Время между событиями | 1/λ | 1/λ² |

Для нормального распределения: 68 % значений в пределах ±1σ, 95 % — ±1.96σ, 99.7 % — ±3σ.

### Метод максимального правдоподобия

Параметры модели выбирают так, чтобы наблюдённые данные были наиболее вероятны:

```text
θ* = argmax Π p(xᵢ | θ) = argmax Σ log p(xᵢ | θ)
```

Логарифм превращает произведение в сумму и не меняет точку максимума. Отсюда берутся стандартные функции потерь:
- **Бернулли** для меток y ∈ {0, 1} с вероятностью p(x) → минус лог-правдоподобие = **logloss**.
- **Нормальный шум** y = f(x) + ε, ε ~ N(0, σ²) → минус лог-правдоподобие ∝ Σ (y − f(x))² = **MSE**.
- **Лапласовский шум** → **MAE**.
- Монетка: n бросков, k орлов → оценка p = k/n.

А **априорное распределение** на параметры превращает правдоподобие в апостериорное (MAP-оценка) и даёт регуляризацию: нормальное априорное → L2, лапласовское → L1.

### Выборочные оценки

По выборке x₁, …, x_n: среднее x̄ = Σ xᵢ / n; дисперсия s² = Σ (xᵢ − x̄)² / (n − 1). Деление на n − 1 (поправка Бесселя) делает оценку несмещённой: отклонения считаются от выборочного среднего, которое «подстроено» под данные и занижает разброс. `np.var` по умолчанию делит на n, pandas — на n − 1.

### Закон больших чисел и ЦПТ

- **Закон больших чисел**: выборочное среднее сходится к матожиданию с ростом n.
- **Центральная предельная теорема**: распределение среднего n независимых одинаково распределённых величин с конечной дисперсией σ² при большом n близко к нормальному N(μ, σ²/n). Стандартная ошибка среднего — σ/√n: чтобы уменьшить погрешность вдвое, нужно вчетверо больше данных.

**Доверительный интервал** для среднего: x̄ ± 1.96·s/√n — 95-процентный. Смысл: при повторении эксперимента такой интервал накроет истинное среднее в 95 % случаев (а не «истинное значение лежит в нём с вероятностью 95 %»).

**Бутстрэп** — эмпирический способ получить интервал для любой статистики (медианы, ROC-AUC): много раз пересэмплировать выборку с возвращением, посчитать статистику, взять 2.5 и 97.5 перцентили.

### Проверка гипотез и A/B-тесты

Хотим понять, лучше ли новая модель в online-метрике. Пользователей случайно делят на группы A (старая) и B (новая).

- **Нулевая гипотеза** H₀: разницы нет. **Альтернатива** H₁: есть.
- **p-value** — вероятность увидеть такую же или бо́льшую разницу, если H₀ верна. Малое p-value (меньше уровня значимости α, обычно 0.05) — повод отвергнуть H₀. p-value **не** вероятность того, что H₀ верна.
- **Ошибка I рода** (α) — найти эффект, которого нет. **Ошибка II рода** (β) — пропустить эффект; **мощность** = 1 − β.
- Для средних — t-тест, для долей (конверсия) — z-тест для пропорций; для метрик-отношений (CTR по пользователям) — дельта-метод или бутстрэп.
- **Размер выборки** считают заранее из α, мощности и минимального эффекта, который важно заметить.
- Ловушки: подглядывание (остановить тест, как только p < 0.05, — ошибка I рода растёт), множественные сравнения (20 метрик — одна «значима» случайно; поправка Бонферрони), разные единицы рандомизации и анализа.

### Типичные ошибки

- Путать P(A | B) и P(B | A) — ровно та ошибка, которую ловит задача про тест на болезнь.
- Складывать дисперсии зависимых величин.
- Считать нулевую корреляцию независимостью.
- Интерпретировать p-value как вероятность нулевой гипотезы.
- Останавливать A/B-тест при первом значимом результате.
- Делить выборочную дисперсию на n и удивляться смещению на маленьких выборках.

## Вопросы на собеседовании

### Выведите logloss из метода максимального правдоподобия.
Метки yᵢ ∈ {0, 1}, модель даёт pᵢ = P(yᵢ = 1 | xᵢ). Вероятность наблюдённой метки по распределению Бернулли — pᵢ^yᵢ·(1 − pᵢ)^(1 − yᵢ). Объекты независимы, правдоподобие — произведение по объектам. Логарифм превращает его в сумму Σ [yᵢ log pᵢ + (1 − yᵢ) log(1 − pᵢ)], максимизация которой эквивалентна минимизации минус этой суммы, делённой на n, — это logloss.

### Чем отличаются корреляция и независимость?
Независимость — P(A и B) = P(A)P(B) для всех событий, связанных с величинами: знание одной ничего не говорит о другой. Корреляция измеряет только линейную связь. Независимые величины некоррелированы, но обратное неверно: X симметрично распределён вокруг нуля, Y = X² — корреляция ноль, а Y полностью определяется X. Исключение — совместно нормальные величины, для них некоррелированность означает независимость.

### Как спланировать и проанализировать A/B-тест новой модели ранжирования?
Выбрать основную метрику (например, долю успешных сессий), единицу рандомизации (пользователь), уровень значимости и мощность, минимальный важный эффект — и по ним посчитать размер выборки и длительность (не меньше недели из-за сезонности по дням). Проверить сплит A/A-тестом. В конце — один статистический тест по заранее выбранной метрике (t-тест, z-тест для долей, бутстрэп или дельта-метод для отношений), без подглядывания; вспомогательные метрики — с поправкой на множественные сравнения. Отдельно — guardrail-метрики, которые не должны ухудшиться (время ответа, жалобы).

### Почему выборочную дисперсию делят на n − 1?
Отклонения считаются от выборочного среднего, а оно по построению минимизирует сумму квадратов отклонений именно для этой выборки — поэтому сумма квадратов в среднем меньше, чем относительно истинного среднего. Математически E[Σ(xᵢ − x̄)²] = (n − 1)σ², и деление на n − 1 делает оценку несмещённой. При больших n разница несущественна; деление на n даёт оценку максимального правдоподобия для нормального распределения.
