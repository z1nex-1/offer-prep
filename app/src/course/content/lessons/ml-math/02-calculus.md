### Производная

Производная f'(x) — скорость изменения функции: f(x + h) ≈ f(x) + f'(x)·h при малом h. Таблица, которой хватает для ML:

| f(x) | f'(x) |
|---|---|
| xⁿ | n·xⁿ⁻¹ |
| eˣ | eˣ |
| ln x | 1/x |
| σ(x) = 1/(1 + e^(−x)) | σ(x)·(1 − σ(x)) |
| tanh x | 1 − tanh² x |
| ReLU(x) = max(0, x) | 1 при x > 0, 0 при x < 0 |
| \|x\| | sign(x), в нуле не определена |

**Правило цепочки**: (f(g(x)))' = f'(g(x))·g'(x). На нём целиком стоит обратное распространение ошибки в нейросетях: производная сложной функции — произведение производных звеньев.

### Частные производные и градиент

Для функции многих переменных f(w₁, …, w_d) частная производная ∂f/∂wⱼ — производная по wⱼ при фиксированных остальных. **Градиент** ∇f = (∂f/∂w₁, …, ∂f/∂w_d) — вектор, указывающий направление наискорейшего роста функции; его длина — скорость роста. Антиградиент −∇f — направление наискорейшего убывания. В точке минимума гладкой функции градиент равен нулю.

### Градиенты, которые стоит помнить

- **MSE линейной модели**: L(w) = (1/n)·‖Xw − y‖², ∇L = (2/n)·Xᵀ(Xw − y).
- **Logloss логистической регрессии**: ∇L = (1/n)·Xᵀ(σ(Xw) − y).
- **L2-регуляризация** λ‖w‖²: градиент 2λw — «затухание весов» (weight decay).
- **L1** λΣ|wⱼ|: субградиент λ·sign(w).
- **Softmax + кросс-энтропия** по логитам z: p − onehot(y).
- **Полезные тождества**: ∇ₓ⟨a, x⟩ = a; ∇ₓ(xᵀAx) = (A + Aᵀ)x, для симметричной A — 2Ax.

Проверка размерностей: градиент по w всегда той же формы, что и w.

### Выпуклость

Функция выпукла, если отрезок между любыми двумя точками графика лежит не ниже графика. Для выпуклой функции **любой локальный минимум глобальный**, и градиентный спуск при правильном шаге к нему сходится. Выпуклы: MSE и logloss линейных моделей, hinge loss SVM, L1 и L2 штрафы. Невыпуклы: функции потерь нейросетей, k-means.

Критерий для дважды дифференцируемых функций — матрица вторых производных (**гессиан**) положительно полуопределена.

### Градиентный спуск

```text
w ← w − η·∇L(w)
```

- **Шаг η (learning rate)**. Слишком большой — перескакиваем минимум, функция растёт и расходится. Слишком маленький — сходимость очень медленная. Для квадратичной функции устойчивость требует η < 2 / λ_max, где λ_max — наибольшее собственное значение гессиана.
- **Масштаб признаков** влияет на обусловленность: если признаки в разных единицах, линии уровня вытянутые, и спуск идёт зигзагом. Стандартизация делает их ближе к окружностям.
- **Критерии остановки**: число итераций, малая норма градиента, отсутствие улучшения на валидации (ранняя остановка).

### SGD и мини-батчи

Полный градиент — сумма по всем n объектам, шаг стоит O(n·d). **Стохастический** градиентный спуск берёт один объект или **мини-батч** из b объектов: оценка градиента несмещённая, но шумная, шаг в n/b раз дешевле. На больших данных SGD за то же время проходит гораздо больше шагов и выигрывает. Шум даже помогает выбираться из плохих областей невыпуклых функций. Для сходимости шаг постепенно уменьшают (learning rate schedule).

**Эпоха** — один проход по всем данным; перед каждой эпохой объекты перемешивают.

### Момент, RMSProp, Adam

- **Момент (momentum)**: копим «скорость» v ← βv + ∇L, шаг w ← w − ηv. Сглаживает колебания поперёк оврага и ускоряет движение вдоль него. β ≈ 0.9.
- **RMSProp**: делит шаг по каждой координате на корень из скользящего среднего квадратов градиента — координаты с большими градиентами получают меньший шаг.
- **Adam**: момент + RMSProp + поправка на смещение в начале. Стандартный выбор для нейросетей; типичный шаг 1e-3.

```python
m = beta1 * m + (1 - beta1) * g
v = beta2 * v + (1 - beta2) * g * g
m_hat = m / (1 - beta1 ** t)
v_hat = v / (1 - beta2 ** t)
w -= lr * m_hat / (v_hat ** 0.5 + eps)
```

Подробнее о них — в модуле «Нейросети».

### Метод Ньютона

Использует и вторые производные: w ← w − H⁻¹∇L, где H — гессиан. Для квадратичной функции находит минимум за один шаг, вблизи минимума сходится очень быстро (квадратично). Цена — O(d²) памяти на гессиан и O(d³) на решение системы на каждом шаге, поэтому для больших моделей используют приближения (L-BFGS — в `LogisticRegression` sklearn по умолчанию).

### Локальные минимумы и седловые точки

У невыпуклых функций градиент равен нулю не только в минимумах: в **седловой точке** функция растёт по одним направлениям и убывает по другим (как f(x, y) = x² − y² в нуле). В пространствах большой размерности седловые точки встречаются гораздо чаще плохих локальных минимумов, и шум SGD с моментом помогает с них сходить.

### Типичные ошибки

- Забыть множитель 2 или 1/n в градиенте MSE — это меняет эффективный шаг.
- Регуляризовать свободный член.
- Слишком большой learning rate и вывод «модель не обучается».
- Не перемешивать данные между эпохами SGD.
- Считать, что градиентный спуск находит глобальный минимум невыпуклой функции.
- Путать градиент (вектор производных) и гессиан (матрица вторых производных).

- [x] σ(x)·(1 − σ(x))
- [ ] 1 − σ(x)
- [ ] σ(x)²
> Максимум производной — 0.25 при x = 0; при больших |x| она почти ноль — отсюда затухание градиентов в глубоких сетях с сигмоидами.

### Каким будет градиент функции L(w) = ‖Xw − y‖² по w?
- [ ] 2X(Xw − y)
- [x] 2Xᵀ(Xw − y)
- [ ] (Xw − y)²
- [ ] 2(Xw − y)Xᵀ
> Проверка размерностей: Xᵀ (d × n) на вектор n даёт вектор d — как у w.

### Функция потерь при обучении растёт с каждой итерацией градиентного спуска. Вероятная причина?
- [ ] Слишком маленький learning rate
- [x] Слишком большой learning rate — шаги перескакивают минимум
- [ ] Слишком много данных
- [ ] Выпуклая функция потерь
> Уменьшите шаг и проверьте масштаб признаков.

### Чем стохастический градиентный спуск лучше полного на больших данных?
- [ ] Он точнее вычисляет градиент
- [x] Шаг дешевле в n/b раз, и за то же время делается гораздо больше шагов
- [ ] Он всегда находит глобальный минимум
- [ ] Ему не нужен learning rate
> Оценка градиента по мини-батчу несмещённая, хотя и шумная.

### Что выведет код?
```python
f = lambda w: (w - 3) ** 2
w, lr = 0.0, 0.25
for _ in range(3):
    w -= lr * 2 * (w - 3)
print(w, f(w))
```
- [x] `2.625 0.140625`
- [ ] `3.0 0.0`
- [ ] `1.5 2.25`
- [ ] `2.25 0.5625`
> Каждый шаг сокращает расстояние до минимума вдвое: 0 → 1.5 → 2.25 → 2.625, f = 0.375² = 0.140625.

## Вопросы на собеседовании

### Что такое градиент и почему градиентный спуск работает?
Градиент — вектор частных производных; он показывает направление наискорейшего роста функции, а по формуле Тейлора f(w − η∇f) ≈ f(w) − η‖∇f‖², то есть при достаточно малом шаге значение уменьшается. Повторяя шаги, приходим в точку, где градиент ноль. Для выпуклых функций это глобальный минимум, для невыпуклых — локальный минимум или седловая точка. Скорость зависит от шага и обусловленности задачи.

### Чем SGD отличается от полного градиентного спуска?
Полный спуск считает градиент по всей выборке — точно, но один шаг стоит O(nd). SGD оценивает градиент по одному объекту или мини-батчу — оценка несмещённая, но шумная, а шаг дешёвый. На больших данных SGD делает намного больше обновлений за то же время и быстрее приходит к хорошему решению; для точной сходимости шаг уменьшают со временем. Мини-батчи эффективно используют векторизацию и GPU.

### Как выбрать learning rate?
Начать со стандартного значения для оптимизатора (для Adam 1e-3) и посмотреть на кривую потерь: растёт или колеблется — уменьшить, падает очень медленно — увеличить. Быстрый способ — перебор по логарифмической сетке на коротком обучении (LR range test). Дальше — расписание: warmup в начале, затем уменьшение (ступенчатое, косинусное). Для классического градиентного спуска на квадратичной функции шаг должен быть меньше 2/λ_max гессиана.

### Что такое выпуклая функция и почему это важно?
Функция, у которой отрезок между любыми двумя точками графика лежит не ниже графика; для дважды дифференцируемых — гессиан положительно полуопределён. Важно, потому что у выпуклой функции любой локальный минимум глобальный, и градиентные методы гарантированно к нему сходятся. MSE и logloss линейных моделей выпуклы, поэтому их обучение предсказуемо; потери нейросетей невыпуклы, и там результат зависит от инициализации и оптимизатора.
