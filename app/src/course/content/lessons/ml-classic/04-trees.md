### Как устроено дерево

Решающее дерево — последовательность вопросов вида «xⱼ ≤ t?». Каждый внутренний узел делит объекты на две части по одному признаку и порогу, лист содержит ответ: самый частый класс (или доли классов) для классификации, среднее для регрессии. Предсказание — спуск от корня к листу, O(глубина).

Дерево разбивает пространство признаков на прямоугольные области со сторонами, параллельными осям, и в каждой области отвечает константой.

Сильные стороны: понятная логика, не нужно масштабирование признаков (важен только порядок значений), естественно ловит нелинейности и взаимодействия признаков. Слабые: одиночное дерево сильно переобучается и неустойчиво — небольшое изменение данных меняет структуру дерева.

### Жадное построение

Найти оптимальное дерево — NP-трудная задача, поэтому его строят жадно, сверху вниз:

1. В текущем узле перебрать все признаки и все пороги.
2. Для каждого разбиения посчитать, насколько уменьшится «неоднородность» (impurity) объектов.
3. Выбрать лучшее разбиение и рекурсивно повторить для двух детей.
4. Остановиться по критерию и записать в лист ответ.

Качество разбиения узла R на левую часть L и правую часть R':

```text
Gain = H(R) − (|L| / |R|)·H(L) − (|R'| / |R|)·H(R')
```

Выбираем разбиение с максимальным Gain — то есть с минимальной взвешенной неоднородностью детей.

### Критерии неоднородности

Пусть pₖ — доля класса k среди объектов узла.

- **Джини**: H = Σ pₖ·(1 − pₖ) = 1 − Σ pₖ². Вероятность ошибиться, если отвечать случайным классом с частотами узла. Для двух классов с долями 0.5 — 0.5, чистый узел — 0.
- **Энтропия**: H = −Σ pₖ·log₂ pₖ. Для 50/50 — 1 бит. Gain по энтропии называют информационным выигрышем.
- **Регрессия — MSE (дисперсия)**: H = (1/|R|)·Σ (yᵢ − ȳ)², ответ в листе — среднее. Для MAE ответ — медиана.

Джини и энтропия почти всегда выбирают одинаковые разбиения; Джини чуть дешевле — без логарифма. Доля ошибок (1 − max pₖ) как критерий хуже: она нечувствительна к улучшениям, которые не меняют большинство в детях.

### Лучший порог за O(n log n)

Для одного признака: отсортировать объекты по значению, а затем идти слева направо, перенося объекты из правой части в левую и обновляя счётчики классов. Проверять разбиение можно только между разными значениями признака.

```python
def best_split_gini(xs, ys, classes):
    order = sorted(range(len(xs)), key=lambda i: xs[i])
    n = len(xs)
    left = {c: 0 for c in classes}
    right = {c: 0 for c in classes}
    for y in ys:
        right[y] += 1
    gini = lambda cnt, m: 1 - sum((v / m) ** 2 for v in cnt.values()) if m else 0.0
    best = (float('inf'), None)
    for pos in range(n - 1):
        i = order[pos]
        left[ys[i]] += 1
        right[ys[i]] -= 1
        if xs[order[pos + 1]] == xs[i]:
            continue                       # нельзя разделить равные значения
        m = pos + 1
        score = m / n * gini(left, m) + (n - m) / n * gini(right, n - m)
        best = min(best, (score, (xs[i] + xs[order[pos + 1]]) / 2))
    return best
```

Итого построение уровня — O(d·n log n) (сортировку можно сделать один раз). В бустингах поверх этого используют **гистограммы**: значения признака заранее разбивают на 255 корзин, и перебор идёт по корзинам, а не по объектам.

### Когда остановиться

Дерево, растущее до чистых листьев, запоминает выборку — ошибка на train ноль. Ограничения (они же гиперпараметры):
- максимальная глубина;
- минимальное число объектов в листе или для разбиения;
- минимальный Gain;
- максимальное число листьев.

**Стрижка** (pruning): вырастить большое дерево, затем удалить поддеревья, которые не улучшают качество на валидации или по штрафу за сложность (cost-complexity pruning в sklearn, параметр `ccp_alpha`).

### Категориальные признаки и пропуски

- Категории можно перебирать разбиением множества значений на две группы; для бинарной классификации достаточно отсортировать категории по доле класса 1 и искать порог в этом порядке. Можно и one-hot, но для категорий с сотнями значений это даёт глубокие и слабые деревья. CatBoost использует для категорий упорядоченные target-статистики.
- Пропуски: в XGBoost и LightGBM для каждого узла выучивается направление по умолчанию — куда отправлять объекты с пропуском. В классическом CART — суррогатные разбиения.

### Важность признаков

- **По уменьшению impurity** (MDI, `feature_importances_` в sklearn): сумма Gain по всем узлам с этим признаком. Быстро, но завышает важность признаков со многими уникальными значениями (id, непрерывные шумовые).
- **Permutation importance**: насколько падает качество на валидации, если перемешать значения признака. Честнее, но дороже.
- **SHAP** — вклад признака в конкретное предсказание, согласованный по теории игр.

### Типичные ошибки

- Масштабировать признаки для деревьев: не вредно, но бесполезно.
- Проверять разбиения между равными значениями признака.
- Не ограничивать глубину одиночного дерева.
- Доверять MDI-важности признаков с большим числом уникальных значений.
- Ожидать, что дерево экстраполирует: за пределами обучающего диапазона оно отвечает константой крайнего листа. Для прогноза растущего тренда это важно.

### Как спрашивают на Яндексе

Деревья — фундамент градиентного бустинга, а бустинг в Яндексе — это CatBoost, собственная библиотека компании. Поэтому вопрос «как строится дерево и как выбирается разбиение» — естественное начало разговора, за которым следуют ансамбли (следующий урок). ## Вопросы на собеседовании

### Как строится решающее дерево?
Жадно сверху вниз: в узле перебираем все признаки и пороги, для каждого разбиения считаем уменьшение неоднородности — Джини или энтропии для классификации, дисперсии для регрессии — и берём лучшее. Рекурсивно повторяем для детей, пока не сработает критерий остановки: глубина, минимальное число объектов в листе, минимальный выигрыш. В лист записываем самый частый класс или долю классов, в регрессии — среднее. Лучший порог по признаку ищется сортировкой и одним проходом с обновлением счётчиков — O(n log n).

### Чем Джини отличается от энтропии?
Это две меры неоднородности узла: 1 − Σ pₖ² и −Σ pₖ log pₖ. Обе равны нулю для чистого узла и максимальны при равных долях классов, форма у них похожая, и на практике они почти всегда выбирают одинаковые разбиения. Джини немного быстрее считать, энтропия чуть сильнее штрафует смешанные узлы. Интерпретации: Джини — вероятность ошибки при случайной разметке по частотам узла, энтропия — количество информации в битах.

### Почему одиночное дерево переобучается и что с этим делать?
Дерево может разбивать пространство до отдельных объектов и выучить шум; к тому же у него высокий разброс — небольшие изменения данных меняют верхние разбиения и всё дерево. Лечат ограничениями (глубина, размер листа), стрижкой по валидации, а главное — ансамблями: случайный лес усредняет много глубоких деревьев и снижает разброс, бустинг складывает много неглубоких деревьев и снижает смещение.

### Как дерево работает с пропусками и категориальными признаками?
Для пропусков в современных бустингах в каждом узле выучивается направление по умолчанию: пробуют отправить пропуски влево и вправо и выбирают лучший вариант; в классическом CART используются суррогатные разбиения по коррелированным признакам. Категории можно закодировать one-hot, упорядочить по среднему таргету (для бинарной задачи это даёт оптимальное разбиение на две группы) или использовать target-статистики без утечки, как в CatBoost.
