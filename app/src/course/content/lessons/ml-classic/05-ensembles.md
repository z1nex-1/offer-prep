### Зачем объединять модели

Возьмём M моделей с одинаковой ошибкой и усредним их ответы. Если их ошибки независимы, дисперсия среднего в M раз меньше. Если модели коррелированы с коэффициентом ρ, дисперсия среднего

```text
ρ·σ² + (1 − ρ)·σ² / M
```

— первое слагаемое не уходит при любом M. Отсюда два рецепта: модели должны быть **сильными** (малая ошибка каждой) и **разными** (малая корреляция). Бэггинг и случайный лес делают деревья разными, бустинг — строит модели, которые исправляют ошибки друг друга.

### Бутстрэп и бэггинг

**Бутстрэп** — выборка размера n **с возвращением** из исходных n объектов. В неё попадает около 63.2 % уникальных объектов: вероятность, что объект ни разу не выбран, (1 − 1/n)ⁿ → 1/e ≈ 0.368.

**Бэггинг** (bootstrap aggregating): обучить M моделей на M бутстрэп-выборках и усреднить (регрессия) или устроить голосование (классификация). Уменьшает **разброс**, почти не меняя смещение, поэтому базовые модели берут с низким смещением и высоким разбросом — глубокие деревья.

### Случайный лес

Бэггинг над деревьями даёт коррелированные деревья: сильный признак стоит в корне у всех. **Случайный лес** добавляет случайность: в каждом узле лучший признак ищется только среди случайного подмножества из m признаков. Стандарт — m ≈ √d для классификации и d/3 для регрессии.

- Деревья растут глубокими, почти до чистых листьев.
- Добавление деревьев не приводит к переобучению: качество выходит на плато. Больше деревьев — только дольше.
- Деревья обучаются независимо — параллельно.
- **Out-of-bag оценка**: каждый объект не попал примерно в 37 % бутстрэп-выборок; предсказание этих деревьев на нём — честная оценка качества без отдельной валидации.

### Градиентный бустинг: идея

Бустинг строит модели **последовательно**, каждая следующая исправляет ошибки суммы предыдущих:

```text
a_M(x) = b₀(x) + η·b₁(x) + η·b₂(x) + … + η·b_M(x)
```

Для MSE это выглядит так: посчитать остатки rᵢ = yᵢ − a(xᵢ), обучить новое дерево предсказывать остатки, прибавить его с маленьким коэффициентом η.

В общем виде — **градиентный спуск в пространстве функций**. Хотим уменьшить Σ L(yᵢ, a(xᵢ)). Если бы мы могли менять предсказания aᵢ произвольно, мы бы шагнули по антиградиенту: gᵢ = −∂L/∂aᵢ. Новое дерево обучается приближать вектор антиградиентов (по MSE), и его ответы — «шаг» в нужную сторону. Для MSE антиградиент — это остаток (с точностью до множителя 2), для logloss — yᵢ − pᵢ.

```python
def boost(X, y, rounds, lr, fit_tree):
    base = sum(y) / len(y)
    pred = [base] * len(y)
    trees = []
    for _ in range(rounds):
        residual = [yi - pi for yi, pi in zip(y, pred)]     # антиградиент MSE
        tree = fit_tree(X, residual)
        trees.append(tree)
        pred = [pi + lr * tree(xi) for pi, xi in zip(pred, X)]
    return base, trees
```

### Гиперпараметры бустинга

- **Learning rate η** (0.01–0.3): маленький шаг — нужно больше деревьев, но качество обычно лучше.
- **Число деревьев**: бустинг, в отличие от леса, **переобучается** при слишком большом числе деревьев. Число выбирают **ранней остановкой** по валидации.
- **Глубина** — 3–8, деревья неглубокие: бустинг уменьшает смещение, а сложность набирается суммой.
- Регуляризация: минимальный размер листа, L2 на значения листьев, subsample (стохастический бустинг: каждое дерево на случайной доле объектов), colsample (доля признаков).

### Бэггинг против бустинга

| | Случайный лес | Градиентный бустинг |
|---|---|---|
| Как строятся модели | Независимо, параллельно | Последовательно |
| Базовые деревья | Глубокие | Неглубокие |
| Что уменьшает | Разброс | Смещение |
| Переобучение по числу деревьев | Нет | Да, нужна ранняя остановка |
| Настройка | Почти из коробки | Чувствителен к гиперпараметрам |
| Качество на табличных данных | Хорошее | Обычно лучшее |

### CatBoost, XGBoost, LightGBM

- **XGBoost** — второй порядок (градиент и гессиан) при выборе разбиений и значений листьев, регуляризация листьев, обработка пропусков направлением по умолчанию.
- **LightGBM** — гистограммы признаков и рост дерева по листьям (leaf-wise): расщепляется лист с максимальным выигрышем, а не весь уровень. Быстро, но легче переобучается на малых данных.
- **CatBoost** (Яндекс) — **симметричные деревья** (на одном уровне во всех узлах одинаковое разбиение: быстрое применение, меньше переобучения), **упорядоченный бустинг** против сдвига предсказаний и **упорядоченные target-статистики** для категориальных признаков без утечки. Сильные настройки по умолчанию.

### Стекинг и блендинг

**Стекинг**: несколько разных моделей первого уровня, их out-of-fold предсказания — признаки для метамодели (часто линейной). Out-of-fold обязательно: предсказания на объектах, на которых модель обучалась, переобучены, и метамодель научится им слишком доверять. **Блендинг** — то же на отдельной отложенной части. Стекинг популярен на соревнованиях, в продакшене его сложность не всегда окупается.

### Типичные ошибки

- «Больше деревьев в бустинге — всегда лучше»: нет, нужна ранняя остановка.
- Глубокие деревья в бустинге и неглубокие в случайном лесе — наоборот.
- Стекинг на предсказаниях train, а не out-of-fold.
- Сравнивать модели без одинаковой схемы валидации.
- Считать, что бустинг «усредняет» деревья: он их **складывает**, каждое исправляет предыдущие.

### Как спрашивают на Яндексе

Градиентный бустинг — главный инструмент на табличных данных, и CatBoost сделан в Яндексе, так что вопрос «как работает градиентный бустинг» почти обязателен для ML-стажёра. Ожидаемый ответ: антиградиент функции потерь, обучение дерева на него, learning rate, ранняя остановка, отличие от случайного леса через bias–variance. Бонус — объяснить, чем особенный CatBoost: симметричные деревья и работа с категориями без утечки.

- [ ] Чтобы ускорить только обучение
- [x] Чтобы деревья были менее коррелированы, и усреднение сильнее уменьшало разброс

### Что выведет код?
```python
y = [1.0, 3.0, 5.0]
pred = [sum(y) / 3] * 3
lr = 0.5
for _ in range(2):
    pred = [p + lr * (t - p) for p, t in zip(pred, y)]
print([round(p, 2) for p in pred])
```
- [ ] `[1.75, 3.0, 4.25]`
- [ ] `[1.0, 3.0, 5.0]`
- [ ] `[2.0, 3.0, 4.0]`
- [x] `[1.5, 3.0, 4.5]`
> Идеальное «дерево», точно предсказывающее остатки, при η = 0.5 за шаг сокращает остаток вдвое: −2 → −1 → −0.5.

## Вопросы на собеседовании

### Как работает градиентный бустинг?
Начинаем с константы. На каждом шаге считаем антиградиент функции потерь по текущим предсказаниям на объектах обучения — для MSE это остатки, для logloss y − p. Обучаем неглубокое дерево приближать эти значения, прибавляем его к ансамблю с маленьким коэффициентом learning rate (листья можно дополнительно подстроить под исходную потерю). Повторяем, пока качество на валидации растёт, — ранняя остановка. Это градиентный спуск в пространстве функций, где шаг — дерево. Основные гиперпараметры: learning rate, число деревьев, глубина, регуляризация листьев, subsample.

### Чем случайный лес отличается от градиентного бустинга?
Лес строит глубокие деревья независимо на бутстрэп-выборках со случайными подмножествами признаков и усредняет — снижает разброс, не переобучается от числа деревьев, хорошо параллелится, мало настраивается. Бустинг строит неглубокие деревья последовательно, каждое исправляет ошибки суммы, — снижает смещение, требует настройки learning rate и ранней остановки, обучается последовательно, но обычно точнее на табличных данных.

### Почему бэггинг уменьшает разброс?
Модели, обученные на разных бутстрэп-выборках, ошибаются по-разному; усреднение взаимно гасит часть этих случайных ошибок. Для M моделей с дисперсией σ² и попарной корреляцией ρ дисперсия среднего равна ρσ² + (1 − ρ)σ²/M. Смещение среднего равно смещению отдельной модели, поэтому бэггинг берут для моделей с низким смещением и высоким разбросом — глубоких деревьев — и стараются уменьшить корреляцию между ними.

### Чем CatBoost отличается от XGBoost и LightGBM?
CatBoost использует симметричные (oblivious) деревья — одно разбиение на весь уровень: быстрое применение и встроенная регуляризация. Категориальные признаки кодирует упорядоченными target-статистиками: для объекта используются только объекты, стоящие раньше в случайной перестановке, поэтому нет утечки таргета. Упорядоченный бустинг борется со смещением градиентов. XGBoost — второй порядок и регуляризация листьев, LightGBM — гистограммы и рост по листьям ради скорости.
