### Линейный классификатор

Для двух классов (y ∈ {−1, +1} или {0, 1}) линейная модель предсказывает знак: a(x) = sign(⟨w, x⟩ + w₀). Граница между классами — гиперплоскость ⟨w, x⟩ + w₀ = 0; вектор w перпендикулярен ей.

**Отступ** (margin) объекта при y ∈ {−1, +1}: Mᵢ = yᵢ·(⟨w, xᵢ⟩ + w₀). Отступ положителен, если объект классифицирован верно, и тем больше, чем дальше объект от границы в правильную сторону. Все линейные классификаторы минимизируют какую-то убывающую функцию отступа:

| Модель | Потеря от отступа M |
|---|---|
| Идеал (доля ошибок) | [M < 0] — не дифференцируема |
| Логистическая регрессия | log(1 + e^(−M)) |
| SVM | max(0, 1 − M) — hinge |
| Перцептрон | max(0, −M) |

Все гладкие варианты — «верхние оценки» для доли ошибок, которые можно оптимизировать градиентом.

### Логистическая регрессия

Хотим не только класс, но и вероятность. Линейная комбинация z = ⟨w, x⟩ + w₀ принимает любые значения, поэтому её пропускают через **сигмоиду**:

```text
p(y = 1 | x) = σ(z) = 1 / (1 + e^(−z))
```

σ(0) = 0.5, σ(z) → 1 при z → +∞, σ(−z) = 1 − σ(z). Величина z — это **логарифм шансов** (log-odds): log(p / (1 − p)) = z. То есть логистическая регрессия — линейная модель для логарифма шансов.

### Откуда logloss

Метод максимального правдоподобия: подберём w так, чтобы наблюдаемые ответы были максимально вероятны. Для объекта с yᵢ ∈ {0, 1} вероятность ответа — pᵢ^yᵢ · (1 − pᵢ)^(1 − yᵢ). Объекты независимы — вероятности перемножаются, логарифм превращает произведение в сумму, а максимум — в минимум минус логарифма:

```text
−log L(w) = −Σ [ yᵢ·log pᵢ + (1 − yᵢ)·log(1 − pᵢ) ]
```

Это и есть logloss (бинарная кросс-энтропия), с точностью до деления на n. В форме с отступом (y ∈ {−1, +1}) та же функция — Σ log(1 + e^(−Mᵢ)).

### Градиент — короткая формула

Производная сигмоиды σ'(z) = σ(z)·(1 − σ(z)). Подставив в logloss, получаем удивительно простой градиент:

```text
∂/∂w [ −y·log p − (1 − y)·log(1 − p) ] = (p − y) · x
```

Ошибка предсказания, умноженная на признаки, — та же форма, что у линейной регрессии с MSE. Шаг градиентного спуска по всей выборке:

```python
from math import exp

def sigmoid(z):
    return 1 / (1 + exp(-z)) if z >= 0 else exp(z) / (1 + exp(z))   # без переполнения exp

def logreg_step(X, y, w, lr):
    n, d = len(X), len(w)
    grad = [0.0] * d
    for xi, yi in zip(X, y):
        p = sigmoid(sum(a * b for a, b in zip(w, xi)))
        for j in range(d):
            grad[j] += (p - yi) * xi[j] / n
    return [wj - lr * g for wj, g in zip(w, grad)]
```

Logloss для логистической регрессии выпуклый, поэтому локальных минимумов нет. Аналитического решения нет — только итеративные методы (градиентный спуск, метод Ньютона, L-BFGS в sklearn).

### Линейно разделимые данные и регуляризация

Если классы разделимы гиперплоскостью, logloss можно уменьшать бесконечно, увеличивая ‖w‖: все вероятности стремятся к 0 и 1, веса растут неограниченно. Модель становится сверхуверенной. L2-регуляризация (в sklearn параметр `C` — **обратный** коэффициент: меньше C — сильнее регуляризация) держит веса конечными. Ещё регуляризация нужна при большом числе признаков — как в линейной регрессии.

### SVM: максимальный зазор

Метод опорных векторов ищет разделяющую гиперплоскость с **максимальной шириной зазора** до ближайших объектов. Ширина зазора равна 2 / ‖w‖, поэтому задача:

```text
(1/2)·‖w‖² + C · Σ max(0, 1 − Mᵢ) → min
```

Hinge loss равна нулю для объектов с отступом ≥ 1: они не влияют на решение. Решение определяют только объекты у границы и нарушители — **опорные векторы**.

- SVM не выдаёт вероятности (score — расстояние до гиперплоскости; вероятности получают калибровкой).
- **Ядровой трюк**: заменив скалярное произведение ⟨x, x'⟩ на ядро K(x, x') (полиномиальное, RBF), SVM строит нелинейную границу, не вычисляя признаки явно. Цена — O(n²) памяти и времени, поэтому на миллионах объектов ядровые SVM не используют.

### Много классов

- **One-vs-rest**: K бинарных классификаторов «класс k против остальных», ответ — класс с наибольшим score.
- **One-vs-one**: классификатор на каждую пару, K(K − 1)/2 моделей, голосование.
- **Softmax (мультиномиальная логистическая регрессия)**: K линейных функций zₖ = ⟨wₖ, x⟩ превращаются в вероятности

```text
p(k | x) = e^(zₖ) / Σⱼ e^(zⱼ)
```

Потеря — кросс-энтропия −log p(верный класс | x), градиент по wₖ равен (pₖ − [y = k])·x. При вычислении вычитают max zⱼ из всех zₖ: результат тот же, а exp не переполняется.

### Калибровка вероятностей

Модель откалибрована, если среди объектов с предсказанием 0.8 ровно 80 % положительных. Логистическая регрессия, обученная на logloss, обычно калибрована неплохо; бустинг, SVM, наивный Байес и модели после пересэмплирования — хуже. Проверка — калибровочная кривая (reliability diagram), исправление — **Platt scaling** (логистическая регрессия поверх score) или **изотоническая регрессия** на отдельной выборке. Калибровка нужна, когда вероятность используется как число: ставки в рекламе, ожидаемый доход, пороги по риску.

### Типичные ошибки

- Считать, что логистическая регрессия — регрессия: это классификатор, регрессия — для логарифма шансов.
- Вычислять сигмоиду как `1 / (1 + exp(-z))` при z = −1000: `exp(1000)` переполняется. Разбирайте знак z.
- Считать softmax без вычитания максимума.
- Путать C в sklearn с λ: C — обратная сила регуляризации.
- Использовать score SVM как вероятность.
- Говорить, что логистическая регрессия строит нелинейную границу: граница линейная в пространстве признаков.

### Как спрашивают на Яндексе

Логистическая регрессия — вторая по частоте модель для разговора «на примере алгоритма» после линейной регрессии. Классическая цепочка: почему не MSE для классификации → откуда берётся logloss → выведите градиент → что будет на линейно разделимых данных → как обобщить на много классов → откалиброваны ли вероятности. Вывод градиента (p − y)·x стоит уметь написать за минуту: это же кусок любой нейросети-классификатора.

### Что выведет код?
```python
from math import exp
z = [2.0, 1.0, 0.0]
m = max(z)
e = [exp(v - m) for v in z]
p = [v / sum(e) for v in e]
print(round(p[0], 3), round(sum(p), 3))
```

- [ ] `0.665 0.999`

## Вопросы на собеседовании

### Почему для классификации не используют MSE с линейной моделью?
Линейная модель выдаёт любые числа, а не вероятности; MSE штрафует даже верно классифицированные объекты, далёкие от границы (score 5 при y = 1 даёт ошибку 16), и граница сдвигается из-за них. Вероятностно MSE соответствует нормальному шуму, а для бинарного ответа естественно распределение Бернулли — его правдоподобие даёт logloss. К тому же MSE поверх сигмоиды невыпукла, а logloss для логистической регрессии выпуклый.

### Выведите градиент логистической регрессии.
p = σ(z), z = ⟨w, x⟩, потеря ℓ = −y log p − (1 − y) log(1 − p). ∂ℓ/∂p = −y/p + (1 − y)/(1 − p) = (p − y) / (p(1 − p)). σ'(z) = p(1 − p), ∂z/∂w = x. По цепному правилу ∂ℓ/∂w = (p − y)/(p(1 − p)) · p(1 − p) · x = (p − y)·x. По выборке — среднее этих векторов плюс градиент регуляризации 2λw.

### Чем логистическая регрессия отличается от SVM?
Обе — линейные классификаторы, разница в функции потерь от отступа: логистическая — log(1 + e^(−M)), гладкая, штрафует все объекты и даёт откалиброванные вероятности; SVM — hinge max(0, 1 − M), решение зависит только от опорных векторов, максимизирует зазор, вероятностей не даёт. У SVM есть ядровой трюк для нелинейных границ, но он плохо масштабируется по числу объектов. На практике на больших разреженных данных обе работают похоже.

### Как сделать многоклассовую классификацию из бинарной?
One-vs-rest — K классификаторов «класс против остальных», выбрать максимальный score; one-vs-one — K(K − 1)/2 классификаторов на пары и голосование; или напрямую мультиномиальная модель: K линейных функций, softmax в вероятности, кросс-энтропия в потерю. Softmax согласованно даёт вероятности, сумма которых равна 1, — это стандарт в нейросетях.

### Что такое калибровка и когда она нужна?
Модель откалибрована, если её вероятности совпадают с наблюдаемыми частотами: из объектов с предсказанием 0.3 положительных около 30 %. Нужна, когда вероятность используется как число — аукционы в рекламе, расчёт ожидаемой выручки, пороги по риску. Проверяют калибровочной кривой и logloss или Brier score; исправляют Platt scaling или изотонической регрессией на отложенной выборке. Ранжирующие метрики вроде ROC-AUC от калибровки не зависят.
