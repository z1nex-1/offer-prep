Сторонние библиотеки на контесте запрещены, но стандартная библиотека Python закрывает почти всё, что нужно для задач стажёрского уровня. На собеседовании знание этих модулей — плюс, но будьте готовы объяснить, как они устроены и какая у них сложность.

### collections.deque — двусторонняя очередь

```python
from collections import deque

q = deque()
q.append(1)         # в конец
q.appendleft(0)     # в начало
q.pop()             # из конца
q.popleft()         # из начала
```

Все четыре операции — **O(1)**. `deque` реализован как двусвязный список блоков. Обращение по индексу `q[i]` — O(n) в середине, O(1) у краёв.

Где нужен: очередь в BFS, скользящее окно с минимумом (монотонная очередь), моделирование очередей. `deque(maxlen=k)` хранит только последние k элементов — удобно для «последних k событий».

`q.rotate(k)` — циклический сдвиг на k.

### Counter и defaultdict

Разобраны в уроке про словари. Коротко:

```python
from collections import Counter, defaultdict

cnt = Counter(words)            # частоты
cnt.most_common(3)              # три самых частых
Counter(a) == Counter(b)        # одинаковые мультимножества
g = defaultdict(list)           # граф списками смежности
```

`most_common(k)` работает за O(n log k) через кучу, без аргумента — полной сортировкой.

### heapq — куча (очередь с приоритетом)

`heapq` превращает обычный список в **минимальную** двоичную кучу:

```python
import heapq

h = []
heapq.heappush(h, 5)
heapq.heappush(h, 1)
heapq.heappush(h, 3)
print(h[0])               # 1 — минимум, O(1)
print(heapq.heappop(h))   # 1, O(log n)
heapq.heapify(a)          # список в кучу за O(n)
heapq.nsmallest(3, a)     # три наименьших
heapq.nlargest(3, a, key=len)
```

Максимальной кучи нет — кладут числа с обратным знаком: `heappush(h, -x)` и `-heappop(h)`.

В кучу можно класть кортежи: они сравниваются по первому элементу, при равенстве по второму. Классика — алгоритм Дейкстры: `heappush(h, (dist, vertex))`. Если второй элемент — несравнимый объект, добавляйте счётчик между ними: `(priority, counter, obj)`.

Где нужна: k наименьших/наибольших, слияние k отсортированных списков, медиана потока, расписания («освобождающийся раньше всех сервер»), Дейкстра. Подробно — в модуле «Куча».

### bisect — бинарный поиск в отсортированном списке

```python
import bisect

a = [1, 3, 3, 3, 7]
bisect.bisect_left(a, 3)    # 1 — первая позиция, куда можно вставить 3, не нарушив порядок
bisect.bisect_right(a, 3)   # 4 — позиция после последней тройки
bisect.bisect_left(a, 4)    # 4
bisect.insort(a, 5)         # вставка с сохранением порядка: поиск O(log n), сдвиг O(n)
```

Полезные следствия:

- количество элементов, равных x: `bisect_right(a, x) - bisect_left(a, x)`;
- количество элементов меньше x: `bisect_left(a, x)`;
- количество в отрезке [l, r]: `bisect_right(a, r) - bisect_left(a, l)`;
- есть ли x: `i = bisect_left(a, x); i < len(a) and a[i] == x`.

С Python 3.10 у функций есть параметр `key`. На собеседовании бинпоиск чаще просят написать руками — это в модуле «Бинарный поиск».

### itertools — комбинаторика и итераторы

```python
from itertools import permutations, combinations, product, accumulate, groupby, combinations_with_replacement

list(permutations([1, 2, 3]))        # 6 перестановок
list(combinations("abcd", 2))        # 6 пар без повторов, порядок не важен
list(product([0, 1], repeat=3))      # 8 двоичных строк длины 3
list(accumulate([1, 2, 3, 4]))       # [1, 3, 6, 10] — префиксные суммы
list(accumulate(a, max))             # префиксные максимумы
[(k, len(list(g))) for k, g in groupby("aaabcc")]   # [('a', 3), ('b', 1), ('c', 2)] — серии подряд
```

- `permutations(a)` — n! вариантов: годится при n до ~9–10.
- `product(range(2), repeat=n)` — 2ⁿ вариантов: полный перебор подмножеств при n до ~20.
- `groupby` группирует только **соседние** равные элементы — готовое решение RLE-подобных задач. Для группировки по всему списку сначала отсортируйте.
- `accumulate(a, initial=0)` добавляет ведущий ноль — удобно для префиксных сумм.

### functools

```python
from functools import lru_cache, cmp_to_key, reduce

@lru_cache(maxsize=None)
def fib(n):
    return n if n < 2 else fib(n - 1) + fib(n - 2)
```

- `lru_cache` (или `cache` с Python 3.9) запоминает результаты по аргументам — мемоизация в одну строку. Аргументы должны быть хешируемыми. Глубина рекурсии при этом не уменьшается.
- `cmp_to_key` — сортировка по функции сравнения, когда ключ сформулировать трудно. Классика — «составить наибольшее число из чисел»:

```python
from functools import cmp_to_key
nums = ["3", "30", "34", "5", "9"]
nums.sort(key=cmp_to_key(lambda a, b: -1 if a + b > b + a else (1 if a + b < b + a else 0)))
print("".join(nums))    # 9534330
```

### math

```python
import math

math.gcd(12, 18)        # 6; с 3.9 принимает любое число аргументов
math.lcm(4, 6)          # 12 (Python 3.9+)
math.isqrt(10)          # 3 — целая часть корня без погрешности
math.ceil(7 / 2)        # 4
math.comb(5, 2)         # 10 — сочетания
math.perm(5, 2)         # 20 — размещения
math.factorial(10)
math.inf, -math.inf     # бесконечности для инициализации минимума и максимума
math.hypot(3, 4)        # 5.0 — длина вектора
math.log2(1024)         # 10.0
```

### Другие полезности

- `sorted(..., key=...)`, `min/max(..., key=...)`, `sum`, `any`, `all`, `zip`, `enumerate`, `reversed` — встроенные функции.
- `str.maketrans` / `str.translate` — быстрые замены символов.
- `re` — регулярные выражения для разбора сложных форматов.
- `datetime` — даты и дни недели (задачи про расписания).
- `decimal.Decimal`, `fractions.Fraction` — точная арифметика дробей.
- `string.ascii_lowercase` — алфавит.
- `sys.maxsize` — не максимальный `int` (его нет), а максимальный размер контейнера; для «бесконечности» берите `math.inf` или `float("inf")`.

## Самопроверка

### Какая сложность `popleft()` у `collections.deque`?
- [ ] O(n)
- [x] O(1)
- [ ] O(log n)
- [ ] Зависит от размера блока
> deque устроен как связный список блоков, операции на обоих концах — O(1). У списка `pop(0)` — O(n).

### Что выведет код?
```python
import heapq
h = [5, 1, 8, 3]
heapq.heapify(h)
print(heapq.heappop(h), heapq.heappop(h))
```
- [ ] `8 5`
- [x] `1 3`
- [ ] `5 1`
- [ ] `1 5`
> `heapq` — минимальная куча: `heappop` каждый раз достаёт наименьший элемент.

### Что выведет код?
```python
import bisect
a = [1, 2, 2, 2, 5]
print(bisect.bisect_left(a, 2), bisect.bisect_right(a, 2))
```
- [ ] `1 3`
- [x] `1 4`
- [ ] `2 4`
- [ ] `0 5`
> `bisect_left` — позиция первой двойки, `bisect_right` — позиция сразу после последней. Их разность — количество двоек.

### Как получить максимальную кучу с помощью heapq?
- [ ] `heapq.heappush(h, x, reverse=True)`
- [x] Хранить числа с обратным знаком: `heappush(h, -x)`, доставать `-heappop(h)`
- [ ] Использовать `heapq.maxheap`
- [ ] Отсортировать список по убыванию после каждой вставки
> В `heapq` только минимальная куча. Смена знака превращает минимум в максимум.

### Что выведет код?
```python
from itertools import groupby
print([k + str(len(list(g))) for k, g in groupby("aabccca")])
```
- [ ] `['a3', 'b1', 'c3']`
- [x] `['a2', 'b1', 'c3', 'a1']`
- [ ] `['a2', 'b1', 'c3']`
- [ ] Ошибку
> `groupby` группирует только соседние равные элементы, поэтому последняя `a` — отдельная группа.

### Сколько элементов вернёт `itertools.combinations(range(5), 2)`?
- [ ] 20
- [x] 10
- [ ] 25
- [ ] 5
> Сочетания из 5 по 2 без учёта порядка: 5·4/2 = 10. Упорядоченных пар (`permutations`) было бы 20.

### Что выведет код?
```python
from itertools import accumulate
print(list(accumulate([3, 1, 4, 1], max)))
```
- [ ] `[3, 4, 8, 9]`
- [x] `[3, 3, 4, 4]`
- [ ] `[4]`
- [ ] `[3, 1, 4, 1]`
> С функцией `max` `accumulate` считает префиксные максимумы.

## Вопросы на собеседовании

### Почему для очереди в BFS используют deque, а не list?
Очередь снимает элементы с начала. У `list` это `pop(0)` — O(n) из-за сдвига всех элементов, и BFS становится квадратичным. У `deque` `popleft()` — O(1). Альтернатива без `deque` — список и индекс головы, который двигается вперёд.

### Как устроен heapq и какая сложность операций?
Двоичная куча, хранящаяся в обычном списке: дети элемента i лежат по индексам 2i+1 и 2i+2, родитель всегда не больше детей, поэтому минимум — в `h[0]`. `heappush` добавляет в конец и «просеивает вверх», `heappop` ставит последний элемент в корень и «просеивает вниз» — обе O(log n). `heapify` — O(n). Посмотреть минимум — O(1).

### Что делает lru_cache и какие у него ограничения?
Декоратор хранит словарь «аргументы → результат» и при повторном вызове возвращает сохранённое значение. Превращает рекурсию с перекрывающимися подзадачами в динамическое программирование сверху вниз. Ограничения: аргументы должны быть хешируемыми (списки не подойдут — нужны кортежи), память растёт с числом разных аргументов (если `maxsize=None`), глубина рекурсии остаётся прежней, а у методов класса кэш держит ссылку на `self`.
