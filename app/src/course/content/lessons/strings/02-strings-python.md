Строки и массивы — первая тема в списке, который Яндекс советует повторить к алгоритмической секции. Задачи со строками на секции обычно простые по идее, а проверяют другое: знаете ли вы стоимость операций, не забыли ли крайние случаи и умеете ли написать компактный код без ошибок.

### Как устроены строки

Строка в Python — **неизменяемая** последовательность символов Unicode. Отсюда стоимость операций:

| Операция | Стоимость |
|---|---|
| `s[i]`, `len(s)` | O(1) |
| `s[l:r]` — срез | O(r − l): создаётся новая строка |
| `a + b` | O(len(a) + len(b)) |
| `x in s`, `s.find(x)`, `s.count(x)` | O(n·m) в худшем случае, на практике быстро |
| `s.replace`, `s.split`, `s.lower`, `s[::-1]` | O(n) |
| `''.join(parts)` | O(суммарной длины) |
| `s == t` | O(min(len)) — до первого различия |

Главное следствие: **строку нельзя изменить на месте**. `s[0] = 'x'` — `TypeError`. Чтобы менять символы, переведите строку в список: `chars = list(s)`, а в конце `''.join(chars)`.

**Сборка строки в цикле.** `res += ch` в цикле в худшем случае копирует всю строку каждый раз — O(n²). CPython иногда оптимизирует это на месте, но полагаться на оптимизацию нельзя. Правильно — накапливать части в списке и один раз вызвать `''.join(parts)`. На собеседовании про это часто спрашивают отдельно.

### Символы и коды

```python
ord('a'), chr(98)          # 97, 'b'
ord(ch) - ord('a')         # номер строчной латинской буквы 0..25
ch.isdigit(), ch.isalpha(), ch.isalnum(), ch.isspace()
ch.lower(), ch.upper()
```

Массив из 26 счётчиков `[0] * 26` с индексом `ord(ch) - 97` быстрее `Counter`, когда алфавит заранее известен и мал. Для произвольных символов — `Counter` или словарь.

### Частоты и анаграммы

Две строки — **анаграммы**, если состоят из одних и тех же символов в одинаковом количестве.

```python
from collections import Counter

def is_anagram(a, b):
    return len(a) == len(b) and Counter(a) == Counter(b)
```

O(n) против O(n log n) у `sorted(a) == sorted(b)`. **Группировка анаграмм** — словарь, где ключ — «подпись» слова: `''.join(sorted(w))` или кортеж из 26 частот. **Все анаграммы шаблона в тексте** — окно длины |p| со счётчиком совпавших частот: при сдвиге одна буква входит, одна выходит (урок о скользящем окне).

Родственные задачи: первый неповторяющийся символ (два прохода: частоты, потом поиск первого с частотой 1), можно ли собрать слово из букв журнала (`Counter(word) <= Counter(letters)` в Python 3.10+ или проверка каждой частоты), «камни и драгоценности» (множество и проход).

### Сжатие серий (RLE)

`AAABCCDDDD` → `A3BC2D4`. Один проход с указателем на начало серии:

```python
def rle(s):
    parts = []
    i = 0
    while i < len(s):
        j = i
        while j < len(s) and s[j] == s[i]:
            j += 1
        parts.append(s[i] + (str(j - i) if j - i > 1 else ''))
        i = j
    return ''.join(parts)
```

Вложенный `while` не делает решение квадратичным: j только растёт, и каждый символ просматривается один раз. Типичная ошибка при варианте «с одним счётчиком» — забыть вывести последнюю серию после цикла. Короткий вариант — `itertools.groupby(s)`.

Обратная задача — распаковка `A3BC2` — разбор числа после буквы: копим цифры, пока они идут подряд (число может быть многозначным).

### Сравнение строк и версий

Строки сравниваются **лексикографически** по кодам символов: `'abc' < 'abd'`, `'ab' < 'abc'`, но `'10' < '9'` и `'B' < 'a'` (заглавные буквы идут раньше строчных). Поэтому:

- числа в строках сравнивайте после `int()`;
- «естественная» сортировка (`file2 < file10`) требует разбить строку на куски цифр и не цифр;
- без учёта регистра — `sorted(words, key=str.lower)` или `str.casefold`.

**Сравнение версий** `1.2.10` и `1.2.9` — разбить по точке, перевести компоненты в `int`, убрать нули в конце (`1.0` равно `1`) и сравнить списки: списки в Python тоже сравниваются лексикографически.

### Два указателя на строках

- **Палиндром с игнорированием не-букв**: указатели с двух концов, пропускаем символы, для которых `not ch.isalnum()`, сравниваем `lower()`. O(n) и O(1) памяти, без построения очищенной копии.
- **Палиндром, если можно удалить один символ**: при первом несовпадении проверяем два варианта — без левого или без правого символа.
- **Разворот слов**: `' '.join(reversed(s.split()))` — `split()` без аргумента сам убирает лишние пробелы. Если просят «на месте», в списке символов разворачивают всю строку, а потом каждое слово.
- **Сравнение с backspace** (`ab#c` и `ad#c` равны): идём с конца, считая, сколько символов нужно пропустить.

### split, strip и разбор

```python
'  a  b '.split()        # ['a', 'b'] — любые пробельные символы, пустые куски выброшены
'  a  b '.split(' ')     # ['', '', 'a', '', 'b', ''] — ровно по одному пробелу
'a,b,,c'.split(',')      # ['a', 'b', '', 'c'] — пустое поле сохраняется
line.rstrip('\n')        # убрать только перевод строки, сохранив значимые пробелы
```

`split()` без аргументов — почти всегда то, что нужно для чисел и слов. С явным разделителем — для форматов, где пустые поля значимы (CSV, логи).

### Unicode-подвохи

- `len('é')` может быть 1 или 2 — в зависимости от того, записан символ одной кодовой точкой или буквой с комбинируемым знаком. Нормализация — `unicodedata.normalize('NFC', s)`.
- `'ß'.upper()` — `'SS'`: длина строки при смене регистра может измениться.
- `'١٢'.isdigit()` — `True` (арабско-индийские цифры), и `int('١٢')` — 12. Для проверки «только ASCII-цифры» используйте `s.isascii() and s.isdigit()` или регулярное выражение `[0-9]+`.
- Строки из файла Windows заканчиваются на `\r\n` — `strip()` убирает и `\r`.

На контесте входные данные обычно ASCII, но на собеседовании знание этих деталей выделяет кандидата, если разговор зашёл о тексте пользователей.

### Типичные ошибки

- `res += ch` в цикле вместо `''.join` — квадратичная сборка строки.
- Попытка изменить строку по индексу: `s[i] = 'x'` — `TypeError`.
- Сравнение чисел или версий как строк: `'10' < '9'`.
- `split(' ')` вместо `split()` при нескольких пробелах подряд.
- Забытая последняя серия в сжатии строки.
- Срез в цикле `s[i:]` — каждый раз копия, O(n²) по времени и памяти. Передавайте индексы.
- Регистр и пробелы в задаче о палиндроме: `"A man, a plan"` — сначала уточните, что учитывать.

## Самопроверка

### Что выведет код?
```python
print('10' < '9', 'B' < 'a', 'ab' < 'abc')
```
- [ ] `False False True`
- [x] `True True True`
- [ ] `False True True`
- [ ] `True False False`
> Строки сравниваются по кодам символов: `'1'` меньше `'9'`, заглавные буквы идут раньше строчных, а префикс меньше более длинной строки.

### Почему сборка строки через `res += ch` в цикле может работать за O(n²)?
- [ ] Из-за сборщика мусора
- [x] Строки неизменяемы, и каждое сложение может создавать новую строку с копированием
- [ ] `+=` для строк всегда O(n²)
- [ ] Не может: это всегда O(n)
> CPython иногда дописывает на месте, но это деталь реализации. Надёжно — список частей и `''.join`.

### Что выведет код?
```python
print('  a  b '.split(' '))
```
- [ ] `['a', 'b']`
- [x] `['', '', 'a', '', 'b', '']`
- [ ] `['', 'a', 'b', '']`
- [ ] `[' a', ' b ']`
> С явным разделителем каждый пробел режет строку, и пустые куски сохраняются. `split()` без аргумента вернул бы `['a', 'b']`.

### Как за O(n) проверить, что две строки — анаграммы?
- [ ] `sorted(a) == sorted(b)`
- [x] Сравнить счётчики символов: `Counter(a) == Counter(b)`
- [ ] `set(a) == set(b)`
- [ ] `a == b[::-1]`
> Сортировка — O(n log n); множества теряют количество (`aab` и `abb`); разворот проверяет совсем другое.

### Что выведет код?
```python
from itertools import groupby
print(''.join(ch + (str(k) if (k := len(list(g))) > 1 else '') for ch, g in groupby('AAABCCDDDD')))
```
- [ ] `A3B1C2D4`
- [x] `A3BC2D4`
- [ ] `ABCD`
- [ ] `A3BC2D`
> `groupby` выдаёт серии одинаковых символов; длина 1 не выводится.

### Какая версия новее: `1.2.10` или `1.2.9`, и как это проверить в коде?
- [ ] `1.2.9`, сравнением строк
- [x] `1.2.10`, сравнением списков целых компонент
- [ ] Они равны
- [ ] `1.2.9`, сравнением длины
> `'1.2.10' < '1.2.9'` как строки, но `[1, 2, 10] > [1, 2, 9]` как списки чисел.

## Вопросы на собеседовании

### Почему строки в Python неизменяемы и что это даёт?
Неизменяемость позволяет использовать строки как ключи словарей и элементы множеств — их хеш не меняется, его можно закешировать. Строки безопасно разделять между переменными и потоками без копирования, а интерпретатор может переиспользовать одинаковые короткие строки. Цена — любое «изменение» создаёт новую строку, поэтому строку собирают через список и `join`, а посимвольные правки делают в `list`.

### Как найти первый неповторяющийся символ в строке?
Два прохода: сначала посчитать частоты символов (`Counter` или массив на 26 букв), потом пройти строку ещё раз и вернуть первый символ с частотой 1. O(n) времени и O(k) памяти, где k — размер алфавита. Если строка приходит потоком, храните частоты и упорядоченный словарь кандидатов, удаляя символ при второй встрече.
