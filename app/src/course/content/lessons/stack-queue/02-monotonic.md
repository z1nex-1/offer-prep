### Задача: ближайший больший справа

Для каждого дня известна температура. Сколько дней ждать до более тёплого? Наивно — для каждого дня идти вправо: O(n²).

Идея: храним в стеке индексы дней, для которых **ответ ещё не найден**. Их температуры в стеке убывают снизу вверх (иначе верхний уже нашёл бы ответ). Новый день «закрывает» все дни на вершине, которые холоднее его.

```python
def days_to_warmer(t):
    n = len(t)
    ans = [0] * n
    st = []                          # индексы, температуры убывают
    for i in range(n):
        while st and t[st[-1]] < t[i]:
            j = st.pop()
            ans[j] = i - j
        st.append(i)
    return ans
```

Каждый индекс кладётся в стек один раз и снимается не больше одного раза — O(n) суммарно.

### Четыре варианта

| Что ищем для каждого i | Направление прохода | Условие снятия с вершины |
|---|---|---|
| ближайший **больший** справа | слева направо, ответ присваивается снятым | `a[top] < a[i]` |
| ближайший **меньший** справа | слева направо | `a[top] > a[i]` |
| ближайший **больший** слева | слева направо, ответ — вершина после снятий | снимаем, пока `a[top] <= a[i]` |
| ближайший **меньший** слева | слева направо | снимаем, пока `a[top] >= a[i]` |

Для «слева» после всех снятий вершина стека (если он не пуст) и есть ответ для `i`:

```python
def prev_smaller(a):
    res, st = [], []
    for i, x in enumerate(a):
        while st and a[st[-1]] >= x:
            st.pop()
        res.append(st[-1] if st else -1)
        st.append(i)
    return res
```

Строгое или нестрогое неравенство выбирается по условию: нужен строго больший или «не меньший».

### Наибольший прямоугольник в гистограмме

Задача из подборки CodeRun для бэкенд-стажёров. Столбики высотой `h[i]` и шириной 1. Найти прямоугольник максимальной площади.

Для каждого столбика — прямоугольник его высоты, растянутый влево и вправо до первых более низких столбиков. Границы — «ближайший меньший слева» и «ближайший меньший справа». Площадь `h[i] * (right[i] - left[i] - 1)`.

Одним проходом:

```python
def largest_rectangle(h):
    st = []                           # индексы, высоты возрастают
    best = 0
    for i in range(len(h) + 1):
        cur = h[i] if i < len(h) else 0      # фиктивный столбик 0 в конце выталкивает всё
        while st and h[st[-1]] >= cur:
            height = h[st.pop()]
            left = st[-1] if st else -1
            best = max(best, height * (i - left - 1))
        st.append(i)
    return best
```

Когда столбик снимается, `i` — первый справа, кто ниже, а новая вершина — первый слева, кто ниже. O(n).

Родственная задача — **наибольший прямоугольник из единиц в бинарной матрице**: для каждой строки считаем высоты «столбиков из единиц» над ней и запускаем гистограмму. O(n·m).

### Сумма минимумов всех подмассивов

Для каждого элемента — в скольких подмассивах он минимальный: `(i - left[i]) * (right[i] - i)`, где границы — ближайшие меньшие слева и справа (с одной стороны строго, с другой нестрого, чтобы равные элементы не посчитать дважды). Ответ — `sum(a[i] * count[i])`. O(n) вместо O(n²).

### Монотонная очередь: максимум в скользящем окне

Для каждого окна длины k нужен максимум. Держим в деке индексы в порядке возрастания, а значения — **убывающими**. Голова дека — максимум текущего окна.

```python
from collections import deque

def window_max(a, k):
    dq = deque()
    res = []
    for i, x in enumerate(a):
        while dq and a[dq[-1]] <= x:     # меньшие элементы больше никогда не станут максимумом
            dq.pop()
        dq.append(i)
        if dq[0] <= i - k:               # голова вышла из окна
            dq.popleft()
        if i >= k - 1:
            res.append(a[dq[0]])
    return res
```

Почему можно выбросить меньшие элементы слева от нового: пока новый элемент в окне, они (более старые и меньшие) не могут быть максимумом, а из окна они выйдут раньше него. O(n) суммарно.

Задача «Минимум на отрезке» из подборки для бэкенд-стажёров — ровно это: минимум в каждом окне длины k, дек с возрастающими значениями.

Монотонная очередь также ускоряет динамику вида `dp[i] = max(dp[j]) + c` по окну `j ∈ [i - k, i - 1]` с O(n·k) до O(n).

### Как узнать задачу на монотонный стек

- «для каждого элемента найдите ближайший (следующий, предыдущий) больший/меньший»;
- «сколько дней ждать», «кого видно из окна», «сколько зданий заслоняет»;
- прямоугольники в гистограмме, «вода между столбиками»;
- максимум или минимум в каждом окне фиксированной длины — монотонная очередь.

## Самопроверка

### Что вернёт `days_to_warmer([73, 74, 75, 71, 69, 72, 76, 73])` из урока?
- [ ] `[1, 1, 4, 1, 1, 1, 0, 0]`
- [x] `[1, 1, 4, 2, 1, 1, 0, 0]`
- [ ] `[1, 1, 3, 2, 1, 1, 0, 0]`
- [ ] `[1, 1, 4, 2, 1, 1, 1, 0]`
> После 75 теплее будет только 76 через 4 дня; после 71 — 72 через 2 дня; после 76 и 73 теплее не будет.

### Почему монотонный стек работает за O(n), хотя внутри есть while?
- [ ] while выполняется не больше одного раза
- [x] Каждый индекс кладётся в стек один раз и снимается не больше одного раза
- [ ] Стек всегда маленький
- [ ] Он работает за O(n log n)
> Суммарное число снятий не больше числа добавлений, то есть n.

### Что выведет код?

```python
a = [2, 1, 5, 6, 2, 3]
st, res = [], []
for i, x in enumerate(a):

        st.pop()

print(res)
```
- [ ] `[-1, 0, 1, 2, 1, 4]`
- [x] `[-1, -1, 1, 2, 1, 4]`
- [ ] `[-1, -1, 1, 2, 2, 4]`
- [ ] `[0, 0, 1, 2, 1, 4]`
> Для каждого i печатается индекс ближайшего строго меньшего элемента слева или −1.

### Какую площадь вернёт `largest_rectangle([2, 1, 5, 6, 2, 3])`?
- [ ] 6
- [x] 10
- [ ] 12
- [ ] 8
> Столбики 5 и 6 дают прямоугольник высоты 5 и ширины 2.

### Почему в монотонной очереди для максимума можно удалить из хвоста все элементы, не больше нового?
- [ ] Для экономии памяти
- [x] Они старше нового и не больше его, поэтому выйдут из окна раньше и никогда не станут максимумом
- [ ] Потому что дек должен быть отсортирован
- [ ] Их нельзя удалять
> Пока новый элемент в окне, он не меньше их, а покинут окно они раньше — удаление ничего не теряет.

### Какая сложность поиска максимумов всех окон длины k монотонной очередью?
- [ ] O(n·k)
- [x] O(n)
- [ ] O(n log k)
- [ ] O(k)
> Каждый индекс один раз попадает в дек и один раз удаляется. С кучей было бы O(n log k).

## Вопросы на собеседовании

### Как для каждого элемента найти следующий больший элемент?
Монотонный стек индексов с убывающими значениями. Идём слева направо; пока текущий элемент больше элемента на вершине, снимаем вершину и записываем ей ответ — текущий элемент. Потом кладём текущий индекс. Оставшимся в стеке ответ «нет». O(n) времени и памяти, потому что каждый индекс добавляется и удаляется не более одного раза.

### Как найти максимум в каждом окне длины k?
Дек индексов, значения в котором убывают. Для нового элемента удаляем из хвоста все не большие его, добавляем его индекс; если голова вышла за левую границу окна — удаляем голову. Голова — максимум окна. O(n). Альтернативы: куча с ленивым удалением — O(n log k), очередь на двух стеках с максимумом — O(n) амортизированно.
