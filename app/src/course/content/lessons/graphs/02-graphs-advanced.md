### Цикл в ориентированном графе

В неориентированном графе цикл есть, если DFS нашёл ребро в уже посещённую вершину, которая не является родителем. В **ориентированном** нужна раскраска в три цвета:

- белый (0) — не посещена;
- серый (1) — в обработке, находится на текущем пути DFS;
- чёрный (2) — обработана полностью.

Ребро в **серую** вершину — это цикл (мы вернулись в вершину на текущем пути). Ребро в чёрную — нет.

```python
def has_cycle(n, g):
    color = [0] * (n + 1)
    for s in range(1, n + 1):
        if color[s]:
            continue
        stack = [(s, 0)]                  # (вершина, индекс следующего соседа)
        color[s] = 1
        while stack:
            u, i = stack[-1]
            if i < len(g[u]):
                stack[-1] = (u, i + 1)
                v = g[u][i]
                if color[v] == 1:
                    return True
                if color[v] == 0:
                    color[v] = 1
                    stack.append((v, 0))
            else:
                color[u] = 2
                stack.pop()
    return False
```

Итеративный DFS с индексом соседа моделирует рекурсию точно: вершина становится чёрной, только когда обработаны все её соседи. Чтобы вывести сам цикл, храните родителя и при нахождении серой вершины пройдите по родителям.

### Топологическая сортировка

Упорядочить вершины ориентированного ациклического графа (DAG) так, чтобы каждое ребро шло «вперёд»: сборка проекта по зависимостям, порядок прохождения курсов, порядок вычисления формул.

**Алгоритм Кана** (через входящие степени) — удобен и сам проверяет наличие цикла:

```python
from collections import deque

def topo_sort(n, g):
    indeg = [0] * (n + 1)
    for u in range(1, n + 1):
        for v in g[u]:
            indeg[v] += 1
    q = deque(v for v in range(1, n + 1) if indeg[v] == 0)
    order = []
    while q:
        u = q.popleft()
        order.append(u)
        for v in g[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    return order if len(order) == n else None      # None — есть цикл
```

Если в очереди держать кучу вместо дека, получится лексикографически наименьший порядок. Задача «Можно ли пройти все курсы» — проверка, что топологическая сортировка существует.

**Через DFS:** порядок выхода из вершин (когда она становится чёрной), развёрнутый, — топологический порядок.

### Алгоритм Дейкстры

Кратчайшие пути от одной вершины во **взвешенном** графе с **неотрицательными** весами.

Идея: как BFS, но вместо очереди — куча по текущему расстоянию. Достаём вершину с минимальным расстоянием — её расстояние окончательное (все остальные пути к ней длиннее, так как веса неотрицательны). Релаксируем рёбра из неё.

```python
import heapq

def dijkstra(n, g, s):                    # g[u] = [(v, w), ...]
    dist = [float("inf")] * (n + 1)
    dist[s] = 0
    heap = [(0, s)]
    while heap:
        d, u = heapq.heappop(heap)
        if d > dist[u]:
            continue                      # устаревшая запись
        for v, w in g[u]:
            nd = d + w
            if nd < dist[v]:
                dist[v] = nd
                heapq.heappush(heap, (nd, v))
    return dist
```

O((V + E) log V). Строку `if d > dist[u]: continue` не забывайте: в куче лежат устаревшие пары, и без проверки время может сильно вырасти.

С **отрицательными** весами Дейкстра неверна — нужен Форд — Беллман, O(V·E). Для всех пар при V до ~400 — Флойд — Уоршелл, O(V³).

### Система непересекающихся множеств (DSU, union-find)

Поддерживает разбиение элементов на группы с двумя операциями: объединить группы двух элементов, узнать, в одной ли группе два элемента.

```python
parent = list(range(n))
size = [1] * n

def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]     # сжатие пути (половинное)
        x = parent[x]
    return x

def union(a, b):
    a, b = find(a), find(b)
    if a == b:
        return False                      # уже в одной группе
    if size[a] < size[b]:
        a, b = b, a
    parent[b] = a                         # меньшее дерево под большее
    size[a] += size[b]
    return True
```

С обеими эвристиками операции работают практически за O(1) (обратная функция Аккермана). Применения:

- компоненты связности при **добавлении** рёбер онлайн;
- проверка, создаёт ли новое ребро цикл (`union` вернул `False`) — задача «Модель молекулы» из бэкенд-сезона CodeRun;
- минимальное остовное дерево (алгоритм Краскала: рёбра по возрастанию веса, берём ребро, если оно соединяет разные компоненты);
- группировка «эквивалентных» объектов (аккаунты с общими почтами).

### Кратко об остальном

- **Остовное дерево минимального веса** — Краскал (DSU) или Прим (куча).
- **Мосты и точки сочленения** — DFS со временем входа и `low`.
- **Сильно связные компоненты** — Косарайю или Тарьян.
- **Кратчайшие пути в DAG** — динамика в топологическом порядке, работает и с отрицательными весами.
- **Эйлеров путь** — степени вершин и DFS по рёбрам.

Для стажёрского уровня главное — BFS, DFS, компоненты, топологическая сортировка, Дейкстра и DSU. Остальное полезно знать по названию и назначению.

### Как узнать графовую задачу

Слова «города, дороги, связи, зависимости, друзья, переходы, соседи, лабиринт, сеть» почти всегда означают граф. Спросите себя:

1. Что вершины и что рёбра? Ориентированы ли они? Есть ли веса?
2. Что спрашивают: достижимость, компоненты, кратчайший путь, порядок, цикл?
3. Какие ограничения: V и E до 10⁵ — только O(V + E) или O(E log V).

### Типичные ошибки

- Цикл в ориентированном графе ищут, как в неориентированном, — ребро в чёрную вершину ошибочно считается циклом.
- В Дейкстре нет проверки устаревших записей кучи.
- Дейкстра на графе с отрицательными рёбрами.
- DSU без сжатия путей и объединения по размеру — на цепочке операции становятся O(n).
- Топологическая сортировка не проверяет, что в ответ попали все вершины.

### Как спрашивают на Яндексе

«Топологическая сортировка» и «Поиск цикла» — задачи занятия о графах в тренировках Яндекса; в бэкенд-сезоне CodeRun есть «Ухудшение графа» (Дейкстра и дерево кратчайших путей) и «Разделение графа», в задачах трека бэкенда — «Модель молекулы» на DSU. На секции могут спросить, как устроен Дейкстра и почему он не работает с отрицательными весами.

## Самопроверка

### Какой признак цикла в ориентированном графе при DFS с тремя цветами?
- [ ] Ребро в белую вершину
- [x] Ребро в серую вершину — она на текущем пути обхода
- [ ] Ребро в чёрную вершину
- [ ] Вершина без исходящих рёбер
> Ребро в чёрную вершину ведёт в уже полностью обработанную часть графа и цикла не образует.

### Алгоритм Кана вернул порядок из меньшего числа вершин, чем в графе. Что это значит?
- [ ] Граф несвязный
- [x] В графе есть цикл: вершины цикла никогда не получат входящую степень 0
- [ ] Ошибка в коде
- [ ] Есть изолированные вершины
> Изолированные и несвязные вершины сразу имеют нулевую степень и попадут в порядок. Не попадут только вершины, зависящие от цикла.

### Почему Дейкстра не работает с отрицательными весами?
- [ ] Куча не умеет хранить отрицательные числа
- [x] Извлечённая вершина может позже получить более короткий путь через отрицательное ребро, а алгоритм считает её расстояние окончательным
- [ ] Из-за переполнения
- [ ] Работает, если нет циклов
> Корректность Дейкстры опирается на то, что любой путь через ещё не обработанную вершину не короче текущего минимума.

### Зачем в Дейкстре строка `if d > dist[u]: continue`?
- [ ] Чтобы не зациклиться
- [x] Пропустить устаревшие записи в куче — вершина уже обработана с меньшим расстоянием
- [ ] Для отрицательных весов
- [ ] Она не нужна
> В куче может лежать несколько записей для одной вершины. Без проверки мы бы заново релаксировали её рёбра.

### Что выведет код?
```python
parent = list(range(5))
def find(x):
    while parent[x] != x:
        x = parent[x]
    return x
def union(a, b):
    a, b = find(a), find(b)
    if a == b:
        return False
    parent[b] = a
    return True
print(union(0, 1), union(1, 2), union(0, 2), find(2))
```
- [ ] `True True True 0`
- [x] `True True False 0`
- [ ] `True True False 2`
- [ ] `True False False 1`
> После двух объединений 0, 1, 2 в одной группе с корнем 0; третье объединение ничего не меняет и возвращает False — ребро 0–2 создало бы цикл.

### Какая сложность Дейкстры с двоичной кучей?
- [ ] O(V²)
- [x] O((V + E) log V)
- [ ] O(V + E)
- [ ] O(V·E)
> Каждое ребро может добавить запись в кучу за O(log V), каждая вершина извлекается с тем же логарифмом.

## Вопросы на собеседовании

### Как найти порядок выполнения задач с зависимостями?
Топологическая сортировка ориентированного графа «задача → зависящая от неё». Алгоритм Кана: считаем входящие степени, кладём в очередь вершины со степенью 0, извлекая вершину, уменьшаем степени её соседей и добавляем тех, у кого стала 0. Если в порядок попали не все вершины — в зависимостях цикл, выполнить нельзя. O(V + E).

### Как работает алгоритм Дейкстры и какие у него ограничения?
Поддерживает оценки расстояний и кучу вершин по оценке. Каждый раз извлекает вершину с минимальной оценкой — для неотрицательных весов она окончательная — и релаксирует исходящие рёбра. O((V + E) log V) с кучей. Не работает с отрицательными весами — там Форд — Беллман. Для невзвешенного графа хватит BFS, для весов 0 и 1 — 0-1 BFS.

### Что такое DSU и где применяется?
Структура для непересекающихся множеств с операциями find (представитель множества) и union (объединить множества). Хранится лесом с родителями; с эвристиками сжатия путей и объединения по размеру операции почти O(1). Применяется для динамической связности (добавление рёбер), алгоритма Краскала, обнаружения цикла в неориентированном графе, группировки эквивалентных объектов.
