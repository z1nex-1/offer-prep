### Что такое граф

Граф — множество **вершин** и **рёбер** между ними. Рёбра бывают **ориентированные** (дорога с односторонним движением, зависимость «A нужно сделать до B») и **неориентированные** (дружба, двусторонняя дорога), **взвешенные** (длина дороги) и **невзвешенные**.

Графом моделируется очень многое: города и дороги, пользователи и подписки, задачи и зависимости, клетки лабиринта и переходы между соседними клетками, состояния игры и ходы.

### Представление в памяти

**Список смежности** — для каждой вершины список соседей. Основной вариант:

```python
n, m = map(int, input().split())
g = [[] for _ in range(n + 1)]       # вершины с 1
for _ in range(m):
    u, v = map(int, input().split())
    g[u].append(v)
    g[v].append(u)                   # для неориентированного графа
```

Память O(V + E), обход всех соседей всех вершин — O(V + E).

**Матрица смежности** `adj[u][v]` — O(V²) памяти, проверка ребра за O(1). Годится при V до нескольких тысяч и плотных графах.

**Список рёбер** `[(u, v, w), …]` — для алгоритмов, которые перебирают рёбра (Краскал, Форд — Беллман).

Если вершины — не числа, а строки, используйте `defaultdict(list)`.

### Обход в глубину (DFS)

Идём из вершины в первого непосещённого соседа, от него — дальше, пока можно; упёрлись — возвращаемся.

```python
def dfs(start, g, visited):
    stack = [start]
    visited[start] = True
    while stack:
        u = stack.pop()
        for v in g[u]:
            if not visited[v]:
                visited[v] = True
                stack.append(v)
```

Рекурсивная версия короче, но на больших графах в Python упирается в глубину рекурсии:

```python
def dfs_rec(u):
    visited[u] = True
    for v in g[u]:
        if not visited[v]:
            dfs_rec(v)
```

Итеративная версия с `stack.pop()` посещает вершины в немного другом порядке, чем рекурсивная, но для компонент, достижимости и циклов это не важно. O(V + E).

### Компоненты связности

Запускаем DFS из каждой ещё не посещённой вершины — каждый запуск находит одну компоненту:

```python
comp = [0] * (n + 1)
count = 0
for s in range(1, n + 1):
    if comp[s] == 0:
        count += 1
        stack = [s]
        comp[s] = count
        while stack:
            u = stack.pop()
            for v in g[u]:
                if comp[v] == 0:
                    comp[v] = count
                    stack.append(v)
```

Задачи из тренировок Яндекса «Поиск в глубину» и «Компоненты связности» — ровно это: вывести вершины компоненты вершины 1 или все компоненты.

### Обход в ширину (BFS) и кратчайшие пути

BFS обходит вершины **по слоям**: сначала на расстоянии 0, потом 1, потом 2… Поэтому в **невзвешенном** графе он находит кратчайшие расстояния.

```python
from collections import deque

def bfs(start, g, n):
    dist = [-1] * (n + 1)
    dist[start] = 0
    q = deque([start])
    while q:
        u = q.popleft()
        for v in g[u]:
            if dist[v] == -1:
                dist[v] = dist[u] + 1
                q.append(v)
    return dist
```

Вершину помечаем **при добавлении в очередь**, а не при извлечении — иначе она может попасть в очередь много раз. O(V + E).

**Восстановление пути** — храним, откуда пришли:

```python
parent[v] = u      # при первом посещении v
# после BFS:
path = []
v = target
while v != -1:
    path.append(v)
    v = parent[v]
path.reverse()
```

### Клетчатые поля

Лабиринт `n × m` — граф, где вершины — клетки, рёбра — переходы к соседям. Список смежности не строим — соседей вычисляем на лету:

```python
from collections import deque

def shortest(grid, sr, sc, tr, tc):
    n, m = len(grid), len(grid[0])
    dist = [[-1] * m for _ in range(n)]
    dist[sr][sc] = 0
    q = deque([(sr, sc)])
    while q:
        r, c = q.popleft()
        for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            nr, nc = r + dr, c + dc
            if 0 <= nr < n and 0 <= nc < m and grid[nr][nc] != "#" and dist[nr][nc] == -1:
                dist[nr][nc] = dist[r][c] + 1
                q.append((nr, nc))
    return dist[tr][tc]
```

Вариации: ходы конём (8 направлений `(±1, ±2), (±2, ±1)`), трёхмерный лабиринт («Путь спелеолога» из тренировок), число островов (компоненты связности клеток), **мультиисточниковый BFS** — все источники кладём в очередь сразу с расстоянием 0 (расстояние до ближайшего выхода, «гниющие апельсины»).

**BFS по состояниям.** Если важно не только «где», но и «в каком состоянии» (сколько осталось бомб, какой ключ подобран, чей ход), вершина — это кортеж `(r, c, state)`, и `visited` — множество кортежей или многомерный массив.

**0-1 BFS** — если рёбра весят 0 или 1: ребро веса 0 кладём в начало дека, веса 1 — в конец. Кратчайшие пути за O(V + E) без Дейкстры.

### Двудольность

Граф двудольный, если вершины можно покрасить в два цвета так, чтобы каждое ребро соединяло разные цвета. Проверка — BFS или DFS с раскраской: соседу даём противоположный цвет; если сосед уже покрашен в тот же — не двудольный. Задача «Списывание» из тренировок Яндекса («можно ли разделить студентов на две группы, чтобы списывающие пары были в разных») — ровно она.

```python
def is_bipartite(g, n):
    color = [-1] * (n + 1)
    for s in range(1, n + 1):
        if color[s] != -1:
            continue
        color[s] = 0
        stack = [s]
        while stack:
            u = stack.pop()
            for v in g[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    stack.append(v)
                elif color[v] == color[u]:
                    return False
    return True
```

### Что выбрать: DFS или BFS

| Задача | Обход |
|---|---|
| достижимость, компоненты | любой |
| кратчайший путь в невзвешенном графе | **BFS** |
| цикл, топологическая сортировка, мосты | DFS |
| двудольность | любой |
| обход дерева «снизу вверх» | DFS (обратный порядок) |

### Типичные ошибки

- Матрица смежности для 10⁵ вершин — не хватит памяти.
- Вершина помечается при извлечении из очереди, а не при добавлении — очередь растёт в разы.
- Неориентированное ребро добавлено только в одну сторону.
- Рекурсивный DFS на больших графах — `RecursionError`.
- Нумерация вершин с единицы во вводе и с нуля в массивах перепутана.

## Вопросы на собеседовании

### Чем BFS отличается от DFS и когда что использовать?
BFS обходит граф по слоям с помощью очереди и находит кратчайшие по числу рёбер пути; память — O(V) на очередь. DFS уходит вглубь с помощью стека или рекурсии; удобен для поиска циклов, топологической сортировки, обработки поддеревьев. Для достижимости и компонент подходят оба. Оба — O(V + E) на списке смежности.

### Как найти кратчайший путь в лабиринте и восстановить его?
BFS от старта по клеткам: соседи — четыре направления, проходимые и не посещённые. Расстояние соседа — расстояние текущей плюс 1, запоминаем родителя. Когда дошли до финиша (или после BFS), идём по родителям от финиша к старту и разворачиваем. O(n·m) времени и памяти.

### Как хранить граф и почему?
Для разреженных графов (E ≈ V, как большинство реальных) — список смежности: O(V + E) памяти и быстрый перебор соседей. Для плотных графов при небольшом V — матрица смежности: проверка ребра O(1), но O(V²) памяти. Для алгоритмов, перебирающих рёбра целиком (Краскал), — список рёбер.
