В условиях контестов граф редко называют графом. «Лабиринт», «конь на доске», «превратить число a в число b операциями», «города и дороги», «зависимости между задачами» — всё это графы. Урок о том, как их увидеть и какой обход выбрать.

### Как увидеть граф

Задайте три вопроса:

1. **Что вершина?** Клетка, город, число, строка, состояние игры, пара (клетка, сколько ключей подобрано).
2. **Что ребро?** Допустимый ход, операция, дорога, зависимость.
3. **Что спрашивают?** Достижимость → любой обход; наименьшее число шагов → BFS; наименьшая стоимость → Дейкстра (или 0-1 BFS); порядок → топологическая сортировка; группы → компоненты или DSU; соединить всё дёшево → остовное дерево.

### Неявные графы: соседей считаем на лету

Строить список смежности для поля 1000 × 1000 или для всех чисел до 10⁶ не нужно — соседей вычисляют при обходе:

```python
from collections import deque

def min_ops(a, b, limit):
    # из x можно получить x + 1, x - 1, 2x; наименьшее число операций до b
    dist = {a: 0}
    q = deque([a])
    while q:
        x = q.popleft()
        if x == b:
            return dist[x]
        for y in (x + 1, x - 1, 2 * x):
            if 0 <= y <= limit and y not in dist:
                dist[y] = dist[x] + 1
                q.append(y)
    return -1
```

Важно ограничить пространство состояний (`0 ≤ y ≤ limit`), иначе BFS уйдёт в бесконечность.

### Состояния из нескольких компонент

Если важно не только «где», но и «с чем», вершина — кортеж. Лабиринт с ключами: `(r, c, mask)`, где `mask` — какие ключи подобраны. Лабиринт, где можно один раз пробить стену: `(r, c, пробивал_ли)`. Число состояний = произведение размеров компонент — проверьте, что оно разумно (1000 × 1000 × 2 = 2·10⁶ — нормально; × 2¹⁰ — уже много).

### Веса 0 и 1: 0-1 BFS

Если одни переходы бесплатные, а другие стоят 1 (например, двигаться по дороге бесплатно, а сворачивать — 1), обычный BFS неверен, а Дейкстра избыточна. Дек: переход веса 0 — в **начало** дека, веса 1 — в **конец**.

```python
from collections import deque

def zero_one_bfs(n, g, s):          # g[u] = [(v, w)], w ∈ {0, 1}
    INF = float("inf")
    dist = [INF] * n
    dist[s] = 0
    dq = deque([s])
    while dq:
        u = dq.popleft()
        for v, w in g[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                if w == 0:
                    dq.appendleft(v)
                else:
                    dq.append(v)
    return dist
```

O(V + E): дек всегда содержит вершины с расстояниями d и d + 1.

### Много источников

Расстояние до **ближайшего** из нескольких объектов (склада, выхода, огня) — один BFS, в котором все источники стартуют одновременно с расстоянием 0. Запускать BFS от каждого источника — в k раз дольше.

### Восстановление пути

Храните `parent[v]` — откуда пришли при первом посещении (BFS) или при последнем улучшении (Дейкстра). После обхода идите от цели к старту по `parent` и разверните список. Если нужен лексикографически наименьший путь — перебирайте соседей в отсортированном порядке и помните, что это меняет не длину, а выбор среди равных.

### Минимальное остовное дерево

Соединить все вершины рёбрами минимального суммарного веса — **остовное дерево**.

- **Краскал**: рёбра по возрастанию веса, берём ребро, если концы в разных компонентах DSU. O(E log E).
- **Прим**: растим дерево от одной вершины, каждый раз добавляя самое лёгкое ребро наружу, — куча. O(E log V).

Корректность обоих — «свойство разреза»: самое лёгкое ребро, пересекающее любой разрез, можно включить в оптимальное дерево.

### Шаблон быстрого графового решения на Python

```python
import sys
from collections import deque

def main():
    data = sys.stdin.buffer.read().split()
    n, m = int(data[0]), int(data[1])
    g = [[] for _ in range(n + 1)]
    it = 2
    for _ in range(m):
        u, v = int(data[it]), int(data[it + 1]); it += 2
        g[u].append(v)
        g[v].append(u)
    dist = [-1] * (n + 1)
    dist[1] = 0
    q = deque([1])
    while q:
        u = q.popleft()
        for v in g[u]:
            if dist[v] == -1:
                dist[v] = dist[u] + 1
                q.append(v)
    print(dist[n])

main()
```

Быстрый ввод, списки вместо словарей для вершин-чисел, помечать при добавлении в очередь, никакой рекурсии.

### Типичные ошибки

- BFS на графе с весами больше 1 — неверные расстояния.
- Состояние «клетка» там, где нужно «клетка + ресурс»: разные состояния в одной клетке затирают друг друга.
- Неограниченное пространство состояний в неявном графе.
- Пометка вершины при извлечении из очереди вместо добавления — очередь раздувается.
- Рекурсивный DFS на 10⁵ вершинах.

## Самопроверка

### Из числа x можно получить x + 1 или 2x. Какой алгоритм даст наименьшее число операций от a до b?
- [ ] DFS
- [x] BFS по числам с ограничением диапазона
- [ ] Дейкстра обязательно
- [ ] Сортировка
> Все операции стоят одинаково — это кратчайший путь в невзвешенном неявном графе.

### Когда нужен 0-1 BFS?
- [ ] Когда все рёбра веса 1
- [x] Когда рёбра имеют вес 0 или 1
- [ ] Когда есть отрицательные веса
- [ ] Когда граф — дерево
> Рёбра веса 0 кладутся в начало дека, веса 1 — в конец.

### Лабиринт, где можно один раз пробить стену. Что должно быть вершиной?
- [ ] Клетка
- [x] Пара (клетка, пробивали ли уже стену)
- [ ] Стена
- [ ] Строка поля
> Одна клетка в двух разных состояниях — разные вершины.

### Что выведет код?
```python
from collections import deque
dist = {3: 0}
q = deque([3])
while q:
    x = q.popleft()
    if x == 10:
        break
    for y in (x + 1, 2 * x):
        if y <= 20 and y not in dist:
            dist[y] = dist[x] + 1
            q.append(y)
print(dist[10])
```
- [ ] `2`
- [x] `3`
- [ ] `4`
- [ ] `7`
> Например, 3 → 4 → 5 → 10 или 3 → 6 → ... — наименьшее число операций 3.

### Какое свойство гарантирует корректность Краскала?
- [ ] Граф ациклический
- [x] Самое лёгкое ребро через любой разрез можно включить в минимальное остовное дерево
- [ ] Все веса различны
- [ ] Граф двудольный
> Поэтому жадно берём лёгкие рёбра, не образующие цикл.

## Вопросы на собеседовании

### Как понять, что задача графовая, если слово «граф» в ней не встречается?
Спросить себя, что можно считать состояниями и переходами между ними: клетки и ходы, числа и операции, города и дороги, задачи и зависимости. Если ответ требует «наименьшего числа шагов», «достижимости», «порядка» или «групп» — это обход, кратчайшие пути, топологическая сортировка или компоненты на этом графе.

### Как найти минимальное остовное дерево?
Краскал: отсортировать рёбра по весу и брать ребро, если его концы в разных компонентах DSU, — O(E log E). Или Прим: растить дерево от вершины, выбирая из кучи самое лёгкое ребро наружу, — O(E log V). Оба корректны по свойству разреза. Если рёбер в итоге меньше V − 1, граф несвязный.
