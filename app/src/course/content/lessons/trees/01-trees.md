### Термины

Дерево — связный граф без циклов. Корневое дерево: одна вершина выделена как **корень**, у каждой другой ровно один **родитель**. Вершины без детей — **листья**. **Глубина** вершины — расстояние от корня, **высота** дерева — максимальная глубина. В дереве из n вершин ровно n − 1 рёбер.

**Бинарное дерево** — у каждой вершины не больше двух детей: левый и правый.

```python
class TreeNode:
    def __init__(self, val, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right
```

### Обходы в глубину

Три порядка — отличаются тем, когда обрабатывается сама вершина:

```python
def preorder(node, out):       # прямой: корень, левое, правое
    if node:
        out.append(node.val)
        preorder(node.left, out)
        preorder(node.right, out)

def inorder(node, out):        # симметричный: левое, корень, правое
    if node:
        inorder(node.left, out)
        out.append(node.val)
        inorder(node.right, out)

def postorder(node, out):      # обратный: левое, правое, корень
    if node:
        postorder(node.left, out)
        postorder(node.right, out)
        out.append(node.val)
```

- **Прямой** — копирование дерева, сериализация, «путь от корня».
- **Симметричный** в дереве поиска выдаёт значения в отсортированном порядке.
- **Обратный** — когда ответ вершины зависит от ответов детей: высота, размер поддерева, удаление дерева.

Каждый обход — O(n) времени и O(h) памяти на стек, где h — высота.

### Обход в ширину — по уровням

```python
from collections import deque

def level_order(root):
    res = []
    q = deque([root]) if root else deque()
    while q:
        level = []
        for _ in range(len(q)):          # ровно те, что на текущем уровне
            node = q.popleft()
            level.append(node.val)
            if node.left: q.append(node.left)
            if node.right: q.append(node.right)
        res.append(level)
    return res
```

Приём `for _ in range(len(q))` отделяет уровни. Применения: «вид справа» (последний на каждом уровне), минимальная глубина до листа, ширина уровня, зигзаг-обход.

### Рекурсия, которая возвращает значение

Большинство задач на деревья решаются одной схемой: функция возвращает ответ для поддерева, а ответ вершины собирается из ответов детей.

```python
def height(node):
    if node is None:
        return 0
    return 1 + max(height(node.left), height(node.right))

def size(node):
    return 0 if node is None else 1 + size(node.left) + size(node.right)

def is_symmetric(a, b):
    if a is None or b is None:
        return a is b
    return a.val == b.val and is_symmetric(a.left, b.right) and is_symmetric(a.right, b.left)
```

**Диаметр** (самый длинный путь между двумя вершинами): для каждой вершины путь через неё = высота левого + высота правого. Функция возвращает высоту, а ответ обновляется «по дороге»:

```python
def diameter(root):
    best = 0
    def h(node):
        nonlocal best
        if node is None:
            return 0
        l, r = h(node.left), h(node.right)
        best = max(best, l + r)
        return 1 + max(l, r)
    h(root)
    return best          # в рёбрах
```

Тот же приём: «максимальная сумма пути», «самый длинный путь из одинаковых значений», «сбалансировано ли дерево» (разница высот поддеревьев ≤ 1 в каждой вершине — АВЛ-сбалансированность, задача из тренировок Яндекса).

### Передача информации сверху вниз

Иногда вершине нужно знать что-то о пути от корня: глубину, сумму, допустимый диапазон значений. Передаём параметром:

```python
def has_path_sum(node, target):
    if node is None:
        return False
    if node.left is None and node.right is None:
        return node.val == target
    rest = target - node.val
    return has_path_sum(node.left, rest) or has_path_sum(node.right, rest)
```

### Наименьший общий предок (LCA)

Для двух вершин p и q — самая глубокая вершина, у которой обе в поддереве.

```python
def lca(node, p, q):
    if node is None or node is p or node is q:
        return node
    left, right = lca(node.left, p, q), lca(node.right, p, q)
    if left and right:
        return node          # p и q в разных поддеревьях
    return left or right
```

O(n). В дереве поиска проще: идём от корня, пока p и q по одну сторону.

### Деревья в формате контеста

На контесте дерево обычно задают **не объектами**, а списком:

- `n − 1` рёбер `u v` — строим список смежности, корень указан или равен 1;
- массив родителей `p[2..n]` — `children[p[i]].append(i)`;
- «добавляйте числа в дерево поиска по порядку, выведите глубину/высоту» (задачи «Высота дерева», «Глубина добавляемых элементов» из тренировок Яндекса) — строим дерево вставками.

Обход дерева из списка смежности — DFS с запоминанием родителя, чтобы не пойти назад:

```python
import sys
from collections import defaultdict

def subtree_sizes(n, edges, root=1):
    g = defaultdict(list)
    for u, v in edges:
        g[u].append(v); g[v].append(u)
    size = [1] * (n + 1)
    parent = [0] * (n + 1)
    order = []
    stack = [root]
    parent[root] = -1
    while stack:                       # итеративный DFS: порядок вершин от корня
        u = stack.pop()
        order.append(u)
        for v in g[u]:
            if v != parent[u]:
                parent[v] = u
                stack.append(v)
    for u in reversed(order):          # дети обработаны раньше родителей
        if parent[u] > 0:
            size[parent[u]] += size[u]
    return size
```

Приём «собрать порядок обхода, затем пройти его в обратном порядке» заменяет рекурсивный обратный обход и не упирается в глубину рекурсии — важно для деревьев-цепочек из 10⁵ вершин.

### Что проверить в решении

- пустое дерево (`root is None`);
- дерево из одной вершины;
- вырожденное дерево-цепочка (глубина n — рекурсия в Python упадёт на 10⁵);
- что возвращает функция для `None` — от этого зависят формулы (высота пустого 0 или −1).

### Типичные ошибки

- Не обработан пустой узел `None` в начале рекурсивной функции — `AttributeError` на листьях.
- Высота пустого дерева то 0, то −1 в разных местах кода — ответ смещается на единицу.
- Обход в ширину без разделения уровней, когда ответ нужен по уровням.
- Рекурсивный обход дерева-цепочки из 10⁵ вершин — `RecursionError`.
- LCA ищут, сравнивая значения, а не узлы, при повторяющихся значениях.

### Как спрашивают на Яндексе

В статье Яндекса об алгоритмической секции обход двоичного дерева прямо назван среди тем для повторения. В подборке CodeRun «Стажировка // Бэкенд» есть «Высота дерева». На секции обычно дают дерево объектами и просят рекурсивную функцию — высоту, симметричность, диаметр, LCA — и спрашивают о памяти на стек.

## Вопросы на собеседовании

### Как найти высоту бинарного дерева? Какая сложность?
Рекурсивно: высота пустого дерева 0, иначе 1 + максимум высот левого и правого поддеревьев. O(n) времени — каждая вершина посещается один раз, O(h) памяти на стек. Для глубоких деревьев — итеративно: BFS по уровням (число уровней) или DFS с явным стеком пар (вершина, глубина).

### Как найти наименьшего общего предка двух вершин?
Рекурсивно: если текущая вершина — None, p или q, возвращаем её. Иначе ищем в левом и правом поддеревьях: если оба результата не пустые, текущая вершина — LCA; иначе возвращаем непустой. O(n). В дереве поиска — O(h): спускаемся от корня туда, где лежат оба значения, и останавливаемся, когда они расходятся. Для множества запросов — двоичные подъёмы, O(log n) на запрос.

### Чем обход в глубину отличается от обхода в ширину на дереве?
DFS идёт вглубь по одной ветке (стек или рекурсия), память O(h). BFS идёт по уровням (очередь), память O(ширина уровня), до O(n). BFS находит ближайшие к корню вершины первыми — минимальная глубина, обработка по уровням. DFS естественен для задач, где ответ вершины зависит от поддеревьев.
