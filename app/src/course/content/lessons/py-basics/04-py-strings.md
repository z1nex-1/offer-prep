### Строка — неизменяемая последовательность символов

```python
s = "Яндекс"
print(len(s))      # 6
print(s[0])        # Я
print(s[-1])       # с — отрицательный индекс считается с конца
```

Строки в Python 3 — это Unicode: кириллица, эмодзи и любые символы — по одному элементу строки. Отдельного типа «символ» нет: `s[0]` — строка длины 1.

**Строки неизменяемы.** `s[0] = "я"` вызовет `TypeError`. Любая «модификация» создаёт новую строку:

```python
s = "hello"
s = "H" + s[1:]     # новая строка "Hello"
```

Если нужно много раз менять символы — превратите строку в список, работайте с ним и соберите обратно: `chars = list(s)`, …, `s = "".join(chars)`.

### Срезы

Срез `s[start:stop:step]` возвращает новую строку из символов с индексами от `start` до `stop` не включительно с шагом `step`. Любую часть можно опустить.

| Срез | Для `s = "abcdef"` |
|---|---|
| `s[1:4]` | `"bcd"` |
| `s[:3]` | `"abc"` — первые 3 символа |
| `s[3:]` | `"def"` — всё с индекса 3 |
| `s[-2:]` | `"ef"` — последние 2 |
| `s[::2]` | `"ace"` — через один |
| `s[::-1]` | `"fedcba"` — перевёрнутая строка |

Срезы не выбрасывают ошибку при выходе за границы: `s[2:100]` вернёт `"cdef"`, `s[10:]` — пустую строку. А вот обращение по индексу `s[10]` — `IndexError`.

Срез копирует символы, поэтому стоит O(k), где k — длина результата. Срез в цикле — скрытый квадрат: `for i in range(n): check(s[i:])` работает за O(n²).

Проверка палиндрома в одну строку: `s == s[::-1]`.

### Операции со строками

```python
"ab" + "cd"        # "abcd" — конкатенация
"ab" * 3           # "ababab"
"ell" in "hello"   # True — проверка подстроки
"z" not in "abc"   # True
```

Сравнение строк — лексикографическое, по кодам символов.

### Коды символов: ord и chr

```python
ord("a")    # 97
chr(98)     # "b"
ord("A")    # 65
ord("0")    # 48
```

Буквы латиницы идут подряд, цифры тоже. Отсюда полезные приёмы:

```python
idx = ord(ch) - ord("a")     # номер буквы 0..25
digit = ord(ch) - ord("0")   # то же, что int(ch) для одной цифры
nxt = chr((ord(ch) - ord("a") + 1) % 26 + ord("a"))   # следующая буква по кругу (шифр Цезаря)
```

Подсчёт частот букв массивом на 26 элементов вместо словаря:

```python
cnt = [0] * 26
for ch in s:
    cnt[ord(ch) - ord("a")] += 1
```

### Методы строк

Методы не меняют строку, а возвращают новую.

| Метод | Что делает | Пример |
|---|---|---|
| `s.lower()`, `s.upper()` | регистр | `"AbC".lower()` → `"abc"` |
| `s.strip()` | убрать пробельные символы по краям | `"  hi \n".strip()` → `"hi"` |
| `s.split(sep)` | разрезать | `"a,b,,c".split(",")` → `['a', 'b', '', 'c']` |
| `sep.join(list)` | склеить | `"-".join(["a", "b"])` → `"a-b"` |
| `s.replace(a, b)` | заменить все вхождения | `"aaa".replace("a", "b", 2)` → `"bba"` |
| `s.find(t)` | индекс первого вхождения или −1 | `"hello".find("l")` → `2` |
| `s.index(t)` | как `find`, но `ValueError`, если нет | |
| `s.count(t)` | число непересекающихся вхождений | `"aaaa".count("aa")` → `2` |
| `s.startswith(t)`, `s.endswith(t)` | начало и конец | |
| `s.isdigit()`, `s.isalpha()`, `s.isalnum()` | из цифр, из букв, из букв и цифр | |
| `s.isspace()`, `s.isupper()`, `s.islower()` | проверки | |

Методы `find`, `count`, `replace` и оператор `in` для подстрок работают за O(n·m) в худшем случае, на практике быстро. На собеседовании, если просят «найти подстроку», уточните, можно ли пользоваться встроенными методами.

### Сборка строки: join, а не +=

```python
# плохо: каждая конкатенация создаёт новую строку
res = ""
for x in words:
    res += x + " "

# хорошо
res = " ".join(words)
```

Так как строки неизменяемы, `res += x` в худшем случае копирует всю накопленную строку, и цикл работает за O(n²). CPython умеет в некоторых случаях дописывать строку на месте, но полагаться на это нельзя — на собеседовании правильный ответ: «собираю части в список и делаю `join`», это O(n).

### Посимвольный разбор: пример RLE

Классическая задача с собеседований Яндекса — сжать строку `"AAABBC"` в `"A3B2C"` (одиночные символы без числа).

```python
def rle(s):
    parts = []
    i = 0
    while i < len(s):
        j = i
        while j < len(s) and s[j] == s[i]:
            j += 1
        parts.append(s[i] + (str(j - i) if j - i > 1 else ""))
        i = j
    return "".join(parts)

print(rle("AAABBC"))   # A3B2C
```

Приём «два индекса»: `i` — начало серии, `j` бежит до конца серии. Внешний `while` прыгает сразу на `j`, поэтому общая сложность — O(n), хотя циклов два. Разберите, почему: каждый символ посещается указателем `j` ровно один раз.

### Строковые константы и форматирование

Модуль `string` содержит готовые наборы: `string.ascii_lowercase` (`"abc…z"`), `string.digits` (`"0123456789"`), `string.ascii_letters`.

Многострочные строки — в тройных кавычках: `"""..."""`. Сырые строки `r"\d+"` не обрабатывают экранирование — удобно для регулярных выражений и путей Windows.

## Самопроверка

### Что выведет код?
```python
s = "abcdef"
print(s[1:5:2], s[::-1][:2])
```
- [ ] `bcde fe`
- [x] `bd fe`
- [ ] `bd ab`
- [ ] `ace fe`
> `s[1:5:2]` берёт индексы 1 и 3 → `bd`. `s[::-1]` — `"fedcba"`, его первые два символа — `fe`.

### Что произойдёт при выполнении `s = "cat"; s[0] = "b"`?
- [ ] `s` станет `"bat"`
- [x] `TypeError`: строки неизменяемы
- [ ] Создастся новая строка `"bat"`, а старая останется
- [ ] `IndexError`
> Строку нельзя изменить по индексу. Новую строку собирают явно: `"b" + s[1:]`.

### Что выведет код?
```python
print("a,b,,c".split(","))
```
- [ ] `['a', 'b', 'c']`
- [x] `['a', 'b', '', 'c']`
- [ ] `['a', 'b', ',', 'c']`
- [ ] `['a,b,,c']`
> С явным разделителем пустой кусок между двумя запятыми сохраняется.

### Что выведет код?
```python
print(chr(ord("a") + 2), ord("c") - ord("a"))
```
- [ ] `b 2`
- [x] `c 2`
- [ ] `c 3`
- [ ] `99 2`
> Коды латинских букв идут подряд: `a` → 97, `c` → 99.

### Почему сборка строки через `+=` в цикле на n итераций может работать за O(n²)?
- [ ] Из-за сборщика мусора
- [x] Строки неизменяемы, и каждая конкатенация может копировать всю накопленную строку
- [ ] `+=` для строк не поддерживается
- [ ] Это всегда O(n), разницы нет
> Правильный шаблон — собрать части в список и один раз вызвать `"".join(parts)`: это линейное время.

### Что выведет код?
```python
print("aaaa".count("aa"), "aaaa".find("b"))
```
- [ ] `3 0`
- [x] `2 -1`
- [ ] `3 -1`
- [ ] `2 None`
> `count` считает непересекающиеся вхождения: `aa|aa` — два. `find` при отсутствии возвращает −1 (а `index` бросил бы исключение).

### Что выведет код?
```python
s = "Hello"
t = s.upper()
print(s, t)
```
- [ ] `HELLO HELLO`
- [x] `Hello HELLO`
- [ ] `Hello Hello`
- [ ] Ошибку
> Методы строк возвращают новую строку и не меняют исходную.

## Вопросы на собеседовании

### Почему строки в Python неизменяемы и какие у этого последствия?
Неизменяемость позволяет использовать строки как ключи словарей и элементы множеств (хеш не меняется), безопасно разделять одну строку между многими переменными и кэшировать хеш. Последствия: любое «изменение» создаёт новый объект, поэтому конкатенация в цикле может быть квадратичной — строку собирают через список и `join`, а для посимвольных правок переводят в список.

### Какая сложность у среза строки и у проверки подстроки через in?
Срез длины k — O(k): символы копируются в новый объект. `t in s` в CPython реализован быстрым алгоритмом поиска подстроки: в среднем почти линейно, в худшем случае O(n·m). Поэтому срезы и `in` внутри цикла по строке легко превращают решение в квадратичное.

### Как проверить, что строка — палиндром, без дополнительной памяти?
Два указателя с концов: `i = 0, j = len(s) - 1`, пока `i < j` сравниваем `s[i]` и `s[j]` и сдвигаем указатели навстречу. O(n) времени и O(1) памяти. `s == s[::-1]` короче, но создаёт копию строки — O(n) памяти. Если нужно игнорировать регистр и не-буквы, пропускаем такие символы указателями (`isalnum`) и сравниваем в `lower()`.
