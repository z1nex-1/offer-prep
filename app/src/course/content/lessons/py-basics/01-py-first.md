### Как запускать код

Python — интерпретируемый язык: программа — это текстовый файл `solution.py`, который выполняет интерпретатор командой `python3 solution.py`. Для экспериментов удобен интерактивный режим: наберите `python3` в терминале и вводите выражения построчно — результат напечатается сразу.

В этом курсе код можно запускать прямо в браузере: в задачах с автопроверкой и в блоке «Запустить на своём вводе». Локально поставьте Python 3.10 или новее с [python.org](https://www.python.org/downloads/) и любой редактор — VS Code или PyCharm Community.

Первая программа:

```python
print("Привет, Яндекс!")
```

`print` — встроенная функция, печатает свои аргументы и переводит строку.

### Переменные — это имена для объектов

```python
age = 20
name = "Илья"
age = age + 1   # теперь age указывает на объект 21
```

Всё в Python — объекты: число 20, строка `"Илья"`, список, функция. Переменная — это **имя**, которое указывает на объект. Присваивание `age = 21` не меняет старое число, а перенаправляет имя на другой объект. Эта модель «имена и объекты» ещё не раз пригодится: на ней держатся ответы на вопросы про изменяемость и копирование.

Правила имён: буквы, цифры и `_`, не начинается с цифры, регистр важен (`count` и `Count` — разные имена). По соглашению PEP 8 переменные и функции пишут `snake_case`: `max_len`, `total_sum`. На собеседовании осмысленные имена — часть оценки «читаемый код»: `cur_len` лучше, чем `c`.

Можно присвоить несколько переменных сразу и обменять значения без временной переменной:

```python
a, b = 1, 2
a, b = b, a     # теперь a = 2, b = 1
x = y = 0       # оба имени указывают на один объект 0
```

### Типы данных: первое знакомство

| Тип | Пример | Что это |
|---|---|---|
| `int` | `42`, `-7`, `10**100` | целое число любой длины |
| `float` | `3.14`, `1e-9`, `2.0` | число с плавающей точкой |
| `str` | `"abc"`, `'abc'` | строка |
| `bool` | `True`, `False` | логическое значение |
| `NoneType` | `None` | «ничего», отсутствие значения |

Узнать тип: `type(42)` вернёт `<class 'int'>`. Проверка типа в коде — `isinstance(x, int)`.

### Целые числа не переполняются

В C++ или Java `int` занимает 32 бита, и `2**31` уже не помещается. В Python `int` — длинная арифметика: число может быть сколь угодно большим, пока хватает памяти.

```python
print(2 ** 100)   # 1267650600228229401496703205376
```

Для контеста это плюс: не нужно думать о переполнении при подсчёте сумм и произведений. Но арифметика огромных чисел не бесплатна — умножение чисел из тысяч цифр работает заметно дольше, чем маленьких.

### Арифметические операторы

| Оператор | Смысл | Пример | Результат |
|---|---|---|---|
| `+ - *` | сложение, вычитание, умножение | `7 * 3` | `21` |
| `/` | деление, **всегда** `float` | `7 / 2`, `6 / 3` | `3.5`, `2.0` |
| `//` | целочисленное деление с округлением **вниз** | `7 // 2` | `3` |
| `%` | остаток от деления | `7 % 2` | `1` |
| `**` | возведение в степень | `2 ** 10` | `1024` |

Главная ловушка — отрицательные числа. `//` округляет вниз, то есть к минус бесконечности, а не к нулю, как в C++:

```python
print(-7 // 2)   # -4, а не -3
print(-7 % 2)    # 1, а не -1
print(7 % -2)    # -1: знак остатка совпадает со знаком делителя
```

Всегда выполняется тождество `a == (a // b) * b + a % b`. Для положительного делителя остаток лежит в диапазоне от 0 до `b - 1` — это удобно, например, для «циклического» индекса: `(i - 1) % n` для `i = 0` даст `n - 1`.

`divmod(a, b)` возвращает пару `(a // b, a % b)` за одну операцию:

```python
minutes, seconds = divmod(135, 60)   # 2, 15
```

### Приоритет операций

От высшего к низшему: `**`, затем унарный минус, затем `* / // %`, затем `+ -`, затем сравнения, затем `not`, `and`, `or`. Возведение в степень правоассоциативно и сильнее унарного минуса:

```python
print(-2 ** 2)    # -4, потому что это -(2 ** 2)
print(2 ** 3 ** 2)  # 512 = 2 ** 9
```

Если сомневаетесь — ставьте скобки. Читаемость важнее краткости.

### Дробные числа и их точность

`float` хранится в двоичном формате IEEE 754 с точностью около 15–16 значащих цифр. Большинство десятичных дробей в двоичной системе бесконечны, поэтому:

```python
print(0.1 + 0.2)          # 0.30000000000000004
print(0.1 + 0.2 == 0.3)   # False
```

Правила для контеста и собеседования:

- **Не сравнивайте `float` через `==`.** Сравнивайте с допуском: `abs(a - b) < 1e-9`.
- **Если можно остаться в целых числах — оставайтесь.** Вместо `a / b < c / d` при положительных знаменателях сравнивайте `a * d < c * b`. Вместо `sqrt(x) <= r` — `x <= r * r`.
- **Для денег** используют `decimal.Decimal` или хранят сумму в копейках целым числом.
- `int(3.9)` отбрасывает дробную часть к нулю: `3`; `int(-3.9)` — это `-3`.
- `round(2.5)` даёт `2`, а `round(3.5)` — `4`: Python использует «банковское» округление к ближайшему чётному. Для округления «как в школе» до целого при положительных числах используйте `int(x + 0.5)`, а для вывода с заданным числом знаков — форматирование, о нём в уроке про ввод и вывод.
- Округление вверх целочисленного деления без `float`: `(a + b - 1) // b` для положительных `a` и `b`, или `-(-a // b)`.

### Сокращённые операторы присваивания

```python
count += 1      # то же, что count = count + 1
total -= x
k *= 2
n //= 10        # отбросить последнюю цифру
```

В Python нет `++` и `--`: `count++` — синтаксическая ошибка, а `++count` просто дважды применяет унарный плюс и ничего не меняет.

### Полезные встроенные функции для чисел

| Функция | Что делает |
|---|---|
| `abs(x)` | модуль |
| `min(a, b, ...)`, `max(...)` | минимум и максимум, работают и со списком |
| `sum(список)` | сумма |
| `pow(a, b, m)` | `a ** b % m`, но быстро, без огромных промежуточных чисел |
| `int("42")`, `float("3.5")` | преобразование строки в число |
| `str(42)` | число в строку |
| `bin(10)`, `hex(255)` | `'0b1010'`, `'0xff'` |
| `int("1010", 2)` | строку в числовой системе с основанием 2 — в число `10` |

Модуль `math` даёт `math.sqrt`, `math.isqrt` (целый корень без погрешности), `math.gcd`, `math.ceil`, `math.floor`, `math.inf`, `math.pi`. Подключение — `import math`.

`math.isqrt(n)` — правильный способ проверить, что число — точный квадрат: `r = math.isqrt(n); r * r == n`. Через `int(n ** 0.5)` на больших числах можно ошибиться на единицу из-за погрешности `float`.

### Разбор типичной задачи

Задача: даны три числа — часы, минуты, секунды. Вывести, сколько всего секунд прошло с начала суток, и сколько полных часов и минут в `n` секундах.

```python
h, m, s = 1, 30, 15
total = h * 3600 + m * 60 + s
print(total)                 # 5415

n = 5415
hours, rest = divmod(n, 3600)
minutes, seconds = divmod(rest, 60)
print(hours, minutes, seconds)   # 1 30 15
```

Так решаются все задачи на «переведи единицы измерения»: делим с остатком на размер старшей единицы, остаток передаём дальше.

## Самопроверка

### Что выведет код?
```python
print(-7 // 2)
```
- [ ] `-3`
- [x] `-4`
- [ ] `-3.5`
- [ ] `3`
> `//` в Python округляет вниз, к минус бесконечности: −3,5 превращается в −4. В C++ и Java целочисленное деление округляет к нулю, отсюда частая ошибка при переходе между языками.

### Что выведет код?
```python
print(7 / 7)
```
- [ ] `1`
- [x] `1.0`
- [ ] `0`
- [ ] Ошибку
> Оператор `/` всегда возвращает `float`, даже если числа делятся нацело. Для целого результата нужен `//`.

### Что выведет код?
```python
print(-7 % 3)
```
- [ ] `-1`
- [x] `2`
- [ ] `1`
- [ ] `-2`
> При положительном делителе остаток в Python всегда от 0 до делитель − 1: `-7 = 3 * (-3) + 2`. Проверка тождества: `(-7 // 3) * 3 + (-7 % 3) = -9 + 2 = -7`.

### Что выведет код?
```python
print(0.1 + 0.2 == 0.3)
```
- [ ] `True`
- [x] `False`
- [ ] Ошибку сравнения
- [ ] `None`
> 0,1 и 0,2 не представимы в двоичном виде точно, сумма равна 0.30000000000000004. Дробные числа сравнивают с допуском: `abs(a - b) < 1e-9`.

### Что выведет код?
```python
a, b = 3, 5
a, b = b, a + b
print(a, b)
```
- [ ] `5 10`
- [x] `5 8`
- [ ] `3 8`
- [ ] `8 5`
> Правая часть вычисляется целиком до присваивания: сначала получается пара `(5, 3 + 5)`, затем она раскладывается по именам. Так записывается шаг чисел Фибоначчи.

### Как округлить вверх результат деления положительных целых `a` на `b`, не используя `float`?
- [ ] `a // b + 1`
- [x] `(a + b - 1) // b`
- [ ] `round(a / b)`
- [ ] `int(a / b)`
> `a // b + 1` ошибается, когда `a` делится нацело. `(a + b - 1) // b` — стандартный приём: добавляем «почти целый» делитель. Вариант через `float` может ошибиться на больших числах.

### Что выведет код?
```python
print(round(2.5), round(3.5))
```
- [ ] `3 4`
- [x] `2 4`
- [ ] `2 3`
- [ ] `3 3`
> `round` в Python округляет «к ближайшему чётному» (банковское округление), если число ровно посередине. Поэтому 2,5 → 2, а 3,5 → 4.

### Почему `math.isqrt(n)` надёжнее, чем `int(n ** 0.5)`, для проверки полного квадрата?
- [ ] `isqrt` быстрее в сто раз
- [x] `n ** 0.5` считается во `float` и на больших числах может ошибиться на единицу
- [ ] `n ** 0.5` не работает с целыми
- [ ] Разницы нет
> `float` хранит около 16 значащих цифр. Для чисел порядка 10¹⁸ корень во `float` может оказаться чуть меньше точного, и `int` отбросит единицу. `isqrt` работает в целых числах без погрешности.

## Вопросы на собеседовании

### Может ли в Python переполниться целое число?
Нет. `int` в Python — число произвольной длины: при выходе за машинное слово интерпретатор переходит на длинную арифметику. Ограничение одно — память. Цена — скорость: операции с очень большими числами медленнее, чем с маленькими. Переполниться может `float`: `1e308 * 10` даёт `inf`.

### Чем `/` отличается от `//` и как `//` работает с отрицательными числами?
`/` — истинное деление, результат всегда `float`. `//` — деление с округлением вниз (floor division), для целых результат целый. С отрицательными числами округление идёт к минус бесконечности: `-7 // 2 == -4`. Остаток `%` согласован с `//`: `a == (a // b) * b + a % b`, поэтому `-7 % 2 == 1`.

### Почему 0.1 + 0.2 не равно 0.3 и что с этим делать?
Числа `float` хранятся в двоичной системе по стандарту IEEE 754, а 0,1 и 0,2 в двоичном виде — бесконечные дроби, поэтому хранятся с округлением. Сравнивать нужно с допуском (`math.isclose` или `abs(a - b) < eps`), по возможности оставаться в целых числах (сравнивать `a * d` и `c * b` вместо дробей), а для денег использовать `Decimal` или хранить копейки целым числом.
