### Как программа получает данные

В контесте ваша программа не видит «пользователя»: проверяющая система подаёт на **стандартный ввод** (stdin) текст теста и читает то, что программа напечатала в **стандартный вывод** (stdout). Поэтому решение состоит из трёх частей: прочитать вход в точном формате из условия → посчитать → напечатать ответ в точном формате.

Никаких приглашений вроде `input("Введите число: ")` — всё напечатанное сверх ответа проверяющая система сочтёт частью ответа и выдаст WA.

### input() читает одну строку

`input()` возвращает очередную строку ввода **как строку**, без символа перевода строки в конце. Чтобы получить число, строку нужно преобразовать:

```python
n = int(input())          # "42" -> 42
x = float(input())        # "3.5" -> 3.5
s = input()               # строка как есть
```

Типичная ошибка новичка — забыть преобразование: `input() + 1` упадёт с `TypeError`, а `input() * 2` для ввода `"3"` даст `"33"`.

### Несколько чисел в одной строке

Вход `3 7`:

```python
a, b = map(int, input().split())
```

Разберём по частям:
- `input()` → `"3 7"`;
- `.split()` без аргументов режет строку по любым пробельным символам (пробелы, табуляции, переводы строк), лишние пробелы игнорирует → `["3", "7"]`;
- `map(int, ...)` применяет `int` к каждому элементу;
- распаковка `a, b = ...` требует ровно два элемента, иначе `ValueError`.

Список чисел из одной строки:

```python
nums = list(map(int, input().split()))
```

`list(...)` нужен, потому что `map` возвращает ленивый итератор, по которому можно пройти только один раз и нельзя обращаться по индексу.

Эквивалент через генератор списка — `nums = [int(x) for x in input().split()]`.

### Типичные форматы ввода

**Число, затем n чисел в строке:**

```
5
3 1 4 1 5
```

```python
n = int(input())
a = list(map(int, input().split()))
```

**Число, затем n строк по одному числу:**

```python
n = int(input())
a = [int(input()) for _ in range(n)]
```

`_` — принятое имя для переменной цикла, значение которой не нужно.

**n строк по два числа (например, отрезки):**

```python
n = int(input())
segments = [tuple(map(int, input().split())) for _ in range(n)]
```

**Матрица n × m:**

```python
n, m = map(int, input().split())
grid = [list(map(int, input().split())) for _ in range(n)]
```

**Поле из символов** (лабиринт):

```
3 4
#..#
....
.##.
```

```python
n, m = map(int, input().split())
field = [input() for _ in range(n)]
# field[i][j] — символ в строке i, столбце j
```

Если строки поля нужно менять, храните их как списки: `field = [list(input()) for _ in range(n)]`.

**Неизвестное число строк до конца ввода** — читаем всё сразу:

```python
import sys
lines = sys.stdin.read().splitlines()
```

### Быстрый способ: прочитать всё сразу

`input()` вызывается для каждой строки, и на 10⁵–10⁶ строк это заметно медленно. Надёжный шаблон для контеста — прочитать весь ввод одним вызовом и разрезать по пробелам:

```python
import sys

data = sys.stdin.buffer.read().split()
n = int(data[0])
a = list(map(int, data[1:n + 1]))
```

`sys.stdin.buffer.read()` читает байты, `split()` режет их по любым пробельным символам, `int` умеет разбирать байтовые строки. Такой способ не зависит от того, как числа раскиданы по строкам. Подробнее и с замерами — в модуле «Python для контеста».

Для строковых данных используйте `sys.stdin.read()` без `.buffer`, чтобы получить обычные строки, а не байты.

### print: разделитель и конец строки

```python
print(1, 2, 3)              # 1 2 3
print(1, 2, 3, sep=", ")    # 1, 2, 3
print("a", end="")          # без перевода строки
print()                     # пустая строка
```

Вывести список через пробел:

```python
a = [3, 1, 4]
print(*a)                   # 3 1 4
print(" ".join(map(str, a)))  # то же самое
```

`*a` распаковывает список в отдельные аргументы. `" ".join(...)` склеивает **строки**, поэтому числа нужно сначала превратить в строки через `map(str, a)`.

Много строк вывода — собирайте в список и печатайте один раз:

```python
out = []
for x in results:
    out.append(str(x))
print("\n".join(out))
```

Один большой `print` быстрее десятков тысяч маленьких.

### f-строки и форматирование

f-строка подставляет значения выражений в фигурные скобки:

```python
name, score = "Аня", 95.456
print(f"{name}: {score}")        # Аня: 95.456
print(f"{score:.2f}")            # 95.46 — два знака после точки
print(f"{7:03d}")                # 007 — дополнить нулями до 3 знаков
print(f"{1234567:,}")            # 1,234,567
print(f"{'ok':>5}|")             # '   ok|' — выровнять вправо на ширину 5
print(f"{x = }")                 # отладка: печатает имя и значение, например x = 5
```

Когда в условии написано «выведите ответ с точностью до 6 знаков» — используйте `f"{ans:.6f}"` или `print("%.6f" % ans)`. Печать `float` как есть может дать `1e-07` вместо `0.000000`.

### Строки ввода могут подвести

- В конце строки бывают лишние пробелы, в конце файла — лишний перевод строки. `split()` без аргументов с этим справляется, а `split(" ")` — нет: `"1  2".split(" ")` даст `['1', '', '2']`.
- Если в строке ровно одно слово, но могут быть пробелы по краям — используйте `input().strip()`.
- Пустая строка ввода: `input().split()` вернёт `[]`, и распаковка `a, b = ...` упадёт. Если по условию массив может быть пустым (n = 0), читайте аккуратно.
- Если ввод кончился, `input()` бросит `EOFError`. Чтение через `sys.stdin.read()` от этого защищено.

### Шаблон решения

```python
import sys


def main():
    data = sys.stdin.read().split()
    n = int(data[0])
    a = list(map(int, data[1:n + 1]))
    print(max(a) - min(a))


main()
```

Почему функция `main`, а не код на верхнем уровне? Доступ к локальным переменным в Python быстрее, чем к глобальным, — на тяжёлых циклах это даёт заметный выигрыш. И код внутри функции проще читать и тестировать.

## Самопроверка

### Что выведет код?
```python
print(1, 2, 3, sep="-", end="!")
```
- [ ] `1 2 3!`
- [x] `1-2-3!`
- [ ] `1-2-3-!`
- [ ] `123!`
> `sep` ставится между аргументами, `end` — один раз в конце вместо перевода строки.

### Во входе одна строка `10 20`. Что окажется в `x` после `x = input().split()`?
- [ ] `[10, 20]`
- [x] `['10', '20']`
- [ ] `'10 20'`
- [ ] `(10, 20)`
> `split` возвращает список строк. Числа из них получают через `map(int, ...)`.

### Почему `print(*a)` печатает элементы списка через пробел?
- [ ] `*` превращает список в строку
- [x] `*a` распаковывает список в отдельные аргументы, а `print` разделяет аргументы пробелом
- [ ] Это специальный режим `print` для списков
- [ ] Звёздочка умножает список
> `print(*[3, 1, 4])` равносильно `print(3, 1, 4)`. Разделитель по умолчанию — пробел, его меняет параметр `sep`.

### Что выведет код?
```python
print(f"{2 / 3:.3f}")
```
- [ ] `0.666`
- [x] `0.667`
- [ ] `0.6666666666666666`
- [ ] `.667`
> Формат `.3f` — три знака после точки с округлением.

### Что выведет код?
```python
print("1  2".split(" "))
```
- [ ] `['1', '2']`
- [x] `['1', '', '2']`
- [ ] `['1  2']`
- [ ] `['1', ' ', '2']`
> С явным разделителем `" "` каждый пробел — граница, и между двумя пробелами получается пустая строка. `split()` без аргументов схлопывает пробелы и был бы правильным выбором.

### Какой способ чтения лучше для 10⁶ чисел, разбросанных по многим строкам?
- [ ] `input()` в цикле для каждой строки
- [x] `sys.stdin.buffer.read().split()` один раз
- [ ] `eval(input())`
- [ ] `open(0).readline()` в цикле
> Одно чтение всего ввода и один `split` — самый быстрый и устойчивый к формату способ. Вызов `input()` на каждую строку в разы медленнее.

### Что выведет код?
```python
a = [1, 2, 3]
print(" ".join(map(str, a)) + ".")
```
- [ ] `1 2 3 .`
- [x] `1 2 3.`
- [ ] `[1, 2, 3].`
- [ ] Ошибку
> `join` склеивает строки через разделитель, точка присоединяется после. Без `map(str, ...)` был бы `TypeError`: `join` не принимает числа.

## Вопросы на собеседовании

### Почему в контесте нельзя писать input("Введите n: ")?
Строка-приглашение печатается в стандартный вывод. Проверяющая система сравнивает весь вывод программы с правильным ответом, и лишний текст превращает верное решение в WA. Выводить нужно ровно то, что требует формат вывода.

### Чем split() отличается от split(" ")?
`split()` без аргументов режет по любой последовательности пробельных символов (пробел, табуляция, перевод строки), отбрасывая пустые куски и пробелы по краям. `split(" ")` режет строго по одному пробелу: подряд идущие пробелы дадут пустые строки в результате, а `\n` и табуляции не считаются разделителями. Для разбора ввода почти всегда нужен `split()`.

### Как быстро вывести сто тысяч чисел?
Собрать строки в список и напечатать одним вызовом: `print("\n".join(map(str, result)))` или `sys.stdout.write(...)`. Каждый вызов `print` имеет накладные расходы, и сто тысяч отдельных вызовов заметно медленнее одного.
