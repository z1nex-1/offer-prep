### Условный оператор

```python
x = int(input())
if x > 0:
    print("положительное")
elif x == 0:
    print("ноль")
else:
    print("отрицательное")
```

Блок кода в Python задаётся **отступом** — принято четыре пробела. Строка с `if`, `elif`, `else`, `for`, `while`, `def` заканчивается двоеточием. Смешение табуляций и пробелов — частая причина `IndentationError`; настройте редактор вставлять пробелы.

`elif` проверяется, только если все условия выше ложны. Веток `elif` может быть сколько угодно, `else` — не больше одной и в конце.

### Операторы сравнения

`==`, `!=`, `<`, `<=`, `>`, `>=`. Python позволяет писать цепочки, как в математике:

```python
if 0 <= i < n:          # то же, что 0 <= i and i < n
    ...
if a == b == c:         # все три равны
    ...
```

Строки сравниваются лексикографически, посимвольно по кодам символов: `"apple" < "banana"`, `"Z" < "a"` (заглавные буквы идут раньше строчных), `"10" < "9"` (сравниваются символы `'1'` и `'9'`, а не числа — частая ошибка, когда числа забыли преобразовать из строк).

Списки и кортежи тоже сравниваются лексикографически: `[1, 2, 3] < [1, 3]` — `True`, потому что на второй позиции 2 < 3.

### Логические операторы и «ленивое» вычисление

`and`, `or`, `not`. Вычисление **ленивое**: `a and b` не вычисляет `b`, если `a` ложно; `a or b` не вычисляет `b`, если `a` истинно. На этом держатся проверки границ:

```python
if i < len(a) and a[i] == target:   # a[i] не вычислится, если i вне массива
    ...
```

Переставьте условия местами — и получите `IndexError`.

`and` и `or` возвращают не обязательно `True`/`False`, а один из операндов: `0 or 5` даёт `5`, `3 and 0` даёт `0`, `"" or "по умолчанию"` даёт `"по умолчанию"`.

### Истинность значений

В условии можно писать любой объект. Ложны: `False`, `None`, `0`, `0.0`, пустая строка `""`, пустые коллекции `[]`, `()`, `{}`, `set()`. Всё остальное истинно.

```python
if a:            # список не пуст
if not s:        # строка пуста
if count:        # count != 0
```

Осторожно с `0`: если переменная может законно быть нулём, пишите явно `if x is not None:`, а не `if x:`.

### Тернарный оператор

```python
sign = "+" if x >= 0 else "-"
best = a if a > b else b      # то же, что max(a, b)
```

### Цикл while

Выполняет тело, пока условие истинно:

```python
n = 12345
digits_sum = 0
while n > 0:
    digits_sum += n % 10    # последняя цифра
    n //= 10                # отрезать последнюю цифру
print(digits_sum)           # 15
```

`while` удобен, когда число шагов заранее неизвестно: разбор числа по цифрам, алгоритм Евклида, два указателя, бинарный поиск. Следите, чтобы условие рано или поздно стало ложным — иначе бесконечный цикл и вердикт TL.

### Цикл for и range

`for` проходит по элементам любой последовательности:

```python
for x in [3, 1, 4]:
    print(x)
for ch in "abc":
    print(ch)
```

`range` генерирует арифметическую прогрессию целых чисел без хранения её в памяти:

| Вызов | Числа |
|---|---|
| `range(5)` | 0, 1, 2, 3, 4 |
| `range(2, 5)` | 2, 3, 4 |
| `range(0, 10, 3)` | 0, 3, 6, 9 |
| `range(5, 0, -1)` | 5, 4, 3, 2, 1 |
| `range(n - 1, -1, -1)` | n−1, …, 1, 0 |

Правая граница **не включается**. Это удобно: `range(len(a))` — ровно все индексы списка, а `range(i, j)` содержит `j - i` чисел.

Индекс и значение сразу — `enumerate`:

```python
for i, x in enumerate(a):
    print(i, x)
```

Два списка параллельно — `zip`:

```python
for name, score in zip(names, scores):
    print(name, score)
```

`zip` останавливается на самом коротком списке. Соседние пары: `for x, y in zip(a, a[1:]):`.

Не изменяйте список, по которому идёт `for`, — удаление элементов внутри цикла пропускает соседние элементы. Если нужно фильтровать, стройте новый список.

### break, continue и else у цикла

- `break` — немедленно выйти из цикла;
- `continue` — перейти к следующей итерации;
- `else` у цикла выполняется, если цикл завершился **без** `break`.

```python
n = 91
for d in range(2, n):
    if n % d == 0:
        print("составное, делитель", d)
        break
else:
    print("простое")
```

`else` у цикла — редкая конструкция, но на собеседовании про неё иногда спрашивают. В рабочем коде понятнее вынести поиск в функцию с `return`.

`break` выходит только из **одного**, самого внутреннего цикла. Чтобы выйти из двух вложенных сразу, вынесите их в функцию и используйте `return` или заведите флаг.

### Главные шаблоны однопроходных алгоритмов

Почти каждая лёгкая задача контеста — это один проход по данным с аккуратно поддерживаемым состоянием.

**Счётчик:**

```python
count = 0
for x in a:
    if x % 2 == 0:
        count += 1
# короче: count = sum(1 for x in a if x % 2 == 0)
```

**Сумма и среднее:**

```python
total = sum(a)
avg = total / len(a) if a else 0
```

**Максимум с позицией:**

```python
best_i = 0
for i in range(1, len(a)):
    if a[i] > a[best_i]:
        best_i = i
```

Инициализируйте максимум **первым элементом** или `-inf` (`float("-inf")`), а не нулём: если все числа отрицательные, ноль даст неверный ответ.

**Флаг «есть ли»:**

```python
found = False
for x in a:
    if x == target:
        found = True
        break
# короче: found = target in a,  или any(x == target for x in a)
```

**Два максимума за один проход** (классика собеседований):

```python
first = second = float("-inf")
for x in a:
    if x > first:
        first, second = x, first
    elif x > second:
        second = x
```

**Серии подряд идущих элементов:**

```python
best = cur = 0
prev = None
for x in a:
    cur = cur + 1 if x == prev else 1
    prev = x
    best = max(best, cur)
```

### Вложенные циклы и их цена

```python
for i in range(n):
    for j in range(i + 1, n):
        # все пары i < j
        ...
```

Внутреннее тело выполнится n·(n−1)/2 раз. При n = 10⁵ это 5·10⁹ операций — на Python такое не пройдёт ни в какие ограничения. Умение увидеть, что двойной цикл можно заменить одним проходом со словарём или сортировкой, — главный навык следующих модулей.

### Пример: FizzBuzz без лишних проверок

Вывести числа от 1 до n, но вместо кратных 3 — `Fizz`, кратных 5 — `Buzz`, кратных 15 — `FizzBuzz`.

```python
n = 15
out = []
for i in range(1, n + 1):
    s = ""
    if i % 3 == 0:
        s += "Fizz"
    if i % 5 == 0:
        s += "Buzz"
    out.append(s or str(i))
print("\n".join(out))
```

Приём `s or str(i)`: если строка пустая (ложная), берётся число.

## Самопроверка

### Что выведет код?
```python
for i in range(10, 0, -3):
    print(i, end=" ")
```
- [ ] `10 7 4 1 0 `
- [x] `10 7 4 1 `
- [ ] `10 7 4 `
- [ ] `9 6 3 `
> Прогрессия с шагом −3 от 10, граница 0 не включается: 10, 7, 4, 1. После каждого числа печатается пробел, поэтому строка заканчивается пробелом.

### Что выведет код?
```python
print("10" < "9", 10 < 9)
```
- [ ] `False False`
- [x] `True False`
- [ ] `True True`
- [ ] `False True`
> Строки сравниваются посимвольно: `'1' < '9'`, поэтому `"10" < "9"`. Числа сравниваются как числа. Типичная ошибка — сравнивать или сортировать числа, забыв преобразовать их из строк.

### Что выведет код?
```python
x = 0
print(x or 5, x and 5)
```
- [ ] `True False`
- [x] `5 0`
- [ ] `0 5`
- [ ] `5 5`
> `or` возвращает первый истинный операнд (или последний), `and` — первый ложный (или последний). 0 ложен: `0 or 5` → 5, `0 and 5` → 0.

### Что выведет код?
```python
for i in range(3):
    if i == 5:
        break
else:
    print("без break")
```
- [x] `без break`
- [ ] Ничего
- [ ] `0 1 2`
- [ ] Ошибку синтаксиса
> `else` у цикла выполняется, если цикл закончился без `break`. Условие `i == 5` ни разу не выполнилось.

### Максимум массива ищут так: `best = 0`, затем `for x in a: best = max(best, x)`. В чём ошибка?
- [ ] `max` нельзя вызывать в цикле
- [x] Если все элементы отрицательные, ответ будет 0, которого в массиве нет
- [ ] Цикл пропустит первый элемент
- [ ] Ошибки нет
> Начальное значение максимума — первый элемент или `float("-inf")`. Ноль подходит, только если по условию числа неотрицательные.

### Сколько раз выполнится тело внутреннего цикла?
```python
for i in range(n):
    for j in range(i + 1, n):
        pass
```
- [ ] n²
- [x] n·(n−1)/2
- [ ] n·log n
- [ ] 2n
> Для каждого i внутренний цикл делает n − i − 1 шагов: (n−1) + (n−2) + … + 0 = n(n−1)/2. Асимптотически это O(n²).

### Что выведет код?
```python
a = [1, 2, 3]
b = [10, 20]
print([x + y for x, y in zip(a, b)])
```
- [ ] `[11, 22, 3]`
- [x] `[11, 22]`
- [ ] Ошибку: списки разной длины
- [ ] `[11, 22, 33]`
> `zip` останавливается на самом коротком входе, третий элемент `a` не участвует.

## Вопросы на собеседовании

### Что такое «ленивое» вычисление логических операторов и где оно полезно?
`a and b` не вычисляет `b`, если `a` ложно, `a or b` — если `a` истинно. Это позволяет ставить проверку границ перед обращением к элементу: `i < len(a) and a[i] == x` не упадёт при выходе за границу. И экономит время, когда вторая проверка дорогая. Кроме того, `and`/`or` возвращают сам операнд, а не `bool`: `name or "аноним"` — идиома значения по умолчанию.

### Какие значения в Python считаются ложными?
`False`, `None`, числовые нули (`0`, `0.0`, `0j`), пустые строки и коллекции (`""`, `[]`, `()`, `{}`, `set()`, `range(0)`), а также объекты, у которых `__bool__` возвращает `False` или `__len__` возвращает 0. Всё остальное истинно.

### Почему нельзя удалять элементы из списка во время прохода по нему for?
`for` идёт по индексам: после удаления элемента все следующие сдвигаются влево, и элемент, вставший на место удалённого, будет пропущен. Правильно — строить новый список (`[x for x in a if keep(x)]`), идти по копии (`for x in a[:]`) или идти по индексам с конца.
