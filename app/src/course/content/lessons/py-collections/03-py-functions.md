### Определение и вызов

```python
def area(width, height):
    return width * height

print(area(3, 4))     # 12
```

- `def` создаёт объект-функцию и связывает его с именем `area`.
- `return` возвращает значение и сразу завершает функцию. Функция без `return` (или с пустым `return`) возвращает `None`.
- Несколько значений возвращаются кортежем: `return lo, hi`, а распаковываются при вызове: `lo, hi = bounds(a)`.

Функции — такие же объекты, как числа: их можно класть в переменные, списки и словари, передавать в другие функции (`sorted(a, key=len)` передаёт функцию `len`).

### Позиционные и именованные аргументы

```python
def greet(name, greeting="Привет"):
    return f"{greeting}, {name}!"

greet("Аня")                      # Привет, Аня!
greet("Аня", "Здравствуй")        # позиционно
greet(greeting="Хай", name="Боб") # по имени, порядок не важен
```

Параметры со значением по умолчанию идут после обязательных.

### Как передаются аргументы

В Python аргументы передаются **по ссылке на объект** (иногда говорят «by object reference» или «by sharing»). Внутри функции параметр — новое имя для того же объекта:

```python
def add_item(lst):
    lst.append(99)      # меняем объект — изменение видно снаружи

def rebind(lst):
    lst = [0]           # перепривязали локальное имя — снаружи ничего не изменилось

a = [1]
add_item(a); rebind(a)
print(a)                # [1, 99]
```

Для неизменяемых объектов (числа, строки, кортежи) изменить их внутри функции нельзя в принципе — можно только вернуть новое значение.

### Ловушка изменяемого значения по умолчанию

```python
def append_to(x, acc=[]):
    acc.append(x)
    return acc

print(append_to(1))   # [1]
print(append_to(2))   # [1, 2] — тот же список!
```

Значение по умолчанию вычисляется **один раз, при определении функции**, и хранится в `append_to.__defaults__`. Все вызовы без `acc` делят один список. Правильно:

```python
def append_to(x, acc=None):
    if acc is None:
        acc = []
    acc.append(x)
    return acc
```

Это один из самых популярных вопросов по Python на собеседованиях.

### *args и **kwargs

```python
def total(*nums):          # любое число позиционных аргументов -> кортеж
    return sum(nums)

def show(**opts):          # любые именованные -> словарь
    for k, v in opts.items():
        print(k, v)

total(1, 2, 3)             # 6
show(color="red", size=3)
```

Звёздочки работают и в обратную сторону — при вызове распаковывают коллекцию в аргументы:

```python
args = [3, 4]
area(*args)                       # area(3, 4)
params = {"width": 3, "height": 4}
area(**params)
```

Параметры после `*` можно передать только по имени: `def f(a, *, strict=False)`. Параметры до `/` — только позиционно: `def f(a, b, /)`.

### Области видимости: правило LEGB

Имя ищется по очереди в четырёх областях:

1. **L**ocal — внутри текущей функции;
2. **E**nclosing — во внешних функциях, если функция вложенная;
3. **G**lobal — на уровне модуля (файла);
4. **B**uilt-in — встроенные имена: `len`, `print`, `max`.

```python
x = "global"

def outer():
    x = "enclosing"
    def inner():
        print(x)      # enclosing — нашли в объемлющей функции
    inner()

outer()
```

Присваивание внутри функции делает имя **локальным для всей функции**. Поэтому так нельзя:

```python
count = 0
def inc():
    count += 1        # UnboundLocalError: count локальная, но ещё не присвоена
```

Чтобы менять глобальную переменную, нужен `global count`, а переменную объемлющей функции — `nonlocal count`. В хорошем коде `global` встречается редко: лучше передать значение аргументом и вернуть результат.

Не называйте переменные именами встроенных функций: после `list = [1, 2]` или `max = 5` встроенные `list()` и `max()` в этой области станут недоступны — типичная причина загадочных ошибок на контесте.

### lambda — функция в одно выражение

```python
square = lambda x: x * x
pairs.sort(key=lambda p: p[1])
```

`lambda` удобна как короткий аргумент для `sorted`, `min`, `max`. Присваивать `lambda` имени, как в первой строке, PEP 8 не рекомендует — для этого есть `def`.

Модуль `operator` даёт готовые функции-ключи: `operator.itemgetter(1)` — то же, что `lambda p: p[1]`, но быстрее.

### Замыкания — кратко

Вложенная функция «запоминает» переменные объемлющей функции даже после её завершения:

```python
def make_counter():
    count = 0
    def inc():
        nonlocal count
        count += 1
        return count
    return inc

c = make_counter()
c(); c()
print(c())   # 3
```

На этом построены декораторы. Подробно — в модуле «Python изнутри».

### Рекурсия

Функция может вызывать саму себя. Нужны **база** (когда остановиться) и **шаг**, приближающий к базе:

```python
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)
```

Каждый вызов занимает кадр в стеке вызовов. В CPython глубина по умолчанию ограничена примерно **1000** — дальше `RecursionError`. Для рекурсивного обхода графа на 10⁵ вершин лимит поднимают `sys.setrecursionlimit(10**6)`, но тогда может закончиться сам стек потока; в контесте рекурсию запускают в потоке с увеличенным стеком или переписывают на явный стек. Подробно — в уроках про контест и рекурсию.

### Функции и скорость

- Локальные переменные читаются быстрее глобальных, поэтому код решения лучше класть в функцию `main()`.
- Вызов функции в Python относительно дорогой (сотни наносекунд). В горячем цикле на 10⁷ итераций лишний вызов заметен.
- `functools.lru_cache` превращает рекурсивную функцию с повторяющимися подзадачами в мемоизированную — одна строка вместо ручного словаря (модуль «Динамическое программирование»).

## Самопроверка

### Что выведет код?
```python
def f(x, acc=[]):
    acc.append(x)
    return len(acc)

print(f(1), f(2), f(3, []))
```
- [ ] `1 1 1`
- [x] `1 2 1`
- [ ] `1 2 3`
- [ ] Ошибку
> Список по умолчанию создан один раз при определении функции, поэтому второй вызов видит элемент из первого. Третий вызов получил свой новый список.

### Что выведет код?
```python
def change(a, b):
    a.append(1)
    b = b + [1]

x, y = [], []
change(x, y)
print(x, y)
```
- [ ] `[1] [1]`
- [x] `[1] []`
- [ ] `[] []`
- [ ] `[] [1]`
> `append` меняет объект, на который указывают и `a`, и `x`. `b = b + [1]` создаёт новый список и перепривязывает только локальное имя `b`.

### Что произойдёт?
```python
n = 0
def inc():
    n += 1
inc()
```
- [ ] `n` станет 1
- [x] `UnboundLocalError`
- [ ] `NameError`
- [ ] Ничего
> Присваивание делает `n` локальной для всей функции, а читать её до присваивания нельзя. Нужно `global n` — или, лучше, вернуть новое значение.

### Что выведет код?
```python
def f(*args, **kwargs):
    print(len(args), sorted(kwargs))

f(1, 2, x=3, y=4)
```
- [ ] `4 []`
- [x] `2 ['x', 'y']`
- [ ] `2 [3, 4]`
- [ ] `(1, 2) {'x': 3, 'y': 4}`
> Позиционные аргументы собираются в кортеж `args`, именованные — в словарь `kwargs`. `sorted` словаря возвращает отсортированные ключи.

### Что выведет код?
```python
x = 1
def outer():
    x = 2
    def inner():
        return x
    x = 3
    return inner()

print(outer())
```
- [ ] `1`
- [ ] `2`
- [x] `3`
- [ ] Ошибку
> Вложенная функция берёт переменную из объемлющей области в момент вызова, а не определения. К вызову `inner()` значение `x` уже 3.

### Что вернёт функция без оператора return?
- [ ] 0
- [x] `None`
- [ ] Пустую строку
- [ ] Ошибку
> Любая функция в Python что-то возвращает; без `return` — `None`.

### Какой примерно предел глубины рекурсии в CPython по умолчанию?
- [ ] 100
- [x] 1000
- [ ] 10⁶
- [ ] Предела нет
> `sys.getrecursionlimit()` по умолчанию 1000. Для глубокой рекурсии предел поднимают `sys.setrecursionlimit` и увеличивают стек потока — или переписывают обход на явный стек.

## Вопросы на собеседовании

### Как в Python передаются аргументы — по значению или по ссылке?
Ни то ни другое в классическом смысле: передаётся ссылка на объект (call by sharing). Параметр — новое имя для того же объекта. Изменение изменяемого объекта внутри функции (`lst.append`) видно снаружи. Присваивание параметру (`lst = ...`) только перепривязывает локальное имя. Неизменяемые объекты изменить нельзя вовсе, поэтому для них поведение выглядит как передача по значению.

### Почему нельзя использовать изменяемый объект как значение по умолчанию?
Значения по умолчанию вычисляются один раз — при выполнении `def` — и хранятся в атрибуте функции `__defaults__`. Если это список или словарь, все вызовы без этого аргумента разделяют один объект, и изменения накапливаются между вызовами. Шаблон: `param=None` и создание нового объекта внутри функции.

### Что такое LEGB?
Порядок поиска имён: Local (текущая функция), Enclosing (объемлющие функции), Global (модуль), Built-in (встроенные имена). Присваивание внутри функции делает имя локальным, если нет объявлений `global` или `nonlocal`. Поэтому `count += 1` для внешней переменной без `nonlocal`/`global` падает с `UnboundLocalError`.

### Что такое *args и **kwargs?
Синтаксис для произвольного числа аргументов: `*args` собирает лишние позиционные аргументы в кортеж, `**kwargs` — именованные в словарь. При вызове `f(*seq)` и `f(**mapping)` распаковывают коллекцию в аргументы. Применяются в обёртках и декораторах, которые должны пробросить любые аргументы дальше.
