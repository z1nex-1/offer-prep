### Словарь: ключ → значение

```python
ages = {"Аня": 20, "Боря": 22}
ages["Вика"] = 19          # добавить или перезаписать
print(ages["Аня"])         # 20
print(len(ages))           # 3
del ages["Боря"]
print("Боря" in ages)      # False — проверка наличия КЛЮЧА
```

`dict` реализован хеш-таблицей: поиск, вставка и удаление по ключу — **O(1) в среднем**. Это главный инструмент ускорения решений: всё, что в наивном решении ищется проходом по списку за O(n), со словарём находится за O(1).

Обращение к отсутствующему ключу `ages["Гоша"]` бросает `KeyError`. Безопасные варианты:

```python
ages.get("Гоша")          # None
ages.get("Гоша", 0)       # 0 — значение по умолчанию
ages.setdefault("Гоша", 18)   # вернуть значение, а если ключа нет — сначала записать 18
```

### Обход словаря

```python
for name in ages:                 # по ключам
    ...
for name, age in ages.items():    # пары ключ-значение
    ...
for age in ages.values():         # значения
    ...
```

С Python 3.7 словарь **гарантированно сохраняет порядок вставки** ключей. Перезапись значения существующего ключа порядок не меняет.

Во время обхода нельзя добавлять и удалять ключи — `RuntimeError: dictionary changed size during iteration`. Если нужно удалять — идите по копии ключей: `for k in list(d):`.

### Создание словарей

```python
d = dict(a=1, b=2)                      # {'a': 1, 'b': 2}
d = dict(zip(keys, values))
d = {x: x * x for x in range(5)}        # генератор словаря
pos = {v: i for i, v in enumerate(a)}   # значение -> индекс (последнее вхождение)
inv = {v: k for k, v in d.items()}      # обратить словарь
```

Сортировка по значениям:

```python
top = sorted(freq.items(), key=lambda kv: (-kv[1], kv[0]))   # по убыванию частоты, при равенстве по ключу
```

### Что может быть ключом: хешируемость

Ключ должен быть **хешируемым**: иметь хеш, который не меняется за время жизни объекта, и корректное сравнение `==`. Хешируемы: числа, строки, `bool`, `None`, кортежи из хешируемых, `frozenset`. Нехешируемы: `list`, `dict`, `set`.

Нужно использовать список как ключ — превратите в кортеж: `key = tuple(sorted(word))` — классический ключ для группировки анаграмм.

Тонкость: `1`, `1.0` и `True` равны и имеют одинаковый хеш, поэтому в словаре это **один** ключ: `{1: "a", True: "b"}` даёт `{1: 'b'}`.

### Множество: только ключи

```python
seen = set()             # пустое множество — только так; {} — это пустой словарь!
seen.add(3)
seen.discard(5)          # удалить, если есть (remove бросит KeyError)
print(3 in seen)         # O(1) в среднем
s = set([1, 2, 2, 3])    # {1, 2, 3} — убрать дубликаты
```

Операции над множествами:

| Операция | Смысл | Сложность |
|---|---|---|
| `a \| b` | объединение | O(len(a) + len(b)) |
| `a & b` | пересечение | O(min(len(a), len(b))) |
| `a - b` | разность | O(len(a)) |
| `a ^ b` | симметрическая разность | O(len(a) + len(b)) |
| `a <= b` | a — подмножество b | O(len(a)) |

`len(set(a)) == len(a)` — проверка, что в списке нет повторов. Порядок элементов множества не гарантирован: не полагайтесь на него при выводе, сортируйте.

`frozenset` — неизменяемое хешируемое множество, может быть ключом словаря.

### Counter: подсчёт частот

```python
from collections import Counter

cnt = Counter("abracadabra")
print(cnt)                  # Counter({'a': 5, 'b': 2, 'r': 2, 'c': 1, 'd': 1})
print(cnt["a"], cnt["z"])   # 5 0 — отсутствующий ключ даёт 0, а не KeyError
print(cnt.most_common(2))   # [('a', 5), ('b', 2)]
cnt["z"] += 1               # можно увеличивать, не проверяя наличие
```

`Counter` — подкласс `dict`. Два счётчика можно сравнить (`Counter(a) == Counter(b)` — проверка анаграмм), сложить и вычесть. Вычитание `c1 - c2` отбрасывает неположительные значения.

Ручной подсчёт без `Counter` — на собеседовании могут попросить именно его:

```python
freq = {}
for x in a:
    freq[x] = freq.get(x, 0) + 1
```

### defaultdict: значение по умолчанию

```python
from collections import defaultdict

groups = defaultdict(list)
for word in words:
    groups[len(word)].append(word)   # если ключа нет, создаётся пустой список

graph = defaultdict(list)
for u, v in edges:
    graph[u].append(v)
    graph[v].append(u)
```

При обращении к отсутствующему ключу `defaultdict` вызывает фабрику (`list`, `int`, `set`) и записывает результат. Внимание: даже простое **чтение** `groups[k]` создаёт ключ. Для проверки наличия используйте `k in groups`.

### Главные приёмы со словарями и множествами

**Уникальные элементы с сохранением порядка:**

```python
unique = list(dict.fromkeys(a))
```

**Первый повторяющийся элемент:**

```python
seen = set()
for x in a:
    if x in seen:
        print(x)
        break
    seen.add(x)
```

**Пара с суммой target за один проход** — самая известная задача собеседований:

```python
def two_sum(a, target):
    pos = {}
    for i, x in enumerate(a):
        if target - x in pos:
            return pos[target - x], i
        pos[x] = i
    return None
```

Вместо двойного цикла O(n²) — один проход O(n): для каждого числа спрашиваем словарь, встречалось ли дополнение. Порядок «сначала проверить, потом добавить» не даёт взять один элемент дважды.

**Группировка:**

```python
by_key = defaultdict(list)
for word in words:
    by_key["".join(sorted(word))].append(word)
```

### Сложность: «в среднем» — это важно

O(1) у словаря — средняя оценка. Если много ключей попадает в одну ячейку хеш-таблицы (коллизии), операции деградируют до O(n). На случайных данных это не происходит. Как устроена хеш-таблица, почему бывают коллизии и что такое открытая адресация — в модуле «Хеш-таблицы».

## Самопроверка

### Что выведет код?
```python
d = {"a": 1}
print(d.get("b", 0), "a" in d, 1 in d)
```
- [ ] `None True True`
- [x] `0 True False`
- [ ] `0 True True`
- [ ] Ошибку KeyError
> `get` с умолчанием не бросает исключение. `in` для словаря проверяет ключи, а не значения, поэтому `1 in d` ложно.

### Что выведет код?
```python
print(type({}), type(set()))
```
- [ ] `<class 'set'> <class 'set'>`
- [x] `<class 'dict'> <class 'set'>`
- [ ] `<class 'dict'> <class 'dict'>`
- [ ] Ошибку
> Пустые фигурные скобки — это словарь. Пустое множество создаётся только через `set()`.

### Что выведет код?
```python
from collections import Counter
c = Counter("hello")
print(c["l"], c["z"])
```
- [ ] `2 None`
- [x] `2 0`
- [ ] `1 0`
- [ ] Ошибку KeyError
> `Counter` для отсутствующего ключа возвращает 0 и не создаёт ключ.

### Что выведет код?
```python
d = {1: "a", True: "b", 1.0: "c"}
print(len(d), d[1])
```
- [ ] `3 a`
- [x] `1 c`
- [ ] `2 c`
- [ ] `1 a`
> `1`, `True` и `1.0` равны и имеют одинаковый хеш — это один ключ. Значение перезаписывается последним, а сам ключ остаётся первым вставленным (`1`).

### Почему `[1, 2]` нельзя использовать как ключ словаря?
- [ ] Ключи могут быть только строками
- [x] Список изменяем и нехешируем: его хеш мог бы поменяться после вставки
- [ ] Списки слишком большие
- [ ] Можно, если список короткий
> Хеш ключа не должен меняться, иначе элемент «потеряется» в таблице. Поэтому изменяемые встроенные коллекции нехешируемы. Список превращают в кортеж.

### Нужно проверять вхождение 10⁵ разных чисел в набор из 10⁵ чисел. Какую структуру выбрать для набора?
- [ ] Список: `x in list`
- [x] Множество: `x in set`
- [ ] Отсортированный список и `in`
- [ ] Строку со всеми числами
> Каждая проверка в списке — O(n), итого 10¹⁰ операций. Во множестве — O(1) в среднем, итого 10⁵.

### Что выведет код?
```python
from collections import defaultdict
g = defaultdict(list)
x = g["a"]
print(len(g), "b" in g, len(g))
```
- [ ] `0 False 0`
- [x] `1 False 1`
- [ ] `1 False 2`
- [ ] Ошибку KeyError
> Чтение `g["a"]` создало ключ с пустым списком. Оператор `in` ключ не создаёт.

### Что выведет код?
```python
a = {1, 2, 3}
b = {2, 3, 4}
print(sorted(a & b), sorted(a - b), sorted(a ^ b))
```
- [ ] `[2, 3] [1, 4] [1, 4]`
- [x] `[2, 3] [1] [1, 4]`
- [ ] `[1, 2, 3, 4] [1] [4]`
- [ ] `[2, 3] [4] [1]`
> Пересечение — общие элементы, разность `a - b` — есть в `a`, но нет в `b`, симметрическая разность — есть ровно в одном из множеств.

## Вопросы на собеседовании

### Как устроен словарь в Python и какая сложность операций?
Хеш-таблица с открытой адресацией. С версии 3.6 хранит компактный массив записей в порядке вставки и отдельную разреженную таблицу индексов; порядок вставки гарантирован с 3.7. Поиск, вставка и удаление — O(1) в среднем и O(n) в худшем случае при множестве коллизий. Таблица увеличивается, когда заполняется примерно на две трети, поэтому вставка — амортизированно O(1).

### Что такое хешируемый объект?
У объекта есть `__hash__`, возвращающий число, которое не меняется за время жизни объекта, и `__eq__`, согласованный с ним: равные объекты обязаны иметь равные хеши. Неизменяемые встроенные типы хешируемы, изменяемые коллекции — нет. Экземпляры пользовательских классов по умолчанию хешируемы по идентичности (`id`); если переопределить `__eq__`, хеш нужно определить явно, иначе класс станет нехешируемым.

### Чем defaultdict отличается от dict.get и setdefault?
`defaultdict(factory)` при обращении к отсутствующему ключу сам создаёт значение вызовом фабрики и записывает его — код группировки и подсчёта становится короче. `get(k, default)` только возвращает умолчание, ничего не записывая. `setdefault(k, default)` записывает умолчание, если ключа нет, и возвращает значение, но объект-умолчание создаётся при каждом вызове, даже когда ключ уже есть. Подвох `defaultdict`: даже чтение отсутствующего ключа добавляет его.

### Как найти в массиве два числа с суммой target быстрее, чем за O(n²)?
Один проход со словарём «значение → индекс»: для текущего `x` проверяем, есть ли в словаре `target - x`; если есть — ответ найден, иначе добавляем `x`. O(n) времени и O(n) памяти. Если массив отсортирован, можно без памяти — двумя указателями с концов за O(n).
