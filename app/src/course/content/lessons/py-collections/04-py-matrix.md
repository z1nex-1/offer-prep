### Матрица — список списков

Матрица из `n` строк и `m` столбцов в Python — это список из `n` списков по `m` элементов. Элемент в строке `i` и столбце `j` — `a[i][j]`: сначала строка, потом столбец.

```python
a = [[1, 2, 3],
     [4, 5, 6]]
n, m = len(a), len(a[0])   # 2 строки, 3 столбца
print(a[1][0])             # 4: строка 1, столбец 0
```

Как создать матрицу нулей и почему нельзя писать `[[0] * m] * n`, разобрано в уроке «Списки и кортежи»: правильно `[[0] * m for _ in range(n)]`.

### Чтение и вывод

Типичный вход: в первой строке `n m`, дальше `n` строк по `m` чисел.

```python
import sys

data = sys.stdin.read().split()
n, m = int(data[0]), int(data[1])
a = [[int(data[2 + i * m + j]) for j in range(m)] for i in range(n)]
```

Или построчно, если строк немного:

```python
n, m = map(int, input().split())
a = [list(map(int, input().split())) for _ in range(n)]
```

Поле из символов (`#` — стена, `.` — пусто) удобнее хранить списком строк: `grid = [input() for _ in range(n)]`. Строки неизменяемы, поэтому если клетки нужно менять — превратите строку в список: `grid = [list(input()) for _ in range(n)]`, а при выводе соберите обратно: `''.join(row)`.

Вывод матрицы — одна строка кода:

```python
print('\n'.join(' '.join(map(str, row)) for row in a))
```

`print(a)` напечатает `[[1, 2, 3], [4, 5, 6]]` со скобками и запятыми — это WA.

### Обход по строкам и столбцам

```python
row_sums = [sum(row) for row in a]
col_sums = [sum(a[i][j] for i in range(n)) for j in range(m)]
```

Для столбцов удобнее `zip(*a)`: звёздочка раскладывает матрицу на отдельные строки, а `zip` берёт из них элементы с одинаковым индексом — то есть столбцы.

```python
a = [[1, 2, 3],
     [4, 5, 6]]
print(list(zip(*a)))          # [(1, 4), (2, 5), (3, 6)]
col_sums = [sum(c) for c in zip(*a)]   # [5, 7, 9]
```

### Транспонирование и поворот

Транспонированная матрица — строки становятся столбцами: элемент `a[i][j]` переходит в `t[j][i]`, размер меняется с `n × m` на `m × n`.

```python
t = [list(col) for col in zip(*a)]
```

Поворот на 90° по часовой стрелке — это «перевернуть строки, затем транспонировать»:

```python
a = [[1, 2, 3],
     [4, 5, 6]]
cw = [list(r) for r in zip(*a[::-1])]
print(cw)   # [[4, 1], [5, 2], [6, 3]]
```

Проверим на картинке: первая строка повёрнутой матрицы — это первый столбец исходной, прочитанный снизу вверх: 4, 1. Против часовой стрелки — «транспонировать, затем перевернуть строки»: `[list(r) for r in zip(*a)][::-1]`.

Эти формулы легко перепутать. Надёжный способ на секции — проверить на матрице 2 × 3, как выше: неквадратная матрица сразу показывает, где перепутаны `n` и `m`.

### Диагонали

У квадратной матрицы `n × n`:

- главная диагональ — клетки, где `i == j`: `sum(a[i][i] for i in range(n))`;
- побочная — где `i + j == n - 1`: `sum(a[i][n - 1 - i] for i in range(n))`.

Все диагонали, параллельные главной, — это клетки с одинаковым `i - j`, параллельные побочной — с одинаковым `i + j`. Сгруппировать элементы по диагоналям можно словарём:

```python
from collections import defaultdict

diag = defaultdict(list)
for i in range(n):
    for j in range(m):
        diag[i - j].append(a[i][j])
```

Этот же приём используется в задаче о ферзях: два ферзя бьют друг друга по диагонали, если у них совпадает `i - j` или `i + j`.

### Обход по спирали

Классическая задача собеседования: выписать элементы матрицы по спирали — по первой строке вправо, по последнему столбцу вниз, по последней строке влево, по первому столбцу вверх, и так далее внутрь.

Держим четыре границы ещё не пройденной части и сдвигаем их после каждой стороны:

```python
def spiral(a):
    res = []
    top, bottom, left, right = 0, len(a) - 1, 0, len(a[0]) - 1
    while top <= bottom and left <= right:
        for j in range(left, right + 1):
            res.append(a[top][j])
        top += 1
        for i in range(top, bottom + 1):
            res.append(a[i][right])
        right -= 1
        if top <= bottom:
            for j in range(right, left - 1, -1):
                res.append(a[bottom][j])
            bottom -= 1
        if left <= right:
            for i in range(bottom, top - 1, -1):
                res.append(a[i][left])
            left += 1
    return res
```

Две проверки внутри цикла нужны для матриц из одной строки или одного столбца: без них средняя строка матрицы 3 × 1 была бы выписана дважды — сначала вниз, потом вверх. Проверьте код на матрицах 1 × 1, 1 × 4, 4 × 1 и 3 × 3 — это и есть тестовые примеры, которые стоит назвать интервьюеру.

### Плоский индекс

Клетку `(i, j)` матрицы `n × m` можно записать одним числом `k = i * m + j` — так нумеруются клетки при чтении по строкам. Обратно: `i = k // m`, `j = k % m`. Это пригодится, когда клетки нужно положить в множество или использовать как вершины графа, хотя в Python кортеж `(i, j)` в множестве тоже работает.

### Изменять на месте или строить новую матрицу

Если новое значение клетки зависит от соседей (как в игре «Жизнь»), нельзя обновлять матрицу на месте: соседи, обработанные раньше, уже будут новыми. Стройте новую матрицу и заменяйте старую целиком:

```python
new = [[0] * m for _ in range(n)]
# ... заполняем new по старой a ...
a = new
```

Копия `a.copy()` или `a[:]` здесь не поможет: она копирует только внешний список, а строки остаются общими. Для полной копии — `[row[:] for row in a]`.

### Сложность и память

Обход матрицы `n × m` — O(n · m). При `n = m = 1000` это 10⁶ клеток: на Python такой обход занимает порядка секунды, если внутри цикла много работы. Помогают `zip(*a)`, `sum` и генераторы списков — они выполняются внутри интерпретатора быстрее явных вложенных циклов. Матрица 1000 × 1000 из чисел занимает около 8 МБ только на ссылки, плюс сами числа.

### Типичные ошибки

- Путать `a[i][j]` и `a[j][i]` — особенно в неквадратной матрице. Тестируйте на 2 × 3.
- `[[0] * m] * n` — все строки один и тот же объект.
- Изменять строку поля как строку: `grid[i][j] = '#'` для `str` даёт `TypeError`.
- Обновлять матрицу на месте, когда новое значение зависит от старых соседей.
- Печатать матрицу через `print(a)` вместо построчного вывода через `join`.
- Спираль без проверок `top <= bottom` и `left <= right` внутри цикла — дубли на вырожденных матрицах.

## Самопроверка

### Что выведет код?
```python
a = [[1, 2, 3], [4, 5, 6]]
print([sum(c) for c in zip(*a)])
```
- [ ] `[6, 15]`
- [x] `[5, 7, 9]`
- [ ] `[21]`
- [ ] `[(1, 4), (2, 5), (3, 6)]`
> `zip(*a)` выдаёт столбцы `(1, 4)`, `(2, 5)`, `(3, 6)`, их суммы — 5, 7, 9. Суммы строк были бы 6 и 15.

### Что выведет код?
```python
a = [[1, 2], [3, 4], [5, 6]]
print([list(r) for r in zip(*a[::-1])])
```
- [ ] `[[1, 3, 5], [2, 4, 6]]`
- [x] `[[5, 3, 1], [6, 4, 2]]`
- [ ] `[[2, 4, 6], [1, 3, 5]]`
- [ ] `[[6, 4, 2], [5, 3, 1]]`
> Это поворот по часовой стрелке: первая строка результата — первый столбец исходной матрицы снизу вверх (5, 3, 1). Размер 3 × 2 стал 2 × 3.

### Что выведет код?
```python
a = [[0, 0], [0, 0]]
b = a.copy()
b[0][0] = 7
print(a[0][0])
```
- [ ] `0`
- [x] `7`
- [ ] `None`
- [ ] `IndexError`
> `copy()` копирует только внешний список: `b[0]` и `a[0]` — один и тот же объект. Полная копия матрицы — `[row[:] for row in a]`.

### У каких клеток матрицы одинаковое значение `i + j`?
- [ ] На одной строке
- [ ] На главной диагонали и параллельных ей
- [x] На побочной диагонали и параллельных ей
- [ ] На одном столбце
> При шаге вправо-вверх `i` уменьшается на 1, а `j` растёт на 1 — сумма сохраняется. Для главной диагонали сохраняется разность `i - j`.

### Зачем в обходе по спирали проверки `if top <= bottom` и `if left <= right` внутри цикла?
- [ ] Для скорости
- [x] Без них матрица из одной строки или одного столбца даст повторяющиеся элементы
- [ ] Чтобы не было IndexError на квадратной матрице
- [ ] Они не нужны, условие цикла всё проверяет
> Условие `while` проверяется только в начале витка. После прохода по верхней строке и правому столбцу границы могут уже сойтись, и обратные проходы повторили бы те же клетки.

## Вопросы на собеседовании

### Как повернуть матрицу на 90° по часовой стрелке в Python?
Перевернуть порядок строк и транспонировать: `[list(r) for r in zip(*a[::-1])]`. Время и память O(n · m). Для квадратной матрицы поворот на месте без дополнительной памяти делают так: транспонируют на месте, меняя `a[i][j]` и `a[j][i]` при `j > i`, затем разворачивают каждую строку.

### Как обойти матрицу по спирали?
Хранить четыре границы непройденной области — `top`, `bottom`, `left`, `right`. Пройти верхнюю строку и сдвинуть `top`, правый столбец и сдвинуть `right`, затем, если область не пуста, нижнюю строку и левый столбец. Сложность O(n · m). Тестовые примеры: 1 × 1, одна строка, один столбец, квадрат 3 × 3.

### Что делает `zip(*a)` для матрицы?
`*a` передаёт строки матрицы в `zip` отдельными аргументами, а `zip` собирает кортежи из элементов с одинаковыми индексами — это столбцы. Получается транспонированная матрица из кортежей. Если строки разной длины, `zip` обрежет всё по самой короткой.
