### Проблема

Дан массив и много запросов «чему равна сумма на отрезке `[l, r]`?». Считать каждый раз циклом — O(n) на запрос, O(n·q) всего. При n и q до 10⁵ это 10¹⁰.

### Префиксные суммы

Посчитаем заранее `pref[i]` — сумму первых `i` элементов:

```python
pref = [0] * (n + 1)
for i in range(n):
    pref[i + 1] = pref[i] + a[i]
# или: from itertools import accumulate; pref = list(accumulate(a, initial=0))
```

Тогда сумма отрезка `a[l..r]` (включительно, индексы с нуля) — `pref[r + 1] - pref[l]`. Каждый запрос — O(1), предподсчёт — O(n).

Почему массив на единицу длиннее и начинается с нуля: так формула одинакова для всех отрезков, включая начинающиеся с индекса 0, — нет отдельного случая `l == 0`. Это то, что Яндекс называет «минимальной обработкой специальных случаев».

```
a    =    [3, 1, 4, 1, 5]
pref = [0, 3, 4, 8, 9, 14]
сумма a[1..3] = pref[4] - pref[1] = 9 - 3 = 6   (1 + 4 + 1)
```

### Применения

- **Средняя на отрезке**, **количество элементов с условием на отрезке** — префиксная сумма индикаторов: `pref[i+1] = pref[i] + (1 if a[i] чётное else 0)`.
- **Отрезок с суммой k** — префиксные суммы плюс словарь (урок «Приёмы с хеш-таблицами»).
- **Баланс скобок**, **«когда впервые накопилось…»** — префикс как траектория.
- **Равновесный индекс** — позиция, где сумма слева равна сумме справа: `pref[i] == total - pref[i + 1]`.

Префиксные суммы работают для любой **обратимой** операции: сумма (обратная — вычитание), XOR (обратная — сам XOR), произведение без нулей (деление). Для минимума и максимума так нельзя — у них нет обратной операции; для запросов минимума на отрезке нужны другие структуры (разреженная таблица, дерево отрезков, а для окна фиксированной длины — монотонная очередь).

### Двумерные префиксные суммы

Сумма в прямоугольнике матрицы — формула включений-исключений:

```python
P = [[0] * (m + 1) for _ in range(n + 1)]
for i in range(n):
    for j in range(m):
        P[i + 1][j + 1] = g[i][j] + P[i][j + 1] + P[i + 1][j] - P[i][j]

def rect(r1, c1, r2, c2):        # включительно
    return P[r2 + 1][c2 + 1] - P[r1][c2 + 1] - P[r2 + 1][c1] + P[r1][c1]
```

`P[i][j]` — сумма прямоугольника от `(0, 0)` до `(i-1, j-1)`. При вычитании двух полос их общий угол вычитается дважды — поэтому его прибавляют обратно. Нарисуйте картинку: на собеседовании формула выводится за минуту.

### Разностный массив

Обратная задача: много операций «прибавить `v` ко всем элементам на `[l, r]`», а в конце нужен итоговый массив.

```python
diff = [0] * (n + 1)
for l, r, v in ops:
    diff[l] += v
    diff[r + 1] -= v
cur = 0
res = []
for i in range(n):
    cur += diff[i]
    res.append(a[i] + cur)
```

Каждая операция — O(1), восстановление — O(n). Итого O(n + q) вместо O(n·q).

Разностный массив — это «префиксная сумма наоборот»: префиксная сумма разностного массива даёт исходный. На нём держится метод событий на целых координатах: «сколько отрезков покрывает точку t».

### Префиксные суммы на строках и подсчёт

Число гласных в `s[l..r]` для многих запросов — префикс индикаторов. Частоты всех 26 букв на отрезке — 26 префиксных массивов или список префиксов-кортежей. Проверка «можно ли переставить буквы отрезка в палиндром» — префиксный XOR битовых масок букв: буква с нечётной частотой даёт единицу в маске.

### Подводные камни

- **Путаница индексов.** Договоритесь: `pref[i]` — сумма первых i элементов. Тогда отрезок `[l, r]` включительно — `pref[r+1] - pref[l]`, полуинтервал `[l, r)` — `pref[r] - pref[l]`.
- **Индексация с единицы во вводе.** В задачах контеста отрезки часто задают с 1: `l, r` — тогда сумма `pref[r] - pref[l - 1]`.
- **Переполнение** в Python не страшно, но на собеседовании на C++/Java об этом спрашивают.

## Самопроверка

### Как по массиву `pref` длины n+1 (`pref[0] = 0`) найти сумму `a[l..r]` включительно?
- [ ] `pref[r] - pref[l]`
- [x] `pref[r + 1] - pref[l]`
- [ ] `pref[r] - pref[l - 1]`
- [ ] `pref[r + 1] - pref[l + 1]`
> `pref[r + 1]` — сумма первых r+1 элементов (индексы 0..r), вычитаем первые l элементов.

### Что выведет код?
```python
from itertools import accumulate
a = [2, -1, 3, 4]
p = list(accumulate(a, initial=0))
print(p[3] - p[1])
```
- [ ] `5`
- [x] `2`
- [ ] `6`
- [ ] `-1`
> `p = [0, 2, 1, 4, 8]`, `p[3] - p[1] = 4 - 2 = 2` — это сумма `a[1] + a[2] = -1 + 3`.

### Можно ли префиксными суммами отвечать на запросы минимума на отрезке?
- [ ] Да, так же как для суммы
- [x] Нет: у минимума нет обратной операции, «вычесть» префикс нельзя
- [ ] Да, если массив положительный
- [ ] Да, через XOR
> Префиксы работают для обратимых операций: сумма, XOR. Для минимума нужны разреженная таблица, дерево отрезков или монотонная очередь.

### Что выведет код?
```python
n = 5
diff = [0] * (n + 1)
for l, r, v in [(0, 2, 1), (1, 4, 2)]:
    diff[l] += v
    diff[r + 1] -= v
cur, res = 0, []
for i in range(n):
    cur += diff[i]
    res.append(cur)
print(res)
```
- [ ] `[1, 2, 2, 2, 2]`
- [x] `[1, 3, 3, 2, 2]`
- [ ] `[1, 3, 3, 3, 2]`
- [ ] `[3, 3, 3, 2, 2]`
> Первая операция прибавляет 1 к позициям 0–2, вторая — 2 к позициям 1–4.

### Сколько стоит q операций «прибавить на отрезке» разностным массивом и восстановление итогового массива?
- [ ] O(n·q)
- [x] O(n + q)
- [ ] O(q log n)
- [ ] O(n log q)
> Каждая операция меняет два элемента, восстановление — один проход префиксной суммы.

### Зачем в формуле двумерной префиксной суммы прибавляют `P[i][j]`?
- [ ] Это ошибка
- [x] Общий угол двух вычитаемых полос вычтен дважды, и его нужно вернуть
- [ ] Чтобы учесть элемент `g[i][j]`
- [ ] Для отрицательных чисел
> Включения-исключения: `P[i][j+1] + P[i+1][j]` содержат прямоугольник `P[i][j]` дважды.

## Вопросы на собеседовании

### Как быстро отвечать на запросы суммы на отрезке?
Предподсчитать префиксные суммы за O(n): `pref[0] = 0`, `pref[i+1] = pref[i] + a[i]`. Сумма `a[l..r]` = `pref[r+1] - pref[l]` за O(1). Если массив меняется между запросами, префиксы не подходят — нужно дерево Фенвика или дерево отрезков с O(log n) на запрос и изменение.

### Что такое разностный массив?
Массив `d`, где `d[i] = a[i] - a[i-1]`. Прибавление v на отрезке `[l, r]` меняет только `d[l] += v` и `d[r+1] -= v`. После всех операций префиксная сумма `d` восстанавливает массив. Позволяет выполнить q прибавлений на отрезках за O(n + q).
