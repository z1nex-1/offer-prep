### Окно фиксированной длины

Максимальная сумма k подряд идущих элементов. Наивно — сумма каждого окна заново, O(n·k). Окно: при сдвиге на один элемент прибавляем вошедший и вычитаем вышедший.

```python
def max_window_sum(a, k):
    cur = sum(a[:k])
    best = cur
    for i in range(k, len(a)):
        cur += a[i] - a[i - k]
        best = max(best, cur)
    return best
```

O(n). Тот же приём для «количество гласных в окне», «число различных элементов в окне» (словарь частот: при выходе элемента уменьшаем счётчик и удаляем ключ при нуле), «является ли окно анаграммой шаблона» (сравниваем счётчики, лучше — поддерживаем число совпавших букв).

### Окно переменной длины: самое длинное

Шаблон: правая граница `r` идёт по всем позициям, левая `l` сдвигается, пока окно **плохое**. После сдвига окно `[l, r]` — самое длинное хорошее, заканчивающееся в `r`.

Самая длинная подстрока без повторяющихся символов:

```python
def longest_unique(s):
    last = {}             # символ -> последняя позиция
    l = best = 0
    for r, ch in enumerate(s):
        if ch in last and last[ch] >= l:
            l = last[ch] + 1          # прыгаем сразу за предыдущее вхождение
        last[ch] = r
        best = max(best, r - l + 1)
    return best
```

Общий вариант со счётчиками:

```python
from collections import defaultdict

def longest_with_at_most_k_distinct(s, k):
    cnt = defaultdict(int)
    l = best = 0
    for r, ch in enumerate(s):
        cnt[ch] += 1
        while len(cnt) > k:          # окно плохое — сужаем слева
            cnt[s[l]] -= 1
            if cnt[s[l]] == 0:
                del cnt[s[l]]
            l += 1
        best = max(best, r - l + 1)
    return best
```

**Самый длинный отрезок из единиц, если можно заменить не больше k нулей** — окно, в котором не больше k нулей. Это обобщение задачи Яндекса про «удалить один элемент».

### Окно переменной длины: самое короткое

Шаблон: `r` расширяет окно, и **пока окно хорошее** — обновляем ответ и сдвигаем `l`.

Самый короткий подмассив с суммой не меньше `s` (все числа положительные):

```python
def min_len_sum(a, s):
    l = cur = 0
    best = float("inf")
    for r, x in enumerate(a):
        cur += x
        while cur >= s:
            best = min(best, r - l + 1)
            cur -= a[l]
            l += 1
    return best if best != float("inf") else 0
```

«Минимальное окно, содержащее все символы шаблона» — тот же шаблон со счётчиком недостающих символов.

### Подсчёт подмассивов с условием

Сколько подмассивов, в которых не больше k различных чисел? Для каждого `r` все отрезки `[l', r]` с `l' ≥ l` тоже хорошие — их `r - l + 1`:

```python
res += r - l + 1
```

«Ровно k» считается как «не больше k» минус «не больше k − 1».

### Почему O(n)

`l` и `r` только растут и не превышают n. Каждый элемент один раз входит в окно и не больше одного раза выходит. Внутренний `while` суммарно делает не больше n шагов — амортизированно O(1) на итерацию внешнего цикла. Это нужно уметь объяснить, когда спросят «но у вас же вложенный цикл».

### Когда окно не работает

Окну нужна **монотонность**: если отрезок хороший, то любой вложенный в него тоже хороший (для «самого длинного»), или если плохой — то и любой больший плохой. Сумма положительных чисел этим свойством обладает, сумма чисел **с отрицательными** — нет: расширение окна может уменьшить сумму.

Для «подмассив с суммой ровно k» при отрицательных числах используйте префиксные суммы со словарём (урок о хеш-таблицах).

Для «максимум или минимум в каждом окне длины k» нужна монотонная очередь (урок о стеке и очереди) — сумма окна пересчитывается, а максимум при выходе элемента — нет.

### Типичные ошибки

- Окно применено к данным без монотонности: сумма с отрицательными числами, условие «ровно k».
- При удалении элемента из словаря частот ключ с нулевой частотой не удалён — `len(cnt)` врёт.
- Левая граница сдвигается назад: в задаче о подстроке без повторов забыта проверка `last[ch] >= l`.
- Ответ обновляется до того, как окно стало хорошим, — в ответ попадает плохое окно.
- Начальное значение лучшей суммы — 0, хотя все окна могут быть отрицательными.

### Сложность

Каждый элемент один раз входит в окно и не больше одного раза выходит: O(n) времени при O(1) на обновление состояния. Память — O(1) для суммы и O(размер алфавита или числа различных значений) для словаря частот.

### Как спрашивают на Яндексе

«Красивая строка» (самая длинная подстрока из одинаковых символов после не более k замен) лежит в подборке CodeRun «Стажировка // Бэкенд», которую составили интервьюеры Яндекса, а «Минимум на отрезке» — в той же подборке и в подборке собеседований в Эйчартех. На секции окно обычно спрашивают через «вложенный цикл»: кандидат пишет `while` внутри `for`, и интервьюер уточняет, почему это всё ещё O(n), — будьте готовы объяснить амортизацию.

## Вопросы на собеседовании

### Найдите самую длинную подстроку без повторяющихся символов.
Скользящее окно: правая граница идёт по строке, словарь хранит последнюю позицию каждого символа. Если текущий символ уже встречался внутри окна (его последняя позиция ≥ l), переносим l на позицию после неё. Ответ — максимум r − l + 1. O(n) времени, O(k) памяти для алфавита размера k.

### Чем скользящее окно отличается от двух указателей?
Окно — частный случай однонаправленных двух указателей: обе границы двигаются только вперёд, а между ними поддерживается состояние (сумма, частоты), которое обновляется за O(1) при сдвиге любой границы. Два указателя шире: бывают встречными и работают на двух последовательностях.
