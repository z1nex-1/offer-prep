### Зачем NumPy

Цикл Python по миллиону чисел — десятые доли секунды на каждую операцию; та же операция над массивом NumPy выполняется в скомпилированном коде в десятки раз быстрее. Все ML-библиотеки (pandas, sklearn, PyTorch) устроены вокруг таких массивов, а на собеседовании «напишите метрику или шаг модели» чаще всего ждут векторизованный код.

В тренажёре этого курса NumPy доступен: он загружается при первом `import numpy`. В Яндекс Контесте набор библиотек зависит от выбранного компилятора — проверьте на тренировочном контесте, а для алгоритмических задач держите в голове решение на чистом Python.

### Массив: форма, тип, оси

```python
import numpy as np

a = np.array([[1, 2, 3], [4, 5, 6]])
a.shape     # (2, 3): 2 строки, 3 столбца
a.dtype     # int64
a.ndim      # 2
a.T.shape   # (3, 2)
```

- Все элементы одного типа. `np.array([1, 2.5])` — float64, `np.array([1, 2]) / 2` — тоже float.
- **Ось 0** — вдоль строк (сверху вниз), **ось 1** — вдоль столбцов. `a.sum(axis=0)` — суммы столбцов `[5, 7, 9]`, `a.sum(axis=1)` — суммы строк `[6, 15]`. Запоминалка: ось, по которой суммируем, исчезает из формы.
- Создание: `np.zeros((n, d))`, `np.ones(n)`, `np.arange(0, 10, 2)`, `np.linspace(0, 1, 5)`, `np.full(n, -1)`, `np.eye(d)`.
- `reshape(-1, 1)` — сделать из вектора столбец; `-1` — «вычисли сам».

### Векторизация

Вместо цикла — операции над целыми массивами:

```python
# MSE циклом и векторно
mse = sum((y[i] - p[i]) ** 2 for i in range(n)) / n
mse = np.mean((y - p) ** 2)

# доля верных ответов
acc = np.mean(y_true == y_pred)

# сигмоида для всего вектора
p = 1 / (1 + np.exp(-X @ w))
```

Арифметика, сравнения, `np.exp`, `np.log`, `np.abs`, `np.maximum` работают поэлементно.

### Broadcasting

Операции над массивами разной формы: размерности сравниваются с конца, и измерение длины 1 «растягивается».

```python
X = np.random.rand(100, 3)           # 100 объектов, 3 признака
mu = X.mean(axis=0)                  # форма (3,)
sd = X.std(axis=0)
Z = (X - mu) / sd                    # (100, 3) − (3,) → (100, 3): стандартизация

# попарные квадраты расстояний: n точек × k центров
D = ((X[:, None, :] - C[None, :, :]) ** 2).sum(axis=2)   # (n, 1, d) − (1, k, d) → (n, k, d) → (n, k)
labels = D.argmin(axis=1)
```

Второй приём — основа векторизованных kNN и k-means. Память — n·k·d чисел: при больших размерах используют тождество ‖x − c‖² = ‖x‖² − 2⟨x, c⟩ + ‖c‖², где ⟨x, c⟩ — одно матричное умножение `X @ C.T`.

### Индексация и маски

```python
a[1:4]            # срез — представление, не копия!
a[a > 0]          # булева маска — копия
a[[0, 3, 5]]      # fancy-индексация списком — копия
X[:, 0]           # первый столбец
X[y == 1]         # объекты класса 1
np.where(p >= 0.5, 1, 0)       # поэлементный if
```

**Представление и копия.** Срез ссылается на те же данные: `b = a[1:3]; b[0] = 100` меняет `a`. Нужна независимая копия — `a[1:3].copy()`. Маски и списки индексов всегда дают копию.

### Сортировки и поиск

- `np.sort(a)` — отсортированная копия; `a.argsort()` — **индексы**, которые сортируют массив. Для ROC-AUC и ранжирования нужен именно `argsort`.
- `a.argmax()`, `a.argmin()` — индекс максимума (первого при равенстве); `argmax(axis=1)` — по строкам, то есть предсказанный класс по матрице вероятностей.
- `np.argsort(-scores)[:k]` — индексы топ-k; `np.argpartition(a, k)` — k наименьших за O(n) без полной сортировки.
- `np.searchsorted(sorted_a, v)` — бинарный поиск.
- `np.unique(a, return_counts=True)`, `np.bincount(labels, weights=w)` — подсчёты по группам без словаря.
- `np.cumsum` — префиксные суммы.

### Линейная алгебра

```python
X @ w                         # матрица на вектор
A @ B                         # матричное умножение
np.linalg.solve(A, b)         # решить A x = b (не обращать A!)
np.linalg.lstsq(X, y, rcond=None)[0]    # МНК
np.linalg.eigh(C)             # собственные значения симметричной матрицы (для PCA)
np.linalg.norm(v)             # длина вектора
```

`*` — поэлементное умножение, `@` — матричное. Путаница между ними — самая частая ошибка на собеседовании.

### Численные ловушки

- `np.exp(1000)` — `inf`. Сигмоида и softmax — со сдвигом: `z - z.max()`, или `np.logaddexp`.
- `np.log(0)` — `-inf` с предупреждением. Обрезайте: `np.clip(p, 1e-15, 1 - 1e-15)`.
- Целочисленные массивы переполняются молча: `np.array([2**62]) * 4` даёт мусор, а не длинное число, как в Python.
- `==` для float — сравнивайте с допуском: `np.isclose`, `np.allclose`.
- Деление на ноль даёт `nan` или `inf` без исключения — проверяйте `np.isnan`.
- `a.std()` по умолчанию делит на n (ddof=0), а pandas `std()` — на n − 1.

### Ввод в контесте

```python
import sys
import numpy as np

data = sys.stdin.buffer.read().split()
n, d = int(data[0]), int(data[1])
X = np.array(data[2:2 + n * d], dtype=np.float64).reshape(n, d)
```

Список байтовых строк NumPy сам переводит в числа через `dtype`. Для вывода — `'\n'.join(map(str, arr.tolist()))` или `np.savetxt(sys.stdout, arr, fmt='%.6f')`; печать массива через `print(arr)` даёт скобки и сокращения.

### Типичные ошибки

- `*` вместо `@` и наоборот.
- Вектор формы (n,) там, где нужен столбец (n, 1): `y - p` с формами (n,) и (n, 1) даёт матрицу (n, n) из-за broadcasting — без ошибки, но с неверным результатом.
- Изменение среза, который оказался представлением исходного массива.
- Сумма по неправильной оси.
- Цикл по строкам массива там, где работает одна векторная операция.
- `print(arr)` вместо форматированного вывода.

## Самопроверка

### X имеет форму (100, 3). Какую форму имеет `X.mean(axis=0)`?
- [ ] (100,)
- [x] (3,)
- [ ] (100, 3)
- [ ] (1,)
> Ось, по которой усредняем, исчезает: получаем среднее каждого из трёх признаков.

### y имеет форму (n,), p — форму (n, 1). Что даст `y - p`?
- [ ] Ошибку несовпадения форм
- [x] Матрицу формы (n, n) из-за broadcasting
- [ ] Вектор формы (n,)
- [ ] Столбец формы (n, 1)
> (n,) трактуется как (1, n), и оба измерения растягиваются. Типичная тихая ошибка в метриках.

### Чем `A * B` отличается от `A @ B` для матриц NumPy?
- [ ] Ничем
- [x] `*` — поэлементное произведение, `@` — матричное
- [ ] `*` — матричное, `@` — поэлементное
- [ ] `@` работает только для векторов
> Для поэлементного произведения формы должны совпадать или согласовываться по правилам broadcasting.

### Как получить индексы трёх объектов с наибольшим score?
- [ ] `np.sort(scores)[-3:]`
- [x] `np.argsort(-scores)[:3]`
- [ ] `scores.argmax(3)`
- [ ] `scores[:3]`
> `sort` вернёт значения, а не индексы.

### Что выведет код?
```python
a = [1, 2, 3, 4]
b = a[1:3]
b[0] = 100
print(a)
```
- [x] `[1, 2, 3, 4]`
- [ ] `[1, 100, 3, 4]`
- [ ] `[100, 2, 3, 4]`
- [ ] `[1, 100, 100, 4]`
> Срез обычного списка Python — копия. У массива NumPy срез — представление, и там `a` изменился бы: `[1, 100, 3, 4]`.

## Вопросы на собеседовании

### Почему векторизованный код NumPy быстрее цикла Python?
Массив NumPy хранит числа одного типа подряд в памяти, а операции над ним выполняются циклом в скомпилированном C-коде без интерпретатора: нет накладных расходов на объекты Python, проверки типов и вызовы на каждом элементе, работают кэш процессора и SIMD-инструкции. Цикл Python на каждом шаге интерпретирует байткод и работает с объектами-числами в куче. Асимптотика та же, константа — в десятки раз меньше.

### Что такое broadcasting?
Правило выполнения поэлементных операций над массивами разной формы: формы сравниваются с конца, измерения должны совпадать или одно из них равно 1; измерения длины 1 (и недостающие слева) виртуально растягиваются без копирования данных. Пример: вычесть из матрицы (n, d) вектор средних (d,) — стандартизация одной строкой; разность (n, 1, d) и (1, k, d) даёт все попарные разности точек и центров. Опасность — случайное растягивание (n,) и (n, 1) в (n, n).

### Как посчитать матрицу попарных расстояний между n точками и k центрами без циклов?
Через broadcasting: `((X[:, None, :] - C[None, :, :]) ** 2).sum(-1)` — просто, но требует памяти n·k·d. Экономнее через тождество ‖x − c‖² = ‖x‖² − 2⟨x, c⟩ + ‖c‖²: `(X**2).sum(1)[:, None] - 2 * X @ C.T + (C**2).sum(1)[None, :]` — память n·k, а основная работа — одно матричное умножение. Из-за округления могут получиться крошечные отрицательные значения — их обрезают нулём.

### Чем копия отличается от представления в NumPy?
Представление (view) — новый объект-массив, который смотрит на те же данные: срезы, `reshape`, `.T`. Изменение представления меняет исходный массив. Копия — независимые данные: `.copy()`, булевы маски, индексация списком. Это важно, когда функция модифицирует переданный срез, и для памяти: представления бесплатны. Проверить можно через `np.shares_memory(a, b)`.
