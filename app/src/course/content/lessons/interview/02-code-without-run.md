На секциях Intern week offer запускать код нельзя. В журнале Яндекс Образования об отборе бэкенд-стажёров это прямо названо навыком, который нужно тренировать: понимать, как работает код, без его запуска. Хорошая новость — это техника, а не талант.

### Трассировка: таблица значений

Возьмите маленький, но не тривиальный пример и выпишите значения переменных после каждой итерации. Например, для «самой длинной подстроки без повторов» на `"abba"`:

```python
def longest_unique(s):
    last = {}
    l = best = 0
    for r, ch in enumerate(s):
        if ch in last and last[ch] >= l:
            l = last[ch] + 1
        last[ch] = r
        best = max(best, r - l + 1)
    return best
```

| r | ch | l до | условие | l после | last | best |
|---|---|---|---|---|---|---|
| 0 | a | 0 | нет | 0 | {a:0} | 1 |
| 1 | b | 0 | нет | 0 | {a:0, b:1} | 2 |
| 2 | b | 0 | `last[b]=1 ≥ 0` | 2 | {a:0, b:2} | 2 |
| 3 | a | 2 | `last[a]=0 ≥ 2`? нет | 2 | {a:3, b:2} | 2 |

Ответ 2 — верно. Именно строка r = 3 показывает, зачем нужна проверка `last[ch] >= l`: без неё `l` откатилось бы назад на 1, и ответ стал бы 3.

На собеседовании таблицу можно вести прямо в редакторе комментарием или проговаривать вслух. Интервьюер видит, что вы проверяете, а не надеетесь.

### Чек-лист краевых случаев

Прогоните код мысленно на каждом, что применимо к задаче:

1. **Пустой ввод**: `[]`, `""`, `n = 0`.
2. **Один элемент.**
3. **Все элементы одинаковые.**
4. **Ответ в самом начале и в самом конце** — особенно «последняя серия после цикла».
5. **Отрицательные числа и ноль.**
6. **Максимальные значения** — хватит ли времени, нет ли квадрата.
7. **Повторы** — если алгоритм полагается на различность.
8. **Уже отсортированный и отсортированный в обратном порядке вход.**

### Инвариант цикла

Для двух указателей, бинпоиска, окна полезно сформулировать **инвариант** — что верно перед каждой итерацией: «ответ лежит в `[lo, hi)`», «окно `[l, r]` не содержит повторов», «в стеке значения убывают». Затем проверить три вещи: инвариант верен в начале, каждая итерация его сохраняет, и из него после выхода следует ответ. Так бинпоиск проверяется без единого примера.

### Десять ошибок, которые остаются в коде на Python

**1. Ошибка на единицу в `range` и срезах.** `range(n - 1)` вместо `range(n)`, `a[i:j]` не включает `j`. Проверяйте первую и последнюю итерацию.

**2. Забытая последняя группа.** Серии, RLE, свёртка диапазонов: после цикла последняя группа не добавлена.

```python
# ошибка: последняя серия не попадёт в ответ
for i in range(1, len(s)):
    if s[i] != s[i - 1]:
        parts.append(...)
```

**3. Неверное начальное значение.** `best = 0` для максимума при отрицательных числах; `min_val = 0` для минимума.

**4. Изменяемый аргумент по умолчанию** и `[[0] * m] * n`.

**5. Изменение коллекции во время обхода.** `for x in a: a.remove(x)` пропускает элементы; изменение словаря во время `for k in d` — `RuntimeError`.

**6. Затенение встроенных имён.** `list = [...]`, `sum = 0`, `max = ...` — через пару строк `max(a, b)` падает.

**7. Целочисленное деление и округление.** `/` вместо `//` в индексах (`a[n / 2]` — `TypeError`), `-7 // 2 == -4`.

**8. Скрытая квадратичная сложность.** `x in list` в цикле, `list.pop(0)`, `s += ch` в цикле, срезы в цикле, `a.count(x)` в цикле.

**9. Неправильное сравнение.** `is` вместо `==` для чисел и строк; сравнение строк-чисел `"10" < "9"`.

**10. Потерянный возврат.** Рекурсивная функция вызывает себя, но не возвращает результат; функция в одной из веток не делает `return` и возвращает `None`.

### Как вести себя, если нашли ошибку

Скажите спокойно: «вижу проблему на пустом массиве — исправлю так-то». По материалам Яндекса, самостоятельно найденная и исправленная ошибка оценивается как внимательность. Если ошибку нашёл интервьюер и дал контрпример — пройдите его по коду сами, найдите место и исправьте, не переписывая решение целиком.

### Как тренироваться

- Решайте задачи в [режиме собеседования](#/iwo/interview): код пишется без запуска, тесты — один раз в конце. Цель — чтобы первый запуск проходил все тесты.
- После каждой неудачной попытки записывайте, какая из десяти ошибок это была. Через неделю у вас будет личный список «моих ошибок» — проверяйте код по нему.
- Читайте чужие решения и ищите в них баги — это тренирует тот же навык.

## Самопроверка

### Что вернёт функция на `[1, 1, 2]`?
```python
def compress(a):
    res = []
    cnt = 1
    for i in range(1, len(a)):
        if a[i] == a[i - 1]:
            cnt += 1
        else:
            res.append((a[i - 1], cnt))
            cnt = 1
    return res
```
- [ ] `[(1, 2), (2, 1)]`
- [x] `[(1, 2)]`
- [ ] `[(1, 1), (1, 1), (2, 1)]`
- [ ] Ошибку
> Последняя серия не добавлена после цикла — классическая ошибка №2. На пустом массиве код тоже нужно проверить.

### Что выведет код?
```python
def find_max(a):
    best = 0
    for x in a:
        if x > best:
            best = x
    return best

print(find_max([-5, -2, -9]))
```
- [ ] `-2`
- [x] `0`
- [ ] `-9`
- [ ] Ошибку
> Начальное значение 0 больше всех элементов. Правильно — `a[0]` или `float("-inf")`.

### Что выведет код?
```python
a = [1, 2, 2, 3]
for x in a:
    if x == 2:
        a.remove(x)
print(a)
```
- [ ] `[1, 3]`
- [x] `[1, 2, 3]`
- [ ] `[1, 2, 2, 3]`
- [ ] Ошибку
> После удаления первой двойки вторая сдвигается на её место и пропускается итератором.

### Что даёт формулировка инварианта цикла?
- [ ] Ускоряет код
- [x] Позволяет проверить корректность цикла без перебора примеров: верен в начале, сохраняется, даёт ответ в конце
- [ ] Нужна только для рекурсии
- [ ] Заменяет тесты интервьюера
> Особенно полезно для бинпоиска и двух указателей.

### Какая из строк скрыто делает решение квадратичным, если стоит внутри цикла по n элементам?
- [ ] `d[x] = d.get(x, 0) + 1`
- [x] `if x in seen_list:`
- [ ] `stack.append(x)`
- [ ] `best = max(best, x)`
> Проверка вхождения в список — O(n).

## Вопросы на собеседовании

### Как вы проверяете код, если его нельзя запустить?
Прохожу его построчно на своём небольшом примере и выписываю значения ключевых переменных после каждой итерации; затем проверяю краевые случаи по списку: пустой ввод, один элемент, все равны, ответ в начале и в конце, отрицательные значения; для циклов с указателями формулирую инвариант и проверяю, что он сохраняется. Отдельно смотрю на скрытую сложность встроенных операций.

### Интервьюер показывает тест, на котором ваш код ошибается. Что вы делаете?
Прохожу этот тест по коду сам, выписывая значения, нахожу строку, где поведение расходится с ожидаемым, объясняю причину и исправляю минимально, не переписывая решение. Потом проверяю, не ломает ли исправление другие примеры.
