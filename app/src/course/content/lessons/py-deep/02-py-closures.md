### Функции — объекты первого класса

Функцию можно положить в переменную, передать аргументом, вернуть из другой функции, хранить в словаре:

```python
def square(x):
    return x * x

f = square
ops = {"sq": square, "neg": lambda x: -x}
print(f(3), ops["neg"](3), sorted([3, -1, 2], key=abs))
```

`def` — исполняемая инструкция: она создаёт объект-функцию в момент выполнения и связывает его с именем. У функции есть атрибуты: `__name__`, `__doc__`, `__defaults__` (значения по умолчанию), `__closure__` (захваченные переменные).

### Замыкание

Вложенная функция, которая использует переменные объемлющей функции, **запоминает** их даже после того, как объемлющая функция завершилась:

```python
def make_multiplier(k):
    def mul(x):
        return x * k       # k берётся из объемлющей области
    return mul

triple = make_multiplier(3)
print(triple(10))          # 30
print(triple.__closure__[0].cell_contents)   # 3
```

Захватывается не значение, а **переменная** (ячейка). Если объемлющая функция поменяет переменную до вызова вложенной, вложенная увидит новое значение.

Чтобы **присвоить** такой переменной внутри вложенной функции, нужен `nonlocal` — иначе присваивание создаст локальную переменную:

```python
def counter():
    count = 0
    def inc():
        nonlocal count
        count += 1
        return count
    return inc

c = counter()
c(); c()
print(c())                 # 3
```

Замыкания — лёгкий способ хранить состояние без класса: счётчики, кэши, генераторы идентификаторов, фабрики функций.

### Позднее связывание: лямбды в цикле

Самый популярный вопрос на эту тему:

```python
funcs = [lambda: i for i in range(3)]
print([f() for f in funcs])     # [2, 2, 2], а не [0, 1, 2]
```

Все три лямбды ссылаются на **одну и ту же** переменную `i`, а её значение читается в момент вызова, когда цикл уже закончился. Исправления:

```python
funcs = [lambda i=i: i for i in range(3)]          # значение по умолчанию вычисляется сразу
funcs = [(lambda k: lambda: k)(i) for i in range(3)]   # новая область на каждой итерации
from functools import partial
funcs = [partial(lambda k: k, i) for i in range(3)]
```

### Декораторы

Декоратор — функция, которая принимает функцию и возвращает другую (обычно обёртку). Синтаксис `@decorator` — сахар:

```python
@timer
def work(): ...
# то же самое, что
def work(): ...
work = timer(work)
```

Пример — замер времени:

```python
import time
from functools import wraps

def timer(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        t0 = time.perf_counter()
        try:
            return func(*args, **kwargs)
        finally:
            print(f"{func.__name__}: {time.perf_counter() - t0:.3f} с")
    return wrapper
```

Детали, которые спрашивают:

- `*args, **kwargs` в обёртке — чтобы пробросить любые аргументы;
- `return func(...)` — не потерять результат;
- `@wraps(func)` копирует в обёртку `__name__`, `__doc__`, `__module__`, `__qualname__` и сохраняет исходную функцию в `__wrapped__`. Без него все декорированные функции будут называться `wrapper` — это ломает логи, отладку и документацию;
- декоратор выполняется **один раз**, при определении функции, а обёртка — при каждом вызове.

### Декоратор с аргументами

`@retry(times=3)` — это вызов `retry(times=3)`, который должен вернуть настоящий декоратор. Получается три уровня вложенности:

```python
from functools import wraps

def retry(times):
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            for attempt in range(times):
                try:
                    return func(*args, **kwargs)
                except Exception:
                    if attempt == times - 1:
                        raise
        return wrapper
    return decorator

@retry(times=3)
def fetch(url): ...
```

Несколько декораторов применяются снизу вверх: `@a @b def f` — это `f = a(b(f))`.

### Декораторы из стандартной библиотеки

- `functools.lru_cache(maxsize=...)` / `functools.cache` — мемоизация по аргументам (они должны быть хешируемыми).
- `functools.wraps` — метаданные обёртки.
- `@property`, `@staticmethod`, `@classmethod` — в классах (урок об ООП).
- `contextlib.contextmanager` — превращает генератор в контекстный менеджер.
- `dataclasses.dataclass` — генерирует `__init__`, `__repr__`, `__eq__`.

Во фреймворках декораторы повсюду: маршруты в Flask и FastAPI (`@app.get("/users")`), проверка прав, транзакции, кэширование ответов.

### Типичные ошибки

- Обёртка не возвращает результат функции.
- Нет `@wraps` — теряются имя и документация.
- Декоратор с аргументами написан с двумя уровнями вложенности вместо трёх.
- Лямбды в цикле захватывают одну переменную.
- Присваивание захваченной переменной без `nonlocal` — `UnboundLocalError`.
- Изменяемое состояние в замыкании, разделяемое между потоками без блокировки.

### Как спрашивают на Яндексе

Декораторы и замыкания — стандартная часть вопросов «на знание языка», которое Яндекс проверяет на технических секциях Intern week offer. Обычный формат: «напишите декоратор, который считает время / число вызовов / повторяет вызов при ошибке» или «что выведет этот код с лямбдами в цикле». Короткий декоратор с `@wraps` пишется за 3–4 минуты — потренируйтесь писать его без подсказок.

## Самопроверка

### Что выведет код?
```python
funcs = [lambda: i for i in range(3)]
print([f() for f in funcs])
```
- [ ] `[0, 1, 2]`
- [x] `[2, 2, 2]`
- [ ] `[0, 0, 0]`
- [ ] Ошибку
> Все лямбды читают одну переменную `i` в момент вызова, когда она уже равна 2.

### Что выведет код?
```python
def outer():
    x = 1
    def inner():
        return x
    x = 5
    return inner

print(outer()())
```
- [ ] `1`
- [x] `5`
- [ ] Ошибку
- [ ] `None`
> Замыкание захватывает переменную, а не значение. К вызову `x` уже 5.

### Что выведет код?
```python
def deco(f):
    def wrapper(*a):
        return f(*a) * 2
    return wrapper

@deco
@deco
def g(x):
    return x + 1

print(g(1), g.__name__)
```
- [ ] `4 g`
- [x] `8 wrapper`
- [ ] `4 wrapper`
- [ ] `8 g`
> Два декоратора удваивают результат дважды: (1 + 1) · 2 · 2 = 8. Без `@wraps` имя функции — `wrapper`.

### Когда выполняется код самого декоратора (не обёртки)?
- [ ] При каждом вызове функции
- [x] Один раз, при определении декорируемой функции
- [ ] При импорте модуля с декоратором
- [ ] Никогда
> `@d def f` означает `f = d(f)` — это выполняется в момент `def`. Обёртка выполняется при каждом вызове.

### Что делает `functools.wraps`?
- [ ] Ускоряет обёртку
- [x] Копирует в обёртку имя, документацию и другие атрибуты исходной функции
- [ ] Кэширует результаты
- [ ] Делает декоратор параметризуемым
> Без него все декорированные функции выглядят как `wrapper`.

### Что выведет код?
```python
def counter():
    n = 0
    def inc():
        nonlocal n
        n += 1
        return n
    return inc

a, b = counter(), counter()
a(); a()
print(a(), b())
```
- [ ] `3 3`
- [x] `3 1`
- [ ] `1 1`
- [ ] `2 1`
> У каждого вызова `counter()` своя переменная `n`.

## Вопросы на собеседовании

### Что такое замыкание?
Функция, которая запоминает переменные из объемлющей области видимости и может использовать их после того, как объемлющая функция завершилась. Захватываются ячейки переменных, а не значения, — поэтому лямбды в цикле видят последнее значение счётчика. Для присваивания захваченной переменной нужен `nonlocal`. Замыкания — основа декораторов и фабрик функций.

### Напишите декоратор, который логирует время выполнения функции.
Функция принимает `func` и возвращает `wrapper(*args, **kwargs)`, помеченный `@functools.wraps(func)`. Внутри — засечь `time.perf_counter()`, вызвать `func(*args, **kwargs)`, в блоке `finally` вывести разницу и вернуть результат. Важно: пробросить все аргументы, вернуть результат, сохранить метаданные через `wraps`.

### Как сделать декоратор с параметрами?
Добавить уровень: внешняя функция принимает параметры и возвращает декоратор, который принимает функцию и возвращает обёртку. `@retry(3)` сначала вызывает `retry(3)`, и уже результат применяется к функции.

### Почему [lambda: i for i in range(3)] возвращает одинаковые значения и как это исправить?
Лямбды не сохраняют значение `i`, а ссылаются на одну переменную, которую читают при вызове — после цикла она равна 2. Исправления: зафиксировать значение аргументом по умолчанию `lambda i=i: i`, создать новую область вложенной функцией или использовать `functools.partial`.
