### Двоичная запись и системы счисления

```python
bin(13)            # '0b1101'
int("1101", 2)     # 13
hex(255), oct(8)   # '0xff', '0o10'
int("ff", 16)      # 255
format(5, "08b")   # '00000101' — с ведущими нулями
```

Перевод в произвольную систему — деление с остатком:

```python
def to_base(n, b):
    if n == 0:
        return "0"
    digits = []
    while n:
        n, r = divmod(n, b)
        digits.append("0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ"[r])
    return "".join(reversed(digits))
```

Обратно — схема Горнера: `value = value * b + digit` для каждой цифры слева направо.

### Битовые операции

| Операция | Смысл | Пример (a = 12 = 1100₂, b = 10 = 1010₂) |
|---|---|---|
| `a & b` | И | `8` (1000) |
| `a \| b` | ИЛИ | `14` (1110) |
| `a ^ b` | исключающее ИЛИ | `6` (0110) |
| `~a` | НЕ | `-13` (в Python: `-a - 1`) |
| `a << k` | сдвиг влево, умножение на 2ᵏ | `12 << 1 = 24` |
| `a >> k` | сдвиг вправо, деление на 2ᵏ вниз | `12 >> 2 = 3` |

Приоритет битовых операций в Python ниже арифметики, но выше сравнений: `x & 1 == 0` означает `(x & 1) == 0`, а `x & 1 + 1` — это `x & 2`. В C++ и Java наоборот: там `x & 1 == 0` читается как `x & (1 == 0)`. Скобки вокруг битовых выражений снимают вопрос в любом языке.

### Приёмы

```python
x & 1                 # чётность: 1 — нечётное
(x >> i) & 1          # i-й бит
x | (1 << i)          # установить i-й бит
x & ~(1 << i)         # сбросить i-й бит
x ^ (1 << i)          # инвертировать i-й бит
x & (x - 1)           # убрать младшую единицу
x & -x                # оставить только младшую единицу
x > 0 and x & (x - 1) == 0    # степень двойки
bin(x).count("1")     # число единиц; в 3.10+ x.bit_count()
x.bit_length()        # число значащих битов
```

`x & (x - 1) == 0` для степени двойки — классический вопрос на собеседовании: у степени двойки ровно одна единица, а вычитание 1 превращает её в ноль, а все нули правее — в единицы.

### XOR-трюки

XOR коммутативен, ассоциативен, `a ^ a = 0`, `a ^ 0 = a`. Отсюда:

- **Единственный элемент без пары**: XOR всех элементов массива, где все остальные встречаются по два раза, — O(n) и O(1) памяти.
- **Пропущенное число** от 0 до n: XOR всех чисел 0..n и всех элементов массива.
- **Обмен без временной переменной**: `a ^= b; b ^= a; a ^= b` (в Python есть `a, b = b, a`).
- **XOR на отрезке** — префиксные XOR-ы, как префиксные суммы.

### Маски подмножеств

Множество из n ≤ 20 элементов — число от 0 до 2ⁿ − 1. Перебор всех подмножеств — цикл по маскам (урок о переборе). Дальше — динамика по маскам (задача коммивояжёра на ~15–18 городах: `dp[mask][last]`), но на стажёрском уровне она встречается редко.

Перебор подмасок маски: `sub = mask; while sub: …; sub = (sub - 1) & mask`.

### Геометрия на целых числах

Главное правило: **оставайтесь в целых числах**, пока возможно. Сравнивайте квадраты расстояний, а не сами расстояния, используйте векторное произведение вместо углов.

```python
def cross(ax, ay, bx, by):         # векторное произведение (z-компонента)
    return ax * by - ay * bx

def orient(p, q, r):               # > 0 — поворот налево, < 0 — направо, 0 — на одной прямой
    return cross(q[0] - p[0], q[1] - p[1], r[0] - p[0], r[1] - p[1])
```

- **Площадь многоугольника** (формула Гаусса, «шнурков»): `abs(sum(x[i]*y[i+1] - x[i+1]*y[i])) / 2`. Удвоенная площадь целая — храните её.
- **Площадь треугольника** — половина модуля векторного произведения.
- **Лежит ли точка на отрезке**: `orient == 0` и координаты в пределах отрезка.
- **Пересекаются ли отрезки**: точки каждого отрезка по разные стороны от другого (знаки `orient`), плюс отдельная проверка коллинеарных случаев.
- **Расстояние**: `math.hypot(dx, dy)`; сравнение — `dx*dx + dy*dy <= r*r`.
- **Манхэттенское расстояние**: `|dx| + |dy|`. Поворот координат `(x + y, x − y)` превращает его в чебышёвское `max(|du|, |dv|)` — приём из задачи «Пробежки по Манхэттену» (подборка Михаила Густокашина на CodeRun).
- **Прямоугольники со сторонами вдоль осей**: пересечение — `max` левых и `min` правых границ; площадь пересечения — `max(0, …)` по каждой оси.

### Вероятность и матожидание в задачах

На CodeRun есть задачи на вероятность с бэкенд-сюжетом: «Ошибка» (на каком сервере вероятнее всего произошла ошибка — формула Байеса) и «Первый герой». База:

- вероятность события = благоприятные исходы / все исходы (для равновероятных);
- независимые события: P(A и B) = P(A)·P(B);
- матожидание линейно: E[X + Y] = E[X] + E[Y] — даже для зависимых величин. Этим решаются «ожидаемое число совпадений», «ожидаемое число бросков»;
- ожидаемое число попыток до первого успеха с вероятностью p — 1/p.

Если ответ нужно вывести дробью или по модулю — используйте `fractions.Fraction` или обратный элемент по модулю.

**Формула Байеса** — «откуда пришла ошибка»: если на сервер i приходит доля запросов aᵢ, а ошибается он с вероятностью bᵢ, то вероятность, что конкретная ошибка случилась на сервере i, равна `aᵢ·bᵢ / Σ aⱼ·bⱼ`. Числитель — вероятность «запрос попал на i и упал», знаменатель — вероятность ошибки вообще.

### Типичные ошибки

- Приоритет операций: в Python `x & 1 == 0` означает `(x & 1) == 0`, потому что `&` связывает сильнее сравнения, а в C++ и Java — наоборот. На собеседовании ставьте скобки, чтобы код читался однозначно.
- `~x` в Python — это `-x - 1`, а не «инвертировать 32 бита»: целые не ограничены по длине. Маску длины k берут как `x ^ ((1 << k) - 1)`.
- `bin(x)` для отрицательного числа — `'-0b101'`, а не дополнительный код.
- Сравнение расстояний через `sqrt` и float вместо квадратов — ошибки на границе.
- Площадь по формуле Гаусса без модуля: при обходе по часовой стрелке она отрицательная.
- Деление удвоенной площади на 2 во float для координат до 10⁹ — теряются младшие цифры.

## Самопроверка

### Что выведет код?
```python
x = 12
print(x & (x - 1), x & -x)
```
- [ ] `11 12`
- [x] `8 4`
- [ ] `4 8`
- [ ] `0 4`
> 12 = 1100₂. `x & (x − 1)` убирает младшую единицу → 1000₂ = 8. `x & −x` оставляет только её → 100₂ = 4.

### Что выведет код?
```python
a = [4, 1, 2, 1, 2]
r = 0
for x in a:
    r ^= x
print(r)
```
- [ ] 0
- [x] 4
- [ ] 10
- [ ] 1
> Парные элементы взаимно уничтожаются при XOR, остаётся единственный без пары.

### Что выведет код?
```python
print(6 & 1 == 0, 6 & 1 + 1)
```
- [x] `True 2`
- [ ] `0 2`
- [ ] `True 0`
- [ ] `False 3`
> В Python `&` выполняется раньше сравнения, но позже сложения: `(6 & 1) == 0` → True, а `6 & (1 + 1)` = `6 & 2` = 2. В C++ первое выражение означало бы `6 & (1 == 0)`.

### Как проверить, что положительное x — степень двойки?
- [ ] `x % 2 == 0`
- [x] `x & (x - 1) == 0`
- [ ] `x ^ 1 == 0`
- [ ] `bin(x).count("0") == 1`
> У степени двойки ровно одна единица в двоичной записи; `x − 1` превращает её в ноль, а нули справа — в единицы.

### Как сравнить расстояния от точки до двух других без погрешности?
- [ ] Сравнить `math.sqrt` расстояний
- [x] Сравнить квадраты расстояний — это целые числа
- [ ] Округлить расстояния до 6 знаков
- [ ] Никак, всегда будет погрешность
> Квадрат расстояния между целыми точками — целое число, а корень — монотонная функция, поэтому порядок сохраняется.

### Что выведет код?
```python
def to_base(n, b):
    d = []
    while n:
        n, r = divmod(n, b)
        d.append(str(r))
    return "".join(reversed(d)) or "0"
print(to_base(10, 3), to_base(0, 2))
```
- [ ] `31 0`
- [x] `101 0`
- [ ] `101 `
- [ ] `11 0`
> 10 = 1·9 + 0·3 + 1. Для нуля цикл не выполнится, и сработает `or "0"`.

## Вопросы на собеседовании

### Как найти в массиве единственный элемент, который не имеет пары, за O(1) памяти?
XOR всех элементов: одинаковые числа дают 0, XOR с нулём не меняет число, операция коммутативна и ассоциативна — остаётся искомый. O(n) времени. Если остальные элементы встречаются по три раза — считаем по каждому биту сумму по модулю 3.

### Как определить, с какой стороны от прямой AB лежит точка C?
По знаку векторного произведения (B − A) × (C − A) = (bx − ax)(cy − ay) − (by − ay)(cx − ax): положительное — слева (поворот против часовой), отрицательное — справа, ноль — на прямой. Всё в целых числах, без погрешностей. На этом строятся проверка пересечения отрезков и выпуклые оболочки.
