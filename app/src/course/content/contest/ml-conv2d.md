Реализуйте двумерную свёртку, как в свёрточном слое нейросети (одноканальное изображение, одно ядро, без переворота ядра). Изображение дополняется p нулями с каждой стороны (паддинг), затем ядро k × k с шагом s проходит по нему, и в каждой позиции вычисляется сумма поэлементных произведений окна и ядра. Окно, выходящее за границу дополненного изображения, не рассматривается.

**Формат ввода.** Первая строка — H, W, k, s, p (1 ≤ H, W ≤ 200, 1 ≤ k ≤ 7, 1 ≤ s ≤ 3, 0 ≤ p ≤ 3, k ≤ H + 2p, k ≤ W + 2p). Следующие H строк — пиксели изображения, затем k строк — ядро. Все числа — целые по модулю не больше 100.

**Формат вывода.** Первая строка — размеры выхода H_out и W_out. Затем H_out строк по W_out чисел.

## Подсказки
- Размер выхода по оси: ⌊(n + 2p − k) / s⌋ + 1.
- Проще всего сначала построить дополненное нулями изображение, а потом идти окнами.

## Разбор
Строим дополненную матрицу размера (H + 2p) × (W + 2p) с нулями по краям и копией изображения в центре. Верхний левый угол окна пробегает строки 0, s, 2s, … пока окно помещается: последний допустимый угол — H + 2p − k. Отсюда H_out = ⌊(H + 2p − k) / s⌋ + 1 — та же формула, по которой считают размер выхода свёрточного слоя в PyTorch.

Для каждого окна — сумма k² произведений. В нейросетях каналов много, и выход канала — сумма свёрток по всем входным каналам плюс смещение; число параметров слоя — C_out·(k·k·C_in + 1), а не зависит от размера изображения. С NumPy окно — срез `P[i:i+k, j:j+k]`, а сумма — `(window * K).sum()`.

**Сложность:** O(H_out · W_out · k²).
