Реализуйте стек, который обрабатывает команды:

- `push n` — положить число n, вывести `ok`;
- `pop` — снять верхний элемент и вывести его;
- `back` — вывести верхний элемент, не снимая;
- `size` — вывести число элементов;
- `clear` — очистить стек, вывести `ok`;
- `exit` — вывести `bye` и завершить работу.

Если `pop` или `back` вызваны для пустого стека, выведите `error`. Похожая задача есть в тренировках Яндекса.

**Формат ввода.** Команды по одной в строке, не больше 10⁵. Последняя команда — `exit`. Числа по модулю не больше 10⁹.

**Формат вывода.** Результат каждой команды на отдельной строке.

## Подсказки
- Список Python — готовый стек: append и pop с конца.
- Ответы копите в список и печатайте в конце одним вызовом.

## Разбор
Разбираем команды по строкам и выполняем их на обычном списке: `append`, `pop()`, `[-1]`, `len`, `clear()`. Пустой стек проверяется до обращения к элементу.

Главное в задаче — аккуратный разбор ввода и вывод строго в формате: после `exit` ничего не обрабатываем, даже если дальше есть строки.

**Сложность:** O(1) на команду.
