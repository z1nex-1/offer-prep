Даны n неотрицательных целых чисел. Расставьте их в таком порядке, чтобы при записи подряд получилось наибольшее возможное число, и выведите его. Ведущие нули в ответе не нужны: если получилось `000`, выведите `0`.

**Формат ввода.** Первая строка — n (1 ≤ n ≤ 10⁵). Вторая — n чисел от 0 до 10⁹.

**Формат вывода.** Одно число (без ведущих нулей).

## Подсказки
- Сортировка по убыванию значений не работает: 9 должно идти раньше 34, а 34 раньше 3?
- Сравнивайте строки a и b по тому, что больше: a + b или b + a. Нужен functools.cmp_to_key.

## Разбор
Числа сравниваются не по величине: для 3 и 30 правильный порядок `330`, а не `303`. Правило: a идёт раньше b, если `a + b > b + a` как строки. Это сравнение транзитивно, поэтому им можно сортировать, а обменный аргумент доказывает оптимальность: если в ответе соседние x, y стоят «неправильно», их перестановка не уменьшит число.

В Python сортировка принимает только `key`, поэтому функцию сравнения оборачиваем в `functools.cmp_to_key`.

Краевой случай — все нули: склейка даёт `000`, а ответ — `0`.

**Сложность:** O(n log n · L), где L — длина чисел.
