Дан массив из n нулей. Выполняется q операций: «прибавить v ко всем элементам с индексами от l до r» (нумерация с единицы). Выведите массив после всех операций.

**Формат ввода.** Первая строка — n и q (1 ≤ n, q ≤ 2·10⁵). Далее q строк по три числа l, r, v (1 ≤ l ≤ r ≤ n, |v| ≤ 10⁹).

**Формат вывода.** n чисел через пробел.

## Подсказки
- Разностный массив: операция меняет только d[l] и d[r + 1].
- Итоговый массив — префиксные суммы d.

## Разбор
Прибавлять в цикле — O(n·q). Разностный массив `d`: операция `(l, r, v)` превращается в `d[l] += v` и `d[r + 1] -= v`. После всех операций префиксная сумма `d` даёт итоговые значения: прибавка v «включается» в позиции l и «выключается» после r.

Массив `d` на две ячейки длиннее, чтобы `d[r + 1]` при r = n не выходил за границу.

**Сложность:** O(n + q).
