В журнале сервера записаны начало и конец n пользовательских сессий — только время суток, без даты. Каждая сессия длилась меньше 24 часов, поэтому если конец раньше начала, сессия перешла через полночь. Если начало и конец совпадают, сессия длилась 0 секунд.

Найдите суммарную длительность всех сессий и номер самой длинной (если таких несколько — с наименьшим номером).

**Формат ввода.** Первая строка — n (1 ≤ n ≤ 10⁵). Далее n строк: время начала и конца в формате `HH:MM:SS`.

**Формат вывода.** В первой строке — суммарная длительность в формате `H:MM:SS`, где часы выводятся без ограничения сверху (минуты и секунды — двумя цифрами). Во второй — номер самой длинной сессии, нумерация с 1.

## Подсказки
- Переведите время в секунды от начала суток.
- Длительность — (конец − начало) % 86400: в Python остаток от отрицательного числа неотрицателен.

## Разбор
Переводим `HH:MM:SS` в секунды: `h * 3600 + m * 60 + s`. Длительность сессии — `(end - start) % 86400`: если сессия перешла через полночь, разность отрицательна, и остаток по модулю суток превращает её в правильное число секунд. В Python `%` с положительным делителем всегда неотрицателен, в C++ и Java пришлось бы прибавлять 86400.

Обратный перевод суммы: `h, rest = divmod(total, 3600)`, `m, s = divmod(rest, 60)`, вывод `f"{h}:{m:02d}:{s:02d}"`.

**Сложность:** O(n).
