Дан отсортированный по неубыванию массив из n чисел и q запросов. Для каждого запроса x выведите элемент массива, ближайший к x. Если таких два, выведите меньший.

Такая задача есть в тренировках Яндекса («Приближённый двоичный поиск»).

**Формат ввода.** Первая строка — n и q (1 ≤ n, q ≤ 10⁵). Вторая — массив, третья — запросы. Числа по модулю не больше 10⁹.

**Формат вывода.** q чисел, каждое на отдельной строке.

## Подсказки
- Найдите первую позицию i с a[i] ≥ x. Ближайший — либо a[i], либо a[i − 1].
- Аккуратно с границами: i может быть 0 или n.

## Разбор
`i = bisect_left(a, x)` — первая позиция с `a[i] >= x`. Ближайший к x элемент — один из двух соседей границы: `a[i - 1]` (последний меньший) или `a[i]` (первый не меньший). Если `i == 0`, кандидат только `a[0]`; если `i == n` — только `a[n - 1]`. При равном расстоянии выбираем `a[i - 1]`: он меньше.

Сравнение `(abs(v - x), v)` сразу учитывает правило «при равенстве — меньший».

**Сложность:** O(q log n).
