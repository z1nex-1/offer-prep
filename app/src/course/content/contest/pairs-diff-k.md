Дан массив из n целых чисел и число k ≥ 0. Сколько существует пар индексов i < j, для которых |aᵢ − aⱼ| = k?

**Формат ввода.** Первая строка — n и k (1 ≤ n ≤ 2·10⁵, 0 ≤ k ≤ 10⁹). Вторая — n целых чисел по модулю не больше 10⁹.

**Формат вывода.** Одно число — количество пар.

## Подсказки
- Идите по массиву и считайте, сколько раз раньше встречались x − k и x + k.
- Случай k = 0 особый: x − k и x + k — одно и то же число, не посчитайте его дважды.

## Разбор
Проход со словарём частот уже просмотренных элементов: для текущего x к ответу прибавляется `cnt[x - k] + cnt[x + k]`, затем `cnt[x] += 1`. Так каждая пара i < j считается ровно один раз — в момент, когда мы стоим на j.

При k = 0 оба слагаемых — одно и то же `cnt[x]`, и пара посчиталась бы дважды. Поэтому при k = 0 прибавляем только `cnt[x]`.

**Сложность:** O(n) в среднем.
