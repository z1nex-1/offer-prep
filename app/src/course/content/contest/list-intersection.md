В таблице из n узлов записаны ссылки: из узла i следующий — nextᵢ, 0 — конец списка. Из узла h₁ начинается первый список, из узла h₂ — второй. Списки могут в какой-то момент сойтись: с общего узла и до конца они совпадают. Найдите первый общий узел или выведите 0, если общих узлов нет.

**Формат ввода.** В первой строке — n, h₁ и h₂ (1 ≤ n ≤ 3·10⁴). Во второй — n чисел next₁ … nextₙ. Циклов нет. Узлы, которые не лежат ни в одном списке, могут образовывать свои цепочки.

**Формат вывода.** Номер первого общего узла или 0.

## Подсказки
- Если бы оба списка имели одинаковую длину до точки слияния, хватило бы идти по ним одновременно. Как уравнять длины?
- Указатель, дошедший до конца своего списка, переставьте в голову другого списка.

## Разбор
Решение со множеством: пройти первый список и запомнить узлы, затем идти по второму до первого узла из множества. Это O(n) памяти.

Решение за O(1) памяти: два указателя идут по своим спискам, а дойдя до конца, переходят в голову чужого. Пусть до слияния в первом списке x узлов, во втором y, общий хвост — t. Первый указатель пройдёт x + t + y узлов до общего узла, второй — y + t + x: пути одинаковы, поэтому указатели встретятся ровно в первом общем узле. Если общего хвоста нет, оба одновременно придут в 0 после x + y шагов — и это тоже ответ.

Частые ошибки: сравнивать значения узлов, а не номера — у разных узлов значения могут совпадать; не учесть, что h₁ = h₂; случай, когда один список целиком — хвост другого.

**Сложность:** O(n) времени, O(1) дополнительной памяти.
