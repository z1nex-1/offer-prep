Сдвиньте массив циклически на k позиций вправо: последний элемент становится первым, и так k раз.

**Формат ввода.** В первой строке — n и k (1 ≤ n ≤ 4·10⁴, 0 ≤ k ≤ 10¹⁸). Во второй — n целых чисел, по модулю не больше 10⁹.

**Формат вывода.** n чисел через пробел — сдвинутый массив.

## Подсказки
- Моделировать k сдвигов по одному нельзя: k до 10¹⁸.
- Что будет после n сдвигов?
- Срезы `a[-k:]` и `a[:-k]` работают, только если 0 ≤ k < n.

## Разбор
После n сдвигов массив возвращается в исходное состояние, поэтому важен только остаток `k % n`. Дальше — последние k элементов в начало: `a[-k:] + a[:-k]`. При k = 0 формула тоже верна: `a[-0:]` — весь список, `a[:-0]` — пустой.

Без `k %= n` при k ≥ n срез `a[-k:]` вернёт весь массив, `a[:-k]` — пустой, и программа выведет массив без сдвига.

На собеседовании ту же задачу просят решить без дополнительной памяти — тремя разворотами: весь массив, первые k, оставшиеся n − k (урок «Массив на месте»).

**Сложность:** O(n).
