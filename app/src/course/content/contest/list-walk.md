Односвязный список из n узлов записан таблицей: узлы пронумерованы от 1 до n, у каждого есть значение и номер следующего узла (0 — следующего нет). Узлы в таблице перечислены в произвольном порядке, а не в порядке списка. Выведите значения узлов в порядке списка, начиная с головы.

**Формат ввода.** В первой строке — n и номер головы (1 ≤ n ≤ 3·10⁴). В следующих n строках — значение i-го узла (целое, по модулю не больше 10⁹) и номер следующего узла. Все n узлов образуют один список без циклов.

**Формат вывода.** Значения через пробел в порядке списка.

## Подсказки
- Номер узла — это индекс в таблице: значение и ссылку узла i храните в `val[i]` и `nxt[i]`.
- Идите от головы по ссылкам, пока номер не станет 0.

## Разбор
Так связные списки выглядят на контесте: вместо объектов с полем `next` — массивы, где «указатель» — это номер строки. Читаем таблицу в два массива и повторяем обход из урока: `cur = head`, пока `cur` не 0, выводим `val[cur]` и переходим к `nxt[cur]`.

Частые ошибки: выводить значения в порядке строк таблицы, а не в порядке ссылок; начать обход с узла 1, а не с головы; перепутать нумерацию с 1 и индексы списка Python с 0.

**Сложность:** O(n).
