Односвязный список L₁ → L₂ → … → Lₙ записан таблицей (значение и номер следующего узла; 0 — конец). Переставьте узлы в порядок L₁ → Lₙ → L₂ → Lₙ₋₁ → L₃ → … и выведите значения в новом порядке.

**Формат ввода.** В первой строке — n и номер головы (1 ≤ n ≤ 3·10⁴). В следующих n строках — значение и номер следующего узла для узлов 1, 2, …, n.

**Формат вывода.** Значения через пробел в новом порядке.

## Подсказки
- С массивом это два указателя с двух концов. На собеседовании просят за O(1) памяти, без массива, — решите так.
- Три шага из урока: найти середину, развернуть вторую половину, склеить половины через одну.

## Разбор
Решение ссылками собирается из трёх приёмов урока. Быстрым и медленным указателем находим середину: для n = 5 медленный остановится на третьем узле, для n = 4 — на втором. Отрезаем вторую половину (`nxt[slow] = 0`) и разворачиваем её. Теперь есть два списка — L₁ → L₂ → L₃ и L₅ → L₄ — и мы склеиваем их по очереди: после каждого узла первой половины вставляем очередной узел второй. Первая половина не короче второй, поэтому склейка заканчивается, когда кончилась вторая.

Частые ошибки: не отрезать первую половину от второй — получается цикл; остановить медленный указатель на узел позже, и тогда при чётном n порядок ломается; при склейке перезаписать ссылку раньше, чем её запомнили.

**Сложность:** O(n) времени, O(1) дополнительной памяти.
