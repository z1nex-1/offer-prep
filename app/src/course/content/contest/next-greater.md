Для каждого элемента массива найдите номер ближайшего справа элемента, который строго больше него. Если такого нет, выведите −1. Нумерация с нуля.

**Формат ввода.** Первая строка — n (1 ≤ n ≤ 2·10⁵). Вторая — n целых чисел по модулю не больше 10⁹.

**Формат вывода.** n чисел через пробел.

## Подсказки
- Монотонный стек индексов, для которых ответ ещё не найден.
- Новый элемент «закрывает» все меньшие элементы на вершине стека.

## Разбор
Идём слева направо и храним в стеке индексы элементов, для которых следующий больший ещё не найден. Их значения не возрастают от дна к вершине. Текущий элемент снимает с вершины все индексы с меньшими значениями — для них он и есть ответ. Потом кладём текущий индекс.

Индексы, оставшиеся в стеке в конце, получают −1.

Каждый индекс кладётся и снимается не больше одного раза.

**Сложность:** O(n).
