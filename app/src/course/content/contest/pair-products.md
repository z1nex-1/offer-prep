Найдите сумму произведений a[i] · a[j] по всем парам индексов i < j.

**Формат ввода.** В первой строке — n (1 ≤ n ≤ 10⁵). Во второй — n целых чисел от −10⁹ до 10⁹.

**Формат вывода.** Одно число — сумма (она может быть очень большой по модулю или отрицательной).

## Подсказки
- Два вложенных цикла — 5·10⁹ умножений.
- Выпишите сумму для j-го элемента: `a[0]·a[j] + a[1]·a[j] + … + a[j−1]·a[j]`. Что можно вынести за скобки?

## Разбор
Для фиксированного j сумма произведений с предыдущими элементами — `a[j] · (a[0] + … + a[j−1])`. Сумму предыдущих ведём на ходу в переменной `pref`: `total += a[j] * pref`, затем `pref += a[j]`. Один проход — O(n).

Есть и формула: `(a[0] + … + a[n−1])² = Σ a[i]² + 2 · Σ_{i<j} a[i]·a[j]`, откуда ответ `(S² − Σ a[i]²) / 2`. Деление нацело точное, потому что числитель всегда чётный; делите через `//`, а не `/` — иначе `float` испортит число из 28 цифр.

Ответ до примерно 5·10²⁷ — в C++ он бы переполнился, в Python `int` растёт сам.

**Сложность:** O(n).
