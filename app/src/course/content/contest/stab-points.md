Охранник обходит длинный коридор и хочет застать каждого из n сотрудников. Сотрудник i стоит в коридоре на отрезке координат от lᵢ до rᵢ включительно. Охранник может остановиться в нескольких целых точках. Сотрудника он застанет, если остановится в какой-то точке его отрезка. Какое наименьшее число остановок нужно, чтобы застать всех?

**Формат ввода.** В первой строке — n (1 ≤ n ≤ 2·10⁴). Далее n строк по два целых числа lᵢ и rᵢ (0 ≤ lᵢ ≤ rᵢ ≤ 10⁶).

**Формат вывода.** Одно число — наименьшее количество остановок.

## Подсказки
- Посмотрите на отрезок, который кончается раньше всех. В нём обязательно есть остановка — где её выгоднее всего поставить?
- Отсортируйте отрезки по правому концу. Сравнивать нужно только с последней поставленной точкой.
- Отрезки касаются концами, если `l` одного равно `r` другого, — одна точка задевает оба.

## Разбор
Сортируем отрезки по правому концу и идём по порядку. Если последняя поставленная точка не лежит в текущем отрезке, то есть `l > last`, ставим новую точку в его правый конец `r`.

Почему правый конец: в отрезке с самым ранним концом r есть точка любого ответа, и она не правее r. Если сдвинуть её в r, она по-прежнему задевает все отрезки, которые задевала: они начинаются не правее её и кончаются не левее r. Значит, есть оптимальный ответ с точкой в r, и можно удалить все отрезки, которые её содержат, и повторить рассуждение.

Проверять только последнюю точку достаточно: точки ставятся слева направо, и если последняя левее `l`, то и остальные левее.

Частые ошибки: сортировка по левому концу (отрезок `[0, 100]` первым поставит точку в 100 и пропустит `[1, 2]`), новая точка в `l` вместо `r`, строгое `l >= last` вместо `l > last` — касание концами считается за одну точку.

**Сложность:** O(n log n).
