Вычислите выражение, записанное в обратной польской (постфиксной) записи: сначала операнды, потом операция. Например, `2 3 + 4 *` означает (2 + 3) · 4. Операции — `+`, `-`, `*`, числа — целые неотрицательные.

Задача «Постфиксная запись» есть в тренировках Яндекса.

**Формат ввода.** Одна строка — числа и знаки операций через пробел, всего от 1 до 10⁵ элементов. Гарантируется, что запись корректна.

**Формат вывода.** Значение выражения.

## Подсказки
- Число — в стек. Операция — снимаем два числа, кладём результат.
- Порядок важен: первым снимается правый операнд.

## Разбор
Стек операндов. Число кладём в стек. Для операции снимаем правый операнд (он сверху), затем левый, кладём результат. В конце в стеке одно число — ответ.

Частая ошибка — перепутать порядок при вычитании: для `5 3 -` ответ 2, а не −2.

Промежуточные значения могут быть огромными — в Python это не проблема.

**Сложность:** O(n).
