Выпишем все перестановки чисел от 1 до n в лексикографическом порядке и пронумеруем с единицы. Например, для n = 3: 1) `1 2 3`, 2) `1 3 2`, 3) `2 1 3`, 4) `2 3 1`, 5) `3 1 2`, 6) `3 2 1`.

Для каждого запроса выведите перестановку с номером k.

**Формат ввода.** В первой строке — числа n и q (1 ≤ n ≤ 20, 1 ≤ q ≤ 1000). В следующих q строках — по одному числу k (1 ≤ k ≤ n!).

**Формат вывода.** Для каждого запроса — перестановка в отдельной строке, числа через пробел.

## Подсказки
- 20! ≈ 2,4·10¹⁸ — выписать перестановки не получится. Но можно посчитать, сколько перестановок начинается с каждого числа.
- С числа 1 начинаются ровно (n − 1)! перестановок, с числа 2 — следующие (n − 1)!, и так далее. По k сразу понятно, какое число стоит первым.
- Дальше та же задача для оставшихся n − 1 чисел и уменьшенного k. Удобно перейти к нумерации с нуля.

## Разбор
Это перебор, в котором мы не ходим по дереву, а **считаем размеры поддеревьев** и сразу спускаемся в нужное. Корень дерева перебора — выбор первого числа. Под каждым вариантом первого числа ровно (n − 1)! листьев, и они идут подряд.

Перейдём к нумерации с нуля: k := k − 1. Тогда первое число — это элемент с индексом k // (n − 1)! среди доступных чисел по возрастанию, а номер внутри его поддерева — k % (n − 1)!. Повторяем для оставшихся чисел:

```python
from math import factorial

def kth(n, k):
    k -= 1
    free = list(range(1, n + 1))
    res = []
    for i in range(n, 0, -1):
        f = factorial(i - 1)
        idx, k = divmod(k, f)
        res.append(free.pop(idx))
    return res
```

Проверка на n = 3, k = 4: k = 3; 3 // 2! = 1 → берём второе число, 2; k = 1; 1 // 1! = 1 → из [1, 3] берём 3; остаётся 1. Ответ `2 3 1` — верно.

Это разложение k в **факториальной системе счисления**: цифры idx показывают, какой по счёту из оставшихся элементов взять. Обратная задача — найти номер перестановки — решается тем же рассуждением: для каждого места прибавить (число меньших ещё не использованных элементов) · (оставшихся мест)!.

Тот же приём «посчитать размер ветки и пропустить её целиком» работает для k-го подмножества, k-й скобочной последовательности (размер ветки считается динамикой) и k-го сочетания. На контесте это частый способ превратить «невозможный» перебор в быстрый.

**Сложность:** O(n²) на запрос из-за `pop` из списка — при n ≤ 20 это мгновенно.
