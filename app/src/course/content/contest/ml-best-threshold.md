Классификатор выдаёт score, а объект считается положительным, если его score **не меньше** порога t. Даны метки и score для n объектов. Найдите наибольшее значение F1 для класса 1, которое можно получить, выбрав порог t (любое действительное число).

F1 = 2·TP / (2·TP + FP + FN). Если TP = 0, F1 = 0. Гарантируется, что в выборке есть хотя бы один положительный объект.

**Формат ввода.** Первая строка — n (1 ≤ n ≤ 10⁵). Следующие n строк — метка (0 или 1) и целый score от 0 до 10⁹ через пробел.

**Формат вывода.** Одно число — наибольшая F1. Ответ принимается с абсолютной или относительной погрешностью 10⁻⁶.

## Подсказки
- Порог имеет смысл ставить только на значения score: между соседними значениями предсказания не меняются.
- Отсортируйте объекты по убыванию score. Если порог равен score k-го объекта, положительными названы все объекты до него — и все объекты с тем же score.
- Не пересчитывайте TP и FP заново для каждого порога: при сдвиге порога вниз они только растут.

## Разбор
Перебор каждого порога с пересчётом F1 — O(n²). Заметим, что при пороге t положительными названы все объекты со score ≥ t, то есть префикс списка, отсортированного по убыванию score. Идём по этому списку и копим TP и FP. Проверять F1 можно только в конце группы одинаковых score: порог не может отделить объекты с равным score друг от друга.

При текущих TP и FP: FN = P − TP, где P — число положительных во всей выборке, и F1 = 2·TP / (TP + FP + P). Максимум по концам групп — ответ. Порог «выше всех score» даёт TP = 0 и F1 = 0, его учитывать не нужно.

Самая частая ошибка — считать F1 после каждого объекта, а не после группы: тогда получается порог, который «разрезает» равные score, и ответ бывает завышен.

**Сложность:** O(n log n).
