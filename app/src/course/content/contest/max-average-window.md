Дан массив из n положительных целых чисел и число k. Найдите отрезок подряд идущих элементов длины **не меньше** k с наибольшим средним арифметическим и выведите это среднее.

Похожая задача — «Среднее в окне» из бэкенд-сезона CodeRun.

**Формат ввода.** Первая строка — n и k (1 ≤ k ≤ n ≤ 5·10⁴). Вторая — n чисел от 1 до 10⁶.

**Формат вывода.** Одно число — наибольшее среднее. Ответ принимается с абсолютной или относительной погрешностью 10⁻⁶.

## Подсказки
- Проверка «есть ли отрезок длины ≥ k со средним ≥ m»: вычтите m из всех элементов и ищите отрезок с неотрицательной суммой.
- Для правого конца r нужен минимальный префикс среди индексов до r − k. Бинпоиск по m — фиксированное число итераций.

## Разбор
Бинпоиск по ответу m. Проверка: среднее отрезка ≥ m ⇔ сумма `(a[i] − m)` по отрезку ≥ 0. Считаем префиксные суммы преобразованного массива и для каждого правого конца r сравниваем текущий префикс с минимальным среди префиксов `0 … r − k` — это самый выгодный левый конец для отрезка длины не меньше k. Если разность ≥ 0 хотя бы раз, среднее m достижимо.

Проверка монотонна: если достижимо m, достижимо и любое меньшее. Ответ лежит между минимумом и максимумом массива; 50 итераций вещественного бинпоиска сужают этот диапазон до точности, с запасом достаточной для 10⁻⁶.

**Сложность:** O(n · 50).
