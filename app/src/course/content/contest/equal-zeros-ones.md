Дан массив из нулей и единиц. Найдите длину самого длинного отрезка подряд идущих элементов, в котором нулей и единиц поровну. Если такого отрезка нет, выведите 0.

**Формат ввода.** Первая строка — n (1 ≤ n ≤ 2·10⁵). Вторая — n чисел 0 или 1.

**Формат вывода.** Одно число.

## Подсказки
- Замените нули на −1: нужен самый длинный отрезок с суммой 0.
- Два одинаковых значения префиксной суммы ограничивают отрезок с нулевой суммой. Храните первое вхождение каждого значения.

## Разбор
После замены 0 → −1 условие «поровну» превращается в «сумма равна 0». Отрезок (l, r] имеет нулевую сумму, если `pref[l] == pref[r]`. Самый длинный — между первым и последним вхождением одного значения префикса.

Словарь «значение префикса → первый индекс», начальное `{0: 0}` (пустой префикс). Для каждого r, если значение уже встречалось, кандидат — `r - first[value]`.

**Сложность:** O(n).
