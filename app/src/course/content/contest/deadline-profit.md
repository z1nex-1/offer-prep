Есть n заданий. Каждое выполняется ровно за один день, у задания i есть дедлайн dᵢ (его нужно выполнить в один из дней 1, 2, …, dᵢ) и награда pᵢ. В день можно выполнить только одно задание. Какую наибольшую суммарную награду можно получить?

**Формат ввода.** Первая строка — n (1 ≤ n ≤ 2·10⁵). Далее n строк по два числа dᵢ и pᵢ (1 ≤ dᵢ ≤ 10⁹, 1 ≤ pᵢ ≤ 10⁹).

**Формат вывода.** Одно число.

## Подсказки
- Отсортируйте задания по дедлайну и набирайте их в «корзину».
- Если заданий в корзине больше, чем текущий дедлайн, выбросьте самое дешёвое — нужна min-куча.

## Разбор
Идём по заданиям в порядке возрастания дедлайна и кладём награду в min-кучу — это набор выбранных заданий. Набор из k заданий с дедлайнами не меньше k всегда можно расписать (выполнять в порядке дедлайнов). Если после добавления в куче стало больше заданий, чем текущий дедлайн d, какое-то задание не успеть — выбрасываем самое дешёвое (корень кучи). В конце сумма наград в куче — ответ.

Почему это оптимально: на каждом префиксе по дедлайнам мы храним самые дорогие задания, которые можно успеть, и выбрасывание самого дешёвого не может помешать будущим выборам — у будущих заданий дедлайны не меньше.

**Сложность:** O(n log n).
