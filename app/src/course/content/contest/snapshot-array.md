Массив из n элементов изначально заполнен нулями. Команды:

- `SET i v` — присвоить элементу i (нумерация с нуля) значение v;
- `SNAP` — сделать снимок массива и вывести его номер (снимки нумеруются с нуля по порядку);
- `GET i s` — вывести значение элемента i в снимке s (гарантируется, что снимок s уже сделан).

**Формат ввода.** Первая строка — n и q (1 ≤ n ≤ 10⁵, 1 ≤ q ≤ 2·10⁵). Далее q команд, |v| ≤ 10⁹.

**Формат вывода.** Ответы команд `SNAP` и `GET`, каждый на отдельной строке.

## Подсказки
- Копировать массив при каждом снимке — слишком дорого.
- Для каждого индекса храните историю пар (номер снимка, значение); GET — бинпоиск.

## Разбор
Для каждого индекса храним историю изменений: списки номеров снимков и значений. Изменение пишется «в текущий снимок» — номер снимка, который будет сделан следующим. Если в этом снимке индекс уже меняли, значение перезаписывается, иначе добавляется новая пара. `SNAP` просто увеличивает счётчик — O(1).

`GET i s` ищет последнее изменение с номером снимка ≤ s — бинпоиском по списку номеров. Если изменений не было — значение 0.

Копирование массива на каждый `SNAP` — O(n·q) = 2·10¹⁰ при максимальных ограничениях.

**Сложность:** `SET` и `SNAP` — O(1), `GET` — O(log q).
