Дан строго возрастающий список целых чисел. Сверните его в строку диапазонов: подряд идущие числа `a, a+1, …, b` записываются как `a-b` (если в группе хотя бы два числа), одиночные числа — как есть. Диапазоны разделяются запятыми без пробелов.

Например, `0 1 2 4 5 7` превращается в `0-2,4-5,7`.

**Формат ввода.** В первой строке — n (1 ≤ n ≤ 10⁵). Во второй — n целых чисел в порядке строгого возрастания, по модулю не больше 10⁹.

**Формат вывода.** Одна строка — свёрнутая запись.

## Подсказки
- Найдите начало серии i и бегите указателем j, пока следующий элемент на единицу больше текущего.
- После обработки серии прыгайте сразу на j + 1 — так каждый элемент просматривается один раз.

## Разбор
Классическая задача с собеседований Яндекса. Два индекса: `i` — начало серии, `j` — её конец. Пока `a[j + 1] == a[j] + 1`, двигаем `j`. Серию из одного числа печатаем как число, длиннее — как `a[i]-a[j]`. Затем `i = j + 1`.

Отрицательные числа не мешают: `-3 -2 -1` превратится в `-3--1` — так и должно быть по условию.

Собирайте части в список и склеивайте `",".join(parts)` — конкатенация строк в цикле может быть квадратичной.

**Сложность:** O(n).
