Дан массив из n натуральных чисел. Можно удалить ровно одно число. Какой наибольший НОД оставшихся чисел можно получить?

**Формат ввода.** Первая строка — n (2 ≤ n ≤ 2·10⁵). Вторая — n чисел от 1 до 10¹⁸.

**Формат вывода.** Одно число.

## Подсказки
- Перебрать, какое число удалить, и каждый раз считать НОД заново — O(n²).
- Префиксные и суффиксные НОД: без элемента i ответ — gcd(pref[i − 1], suf[i + 1]).

## Разбор
НОД, как и сумма, «складывается» по префиксам: `pref[i] = gcd(pref[i-1], a[i])`, `suf[i] = gcd(a[i], suf[i+1])`. НОД всех чисел, кроме i-го, — `gcd(pref[i-1], suf[i+1])`, причём `gcd(0, x) = x` удобно служит нейтральным элементом для краёв.

Считаем два массива за O(n) и перебираем удаляемый элемент — ещё O(n). Тот же приём работает для любой ассоциативной операции без обратной: максимум, побитовое ИЛИ, произведение по модулю не простого числа.

**Сложность:** O(n log C), где log C — стоимость одного НОД.
