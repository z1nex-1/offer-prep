Банкомат выдаёт купюры номиналами 50, 100, 200, 500, 1000, 2000 и 5000 рублей, каждого номинала — сколько угодно. Нужно выдать сумму S минимальным количеством купюр. Если выдать сумму нельзя, выведите −1.

**Формат ввода.** Одно число S (1 ≤ S ≤ 10¹⁸).

**Формат вывода.** Минимальное число купюр или −1.

## Подсказки
- Сумму, не кратную 50, выдать нельзя.
- Для такой системы номиналов жадность верна: берите как можно больше самых крупных купюр.

## Разбор
Если S не делится на 50 — ответ −1. Иначе жадно: сколько влезает купюр по 5000, потом по 2000 и так далее, с помощью `divmod`, а не цикла по одной купюре — S может быть до 10¹⁸.

Почему жадность здесь верна: номиналы 50·(1, 2, 4, 10, 20, 40, 100) образуют «каноническую» систему — в оптимальном ответе меньших купюр всегда мало (например, двух купюр по 50 никогда не бывает: их заменяет одна 100). Для произвольных номиналов, например 1, 3, 4, жадность ошибается, и нужна динамика.

**Сложность:** O(число номиналов).
