Даны n отрезков [lᵢ, rᵢ] (концы включаются, возможно lᵢ > rᵢ — тогда отрезок задан в обратном порядке) и m точек. Для каждой точки выведите, скольким отрезкам она принадлежит.

Похожая задача есть в подборке CodeRun для бэкенд-стажёров.

**Формат ввода.** Первая строка — n и m (1 ≤ n, m ≤ 10⁵). Далее n строк по два числа — концы отрезков. Последняя строка — m чисел, координаты точек. Все числа по модулю не больше 10⁹.

**Формат вывода.** m чисел через пробел — ответы для точек в порядке ввода.

## Подсказки
- Метод событий: начало отрезка, точка, конец отрезка. При равной координате: сначала начала, потом точки, потом концы.
- Альтернатива — два отсортированных массива начал и концов и бинпоиск.

## Разбор
**События.** Для каждого отрезка — `(min(l, r), 0)` и `(max(l, r), 2)`, для каждой точки — `(x, 1, индекс)`. Сортируем. При одинаковой координате начала (тип 0) идут раньше точек, а концы (тип 2) — позже: так точка на границе отрезка засчитывается, ведь концы включены. Проходим со счётчиком открытых отрезков; в событии-точке записываем счётчик в ответ по её индексу.

**Бинпоиск.** Отсортируем отдельно все левые концы L и все правые R. Для точки x ответ = (число левых концов ≤ x) − (число правых концов < x) = `bisect_right(L, x) - bisect_left(R, x)`. Каждая точка — O(log n).

**Сложность:** O((n + m) log(n + m)).
