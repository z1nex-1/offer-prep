Дан массив из нулей и единиц. Найдите длину самой длинной последовательности единиц, идущих подряд.

**Формат ввода.** В первой строке — число n (0 ≤ n ≤ 10⁵). Во второй строке — n чисел, каждое равно 0 или 1, через пробел. При n = 0 вторая строка пустая.

**Формат вывода.** Одно число — длина самой длинной серии единиц.

## Подсказки
- Достаточно одного прохода: храните длину текущей серии и лучшую длину.
- Встретили ноль — текущая серия обнуляется. Отдельно обрабатывать пустой массив не нужно, если начальные значения — нули.

## Разбор
Идём по массиву и поддерживаем два числа: `cur` — длину серии единиц, которая заканчивается на текущем элементе, и `best` — лучший ответ. Единица продлевает серию, ноль обнуляет её. После каждого шага обновляем `best`.

Эта задача — пример из официальной статьи Яндекса об алгоритмических секциях. Обратите внимание: решение с нулевыми начальными значениями само обрабатывает пустой массив, и отдельная проверка `if not arr` не нужна — именно такой код Яндекс называет «поэлегантнее».

**Сложность:** O(n) времени, O(1) дополнительной памяти, не считая чтения ввода.
