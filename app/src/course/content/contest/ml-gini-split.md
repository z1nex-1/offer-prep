Решающее дерево выбирает в узле разбиение «x ≤ t» по одному признаку. Даны n объектов: значение признака и класс. Найдите порог t, который минимизирует взвешенный критерий Джини детей:

```text
G(t) = (|L| / n) · Gini(L) + (|R| / n) · Gini(R),     Gini(S) = 1 − Σₖ pₖ²
```

где L — объекты с x ≤ t, R — объекты с x > t, pₖ — доля класса k в части. Обе части должны быть непустыми. В качестве t рассматриваются только середины между соседними различными значениями признака. Гарантируется, что различных значений хотя бы два, а лучший порог единственный.

**Формат ввода.** Первая строка — n (2 ≤ n ≤ 10⁵). Следующие n строк — значение признака (целое, по модулю не больше 10⁹) и класс (целое от 0 до 9).

**Формат вывода.** Два числа через пробел: порог t и значение G(t). Ответ принимается с абсолютной или относительной погрешностью 10⁻⁶.

## Подсказки
- Перебор порогов с пересчётом Джини с нуля — O(n²). Отсортируйте объекты по признаку.
- Идите по отсортированному списку и переносите объекты из правой части в левую, обновляя счётчики классов.
- Проверяйте разбиение только там, где следующее значение признака отличается от текущего.

## Разбор
Сортируем пары (x, класс). Изначально все объекты справа: `right[k]` — число объектов класса k. Идём по позициям: переносим объект влево (`left[y] += 1`, `right[y] -= 1`) и, если следующее значение признака другое, считаем G для порога посередине между ними.

Джини части за O(число классов): 1 − Σ (cntₖ / m)². Удобно заметить, что m · Gini = m − Σ cntₖ² / m, тогда

```text
n · G = |L| − ΣL² / |L| + |R| − ΣR² / |R|
```

и суммы квадратов можно обновлять за O(1) при переносе одного объекта: (c + 1)² − c² = 2c + 1. С десятью классами это не обязательно, но для общего случая удобно.

Почему только середины между различными значениями: порог внутри группы равных x не может разделить их, а любой порог между двумя соседними значениями даёт одно и то же разбиение — середина лишь соглашение (так делает sklearn).

**Сложность:** O(n log n + n·K), K — число классов.
