В поисковой строке работает подсказка: по введённому началу слова она показывает, сколько слов из словаря с него начинаются. Словарь из n слов (слова могут повторяться — каждое вхождение считается отдельно). Ответьте на q запросов: сколько слов словаря начинаются с данной строки.

**Формат ввода.** В первой строке — числа n и q (1 ≤ n, q ≤ 10⁵). В следующих n строках — слова словаря, в следующих q строках — запросы. Все строки непустые, состоят из строчных латинских букв. Суммарная длина всех слов и всех запросов не больше 3·10⁵.

**Формат вывода.** Для каждого запроса — число в отдельной строке.

## Подсказки
- Если для каждого запроса проверять все слова через `startswith`, получится O(n · q) — слишком долго.
- Можно сложить в словарь все префиксы всех слов. Но сколько префиксов у слова длины 10⁵ и сколько памяти они займут?
- Префиксное дерево (trie): каждая вершина — префикс, в вершине храним, сколько слов через неё проходит.

## Разбор
Идея со словарём префиксов — `cnt[w[:i]] += 1` для всех i — работает для коротких слов, но ломается на длинных: у слова длины L есть L префиксов суммарной длиной около L²/2. Для слова из 10⁵ букв это 5·10⁹ символов — ни времени, ни памяти не хватит.

**Префиксное дерево** хранит общие начала один раз. Каждая вершина соответствует префиксу, рёбра подписаны буквами. В вершине держим счётчик: сколько слов словаря проходят через неё — это и есть число слов с таким префиксом.

```python
children = [{}]          # children[v] — словарь «буква → номер вершины»
count = [0]

def add(word):
    v = 0
    for ch in word:
        nxt = children[v].get(ch)
        if nxt is None:
            nxt = len(children)
            children[v][ch] = nxt
            children.append({})
            count.append(0)
        v = nxt
        count[v] += 1

def query(prefix):
    v = 0
    for ch in prefix:
        v = children[v].get(ch)
        if v is None:
            return 0
    return count[v]
```

Добавление слова длины L — O(L), запрос длины m — O(m). Вершин не больше суммарной длины слов плюс одна.

Хранить вершины удобнее в списках с номерами, чем объектами класса: так быстрее и меньше памяти в Python.

Альтернатива без дерева — **сортировка и бинарный поиск**: отсортировать слова, и все слова с префиксом p образуют непрерывный отрезок. Его левая граница — `bisect_left(words, p)`, правая — `bisect_left(words, p + "{")`: символ `{` идёт в таблице сразу после `z`. Это O(m log n) на запрос, тоже укладывается.

**Сложность:** O(суммарной длины строк) времени и памяти для trie.
