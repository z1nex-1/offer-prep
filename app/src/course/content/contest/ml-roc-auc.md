Даны n объектов: верная метка (0 или 1) и score модели. Посчитайте ROC-AUC — долю пар «положительный объект, отрицательный объект», в которых у положительного score больше. Пара с равными score засчитывается как половина.

Гарантируется, что в выборке есть объекты обоих классов.

**Формат ввода.** Первая строка — n (2 ≤ n ≤ 10⁵). Следующие n строк — метка и score через пробел. Score — число от 0 до 1, не больше 4 знаков после точки; равные score встречаются часто.

**Формат вывода.** Одно число — ROC-AUC. Ответ принимается с абсолютной или относительной погрешностью 10⁻⁶.

## Подсказки
- Перебор всех пар — O(n²), при n = 10⁵ это 2,5·10⁹ пар. Отсортируйте объекты по score.
- Идите по возрастанию score группами равных значений: каждый положительный объект группы «выигрывает» у всех отрицательных, пройденных раньше, и делит половину пары с отрицательными своей группы.
- Другой способ — сумма рангов положительных (ранг группы равных — среднее её позиций).

## Разбор
ROC-AUC равен вероятности того, что случайный положительный объект получит score выше случайного отрицательного, — это и есть доля «правильно упорядоченных» пар. Считать её надо без перебора пар.

Отсортируем объекты по score и пойдём группами равных значений, храня `neg_before` — число отрицательных с меньшим score. Для группы с `pos` положительными и `neg` отрицательными добавляем `pos · neg_before + pos · neg / 2`: у всех отрицательных левее положительные выигрывают, с отрицательными своей группы — ничья. Затем `neg_before += neg`. Ответ — сумма, делённая на P·N, где P и N — число положительных и отрицательных.

```python
good = 0.0
neg_before = 0
for group in groups_by_score_ascending:
    good += pos * neg_before + pos * neg / 2
    neg_before += neg
print(good / (P * N))
```

Это то же самое, что формула через сумму рангов (статистика Манна — Уитни): (Σ рангов положительных − P(P + 1)/2) / (P·N).

Ловушки: забыть про равные score (без них ответ будет смещён — в тестах много одинаковых значений) и сравнивать score как строки — `"0.5"` и `"0.50"` должны быть равны.

**Сложность:** O(n log n) на сортировку.
