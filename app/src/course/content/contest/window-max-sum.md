Дан массив из n целых чисел и число k. Найдите наибольшую сумму k подряд идущих элементов.

**Формат ввода.** Первая строка — n и k (1 ≤ k ≤ n ≤ 2·10⁵). Вторая — n целых чисел по модулю не больше 10⁹.

**Формат вывода.** Одно число.

## Подсказки
- Сдвигая окно на один элемент, прибавьте вошедший и вычтите вышедший.

## Разбор
Сумма первого окна считается один раз. При сдвиге окна вправо в него входит `a[i]` и выходит `a[i - k]` — сумма пересчитывается за O(1). Максимум по всем окнам — ответ.

Начальный ответ — сумма первого окна, а не 0: все числа могут быть отрицательными.

**Сложность:** O(n).
