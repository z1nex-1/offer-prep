Есть n предметов, у предмета i вес wᵢ и ценность cᵢ. В рюкзак помещается суммарный вес не больше W. Каждый предмет можно взять не больше одного раза. Какую наибольшую суммарную ценность можно унести?

**Формат ввода.** Первая строка — n и W (1 ≤ n ≤ 100, 1 ≤ W ≤ 10⁴). Далее n строк: wᵢ cᵢ (1 ≤ wᵢ ≤ 10⁴, 1 ≤ cᵢ ≤ 10⁹).

**Формат вывода.** Одно число.

## Подсказки
- dp[c] — наибольшая ценность при вместимости c.
- Для рюкзака 0/1 перебирайте вместимость справа налево, иначе предмет возьмётся несколько раз.

## Разбор
Одномерная динамика: `dp[c]` — лучшая ценность, которую можно уложить в вместимость c, предметами, рассмотренными до сих пор. Для каждого предмета обновляем `dp[c] = max(dp[c], dp[c − w] + v)` для c от W вниз до w. Обход **справа налево** гарантирует, что `dp[c − w]` ещё не учитывает текущий предмет — иначе он бы взялся дважды (это был бы неограниченный рюкзак).

Жадность по удельной ценности здесь не работает — предметы нельзя делить.

**Сложность:** O(n · W).
