Бинарный классификатор сделал предсказания для n объектов. Даны верные метки и предсказанные метки (1 — положительный класс). Посчитайте precision, recall и F1 для класса 1.

Если знаменатель какой-то метрики равен нулю (модель не назвала положительным ни один объект или в выборке нет положительных), считайте эту метрику равной 0. F1 тоже равна 0, если precision + recall = 0.

**Формат ввода.** Первая строка — n (1 ≤ n ≤ 10⁵). Вторая — n верных меток (0 или 1). Третья — n предсказанных меток (0 или 1).

**Формат вывода.** Три числа через пробел — precision, recall и F1. Ответ принимается с абсолютной или относительной погрешностью 10⁻⁶.

## Подсказки
- Посчитайте TP, FP и FN одним проходом по парам меток.
- F1 удобно считать как 2·TP / (2·TP + FP + FN): так не нужна отдельная проверка precision + recall = 0.

## Разбор
Один проход по парам (y, p): TP — обе единицы, FP — предсказали 1 при y = 0, FN — предсказали 0 при y = 1. Дальше формулы precision = TP / (TP + FP), recall = TP / (TP + FN) с защитой от деления на ноль.

F1 = 2PR / (P + R) = 2·TP / (2·TP + FP + FN) — вторую форму легко получить, подставив определения. Если TP = 0, F1 = 0, а знаменатель 2·TP + FP + FN равен нулю, только когда в выборке нет ни положительных, ни ложных срабатываний.

Печатать лучше с запасом знаков: `print(f"{p:.9f} {r:.9f} {f:.9f}")`.

**Сложность:** O(n).
