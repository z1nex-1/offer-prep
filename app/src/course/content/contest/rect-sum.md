Дана таблица n × m из целых чисел и q запросов. Каждый запрос — прямоугольник с противоположными углами (x₁, y₁) и (x₂, y₂) (строка, столбец, нумерация с единицы, x₁ ≤ x₂, y₁ ≤ y₂). Выведите сумму чисел в прямоугольнике.

Задача с таким названием есть в тренировках Яндекса по алгоритмам.

**Формат ввода.** Первая строка — n, m, q (1 ≤ n, m ≤ 300, 1 ≤ q ≤ 10⁵). Далее n строк по m чисел (по модулю не больше 10⁶). Далее q строк по четыре числа x₁ y₁ x₂ y₂.

**Формат вывода.** q чисел, каждое на отдельной строке.

## Подсказки
- Двумерная префиксная сумма P[i][j] — сумма прямоугольника от (1, 1) до (i, j).
- Ответ — P[x₂][y₂] − P[x₁−1][y₂] − P[x₂][y₁−1] + P[x₁−1][y₁−1].

## Разбор
`P[i][j]` — сумма всех чисел в прямоугольнике от (1, 1) до (i, j), с нулевыми строкой и столбцом по краям. Заполняется за O(n·m): `P[i][j] = a[i][j] + P[i-1][j] + P[i][j-1] - P[i-1][j-1]` — прямоугольник `P[i-1][j-1]` посчитан в двух слагаемых, поэтому вычитается.

Ответ на запрос — формула включений-исключений: из большого прямоугольника вычитаем полосу сверху и полосу слева, а угол, вычтенный дважды, возвращаем.

**Сложность:** O(n·m + q).
