Дан массив из n целых чисел и число X. Выберите два элемента с разными индексами так, чтобы их сумма была как можно ближе к X. Выведите эту сумму. Если лучших вариантов несколько — выведите наименьшую из подходящих сумм.

**Формат ввода.** Первая строка — n и X (2 ≤ n ≤ 2·10⁵, |X| ≤ 2·10⁹). Вторая — n целых чисел по модулю не больше 10⁹.

**Формат вывода.** Одно число — сумма пары, ближайшая к X.

## Подсказки
- Отсортируйте и примените встречные указатели: сумма меньше X — сдвигайте левый, больше — правый.
- Сравнивайте кандидатов парой (|сумма − X|, сумма): так при равенстве выберется меньшая сумма.

## Разбор
После сортировки встречные указатели перебирают все «перспективные» пары: если `a[l] + a[r] < X`, то увеличить сумму можно только сдвигом `l` (с `a[r]` и меньшими правыми сумма лишь уменьшится — они не ближе). Если больше — сдвигаем `r`. Если ровно X — ответ найден.

Каждую рассмотренную сумму сравниваем с лучшей по ключу `(abs(s - X), s)` — это автоматически учитывает правило «при равенстве — меньшая сумма».

**Сложность:** O(n log n).
