Дан массив из n чисел и число k. Для каждого окна из k подряд идущих элементов выведите нижнюю медиану окна: элемент с номером ⌊(k + 1) / 2⌋ в отсортированном по возрастанию окне.

**Формат ввода.** Первая строка — n и k (1 ≤ k ≤ n ≤ 10⁵). Вторая — n целых чисел по модулю не больше 10⁹.

**Формат вывода.** n − k + 1 чисел через пробел.

## Подсказки
- Две кучи как в медиане потока, но элементы ещё и уходят из окна.
- Ленивое удаление: помечайте ушедший элемент и выбрасывайте его, когда он окажется на вершине. Балансируйте по «логическим» размерам.

## Разбор
Две кучи (левая max, правая min) с ленивым удалением. Словарь `delayed` считает, сколько копий каждого значения должно быть удалено. При выходе элемента из окна: помечаем его, уменьшаем логический размер той половины, где он лежит (сравнив с вершиной левой кучи), и если он на вершине — сразу чистим кучу. После каждого изменения балансируем так, чтобы логический размер левой был равен ⌈k / 2⌉, и очищаем вершины от помеченных элементов. Нижняя медиана — вершина левой кучи.

Более простой вариант, который проходит при умеренных k: отсортированный список окна, `bisect.insort` для нового элемента и удаление ушедшего по `bisect_left` — O(k) на шаг из-за сдвига, O(n · k) всего.

**Сложность:** O(n log n) с кучами.
