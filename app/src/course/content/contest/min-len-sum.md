Дан массив из n **положительных** чисел и число S. Найдите длину самого короткого отрезка подряд идущих элементов с суммой не меньше S. Если такого нет, выведите 0.

**Формат ввода.** Первая строка — n и S (1 ≤ n ≤ 2·10⁵, 1 ≤ S ≤ 10¹⁵). Вторая — n чисел от 1 до 10⁹.

**Формат вывода.** Одно число.

## Подсказки
- Окно переменной длины: расширяйте правую границу, а пока сумма ≥ S — обновляйте ответ и сужайте слева.
- Положительность чисел гарантирует монотонность: сужение окна уменьшает сумму.

## Разбор
Правая граница `r` идёт по массиву и добавляет элементы в окно. Пока сумма окна не меньше S, окно — кандидат: обновляем ответ его длиной и выбрасываем левый элемент. Так для каждого r находим самое короткое хорошее окно, заканчивающееся в r.

Это работает только потому, что числа положительные: при сужении сумма уменьшается, при расширении — растёт. С отрицательными числами нужен другой подход (префиксные суммы и монотонный дек).

**Сложность:** O(n) — каждый элемент входит в окно и выходит из него один раз.
