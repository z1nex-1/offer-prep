Обучите нейросеть с одним скрытым слоем полным градиентным спуском. Архитектура для входа x ∈ ℝᵈ:

```text
z = W₁·x + b₁          W₁ — матрица h × d, b₁ — вектор h
a = σ(z)               σ(t) = 1 / (1 + e^(−t)) поэлементно
ŷ = w₂·a + b₂          w₂ — вектор h, b₂ — число
L = (1/n) · Σᵢ (ŷᵢ − yᵢ)²
```

Даны начальные веса. Выполните T шагов: на каждом посчитайте градиент L по всем параметрам на всей выборке (по весам до обновления) и сделайте шаг θ ← θ − η·∇L одновременно для всех параметров. Выведите итоговые веса и значение L после обучения.

**Формат ввода.** Первая строка — n, d, h, T и η (1 ≤ n ≤ 100, 1 ≤ d ≤ 4, 1 ≤ h ≤ 8, 1 ≤ T ≤ 100, 0 < η ≤ 1). Следующие n строк — d признаков и y. Затем h строк матрицы W₁ (по d чисел), строка b₁ (h чисел), строка w₂ (h чисел) и строка с b₂. Признаки и y — числа по модулю не больше 3 с не более чем двумя знаками после точки; начальные веса — по модулю не больше 1.

**Формат вывода.** h строк W₁, строка b₁, строка w₂, строка b₂ и строка с L — все числа через пробел. Ответ принимается с абсолютной или относительной погрешностью 10⁻⁶.

## Подсказки
- ∂L/∂ŷᵢ = 2(ŷᵢ − yᵢ)/n. Дальше — правило цепочки назад по слоям.
- σ'(z) = σ(z)·(1 − σ(z)) — сохраните a с прямого прохода.
- Градиент по a считается через w₂ **до** обновления.

## Разбор
Прямой проход для каждого объекта: zᵢ = W₁xᵢ + b₁, aᵢ = σ(zᵢ), ŷᵢ = ⟨w₂, aᵢ⟩ + b₂. Обратный:

```text
gᵢ = 2(ŷᵢ − yᵢ) / n                 ∂L/∂ŷᵢ
∂L/∂b₂ = Σ gᵢ
∂L/∂w₂ = Σ gᵢ · aᵢ
δᵢ = gᵢ · w₂ ⊙ aᵢ ⊙ (1 − aᵢ)         ∂L/∂zᵢ, вектор длины h
∂L/∂b₁ = Σ δᵢ
∂L/∂W₁ = Σ δᵢ · xᵢᵀ                  внешнее произведение h × d
```

Градиенты копим по всем объектам, затем обновляем все параметры одновременно. Самые частые ошибки: обновить w₂ до вычисления δ (тогда δ считается по новым весам), забыть множитель 2/n, перепутать индексы в W₁ (строка — нейрон, столбец — признак).

Так устроен любой фреймворк: `loss.backward()` в PyTorch делает ровно эти шаги по графу вычислений, а `optimizer.step()` — обновление. Проверить свои формулы можно численной производной: (L(θ + ε) − L(θ − ε)) / 2ε для каждого параметра.

**Сложность:** O(T · n · d · h).
