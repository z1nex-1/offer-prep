По массиву из n чисел двигается окно длины k: сначала в нём первые k чисел, затем окно сдвигается на один элемент вправо, и так до конца. Выведите минимум для каждого положения окна.

Задача «Минимум на отрезке» с тем же смыслом есть в подборках CodeRun «Стажировка // Бэкенд» и «Собеседование в Эйчартех».

**Формат ввода.** Первая строка — n и k (1 ≤ k ≤ n ≤ 2·10⁵). Вторая — n целых чисел по модулю не больше 10⁹.

**Формат вывода.** n − k + 1 чисел, каждое на отдельной строке.

## Подсказки
- Монотонная очередь: дек индексов, значения в котором возрастают от головы к хвосту.
- Голова дека — минимум окна; если она вышла за левую границу окна, удалите её.

## Разбор
Дек индексов с **возрастающими** значениями. Новый элемент удаляет из хвоста все элементы, не меньшие его: пока он в окне, они не станут минимумом, а выйдут из окна раньше него. Затем, если голова дека вышла за левую границу окна, удаляем голову. Голова — минимум текущего окна.

Решение «пересчитать `min` по окну» — O(n·k), при n и k до 10⁵ это 10¹⁰. Куча с ленивым удалением — O(n log n), тоже проходит, но дек проще и быстрее.

**Сложность:** O(n).
