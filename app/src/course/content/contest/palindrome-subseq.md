Найдите длину самой длинной подпоследовательности строки, которая является палиндромом (символы подпоследовательности не обязаны идти подряд).

**Формат ввода.** Строка из строчных латинских букв длиной от 1 до 1500.

**Формат вывода.** Одно число.

## Подсказки
- Динамика по отрезкам: dp[i][j] — ответ для подстроки s[i..j].
- Если крайние символы равны — они оба входят в ответ; иначе выбросите один из них. Считайте i по убыванию, j по возрастанию.

## Разбор
`dp[i][j]` — длина самой длинной палиндромной подпоследовательности в `s[i..j]`. Один символ — палиндром длины 1. Если `s[i] == s[j]`, крайние символы можно взять оба: `dp[i+1][j−1] + 2`. Иначе один из них не входит в ответ: `max(dp[i+1][j], dp[i][j−1])`.

Порядок: i от конца к началу, j от i + 1 вправо — тогда нужные значения уже посчитаны. Можно хранить только две строки таблицы по i.

Эквивалентная формулировка — НОП строки и её разворота.

**Сложность:** O(n²).
