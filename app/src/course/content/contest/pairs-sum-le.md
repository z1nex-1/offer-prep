Дан массив из n целых чисел и число S. Сколько существует пар индексов i < j, для которых aᵢ + aⱼ ≤ S?

**Формат ввода.** Первая строка — n и S (1 ≤ n ≤ 2·10⁵, |S| ≤ 2·10⁹). Вторая — n целых чисел по модулю не больше 10⁹.

**Формат вывода.** Одно число — количество пар.

## Подсказки
- Порядок элементов не влияет на количество пар — массив можно отсортировать.
- В отсортированном массиве встречные указатели: если a[l] + a[r] ≤ S, то подходят все пары (l, l+1..r).

## Разбор
Ответ не зависит от порядка элементов, поэтому сортируем. Встречные указатели `l = 0`, `r = n - 1`:

- если `a[l] + a[r] <= S`, то с `a[l]` подходит и любой элемент между `l` и `r` (они не больше `a[r]`) — это `r - l` пар; сдвигаем `l`;
- иначе `a[r]` слишком велик даже для самого маленького — сдвигаем `r`.

Альтернатива — для каждого i бинпоиском найти последний j с `a[j] <= S - a[i]`, тоже O(n log n).

Ответ может быть до 2·10¹⁰ — в Python переполнения нет, но в C++ понадобился бы 64-битный тип.

**Сложность:** O(n log n) на сортировку и O(n) на проход.
