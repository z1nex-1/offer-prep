Числа приходят по одному. После каждого нового числа выведите k-е по величине среди всех уже пришедших чисел (k-е наибольшее с учётом повторов), или −1, если чисел пока меньше k.

**Формат ввода.** В первой строке — n и k (1 ≤ k ≤ n ≤ 3·10⁴). Во второй — n целых чисел от −10⁹ до 10⁹.

**Формат вывода.** n чисел через пробел.

## Подсказки
- Сортировать все числа после каждого нового — O(n² log n).
- Нужны только k самых больших чисел. Среди них важно одно — наименьшее. Какая структура быстро отдаёт минимум?

## Разбор
Храним k наибольших чисел в куче-минимуме `heapq`. На вершине кучи `h[0]` — наименьшее из k наибольших, то есть ровно k-е по величине.

Новое число `x`:

- если в куче меньше k чисел — `heappush(h, x)`;
- иначе, если `x > h[0]`, — `heapreplace(h, x)`: вытолкнуть минимум и положить `x` одной операцией за O(log k). Если `x <= h[0]`, оно не входит в k наибольших и ничего не меняет.

Ответ после шага — `h[0]`, если в куче k чисел, иначе −1.

`heapq` в Python — куча-минимум. Для задач «k наименьших» кладут числа со знаком минус.

**Сложность:** O(n log k) времени, O(k) памяти.
