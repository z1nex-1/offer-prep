Модель предсказала вероятности класса 1 для n объектов. Посчитайте logloss модели и logloss константного предсказания, которое каждому объекту даёт долю единиц в выборке. Так проверяют, лучше ли модель простейшего бейзлайна.

logloss = −(1/n) · Σ [yᵢ·ln(pᵢ) + (1 − yᵢ)·ln(1 − pᵢ)], натуральный логарифм. Перед подсчётом каждую вероятность (и модели, и константы) обрежьте до отрезка [10⁻¹⁵, 1 − 10⁻¹⁵].

**Формат ввода.** Первая строка — n (1 ≤ n ≤ 10⁵). Вторая — n меток 0 или 1. Третья — n вероятностей от 0 до 1 включительно, не больше 6 знаков после точки.

**Формат вывода.** Два числа через пробел — logloss модели и logloss константы. Ответ принимается с абсолютной или относительной погрешностью 10⁻⁶.

## Подсказки
- Без обрезки вероятность 0 для объекта класса 1 даёт ln(0) — ошибку.
- Константа — среднее меток. Если все метки одинаковы, она равна 0 или 1 и тоже обрезается.

## Разбор
Для каждого объекта берём логарифм вероятности, которую модель дала **верному** ответу: ln(p) при y = 1 и ln(1 − p) при y = 0; logloss — минус среднее этих логарифмов. Обрезка `p = min(max(p, eps), 1 - eps)` нужна, потому что модели выдают ровно 0 и 1, а ln(0) не определён. Уверенная ошибка даёт штраф около −ln(10⁻¹⁵) ≈ 34.5 — одна такая ошибка на сотню объектов заметно портит метрику.

Константа p̄ = (Σ yᵢ) / n — лучшая константа для logloss: её logloss равен энтропии −p̄·ln p̄ − (1 − p̄)·ln(1 − p̄). Модель с logloss хуже константы не умеет ничего полезного.

В Python `math.log` — натуральный логарифм.

**Сложность:** O(n).
