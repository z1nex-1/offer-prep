Для каждой пары дробей a/b и c/d выведите `<`, `>` или `=`.

**Формат ввода.** В первой строке — q (1 ≤ q ≤ 10⁴). В каждой из следующих q строк — четыре натуральных числа a, b, c, d (все от 1 до 10¹⁸).

**Формат вывода.** Для каждой пары в отдельной строке один символ: `<`, если a/b < c/d, `>`, если больше, и `=`, если дроби равны.

## Подсказки
- Попробуйте на своём решении пару `999999999999999999 1000000000000000000 999999999999999998 999999999999999999`.
- Как сравнить две дроби, не деля?

## Разбор
Деление `a / b` даёт `float` с 15–16 значащими цифрами. Дроби с числителями и знаменателями до 10¹⁸ могут отличаться в 36-м знаке, и `float` их не различит: пара из подсказки при делении даёт равенство, хотя первая дробь больше. Допуск `1e-9` делу не поможет — он лишь меняет, какие близкие дроби будут считаться равными.

При положительных знаменателях `a/b < c/d` равносильно `a · d < c · b`. Произведения до 10³⁶ Python хранит точно, и сравнение получается честным.

Можно и `fractions.Fraction(a, b) < Fraction(c, d)` — тоже точно, но медленнее: `Fraction` сокращает дробь, вычисляя НОД.

**Сложность:** O(1) на запрос для чисел фиксированной длины.
