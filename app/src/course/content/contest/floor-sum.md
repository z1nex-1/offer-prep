Найдите сумму `⌊n/1⌋ + ⌊n/2⌋ + ⌊n/3⌋ + … + ⌊n/n⌋`, где `⌊x⌋` — целая часть.

**Формат ввода.** Одно целое n (1 ≤ n ≤ 10¹¹).

**Формат вывода.** Одно число — сумма.

## Подсказки
- Цикл до n — 10¹¹ итераций. Выпишите значения `n // i` для n = 20: много ли среди них разных?
- При i > √n значение `n // i` меньше √n. Значит, разных значений не больше 2√n.
- Для текущего i найдите последнее i', при котором `n // i'` такое же, и прибавьте всё это значение сразу за весь блок.

## Разбор
Значения `n // i` идут блоками одинаковых. Если `q = n // i`, то последний индекс с тем же частным — `last = n // q`. Прибавляем `q · (last − i + 1)` и переходим к `i = last + 1`.

Разных значений не больше 2√n: при i ≤ √n различных i не больше √n, а при i > √n само частное меньше √n. Поэтому цикл делает O(√n) шагов — около 6·10⁵ при n = 10¹¹.

Другой способ — через симметрию. Сумма равна числу пар (i, j) с `i · j ≤ n`. Эти точки под гиперболой симметричны относительно прямой i = j, поэтому ответ `2 · (n // 1 + … + n // s) − s²`, где `s = ⌊√n⌋` (`math.isqrt`). Здесь всего √n шагов.

Заодно сумма равна `d(1) + d(2) + … + d(n)` — суммарному числу делителей всех чисел до n: каждое i посчитано столько раз, сколько у него кратных, не больших n.

**Сложность:** O(√n).
