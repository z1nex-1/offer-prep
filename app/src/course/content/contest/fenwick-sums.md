Дан массив из n целых чисел. Нужно обработать q запросов двух видов:

- `1 i x` — присвоить элементу с номером i значение x;
- `2 l r` — вывести сумму элементов с номерами от l до r включительно.

Элементы нумеруются с единицы.

**Формат ввода.** В первой строке — n и q (1 ≤ n, q ≤ 10⁵). Во второй — n чисел массива. Далее q строк с запросами. Все значения по модулю не больше 10⁹, 1 ≤ i ≤ n, 1 ≤ l ≤ r ≤ n.

**Формат вывода.** Для каждого запроса второго вида — сумму в отдельной строке.

## Подсказки
- Префиксные суммы отвечают за O(1), но после изменения одного элемента их нужно пересчитывать за O(n).
- Нужна структура, где и изменение, и сумма на префиксе стоят O(log n).
- Дерево Фенвика хранит в ячейке i сумму отрезка длины `i & -i`, который заканчивается в i.
- Присваивание x — это прибавление разности `x - a[i]`. Храните сам массив рядом с деревом.

## Разбор
Два наивных решения: хранить массив и суммировать отрезок циклом (изменение O(1), сумма O(n)) или хранить префиксные суммы (сумма O(1), изменение O(n)). В худшем случае оба — 10¹⁰ операций.

**Дерево Фенвика** держит обе операции за O(log n). Ячейка `t[i]` (нумерация с единицы) хранит сумму элементов с `i - (i & -i) + 1` по `i`. Выражение `i & -i` — младший установленный бит числа i: для 12 = 1100₂ это 4, значит, `t[12]` хранит сумму a[9..12].

```python
def add(i, delta):          # a[i] += delta
    while i <= n:
        t[i] += delta
        i += i & -i

def prefix(i):              # a[1] + ... + a[i]
    s = 0
    while i > 0:
        s += t[i]
        i -= i & -i
    return s
```

При подсчёте префикса мы откусываем от i младший бит: отрезки `t[i]` идут встык и покрывают [1, i]. При изменении поднимаемся ко всем ячейкам, чей отрезок содержит i. Каждый цикл делает не больше log₂ n шагов.

Сумма на [l, r] — это `prefix(r) - prefix(l - 1)`. Присваивание превращаем в прибавление: `add(i, x - a[i])`, затем `a[i] = x`. Забыть обновить `a[i]` — самая частая ошибка: второе присваивание тому же элементу прибавит неверную разность.

Построить дерево можно n вызовами `add` за O(n log n). Есть и линейный способ: каждая ячейка передаёт свою сумму «родителю» `i + (i & -i)`.

```python
t = [0] + a[:]
for i in range(1, n + 1):
    j = i + (i & -i)
    if j <= n:
        t[j] += t[i]
```

Ту же задачу решает дерево отрезков. Оно длиннее в коде, но умеет больше: минимум, максимум, изменение на отрезке. Для суммы с точечными изменениями Фенвик короче и быстрее.

**Сложность:** O((n + q) log n) времени, O(n) памяти.
