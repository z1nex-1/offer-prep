Дано n слов. Разобьём их на группы: слова в одной группе — анаграммы друг друга. Выведите количество групп и размер самой большой группы.

**Формат ввода.** Первая строка — n (1 ≤ n ≤ 10⁵). Далее n строк — слова из строчных латинских букв длиной от 1 до 20.

**Формат вывода.** Два числа через пробел.

## Подсказки
- Нужен ключ, одинаковый у всех анаграмм.
- Отсортированные буквы слова или кортеж частот — хороший ключ для словаря.

## Разбор
Каноническая форма слова — строка его отсортированных букв: у анаграмм она совпадает, у остальных различается. Считаем, сколько раз встречается каждый ключ: число ключей — число групп, максимальный счётчик — размер наибольшей группы.

Одинаковые слова тоже анаграммы друг друга (перестановка может быть тождественной) — они попадают в одну группу.

**Сложность:** O(n · L log L), где L — длина слова.
