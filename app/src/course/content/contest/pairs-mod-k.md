Дан массив из n целых чисел и число k. Сколько существует пар индексов i < j, для которых aᵢ + aⱼ делится на k?

**Формат ввода.** Первая строка — n и k (1 ≤ n ≤ 2·10⁵, 1 ≤ k ≤ 10⁹). Вторая — n целых чисел, по модулю не больше 10⁹ (числа могут быть отрицательными).

**Формат вывода.** Одно число.

## Подсказки
- Важен только остаток каждого числа по модулю k.
- Для числа с остатком r пара — число с остатком (k − r) % k. Считайте остатки в словаре за один проход.

## Разбор
Сумма делится на k, когда остатки дополняют друг друга: `(r1 + r2) % k == 0`, то есть `r2 == (k - r1) % k`. Идём по массиву и для каждого числа прибавляем к ответу, сколько раньше встретилось чисел с нужным остатком, а потом учитываем само число в словаре.

`% k` нужен и во второй раз: для остатка 0 пара — тоже 0, а не k. В Python остаток отрицательного числа по положительному модулю неотрицателен (`-3 % 5 == 2`), поэтому отрицательные числа не требуют особой обработки. Словарь вместо массива длины k — потому что k до 10⁹.

**Сложность:** O(n).
