Ответьте на t запросов: сколько единиц в двоичной записи всех чисел от 1 до n вместе?

**Формат ввода.** Первая строка — t (1 ≤ t ≤ 10⁴). Далее t строк с числом n (1 ≤ n ≤ 10¹⁸).

**Формат вывода.** t чисел — по одному в строке.

## Подсказки
- Считайте отдельно для каждого бита: в скольких числах от 0 до n он равен 1?
- Бит b повторяется блоками: 2ᵇ нулей, потом 2ᵇ единиц, период 2ᵇ⁺¹.

## Разбор
Перебор чисел до 10¹⁸ невозможен, но ответ складывается по битам. Выпишите числа 0, 1, 2, … в двоичной записи: бит номер b идёт блоками — 2ᵇ нулей, 2ᵇ единиц, и так с периодом 2ᵇ⁺¹.

Среди чисел от 0 до n (их m = n + 1) полных периодов `m // 2^(b+1)`, каждый даёт 2ᵇ единиц. Остаток `m % 2^(b+1)` даёт ещё `max(0, остаток − 2ᵇ)` единиц. Сумма по b от 0 до 60 — ответ.

Проверка на маленьком n: для n = 3 числа 1, 10, 11 — 4 единицы.

**Сложность:** O(log n) на запрос.
