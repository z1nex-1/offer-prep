Есть три стержня с номерами 1, 2 и 3. На стержне 1 лежат n дисков разного размера: внизу самый большой, сверху самый маленький. Нужно переложить все диски на стержень 3. За один ход можно снять верхний диск с любого стержня и положить на другой стержень, но нельзя класть больший диск на меньший.

Выведите последовательность ходов минимальной длины.

**Формат ввода.** Одно число n (1 ≤ n ≤ 12).

**Формат вывода.** В первой строке — число ходов k. В следующих k строках — ходы: номер стержня, с которого снимается диск, и номер стержня, на который он кладётся, через пробел.

## Подсказки
- Чтобы переложить самый большой диск со стержня 1 на стержень 3, все остальные n − 1 дисков должны лежать на стержне 2.
- Функция `move(n, a, b, c)`: переложить n дисков с `a` на `c`, используя `b` как вспомогательный. Как она выражается через `move(n - 1, …)`?

## Разбор
Классический пример «доверяй рекурсии». Чтобы переложить n дисков с `a` на `c`:

1. переложить верхние n − 1 дисков с `a` на `b` (рекурсивно, вспомогательный — `c`);
2. переложить самый большой диск с `a` на `c`;
3. переложить n − 1 дисков с `b` на `c` (рекурсивно, вспомогательный — `a`).

База — n = 0: делать ничего не нужно.

```python
def move(n, a, b, c, out):
    if n == 0:
        return
    move(n - 1, a, c, b, out)
    out.append(f"{a} {c}")
    move(n - 1, b, a, c, out)
```

Число ходов T(n) = 2T(n − 1) + 1 = 2ⁿ − 1. Меньше нельзя: самый большой диск нужно переложить хотя бы раз, а перед этим все остальные должны оказаться на третьем стержне — это уже T(n − 1) ходов, и столько же после.

Ходы копим в список и выводим одним `print("\n".join(out))` — так быстрее, чем печатать по строке.

**Сложность:** O(2ⁿ) времени — столько ходов нужно вывести; глубина рекурсии n.
