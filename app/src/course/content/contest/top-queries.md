Сервис подсказок считает, какие запросы пользователи вводят чаще всего. Команды:

- `ADD w` — пользователь ввёл запрос w (одно слово);
- `TOP k` — вывести через пробел k самых частых запросов по убыванию частоты, при равной частоте — в лексикографическом порядке. Если различных запросов меньше k — вывести все.

**Формат ввода.** Первая строка — q (1 ≤ q ≤ 10⁵). Далее q команд. Слова — из строчных латинских букв, различных слов не больше 2000, команд `TOP` не больше 1000, 1 ≤ k ≤ 10.

**Формат вывода.** Ответы команд `TOP`, каждый на отдельной строке.

## Подсказки
- Счётчик частот и частичная сортировка на каждый TOP.
- heapq.nsmallest(k, items, key=lambda x: (-x[1], x[0])) — O(D log k).

## Разбор
Словарь частот (`Counter`) обновляется за O(1) на `ADD`. Для `TOP k` нужны k лучших по ключу `(−частота, слово)`: `heapq.nsmallest(k, cnt.items(), key=...)` делает это за O(D log k), где D — число различных слов, — быстрее полной сортировки за O(D log D).

Ограничения подобраны так: D ≤ 2000 и не больше 1000 запросов топа — около 2·10⁶ операций. Если бы запросов топа было много, пришлось бы поддерживать упорядоченную структуру при каждом `ADD`.

Детерминированный порядок при равных частотах (лексикографический) — обязательная часть условия: без него ответ неоднозначен.

**Сложность:** `ADD` — O(1), `TOP` — O(D log k).
