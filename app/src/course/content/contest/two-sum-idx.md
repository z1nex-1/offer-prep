Дан массив a₁, …, aₙ и число T. Найдите индексы i < j, для которых aᵢ + aⱼ = T. Если подходящих пар несколько, выберите пару с наименьшим j, а среди них — с наименьшим i.

**Формат ввода.** Первая строка — n и T (1 ≤ n ≤ 2·10⁵, |T| ≤ 2·10⁹). Вторая — n целых чисел по модулю не больше 10⁹.

**Формат вывода.** Два числа i и j (нумерация с единицы) или 0, если пары нет.

## Подсказки
- Идите по массиву и для каждого aⱼ спрашивайте словарь: встречалось ли T − aⱼ раньше?
- Чтобы i было наименьшим, храните в словаре первое вхождение каждого значения.

## Разбор
Два вложенных цикла — O(n²). Один проход со словарём «значение → индекс первого вхождения»: для текущего j проверяем, есть ли в словаре `T - a[j]`. Первая найденная пара имеет наименьший j (идём по возрастанию j), а словарь хранит самый левый индекс — значит, и i наименьший.

Порядок «сначала проверить, потом добавить» не даёт взять элемент в пару с самим собой. Добавляем значение, только если его ещё нет, — иначе затрём первое вхождение.

**Сложность:** O(n) в среднем.
