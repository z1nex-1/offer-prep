Дан массив из нулей и единиц. Из него нужно удалить **ровно один** элемент. Какой наибольшей длины может получиться отрезок подряд идущих единиц?

Это задача с алгоритмических секций Яндекса.

**Формат ввода.** В первой строке — n (1 ≤ n ≤ 2·10⁵). Во второй — n чисел, каждое 0 или 1.

**Формат вывода.** Одно число — наибольшая длина отрезка из единиц после удаления одного элемента.

## Подсказки
- Удалять выгодно ноль, который разделяет две серии единиц: ответ — сумма длин соседних серий.
- Храните длину серии до последнего нуля и после него. Отдельно обдумайте массив совсем без нулей.

## Разбор
Состояние прохода: `cur` — длина текущей серии единиц, `prev` — длина серии перед последним встреченным нулём. На нуле `prev = cur`, `cur = 0`. Кандидат ответа на каждом шаге — `prev + cur`: это две серии, склеенные удалением разделяющего нуля.

Краевой случай: если нулей нет вовсе, удалить всё равно придётся одну единицу, и ответ `n - 1`. Проверка: максимум получился равным n только в этом случае.

Разберите на примерах `1 1 0 1` → 3, `1 1 1` → 2, `0 0` → 0.

**Сложность:** O(n) времени, O(1) памяти.
