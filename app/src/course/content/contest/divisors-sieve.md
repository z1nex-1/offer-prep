Сколько чисел от 1 до n имеют ровно t натуральных делителей?

**Формат ввода.** Два целых числа n и t (1 ≤ n ≤ 10⁶, 1 ≤ t ≤ 1000) через пробел.

**Формат вывода.** Одно число — количество таких чисел.

## Подсказки
- Перебор делителей до √k для каждого k — около (2/3) · n · √n ≈ 7·10⁸ итераций при n = 10⁶. Это TL.
- Переверните вопрос: вместо «какие делители у k» спросите «кратным каким числам d раздать +1».
- Цикл `for j in range(d, n + 1, d)` делает n / d шагов. Сколько шагов по всем d?

## Разбор
Заведём массив `cnt` из нулей длины n + 1. Для каждого d от 1 до n пройдём по его кратным — `d, 2d, 3d, …` — и увеличим у них счётчик. Каждое число k получит +1 ровно от каждого своего делителя, и после циклов `cnt[k] = d(k)`. Ответ — сколько раз в `cnt[1:]` встречается t: `cnt.count(t)`, не забыв, что `cnt[0] = 0`.

Внутренний цикл делает n / d шагов, всего n/1 + n/2 + … + n/n = n · (1 + 1/2 + … + 1/n) ≈ n ln n — около 1,4·10⁷ при n = 10⁶. Это приём решета: вместо того чтобы для каждого числа искать делители, каждый делитель «раздаёт» себя кратным. Так же устроено решето Эратосфена.

При t = 2 ответ — количество простых чисел до n: у простого ровно два делителя. У числа до 10⁶ не больше 240 делителей, поэтому при больших t ответ 0 — но и это нужно получить, а не угадать.

**Сложность:** O(n log n) времени, O(n) памяти.
