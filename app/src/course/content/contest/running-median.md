Числа поступают по одному. После каждого числа выведите медиану всех поступивших: если их нечётное количество — средний по величине элемент, если чётное — меньший из двух средних (нижняя медиана).

**Формат ввода.** Первая строка — n (1 ≤ n ≤ 2·10⁵). Вторая — n целых чисел по модулю не больше 10⁹.

**Формат вывода.** n чисел, каждое на отдельной строке.

## Подсказки
- Две кучи: max-куча для меньшей половины, min-куча для большей.
- Держите левую кучу не меньше правой и не больше чем на один элемент — нижняя медиана будет её вершиной.

## Разбор
Меньшая половина — в max-куче (с минусом), большая — в min-куче. Новое число кладём в левую, затем наибольшее из левой перекладываем в правую — так сохраняется порядок «всё левое ≤ всего правого». Если правая стала больше левой, перекладываем её минимум обратно. Левая всегда содержит на один элемент больше или столько же, и её вершина — нижняя медиана.

Сортировать после каждого числа или вставлять в отсортированный список (`insort` — O(n) на вставку) — слишком медленно на 2·10⁵.

**Сложность:** O(log n) на число.
