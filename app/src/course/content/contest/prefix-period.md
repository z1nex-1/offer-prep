Строка t называется периодом строки s, если s — префикс строки ttt…t (t, повторённая достаточно много раз). Например, у `abcabca` периоды `abc`, `abcabc` и `abcabca`. Найдите длину самого короткого периода.

**Формат ввода.** Строка из строчных латинских букв длиной от 1 до 2·10⁵.

**Формат вывода.** Одно число.

## Подсказки
- Длина k — период, если s[i] == s[i + k] для всех i, то есть префикс длины n − k совпадает с суффиксом той же длины.
- Самый длинный префикс, равный суффиксу, — последнее значение префикс-функции. Ответ n − pi[n − 1].

## Разбор
k — период тогда и только тогда, когда `s[i] == s[i + k]` для всех допустимых i, то есть префикс длины n − k равен суффиксу длины n − k. Самый короткий период соответствует самому длинному такому «бордеру» — собственному префиксу, который одновременно суффикс.

Длина наибольшего бордера — последнее значение **префикс-функции**: `pi[i]` — длина наибольшего собственного префикса `s[:i+1]`, равного его суффиксу. Ответ — `n − pi[n − 1]`.

Префикс-функция считается за O(n): каждый шаг `k = pi[k − 1]` уменьшает k, а увеличивается k не больше чем на 1 за итерацию. Проверка всех k с перебором — O(n²).

**Сложность:** O(n).
