Чтобы подняться на лестницу из n ступенек, можно шагать на 1, 2 или 3 ступеньки. Некоторые ступеньки сломаны — на них вставать нельзя. Сколькими способами можно добраться со ступеньки 0 до ступеньки n? Выведите ответ по модулю 10⁹ + 7.

**Формат ввода.** Первая строка — n и k (1 ≤ n ≤ 10⁶, 0 ≤ k < n). Вторая — k номеров сломанных ступенек (от 1 до n − 1); если k = 0, строка пустая.

**Формат вывода.** Одно число.

## Подсказки
- dp[i] — число способов добраться до ступеньки i.
- На сломанную ступеньку способов 0; остаток берите в каждом шаге.

## Разбор
`dp[i]` — число способов встать на ступеньку i. На неё можно прийти с i − 1, i − 2, i − 3: `dp[i] = dp[i−1] + dp[i−2] + dp[i−3]`. Для сломанной ступеньки `dp[i] = 0` — через неё путь невозможен. База: `dp[0] = 1`.

Остаток по модулю берём на каждом шаге, иначе числа станут огромными. Хранить можно только три последних значения, но массив на 10⁶ чисел тоже помещается.

**Сложность:** O(n).
