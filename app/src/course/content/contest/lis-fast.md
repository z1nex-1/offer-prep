Найдите длину наибольшей строго возрастающей подпоследовательности массива (элементы не обязательно идут подряд).

**Формат ввода.** Первая строка — n (1 ≤ n ≤ 2·10⁵). Вторая — n целых чисел по модулю не больше 10⁹.

**Формат вывода.** Одно число.

## Подсказки
- Решение O(n²) при n = 2·10⁵ не пройдёт.
- Массив tails[k] — минимальный последний элемент возрастающей подпоследовательности длины k + 1; для каждого числа бинпоиском найдите, какой хвост заменить.

## Разбор
Классическая динамика `dp[i] = 1 + max(dp[j] для j < i, a[j] < a[i])` — O(n²), при 2·10⁵ это 4·10¹⁰.

Решение за O(n log n): `tails[k]` — наименьший возможный последний элемент возрастающей подпоследовательности длины k + 1. Массив `tails` строго возрастает. Для очередного x находим `bisect_left(tails, x)` — первую позицию с хвостом ≥ x — и ставим туда x (или дописываем в конец). Длина `tails` в конце — ответ.

Для **нестрого** возрастающей подпоследовательности нужен `bisect_right`.

**Сложность:** O(n log n).
