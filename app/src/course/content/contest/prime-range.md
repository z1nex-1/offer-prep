Ответьте на q запросов: сколько простых чисел на отрезке [l, r]?

**Формат ввода.** Первая строка — q (1 ≤ q ≤ 10⁵). Далее q строк: l и r (1 ≤ l ≤ r ≤ 10⁶).

**Формат вывода.** q чисел — по одному в строке.

## Подсказки
- Проверять каждое число делением на каждом запросе — слишком долго.
- Решето Эратосфена до 10⁶ один раз и префиксные суммы по числу простых.

## Разбор
Решето Эратосфена до максимального r: для каждого простого p вычёркиваем `p*p, p*p + p, …`. В Python быстрее всего вычёркивать срезом bytearray: `sieve[p*p::p] = bytes(len(range(p*p, N + 1, p)))`.

Затем префиксные суммы: `pref[x]` — число простых от 1 до x. Ответ на запрос — `pref[r] - pref[l - 1]`, O(1).

Не забудьте, что 1 — не простое.

**Сложность:** O(N log log N + q).
