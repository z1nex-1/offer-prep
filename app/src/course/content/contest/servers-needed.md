У каждого из n сервисов своя нагрузка — rᵢ запросов в секунду. Один сервер выдерживает c запросов в секунду, и каждому сервису выделяются собственные серверы. Сколько серверов нужно всего?

**Формат ввода.** Первая строка — n и c (1 ≤ n ≤ 10⁵, 1 ≤ c ≤ 10¹⁸). Вторая — n чисел rᵢ (0 ≤ rᵢ ≤ 2·10¹⁸).

**Формат вывода.** Одно число.

## Подсказки
- Сервису нужно ⌈rᵢ / c⌉ серверов.
- math.ceil(r / c) считает через float и ошибается на больших числах. Делите нацело.

## Разбор
Сервису с нагрузкой r нужно ⌈r / c⌉ серверов — округление вверх. Частая ошибка — `math.ceil(r / c)`: оператор `/` возвращает float, у которого 53 бита мантиссы, и для r около 10¹⁸ дробная часть просто теряется. Например, `math.ceil((10**18 + 1) / 10**9)` даёт 10⁹ вместо 10⁹ + 1.

Округление вверх в целых числах: `(r + c - 1) // c` для неотрицательных r или `-(-r // c)` — работает и для отрицательных.

**Сложность:** O(n).
