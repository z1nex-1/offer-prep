Дан журнал запросов к веб-сервису. Каждая строка выглядит так:

`2025-10-18T12:03:05 GET /api/users 200 35ms`

— время, метод, путь, код ответа и время обработки в миллисекундах. Между полями ровно один пробел, но в конце строки могут быть лишние пробелы, а среди записей — пустые строки (их нужно пропустить).

Для каждой пары «метод + путь» посчитайте число запросов, число ответов с ошибкой сервера (код от 500 до 599) и среднее время обработки, округлённое вниз до целого. Выведите пары по убыванию числа запросов, при равенстве — по возрастанию строки «метод путь».

**Формат ввода.** Записи журнала, по одной в строке, до 10⁵ записей.

**Формат вывода.** Для каждой пары строка: метод, путь, число запросов, число ошибок сервера, среднее время — через пробел.

## Подсказки
- Читайте весь ввод, делите на строки и пропускайте пустые после strip().
- Ключ словаря — кортеж (метод, путь); время обработки — int(поле[:-2]).

## Разбор
Классическая «бэкендовая» задача: алгоритм тривиален, баллы теряются на разборе.

1. `sys.stdin.read().splitlines()`, для каждой строки `strip()` и пропуск пустых.
2. `split()` даёт пять полей. Код ответа — `int`, время — `int(ms[:-2])` (отрезаем суффикс `ms`).
3. Словарь по ключу `(method, path)` хранит три числа: количество, ошибки, сумму времени.
4. Сортировка по ключу `(-count, method + ' ' + path)`. Среднее — `total // count` в целых.

Ошибка сервера — только 5xx: 404 — это ошибка клиента.

**Сложность:** O(n log n) из-за сортировки.
