Для каждого запроса даны числа a, n и m. Найдите остаток от деления суммы 1 + a + a² + … + aⁿ⁻¹ на m. При n = 0 сумма пустая и равна нулю.

**Формат ввода.** В первой строке — число запросов q (1 ≤ q ≤ 1000). В каждой из следующих q строк — три числа a, n, m (0 ≤ a ≤ 10⁹, 0 ≤ n ≤ 10¹⁸, 1 ≤ m ≤ 10⁹).

**Формат вывода.** Для каждого запроса — остаток в отдельной строке.

## Подсказки
- Формула (aⁿ − 1) / (a − 1) не помогает напрямую: делить по модулю можно только на числа, взаимно простые с модулем, а m здесь любое.
- Сумма первых 2k слагаемых — это сумма первых k слагаемых плюс она же, умноженная на aᵏ.
- Нечётное n сводится к n − 1: S(n) = 1 + a · S(n − 1).
- Как и в быстром возведении в степень, считайте S и aᵏ в одной рекурсии, чтобы не вызывать функцию дважды.

## Разбор
Обозначим S(n) = 1 + a + … + aⁿ⁻¹ (по модулю m). Линейный цикл по n невозможен: n до 10¹⁸. Нужна рекурсия, которая уменьшает n вдвое, — как в быстром возведении в степень.

Для чётного n = 2k сумма разбивается на две половины: первые k слагаемых дают S(k), а следующие k — это те же слагаемые, умноженные на aᵏ:

S(2k) = S(k) + aᵏ · S(k) = S(k) · (1 + aᵏ).

Для нечётного n вынесем единицу: S(n) = 1 + a · S(n − 1).

Функция возвращает сразу пару (S(n), aⁿ), чтобы степень не считать отдельно:

```python
def go(n):
    if n == 0:
        return 0, 1 % m
    if n % 2 == 1:
        s, p = go(n - 1)
        return (1 + a * s) % m, p * a % m
    s, p = go(n // 2)
    return s * (1 + p) % m, p * p % m
```

Глубина рекурсии — не больше 2·log₂ n ≈ 120: после нечётного шага n становится чётным и сразу делится пополам.

Почему не формула. (aⁿ − 1) / (a − 1) по простому модулю считают через обратный элемент (малая теорема Ферма), но при составном m и a − 1, не взаимно простом с m, обратного нет. Можно выкрутиться, считая степень по модулю m · (a − 1), но это хрупко: m · (a − 1) доходит до 10¹⁸ и работает только благодаря длинной арифметике Python. Рекурсия «разделяй и властвуй» работает всегда.

Ловушки: m = 1 (все ответы — 0, отсюда `1 % m` в базе), a = 0 (сумма равна 1 при n ≥ 1), a = 1 (сумма равна n).

**Сложность:** O(log n) на запрос, всего O(q · log n).
