Реализуйте мультиномиальный наивный байесовский классификатор со сглаживанием Лапласа. Обучающая выборка — n документов с классами, тестовая — q документов. Для тестового документа выберите класс c с наибольшей величиной

```text
log P(c) + Σ по словам w документа  log P(w | c)
```

- P(c) — доля обучающих документов класса c;
- P(w | c) = (count(w, c) + 1) / (total(c) + V), где count(w, c) — сколько раз слово w встретилось во всех документах класса c, total(c) — общее число слов в документах класса c, V — число различных слов во всей обучающей выборке;
- каждое вхождение слова учитывается отдельно (слово дважды в документе — два слагаемых);
- слова тестового документа, которых нет в обучающей выборке, пропускаются.

Гарантируется, что для каждого тестового документа лучший класс определён однозначно: его величина больше остальных хотя бы на 10⁻⁶.

**Формат ввода.** Первая строка — n (1 ≤ n ≤ 2000). Следующие n строк — класс и слова документа через пробел. Затем строка с q (1 ≤ q ≤ 1000) и q строк — слова тестовых документов (строка может быть пустой). Классы и слова — строки из строчных латинских букв длиной до 10. Всего слов во входных данных не больше 10⁵.

**Формат вывода.** q строк — предсказанный класс для каждого тестового документа.

## Подсказки
- Храните `Counter` слов для каждого класса и число слов в классе.
- Перемножать вероятности нельзя — сотни множителей уйдут в машинный ноль. Складывайте логарифмы.
- Пустой тестовый документ — ответ определяется только долей классов. Читайте ввод построчно.

## Разбор
Обучение — один проход: для каждого класса число документов, `Counter` слов и сумма слов; словарь V — множество всех слов. Предсказание для документа — перебор классов со суммой логарифмов:

```python
score = log(docs[c] / n)
for w in words:
    if w in vocab:
        score += log((cnt[c][w] + 1) / (total[c] + V))
```

Сглаживание Лапласа (+1 в числителе и +V в знаменателе) нужно, чтобы слово, ни разу не встреченное в классе, не давало вероятность 0 и не обнуляло весь класс. Логарифмы — чтобы произведение не ушло в машинный ноль. Слова не из словаря пропускаются — так же делает `CountVectorizer` + `MultinomialNB` в sklearn, с которыми совпадает эта формула.

Ловушка ввода — пустые строки тестовых документов: `sys.stdin.read().split()` их потеряет, поэтому читаем `splitlines()`.

**Сложность:** O(общее число слов · число классов).
