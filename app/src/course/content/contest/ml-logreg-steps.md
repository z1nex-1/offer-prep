Обучите логистическую регрессию градиентным спуском по logloss с L2-регуляризацией. Модель: p(x) = σ(w₀ + w₁x₁ + … + w_d x_d), σ(z) = 1 / (1 + e^(−z)). Начальные веса — нули. На каждом из T шагов все веса обновляются одновременно по весам до обновления:

```text
w₀ ← w₀ − η · (1/n) · Σᵢ (pᵢ − yᵢ)
wⱼ ← wⱼ − η · ( (1/n) · Σᵢ (pᵢ − yᵢ)·xᵢⱼ + 2λ·wⱼ )      для j = 1..d
```

Свободный член не регуляризуется. После T шагов выведите веса и logloss на обучающей выборке (натуральный логарифм, без регуляризационного слагаемого).

**Формат ввода.** Первая строка — n, d, T, η и λ (1 ≤ n ≤ 200, 1 ≤ d ≤ 3, 1 ≤ T ≤ 300, 0 < η ≤ 1, 0 ≤ λ ≤ 1). Следующие n строк — d признаков (числа от −5 до 5, не больше двух знаков после точки) и метка 0 или 1.

**Формат вывода.** Первая строка — d + 1 весов через пробел. Вторая — logloss. Ответ принимается с абсолютной или относительной погрешностью 10⁻⁶.

## Подсказки
- Градиент logloss по весам — (p − y)·x, усреднённый по объектам. Производная λ·w² — 2λ·w.
- Сигмоида при больших по модулю отрицательных z: `exp(-z)` переполняется. Считайте `exp(z) / (1 + exp(z))` при z < 0.

## Разбор
Каждый шаг: для всех объектов считаем zᵢ = ⟨w, xᵢ⟩ (с единицей для свободного члена), pᵢ = σ(zᵢ), копим градиент Σ (pᵢ − yᵢ)·xᵢ, делим на n, добавляем 2λ·wⱼ ко всем координатам, кроме свободного члена, и одновременно обновляем веса.

Устойчивая сигмоида:

```python
def sigmoid(z):
    if z >= 0:
        return 1 / (1 + exp(-z))
    e = exp(z)
    return e / (1 + e)
```

В конце — logloss −(1/n)·Σ [yᵢ·ln pᵢ + (1 − yᵢ)·ln(1 − pᵢ)] с итоговыми весами.

Если классы в выборке разделимы, без регуляризации веса росли бы с каждым шагом — logloss можно уменьшать бесконечно. Слагаемое 2λ·w держит их конечными; в тестах есть и λ = 0, и λ > 0.

**Сложность:** O(T · n · d).
