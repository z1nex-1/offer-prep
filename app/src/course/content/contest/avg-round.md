Даны баллы n участников. Выведите средний балл, округлённый до двух знаков после запятой по правилам математики: если третий знак и дальше — ровно половина сотой или больше, округляем вверх.

**Формат ввода.** В первой строке — n (1 ≤ n ≤ 10⁴). Во второй — n целых чисел от 0 до 10¹⁵.

**Формат вывода.** Средний балл ровно с двумя знаками после запятой, например `2.50`.

## Подсказки
- `f"{s / n:.2f}"` проходит примеры, но не все тесты. Попробуйте баллы `0 0 0 0 0 0 0 1`: среднее 0,125.
- Среднее — дробь `s / n` из целых чисел. Округление тоже можно сделать в целых.

## Разбор
Два источника ошибок у решения через `float`:

- форматирование `:.2f` и `round` при ровной половине выбирают чётную цифру: `0.125` превращается в `0.12`, а нужно `0.13`;
- многие дроби не представимы точно: 107 / 40 = 2,675 хранится как 2,67499…, и получается `2.67`. При суммах до 10¹⁹ `float` теряет ещё и младшие цифры.

Решение в целых: нам нужно `⌊s / n · 100 + 1/2⌋`. Умножаем всё на `2n`: `x = (200 · s + n) // (2n)`. Это сотые доли ответа, округлённые по правилам математики. Выводим `x // 100`, точку и `x % 100` с ведущим нулём: `f"{x // 100}.{x % 100:02d}"`.

**Сложность:** O(n).
