Рельеф задан столбиками высоты h₁, …, hₙ ширины 1, стоящими вплотную. Прошёл дождь. Сколько единиц воды задержится между столбиками? Вода над столбиком i поднимается до уровня `min(максимум слева, максимум справа)`, если этот уровень выше столбика.

**Формат ввода.** В первой строке — n (1 ≤ n ≤ 2·10⁵). Во второй — n целых чисел hᵢ (0 ≤ hᵢ ≤ 10⁹).

**Формат вывода.** Одно число — объём воды.

## Подсказки
- Посчитайте массивы максимумов слева и справа — это два прохода.
- Решение за O(1) памяти: два указателя с концов, двигайте тот, где текущий максимум меньше.

## Разбор
Над столбиком i вода стоит на уровне `min(L[i], R[i])`, где `L[i]` — максимум высот на префиксе до i включительно, `R[i]` — на суффиксе. Объём над ним — `min(L[i], R[i]) - h[i]`. Два предподсчёта и один проход — O(n) времени и памяти.

Решение без памяти — встречные указатели. Храним `lmax` и `rmax`. Если `lmax <= rmax`, то для левого столбика уровень воды точно определяется `lmax` (справа есть стенка не ниже) — считаем его и двигаем левый указатель. Иначе симметрично.

**Сложность:** O(n) времени, O(1) дополнительной памяти.
