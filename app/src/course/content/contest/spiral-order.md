Выпишите элементы матрицы из n строк и m столбцов по спирали: начиная с левого верхнего угла, по первой строке вправо, по последнему столбцу вниз, по последней строке влево, по первому столбцу вверх — и так далее, закручиваясь внутрь по часовой стрелке.

**Формат ввода.** В первой строке — n и m (1 ≤ n, m ≤ 300). Далее n строк по m целых чисел от −10⁹ до 10⁹.

**Формат вывода.** n · m чисел через пробел в порядке обхода.

## Подсказки
- Храните четыре границы ещё не пройденной части: верхнюю и нижнюю строку, левый и правый столбец.
- После каждой стороны сдвигайте соответствующую границу внутрь.
- Проверьте решение на матрицах из одной строки и из одного столбца: не выписываются ли элементы дважды?

## Разбор
Границы `top`, `bottom`, `left`, `right` описывают прямоугольник, который ещё не обойдён. Один виток:

1. верхняя строка слева направо, затем `top += 1`;
2. правый столбец сверху вниз, затем `right -= 1`;
3. если `top <= bottom` — нижняя строка справа налево, затем `bottom -= 1`;
4. если `left <= right` — левый столбец снизу вверх, затем `left += 1`.

Цикл идёт, пока `top <= bottom and left <= right`. Проверки в шагах 3 и 4 обязательны: у матрицы из одной строки после шага 1 `top > bottom`, и без проверки шаг 3 выписал бы ту же строку ещё раз в обратном порядке.

Другой способ — «черепашка»: идём в текущем направлении, а когда следующая клетка за границей или уже посещена, поворачиваем направо. Он проще придумывается, но требует матрицы посещённых клеток.

**Сложность:** O(n · m).
