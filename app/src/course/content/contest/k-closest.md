Даны n точек на плоскости с целыми координатами. Выведите k ближайших к началу координат. Порядок вывода — по возрастанию расстояния, при равном расстоянии — по возрастанию x, затем y.

**Формат ввода.** Первая строка — n и k (1 ≤ k ≤ n ≤ 2·10⁵). Далее n строк: x y (|x|, |y| ≤ 10⁴).

**Формат вывода.** k строк: координаты точек.

## Подсказки
- Сравнивайте квадраты расстояний — это целые числа, без корней и погрешностей.
- heapq.nsmallest(k, points, key=...) — O(n log k).

## Разбор
Расстояние сравниваем по квадрату `x² + y²` — корень монотонен и не нужен, а целые числа избавляют от погрешности. Ключ `(x² + y², x, y)` сразу задаёт порядок вывода. `heapq.nsmallest(k, points, key=...)` держит кучу размера k и работает за O(n log k).

При k близком к n проще отсортировать всё — O(n log n), разница невелика.

**Сложность:** O(n log k).
