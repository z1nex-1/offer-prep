Дан отсортированный по неубыванию массив из n чисел и q запросов. Для каждого запроса x выведите, сколько раз x встречается в массиве.

**Формат ввода.** Первая строка — n (1 ≤ n ≤ 10⁵), вторая — массив. Третья — q (1 ≤ q ≤ 10⁵), четвёртая — q чисел-запросов. Все числа по модулю не больше 10⁹.

**Формат вывода.** q чисел через пробел.

## Подсказки
- Два бинпоиска: первая позиция, где элемент ≥ x, и первая, где элемент > x.
- В Python — bisect_left и bisect_right.

## Разбор
Все вхождения x в отсортированном массиве стоят подряд — между «левой границей» (первая позиция с `a[i] >= x`) и «правой» (первая с `a[i] > x`). Их разность — ответ. Каждая граница — бинпоиск за O(log n).

`a.count(x)` для каждого запроса — O(n·q) = 10¹⁰, не пройдёт.

**Сложность:** O(q log n).
