Есть результаты олимпиады школы: для каждого участника — фамилия, класс и балл. Составьте списки по классам: классы по возрастанию, внутри класса участники по убыванию балла, при равном балле — по фамилии в алфавитном порядке.

**Формат ввода.** В первой строке — n (1 ≤ n ≤ 3·10⁴). В каждой из следующих n строк — фамилия (латинские буквы, до 20 символов), номер класса от 1 до 11 и балл от 0 до 100 через пробел. Фамилии могут повторяться.

**Формат вывода.** Для каждого класса, в котором есть участники, — строка `Class k`, где k — номер класса, и затем строки участников этого класса: фамилия и балл через пробел.

## Подсказки
- Сгруппируйте участников по классам словарём: класс → список пар.
- Сортировка внутри класса — ключ-кортеж с минусом перед баллом.
- Классы — числа: сортируйте их как числа, а не как строки, иначе `10` окажется раньше `9`.

## Разбор
`defaultdict(list)`: `groups[cls].append((score, name))`. Затем обходим `sorted(groups)` — ключи-числа сортируются численно — и для каждого класса сортируем участников по `(-score, name)`.

Можно обойтись без словаря: отсортировать всех участников по ключу `(cls, -score, name)` и печатать заголовок, когда класс меняется. Но группировка словарём понятнее и её легче расширить — например, посчитать средний балл класса.

Вывод собираем в список строк и печатаем одним `join`.

**Сложность:** O(n log n).
