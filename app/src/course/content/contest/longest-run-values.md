Дан неупорядоченный массив целых чисел. Найдите длину самой длинной последовательности чисел вида x, x+1, x+2, …, все элементы которой встречаются в массиве (порядок в массиве не важен, повторы не мешают).

**Формат ввода.** Первая строка — n (1 ≤ n ≤ 2·10⁵). Вторая — n целых чисел по модулю не больше 10⁹.

**Формат вывода.** Одно число.

## Подсказки
- Сортировка решает за O(n log n). А за O(n)?
- Множество чисел. Начинайте считать цепочку только от x, для которого x − 1 нет во множестве.

## Разбор
Решение за O(n log n) — отсортировать уникальные значения и найти самую длинную серию соседей с разностью 1.

Решение за O(n) — множество. Для каждого x, у которого нет x − 1 во множестве (x — начало цепочки), идём вверх, пока x + 1, x + 2, … есть во множестве. Каждое число участвует в подсчёте не больше одного раза, потому что подсчёт стартует только от начал цепочек.

Без проверки «x — начало» решение станет квадратичным на входе 1, 2, …, n.

**Сложность:** O(n) в среднем.
