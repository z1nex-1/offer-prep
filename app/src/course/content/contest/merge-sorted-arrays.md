Даны два массива, каждый отсортирован по неубыванию. Выведите все их элементы одним массивом, отсортированным по неубыванию.

Встроенной сортировкой пользоваться можно, но попробуйте решить за O(n + m) — именно это спросят на секции.

**Формат ввода.** Первая строка — n, вторая — n чисел первого массива. Третья строка — m, четвёртая — m чисел второго массива. 0 ≤ n, m ≤ 10⁵, числа по модулю не больше 10⁹. Пустой массив задаётся пустой строкой.

**Формат вывода.** n + m чисел через пробел.

## Подсказки
- Два указателя: на каждом шаге берите меньший из текущих элементов.
- Когда один массив закончился, допишите остаток другого целиком.

## Разбор
Указатели `i` и `j` на текущие элементы массивов. Пока оба не закончились, кладём в ответ меньший (`<=`, чтобы сохранить устойчивость) и сдвигаем соответствующий указатель. Остаток дописываем срезом.

Читать ввод аккуратно: при n = 0 строка массива пустая. Надёжнее разобрать весь ввод по строкам (`splitlines`), а не по токенам: иначе пустая строка просто исчезнет, и числа второго массива «съедутся».

**Сложность:** O(n + m).
