Дан массив, упорядоченный по неубыванию. Удалите из него лишние повторы так, чтобы каждое значение встречалось не больше двух раз, сохранив порядок.

**Формат ввода.** В первой строке — n (1 ≤ n ≤ 10⁵). Во второй — n целых чисел от −10⁹ до 10⁹ по неубыванию.

**Формат вывода.** В первой строке — длина нового массива. Во второй — его элементы через пробел.

## Подсказки
- Массив отсортирован, значит, одинаковые стоят рядом.
- Держите указатель записи `w`. С каким уже записанным элементом нужно сравнить очередной, чтобы понять, не третий ли он?

## Разбор
Идём по массиву с указателем записи `w` — сколько элементов уже в ответе. Очередной `x` записываем, если `w < 2` или `x != a[w - 2]`: если он равен элементу на две позиции левее в записанной части, то два таких значения там уже есть, потому что массив отсортирован.

Сравнивать нужно именно с записанной частью `a[w - 2]`, а не с `a[i - 2]` исходного массива: когда запись отстаёт от чтения, элементы левее `i` уже перезаписаны. Пример, на котором сравнение с `a[i - 2]` ошибается: `0 1 2 2 2 3 3 3` — оно потеряет одну тройку.

Можно решить и подсчётом серий: для каждой серии одинаковых вывести `min(длина, 2)` копий. Способ с `w` работает на месте, O(1) памяти, и обобщается на «не больше k повторов» заменой 2 на k.

**Сложность:** O(n).
