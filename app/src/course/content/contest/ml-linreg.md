Обучите линейную регрессию методом наименьших квадратов: найдите веса w₀, w₁, …, w_d, минимизирующие

```text
Σᵢ (w₀ + w₁·xᵢ₁ + … + w_d·xᵢ_d − yᵢ)²
```

Гарантируется, что решение единственно и матрица системы хорошо обусловлена.

**Формат ввода.** Первая строка — n и d (2 ≤ n ≤ 5000, 1 ≤ d ≤ 5, n > d). Следующие n строк — d признаков и ответ y. Все числа — целые, по модулю не больше 1000.

**Формат вывода.** d + 1 чисел через пробел: w₀, w₁, …, w_d. Ответ принимается с абсолютной или относительной погрешностью 10⁻⁶.

## Подсказки
- Минимум достигается там, где градиент равен нулю: XᵀX·w = Xᵀy, где X — матрица признаков со столбцом единиц в начале.
- Система маленькая — (d + 1) × (d + 1). Решите её методом Гаусса с выбором главного элемента.
- С NumPy: `np.linalg.lstsq(X, y, rcond=None)[0]`.

## Разбор
Добавляем к каждому объекту признак-единицу для свободного члена и строим нормальное уравнение: A = XᵀX (размер (d + 1) × (d + 1), элементы — суммы попарных произведений признаков) и b = Xᵀy. Это O(n·d²).

Систему A·w = b решаем методом Гаусса: для каждого столбца выбираем строку с максимальным по модулю элементом (главный элемент), меняем её с текущей и вычитаем её из остальных строк, обнуляя столбец. После прямого хода матрица диагональная, и wᵢ = bᵢ / Aᵢᵢ. Это O(d³).

Почему главный элемент: без него можно поделить на ноль или на маленькое число, и ошибки округления вырастут. Обращать матрицу явно не нужно — решение системы и дешевле, и точнее.

С NumPy решение занимает три строки:

```python
X1 = np.hstack([np.ones((n, 1)), X])
w = np.linalg.lstsq(X1, y, rcond=None)[0]
print(' '.join(f"{v:.9f}" for v in w))
```

**Сложность:** O(n·d² + d³).
