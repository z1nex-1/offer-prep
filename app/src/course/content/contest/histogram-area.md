Гистограмма состоит из n столбиков ширины 1, стоящих вплотную, высота i-го — hᵢ. Найдите площадь наибольшего прямоугольника, который целиком помещается в гистограмме (стороны параллельны осям, основание — на общей прямой).

Задача с таким названием есть в подборке CodeRun «Стажировка // Бэкенд».

**Формат ввода.** Первая строка — n (1 ≤ n ≤ 2·10⁵). Вторая — n чисел hᵢ (0 ≤ hᵢ ≤ 10⁹).

**Формат вывода.** Одно число.

## Подсказки
- Для каждого столбика — прямоугольник его высоты, растянутый до ближайших более низких столбиков слева и справа.
- Ближайшие меньшие слева и справа находит монотонный стек; можно в один проход с фиктивным столбиком высоты 0 в конце.

## Разбор
Оптимальный прямоугольник упирается сверху в какой-то столбик i — его высота равна `h[i]`, а ширина ограничена ближайшими более низкими столбиками слева и справа. Значит, ответ — максимум `h[i] · (right[i] − left[i] − 1)`.

Один проход монотонным стеком: храним индексы с возрастающими высотами. Когда текущий столбик ниже вершины, для вершины он — ближайший меньший справа, а новый элемент под ней — ближайший меньший слева. Считаем площадь и снимаем. Фиктивный столбик высоты 0 после конца выталкивает всё оставшееся.

**Сложность:** O(n).
