Дано n целых чисел. Найдите наименьшую разность |aᵢ − aⱼ| среди всех пар различных индексов i ≠ j.

**Формат ввода.** Первая строка — n (2 ≤ n ≤ 2·10⁵). Вторая — n целых чисел по модулю не больше 10⁹.

**Формат вывода.** Одно число.

## Подсказки
- После сортировки ближайший по значению элемент стоит рядом.

## Разбор
Перебор всех пар — O(n²). После сортировки минимальная разность достигается на соседних элементах: если между a и c в отсортированном порядке стоит b, то |c − a| ≥ |b − a|. Значит, достаточно пройти соседние пары.

**Сложность:** O(n log n).
