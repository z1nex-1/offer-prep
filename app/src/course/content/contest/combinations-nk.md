Выведите все способы выбрать k различных чисел из чисел от 1 до n. Каждый способ выводится как возрастающая последовательность чисел, а сами способы — в лексикографическом порядке.

**Формат ввода.** Два числа n и k (1 ≤ k ≤ n ≤ 16). Гарантируется, что количество способов не больше 5000.

**Формат вывода.** Каждый способ — в отдельной строке, числа через пробел.

## Подсказки
- Строите сочетание по одному числу. Чтобы не получить одно и то же сочетание в разном порядке, каждое следующее число берите больше предыдущего.
- Функция `go(start)`: в текущий список можно дописать любое число от `start` до n. После рекурсивного вызова число нужно убрать.
- Если осталось взять больше чисел, чем их есть от `start` до n, ветку можно не продолжать.

## Разбор
Перебор с возвратом. Состояние — список уже выбранных чисел `cur`. Функция `go(start)` дописывает следующее число, начиная со `start`:

```python
def go(start):
    if len(cur) == k:
        out.append(" ".join(map(str, cur)))
        return
    for x in range(start, n + 1):
        if len(cur) + (n - x + 1) < k:
            break
        cur.append(x)
        go(x + 1)
        cur.pop()
```

Числа в сочетании возрастают, потому что следующее число всегда больше последнего взятого. Лексикографический порядок получается сам: на каждом уровне варианты перебираются по возрастанию.

Отсечение `len(cur) + (n - x + 1) < k` отбрасывает ветки, где чисел уже не хватит. Без него решение тоже правильное, но делает лишнюю работу.

Типичная ошибка — сохранять в ответ сам список `cur`, а не его копию или строку: к концу перебора `cur` пуст, и все сохранённые ссылки покажут пустоту.

На контесте то же самое даёт `itertools.combinations(range(1, n + 1), k)` — он выдаёт сочетания в нужном порядке. Но на собеседовании попросят написать перебор руками.

**Сложность:** O(C(n, k) · k) — число сочетаний, умноженное на длину вывода каждого.
