Сколько существует пар индексов i < j, для которых a[i] = a[j]?

**Формат ввода.** В первой строке — n (1 ≤ n ≤ 10⁵). Во второй — n целых чисел от −10⁹ до 10⁹.

**Формат вывода.** Одно число — количество пар.

## Подсказки
- Перебор всех пар — около 5·10⁹ сравнений при n = 10⁵.
- Когда встречаете очередное число, сколько новых пар оно образует с уже прочитанными?

## Разбор
Идём по массиву и храним в словаре, сколько раз уже встречалось каждое значение. Очередное число `x` образует новую пару с каждым предыдущим таким же — прибавляем `seen[x]` к ответу, затем увеличиваем `seen[x]`.

Второй способ: посчитать частоты `Counter(a)` и для каждого значения, встретившегося k раз, прибавить `k * (k - 1) // 2` — число пар из k элементов.

Ответ может быть около 5·10⁹ — больше 2³¹, в Python это не проблема.

**Сложность:** O(n) в среднем.
