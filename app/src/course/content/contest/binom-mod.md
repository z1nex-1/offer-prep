Ответьте на q запросов: сколько способов выбрать k предметов из n (без учёта порядка)? Ответ — C(n, k) по модулю 10⁹ + 7; если k > n, ответ 0.

**Формат ввода.** Первая строка — q (1 ≤ q ≤ 10⁵). Далее q строк: n и k (0 ≤ n, k ≤ 10⁶).

**Формат вывода.** q чисел — по одному в строке.

## Подсказки
- math.comb на каждый запрос с n до 10⁶ слишком медленный.
- Предподсчитайте факториалы и обратные факториалы по модулю: C(n, k) = n! · (k!)⁻¹ · ((n − k)!)⁻¹. Обратный — pow(x, MOD − 2, MOD).

## Разбор
Делить по модулю нельзя, но можно умножать на обратный элемент. Модуль 10⁹ + 7 простой, поэтому по малой теореме Ферма обратный к x — `pow(x, MOD - 2, MOD)`.

Предподсчёт до максимального n из запросов: `fact[i] = fact[i-1] * i % MOD`. Обратные факториалы считаем с конца, одним возведением в степень: `inv[N] = pow(fact[N], MOD - 2, MOD)`, а `inv[i-1] = inv[i] * i % MOD`. Тогда каждый запрос — O(1): `fact[n] * inv[k] % MOD * inv[n-k] % MOD`.

`math.comb(n, k) % MOD` точен, но считает огромное число целиком — на 10⁵ запросах с n до 10⁶ это не успеет.

**Сложность:** O(N + q), где N — максимальное n.
