Сервис принимает пароль, если выполнены все правила:

1. длина от 8 до 32 символов включительно;
2. есть хотя бы одна строчная латинская буква, хотя бы одна заглавная латинская буква и хотя бы одна цифра;
3. нигде не идут подряд три одинаковых символа.

Проверьте q паролей.

**Формат ввода.** В первой строке — q (1 ≤ q ≤ 10⁴). В каждой из следующих q строк — пароль: непустая строка длиной до 100 из символов с кодами от 33 до 126 (без пробелов).

**Формат вывода.** Для каждого пароля в отдельной строке `YES`, если он принимается, и `NO` иначе.

## Подсказки
- Вынесите проверку в функцию `ok(p)`, которая возвращает `True` или `False`, — так её легко тестировать отдельно.
- Для «три подряд» достаточно сравнить каждый символ с двумя предыдущими.

## Разбор
Функция проверяет правила по очереди и возвращает `False` при первом нарушении:

- `8 <= len(p) <= 32`;
- `any('a' <= c <= 'z' for c in p)`, то же для заглавных и цифр;
- для i от 2 до len(p) − 1: `p[i] == p[i - 1] == p[i - 2]` — нарушение.

Ответы собираем в список и печатаем одним `print('\n'.join(res))`: при 10⁴ строках это заметно быстрее, чем `print` в цикле.

Типичные ошибки: `len(p) < 32` вместо `<=` (границы включительно), проверка «три подряд» с `range(len(p) - 2)` и индексами `i + 1`, `i + 2` — это тоже верно, но легко ошибиться на единицу; печать `True`/`False` вместо `YES`/`NO`.

**Сложность:** O(суммарной длины паролей).
