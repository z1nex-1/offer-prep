Модель регрессии предсказала значения для n объектов. Посчитайте MSE, MAE и коэффициент детерминации R².

- MSE = (1/n) · Σ (yᵢ − pᵢ)²;
- MAE = (1/n) · Σ |yᵢ − pᵢ|;
- R² = 1 − Σ (yᵢ − pᵢ)² / Σ (yᵢ − ȳ)², где ȳ — среднее верных значений.

Если все верные значения одинаковы, знаменатель R² равен нулю: тогда выведите 1, если все предсказания точные, и 0 иначе (так делает sklearn).

**Формат ввода.** Первая строка — n (1 ≤ n ≤ 10⁵). Вторая — n верных значений, третья — n предсказаний. Все числа по модулю не больше 10⁴, не больше 3 знаков после точки.

**Формат вывода.** Три числа через пробел — MSE, MAE и R². Ответ принимается с абсолютной или относительной погрешностью 10⁻⁶.

## Подсказки
- R² сравнивает ошибку модели с ошибкой константы ȳ: знаменатель — это n · (MSE константы).
- R² может быть отрицательным — если модель хуже константы. Это не ошибка.

## Разбор
Все три метрики — один проход по парам (y, p) плюс среднее ȳ для R². Числитель R² — сумма квадратов остатков (n · MSE), знаменатель — сумма квадратов отклонений y от среднего, то есть ошибка лучшей константы для MSE. Поэтому R² = 0 значит «не лучше среднего», а отрицательный R² — «хуже среднего».

Краевой случай — константный y: знаменатель ноль. Условие задаёт соглашение sklearn (`r2_score` с `force_finite=True`): 1 при идеальных предсказаниях, иначе 0. Проверять константность по знаменателю ненадёжно: среднее одинаковых чисел в float может отличаться от них в последнем бите, и знаменатель получится крошечным, но не нулём. Надёжнее проверить `max(y) == min(y)`.

**Сложность:** O(n).
