Конфигурация сервиса хранится во вложенном JSON-объекте. Превратите его в плоский список «путь=значение». Путь состоит из ключей через точку; элементы массивов обозначаются индексом с нуля. Значения выводятся в формате JSON: строки — в двойных кавычках, `true`, `false`, `null` — как есть. Пустые объект и массив считаются значениями и выводятся как `{}` и `[]`.

Например, для `{"db": {"hosts": ["a", "b"], "port": 5432}, "debug": false}` ответ:

```
db.hosts.0="a"
db.hosts.1="b"
db.port=5432
debug=false
```

Строки выведите в лексикографическом порядке путей.

**Формат ввода.** Одна строка — JSON-объект длиной до 10⁵ символов. Ключи состоят из латинских букв, цифр и `_`; вложенность не больше 50; числа целые.

**Формат вывода.** Строки «путь=значение».

## Подсказки
- json.loads превращает строку в словари и списки Python.
- Рекурсивный обход с текущим путём; для значения-листа json.dumps(value, ensure_ascii=False) даёт нужный формат.

## Разбор
Разбирать JSON руками не нужно: `json.loads` возвращает словари, списки, строки, числа, `True`/`False`/`None`.

Обход: функция `walk(value, path)`. Если значение — непустой словарь, идём по его ключам с путём `path + '.' + key` (у корня — просто `key`). Если непустой список — по индексам. Иначе это лист: записываем `path + '=' + json.dumps(value, ensure_ascii=False)`. `json.dumps` сам выводит строки в кавычках с экранированием, `False` как `false`, `None` как `null`, пустые контейнеры как `{}` и `[]`.

В конце сортируем строки по пути. Сортировать нужно именно по пути, а не по строке целиком: символ `=` может оказаться не там, где ожидаете (путь `a` против пути `a.b`).

Глубина 50 — рекурсия безопасна.

**Сложность:** O(L log L) из-за сортировки.
