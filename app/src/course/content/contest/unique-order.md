Дана последовательность чисел. Удалите из неё повторы: оставьте каждое число только в первом его появлении, сохранив порядок.

**Формат ввода.** В первой строке — n (1 ≤ n ≤ 3·10⁴). Во второй — n целых чисел от −10⁹ до 10⁹.

**Формат вывода.** Оставшиеся числа через пробел.

## Подсказки
- Проверка `x in result` для списка — O(n), и всё решение станет O(n²). Какая структура даёт проверку за O(1)?
- Порядок хранит список, а «уже видели» — множество.

## Разбор
Идём по числам, держим множество `seen` уже встреченных и список ответа. Если числа нет в `seen` — добавляем его и туда, и в ответ.

Решение с `if x not in res` для списка правильное, но при n = 3·10⁴ различных чисел делает порядка 4,5·10⁸ сравнений — на Python это TL. `list(set(a))` тоже не подходит: множество не хранит порядок появления.

Короткий вариант: `list(dict.fromkeys(a))`. Ключи словаря уникальны, а с Python 3.7 словарь гарантированно хранит порядок вставки.

**Сложность:** O(n) в среднем.
