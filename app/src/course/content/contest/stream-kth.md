Числа поступают по одному. После каждого числа выведите k-е по величине среди всех поступивших (k-е в порядке убывания). Пока чисел меньше k, выводите −1.

**Формат ввода.** Первая строка — n и k (1 ≤ k ≤ n ≤ 2·10⁵). Вторая — n целых чисел по модулю не больше 10⁹.

**Формат вывода.** n чисел, каждое на отдельной строке.

## Подсказки
- Храните k наибольших чисел в min-куче.
- Корень min-кучи — k-е по величине; новое число больше корня вытесняет его.

## Разбор
Min-куча из k наибольших поступивших чисел. Пока в ней меньше k элементов — просто добавляем. Когда k набралось, новое число больше корня заменяет корень (`heapreplace`), меньшее — отбрасывается: оно уже не войдёт в k лучших. Корень — наименьший из k наибольших, то есть k-е по величине.

Сортировать после каждого числа — O(n² log n).

**Сложность:** O(n log k).
