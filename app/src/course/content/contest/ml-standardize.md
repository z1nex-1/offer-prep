Перед обучением линейной модели или kNN признаки стандартизируют: для каждого признака вычитают среднее и делят на стандартное отклонение. Среднее и отклонение считаются **только по обучающей выборке**, а применяются и к ней, и к тестовой — иначе статистики теста попадут в обучение.

Даны обучающая выборка (n объектов) и тестовая (m объектов) с d признаками. Для каждого признака j найдите по обучающей выборке среднее μⱼ и стандартное отклонение σⱼ = √((1/n)·Σ (xᵢⱼ − μⱼ)²) (деление на n). Выведите стандартизованную тестовую выборку: (x − μⱼ) / σⱼ. Если σⱼ = 0, выведите для этого признака 0.

**Формат ввода.** Первая строка — n, m, d (1 ≤ n, m ≤ 10⁴, 1 ≤ d ≤ 5). Следующие n строк — объекты обучающей выборки, затем m строк — тестовой. Все значения — целые числа по модулю не больше 10⁶.

**Формат вывода.** m строк по d чисел. Ответ принимается с абсолютной или относительной погрешностью 10⁻⁶.

## Подсказки
- Отклонение делится на n, а не на n − 1: так считает `StandardScaler` в sklearn и `np.std` по умолчанию.
- Признак-константа в обучающей выборке даёт σ = 0 — проверьте это до деления.

## Разбор
Два прохода по обучающей выборке: средние по признакам, затем средние квадратов отклонений. Потом каждый тестовый объект преобразуется по формуле. Константный признак (σ = 0) не несёт информации — по условию он превращается в 0. У `StandardScaler` соглашение другое: нулевое отклонение он заменяет единицей, поэтому обучающие объекты получают 0, а тестовые — x − μ. На контесте всегда реализуйте соглашение из условия, а не библиотечное.

Проверять σ на ноль безопасно, если считать дисперсию как среднее квадратов отклонений от среднего: для одинаковых целых чисел среднее вычисляется точно, и отклонения ровно нули. Формула E[x²] − (E[x])² даёт погрешности и даже отрицательную дисперсию на больших числах — её лучше избегать.

С NumPy:

```python
mu = train.mean(axis=0)
sd = train.std(axis=0)
Z = np.where(sd > 0, (test - mu) / np.where(sd > 0, sd, 1), 0.0)
```

**Сложность:** O((n + m)·d).
