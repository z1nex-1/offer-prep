Хранилище запоминает историю значений ключей. Команды:

- `SET key value t` — в момент t ключ key получил значение value;
- `GET key t` — вывести значение key на момент t: последнее из установленных в моменты ≤ t, или `NONE`, если такого нет.

Моменты команд `SET` для одного ключа строго возрастают. Команды `GET` могут спрашивать любые моменты.

**Формат ввода.** Первая строка — q (1 ≤ q ≤ 2·10⁵). Далее q команд. Ключи и значения — строки из латинских букв и цифр длиной до 10, 0 ≤ t ≤ 10⁹.

**Формат вывода.** Ответы команд `GET`, каждый на отдельной строке.

## Подсказки
- Для каждого ключа храните список моментов и список значений в порядке добавления.
- Моменты возрастают — ищите бинпоиском последний момент ≤ t.

## Разбор
Для каждого ключа — два списка: моменты и значения. Так как моменты одного ключа возрастают, `SET` просто дописывает в конец, а `GET` ищет `bisect_right(times, t) − 1` — индекс последнего изменения не позже t. Если индекс отрицательный — значения ещё не было.

Перебор истории ключа на каждый `GET` — O(n) на запрос, O(n²) в худшем случае.

**Сложность:** `SET` — O(1), `GET` — O(log n).
