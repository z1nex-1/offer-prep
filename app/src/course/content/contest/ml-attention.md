Посчитайте scaled dot-product attention — основную операцию трансформера:

```text
Attention(Q, K, V) = softmax(Q·Kᵀ / √d) · V
```

Q и K — матрицы T × d (запросы и ключи позиций), V — матрица T × m (значения). Softmax берётся по каждой строке матрицы T × T. Если включена причинная маска, позиция i может смотреть только на позиции j ≤ i: остальные элементы строки перед softmax заменяются на −∞ (их веса равны нулю).

**Формат ввода.** Первая строка — T, d, m и флаг маски c (1 ≤ T ≤ 200, 1 ≤ d, m ≤ 16, c — 0 или 1). Далее T строк матрицы Q, T строк матрицы K и T строк матрицы V. Все элементы — целые по модулю не больше 20.

**Формат вывода.** T строк по m чисел — результат внимания. Ответ принимается с абсолютной или относительной погрешностью 10⁻⁶.

## Подсказки
- Элементы Q·Kᵀ / √d доходят до 20·20·16 / 4 = 1600 — прямой `exp` переполнится. Вычитайте максимум строки.
- При маске берите в softmax только позиции j ≤ i — замена на −∞ эквивалентна их пропуску.

## Разбор
Для позиции i: считаем сходства sᵢⱼ = ⟨qᵢ, kⱼ⟩ / √d для всех допустимых j (все j или только j ≤ i при маске), вычитаем максимум, берём экспоненты и нормируем — это веса. Выход — Σⱼ weightᵢⱼ · vⱼ, вектор длины m.

Деление на √d в реальных моделях нужно, чтобы дисперсия скалярного произведения не росла с размерностью и softmax не насыщался в one-hot — тогда градиенты через него почти нулевые. Вычитание максимума — стандартный приём устойчивого softmax. Причинная маска — то, что делает декодер (GPT) авторегрессионным: при обучении все позиции считаются параллельно, но каждая «видит» только прошлое.

С NumPy:

```python
S = Q @ K.T / np.sqrt(d)
if c:
    S[np.triu_indices(T, 1)] = -np.inf
S -= S.max(axis=1, keepdims=True)
Wt = np.exp(S)
Wt /= Wt.sum(axis=1, keepdims=True)
out = Wt @ V
```

**Сложность:** O(T²·(d + m)) — квадрат длины последовательности, главная причина ограничений на длину контекста.
