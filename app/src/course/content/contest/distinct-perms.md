Дана строка из строчных латинских букв; буквы в ней могут повторяться. Выведите все различные строки, которые получаются перестановкой её букв, в лексикографическом порядке.

**Формат ввода.** Одна строка s (1 ≤ |s| ≤ 10). Гарантируется, что различных перестановок не больше 6000.

**Формат вывода.** Все различные перестановки, каждая в отдельной строке, в лексикографическом порядке.

## Подсказки
- Если перебирать перестановки позиций и складывать результат в множество, для строки `aaaaaaaaab` вы переберёте 10! ≈ 3,6 миллиона вариантов ради десяти ответов.
- Перебирайте не позиции, а различные буквы: на очередное место можно поставить любую букву, которая ещё осталась. Сколько каких букв осталось — хранит счётчик.
- Если перебирать буквы по алфавиту, ответ сразу получится отсортированным.

## Разбор
Наивный путь — `set(itertools.permutations(s))` и сортировка — перебирает все n! перестановок позиций, хотя различных может быть намного меньше. Для `aaaaaaaaab` это 3,6 миллиона кортежей ради 10 строк.

Правильный перебор строит строку по буквам и на каждом шаге ставит **различные** буквы. Остаток букв хранится в счётчике:

```python
from collections import Counter

cnt = Counter(s)
letters = sorted(cnt)
cur, out = [], []

def go():
    if len(cur) == len(s):
        out.append("".join(cur))
        return
    for ch in letters:
        if cnt[ch]:
            cnt[ch] -= 1
            cur.append(ch)
            go()
            cur.pop()
            cnt[ch] += 1
```

Каждая одинаковая буква на данном месте пробуется один раз, поэтому повторов нет, и каждый лист дерева перебора — новая перестановка. Буквы перебираются по алфавиту — вывод уже отсортирован.

Второй способ, который часто просят на собеседовании: отсортировать строку и перебирать позиции с массивом `used`, пропуская `s[i]`, если `s[i] == s[i - 1]` и `s[i - 1]` ещё не использован. Правило гарантирует, что одинаковые буквы занимают места строго в порядке их следования.

Третий способ — алгоритм «следующая перестановка»: начиная с отсортированной строки, получать следующую в лексикографическом порядке за O(n), пока она существует. Он тоже естественно пропускает повторы.

**Сложность:** O(P · n), где P — число различных перестановок: каждый путь в дереве перебора заканчивается ответом.
