Есть n кучек бананов, в i-й — pᵢ бананов. Обезьяна ест с постоянной скоростью k бананов в час: за час выбирает одну кучку и съедает из неё k бананов (если в кучке меньше, съедает всю и до конца часа ничего не ест). Какая наименьшая целая скорость k позволит съесть всё не больше чем за h часов? Гарантируется, что h ≥ n.

**Формат ввода.** Первая строка — n и h (1 ≤ n ≤ 10⁵, n ≤ h ≤ 10⁹). Вторая — n чисел pᵢ (1 ≤ pᵢ ≤ 10⁹).

**Формат вывода.** Одно число k.

## Подсказки
- При скорости k на кучку p уходит ⌈p / k⌉ часов.
- Чем больше k, тем меньше часов — бинпоиск по k от 1 до max(p).

## Разбор
Проверка скорости k: часов нужно `sum((p + k - 1) // k)` — O(n). Функция «успеваем ли» монотонна по k, поэтому ищем минимальное подходящее k бинпоиском по ответу в диапазоне [1, max(p)] — при k = max(p) на каждую кучку уходит час, и n ≤ h часов точно хватит.

Округление вверх без float — `(p + k - 1) // k`.

**Сложность:** O(n log max p).
