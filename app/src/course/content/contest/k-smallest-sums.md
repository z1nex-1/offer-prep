Даны два массива a и b, каждый отсортирован по неубыванию. Рассмотрим все n · m сумм aᵢ + bⱼ. Выведите k наименьших из них по неубыванию.

**Формат ввода.** Первая строка — n, m, k (1 ≤ n, m ≤ 10⁵, 1 ≤ k ≤ min(n · m, 10⁵)). Вторая строка — массив a, третья — массив b. Числа по модулю не больше 10⁹.

**Формат вывода.** k чисел через пробел.

## Подсказки
- Все пары перебрать нельзя — их до 10¹⁰.
- Куча «фронта»: начните с (0, 0); достав пару (i, j), добавьте (i + 1, j) и (i, j + 1), если они ещё не добавлялись.

## Разбор
Представим суммы как матрицу n × m, где строки и столбцы отсортированы: значение справа и снизу не меньше. Наименьшая — в углу (0, 0). Следующая наименьшая — среди соседей уже извлечённых клеток. Куча `(сумма, i, j)` и множество добавленных клеток: достаём минимум, выводим, добавляем `(i + 1, j)` и `(i, j + 1)`, если их ещё не было. k извлечений, в куче не больше 2k элементов.

Экономнее по памяти — начать с кучи из пар `(a[i] + b[0], i, 0)` для i < k и при извлечении добавлять только `(i, j + 1)`: множество посещённых не нужно.

**Сложность:** O(k log k).
