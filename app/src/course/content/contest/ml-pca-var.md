Даны n точек в d-мерном пространстве. Найдите, какую долю общей дисперсии объясняет первая главная компонента, — то есть λ₁ / (λ₁ + … + λ_d), где λ₁ ≥ … ≥ λ_d — собственные значения выборочной ковариационной матрицы

```text
C_jk = (1/n) · Σᵢ (xᵢⱼ − μⱼ)(xᵢₖ − μₖ)
```

Гарантируется, что λ₁ ≥ 1.5·λ₂ и что не все точки совпадают.

**Формат ввода.** Первая строка — n и d (2 ≤ n ≤ 3000, 2 ≤ d ≤ 8). Следующие n строк — d целых координат по модулю не больше 10⁴.

**Формат вывода.** Одно число — доля объяснённой дисперсии. Ответ принимается с абсолютной или относительной погрешностью 10⁻⁶.

## Подсказки
- Сумма всех собственных значений равна следу матрицы — сумме дисперсий признаков. Искать все собственные значения не нужно.
- Наибольшее собственное значение ищется степенным методом: v ← Cv / ‖Cv‖ много раз, затем λ₁ = vᵀCv.
- Условие λ₁ ≥ 1.5·λ₂ гарантирует быструю сходимость: ошибка убывает как (λ₂/λ₁)^k.

## Разбор
1. Центрируем данные и строим ковариационную матрицу C размера d × d — O(n·d²).
2. След C — сумма дисперсий признаков — равен сумме всех собственных значений. Это знаменатель ответа.
3. λ₁ — степенным методом. Начинаем с вектора из единиц (или случайного), многократно умножаем на C и нормируем. Вектор сходится к главной компоненте, потому что при каждом умножении её коэффициент растёт в λ₁ раз, а остальные — медленнее. После сходимости λ₁ = vᵀCv (отношение Рэлея).

```python
v = [1.0] * d
for _ in range(500):
    w = [sum(C[i][j] * v[j] for j in range(d)) for i in range(d)]
    norm = sum(x * x for x in w) ** 0.5
    v = [x / norm for x in w]
lam = sum(v[i] * C[i][j] * v[j] for i in range(d) for j in range(d))
```

Тонкость: если начальный вектор ортогонален главной компоненте, метод найдёт другую. Вектор из единиц к этому уязвим на специально подобранных данных; надёжнее начать со случайного вектора, а ещё надёжнее — посчитать несколько итераций с разных стартов. При λ₁ ≥ 1.5·λ₂ 500 итераций дают ошибку порядка (2/3)⁵⁰⁰ — далеко за пределами точности double.

С NumPy: `vals = np.linalg.eigvalsh(np.cov(X, rowvar=False, bias=True)); print(vals[-1] / vals.sum())`.

**Сложность:** O(n·d² + итерации·d²).
