Даны k отсортированных по неубыванию списков. Выведите все их элементы одним отсортированным списком.

Похожая задача («Объединить k отсортированных списков») есть в статье Яндекса об алгоритмических секциях.

**Формат ввода.** Первая строка — k (1 ≤ k ≤ 10⁴). Далее k строк: в начале строки число элементов списка mᵢ (0 ≤ mᵢ), затем mᵢ чисел. Суммарно элементов не больше 2·10⁵, числа по модулю не больше 10⁹.

**Формат вывода.** Все элементы через пробел (если элементов нет — пустая строка).

## Подсказки
- В куче держите по одному текущему элементу от каждого списка.
- Кортеж (значение, номер списка, позиция) — при равных значениях сравнение идёт по номеру.

## Разбор
Куча текущих элементов: изначально — первые элементы непустых списков в виде `(значение, номер списка, позиция)`. Достаём минимум, выводим, кладём следующий элемент того же списка. В куче никогда не больше k элементов, поэтому каждая операция — O(log k).

Склеить всё и отсортировать — O(N log N), тоже проходит, но на секции ждут слияния с кучей. `heapq.merge(*lists)` делает то же самое.

**Сложность:** O(N log k).
