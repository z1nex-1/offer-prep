На плоскости даны n точек с целыми координатами, некоторые могут совпадать. Какое наибольшее число из них лежит на одной прямой?

**Формат ввода.** В первой строке — n (1 ≤ n ≤ 700). Далее n строк по два целых числа x, y (|x|, |y| ≤ 10⁹).

**Формат вывода.** Одно число — наибольшее количество точек на одной прямой (совпадающие точки считаются отдельно).

## Подсказки
- Перебор всех прямых через пары точек и проверка всех точек — O(n³) ≈ 3·10⁸. Много.
- Зафиксируйте одну точку p. Все остальные точки на одной прямой с p лежат в одном направлении от неё. Как сделать из направления ключ словаря?
- Наклон `dy / dx` во `float` не подходит: вертикальные прямые и близкие дроби при координатах до 10⁹. Сократите вектор на НОД и приведите знак к одному виду.

## Разбор
Для каждой точки p считаем, сколько других точек лежит в каждом направлении от неё. Направление на точку q — вектор `(dx, dy) = (q.x − p.x, q.y − p.y)`. Векторы одной прямой через p пропорциональны, поэтому ключ — вектор, делённый на `gcd(dx, dy)`, со знаком, приведённым так, чтобы `dx > 0` или `dx = 0, dy > 0`. Без нормализации знака точки по разные стороны от p попали бы в разные группы.

Точки, совпадающие с p, лежат на любой прямой через неё — их считаем отдельно в `same`. Ответ для p — `same + 1 + max(словаря)`, а если словарь пуст (все точки совпадают с p) — `same + 1`. Общий ответ — максимум по всем p.

Почему не `float`: при координатах до 10⁹ дроби `999999999/1000000000` и `999999998/999999999` различаются меньше, чем точность `float`, — они дадут один ключ, хотя прямые разные. А `dx = 0` — деление на ноль.

**Сложность:** O(n² log C), где log C — стоимость НОД. При n = 700 — около 2,5·10⁵ пар.
