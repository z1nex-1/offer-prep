Сеть из n пунктов выдачи соединена n − 1 дорогами так, что из любого пункта можно доехать в любой, причём единственным путём без повторов. Известна длина каждой дороги. Найдите длину самого длинного из таких путей между двумя пунктами.

**Формат ввода.** В первой строке — число n (1 ≤ n ≤ 10⁵). В следующих n − 1 строках — дороги: номера пунктов u, v и длина w (1 ≤ w ≤ 10⁹).

**Формат вывода.** Одно число — длина самого длинного пути. При n = 1 ответ 0.

## Подсказки
- Сеть — дерево: путь между двумя вершинами единственный, и его длина — сумма длин рёбер.
- Перебор всех пар вершин — O(n²), это слишком долго при n = 10⁵.
- Найдите самую далёкую вершину от произвольной вершины. Затем самую далёкую от найденной. Почему это ответ?

## Разбор
Самый длинный путь в дереве называется **диаметром**. Классический способ — два обхода:

1. От любой вершины s найти самую далёкую вершину a.
2. От a найти самую далёкую вершину b. Расстояние от a до b — диаметр.

В дереве путь между вершинами единственный, поэтому расстояния от одной вершины до всех считаются простым обходом: расстояние до соседа — расстояние до текущей вершины плюс длина ребра. Порядок обхода не важен, годятся и стек, и очередь:

```python
def farthest(s):
    dist = [-1] * (n + 1)
    dist[s] = 0
    stack = [s]
    while stack:
        v = stack.pop()
        for u, w in g[v]:
            if dist[u] < 0:
                dist[u] = dist[v] + w
                stack.append(u)
    far = max(range(1, n + 1), key=lambda v: dist[v])
    return far, dist[far]

a, _ = farthest(1)
b, d = farthest(a)
```

Почему работает. Ключевой факт: самая далёкая от любой вершины s вершина a — конец какого-то диаметра. Доказывается от противного: пусть диаметр — путь x–y, а a не конец ни одного диаметра; разобрав, где путь s–a встречается с путём x–y, можно собрать путь длиннее x–y, чего быть не может. Раз a — конец диаметра, самая далёкая от a вершина даёт путь длины диаметра. Важно, что длины рёбер положительные — при отрицательных весах трюк не работает.

Другой способ — динамика по поддеревьям, как в уроке «Деревья и обходы»: для каждой вершины посчитать две самые длинные ветви вниз и обновить ответ их суммой. Он же работает и при отрицательных весах.

Ответ может достигать 10⁵ · 10⁹ = 10¹⁴ — в Python переполнения нет, но в C++ понадобился бы 64-битный тип.

**Сложность:** O(n) времени и памяти.
