Инверсия в массиве — пара индексов i < j, для которой aᵢ > aⱼ. Посчитайте количество инверсий.

**Формат ввода.** Первая строка — n (1 ≤ n ≤ 10⁵). Вторая — n целых чисел по модулю не больше 10⁹.

**Формат вывода.** Одно число.

## Подсказки
- Перебор пар — O(n²), слишком медленно.
- Сортировка слиянием: при слиянии, когда берём элемент из правой половины, все оставшиеся элементы левой половины больше него.

## Разбор
Модифицируем сортировку слиянием. Инверсии делятся на три вида: внутри левой половины, внутри правой и «между половинами». Первые два считаются рекурсивно. Третьи — при слиянии: когда из правой половины берётся элемент `right[j]`, все ещё не взятые элементы левой половины (их `len(left) - i`) больше него — это ровно столько инверсий.

При равенстве берём из левой половины (`<=`): равные элементы инверсию не образуют.

Для глубины рекурсии log n ≈ 17 лимит Python не страшен. Альтернатива — дерево Фенвика по сжатым значениям.

**Сложность:** O(n log n).
