Зашифруйте строку шифром Цезаря со сдвигом k: каждая латинская буква заменяется на букву, стоящую в алфавите на k позиций дальше, по кругу (после `z` идёт `a`). Регистр букв сохраняется, остальные символы не меняются. Сдвиг может быть отрицательным — тогда буквы сдвигаются назад.

**Формат ввода.** В первой строке — целое k (−10⁹ ≤ k ≤ 10⁹). Во второй — строка длиной от 1 до 10⁵ из символов с кодами от 32 до 126; она не начинается и не заканчивается пробелом.

**Формат вывода.** Зашифрованная строка.

## Подсказки
- Номер буквы в алфавите: `ord(ch) - ord('a')`. Сдвиг по кругу — это остаток от деления на 26.
- Что даёт `%` в Python для отрицательного числа?
- Собирайте результат в список и соединяйте `''.join(...)` — склеивание строки в цикле через `+=` может быть медленным.

## Разбор
Для строчной буквы: `chr((ord(ch) - ord('a') + k) % 26 + ord('a'))`, для заглавной то же с `'A'`. Остальные символы переносим как есть.

`% 26` в Python всегда даёт число от 0 до 25, даже если `k` отрицательный, поэтому отдельно обрабатывать сдвиг назад не нужно. Большой `k` тоже не страшен: остаток отбрасывает целые круги. Можно заранее сделать `k %= 26`.

Проверять «буква ли это» через `ch.isalpha()` опасно: для букв других алфавитов оно тоже вернёт `True`. Надёжнее сравнение `'a' <= ch <= 'z'`.

Строку читаем через `readline()` и отрезаем только перевод строки — `split()` здесь сломал бы пробелы внутри текста.

**Сложность:** O(L).
