Сколько существует строк длины n из нулей и единиц, в которых нет трёх единиц подряд? Выведите ответ по модулю 10⁹ + 7.

Похожая задача «Три единицы подряд» есть в подборке CodeRun «Стажировка // Бэкенд».

**Формат ввода.** Одно число n (1 ≤ n ≤ 10⁶).

**Формат вывода.** Одно число.

## Подсказки
- Для продолжения строки важно только, сколькими единицами она оканчивается: 0, 1 или 2.
- Три состояния и переходы: дописали 0 — хвост обнулился, дописали 1 — хвост вырос на один (кроме хвоста 2).

## Разбор
Состояние: длина строки и число единиц на конце — 0, 1 или 2. Дописав 0, любое состояние переходит в «0 единиц на конце»; дописав 1, «0 → 1» и «1 → 2», а из «2» дописывать 1 нельзя. Значит:

- `a0' = a0 + a1 + a2`,
- `a1' = a0`,
- `a2' = a1`.

Начинаем с пустой строки: `a0 = 1`. Ответ — `a0 + a1 + a2` после n шагов. Три переменных, O(1) памяти.

**Сложность:** O(n).
