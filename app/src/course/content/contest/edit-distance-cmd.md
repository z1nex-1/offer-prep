Даны две строки. За одну операцию можно вставить символ, удалить символ или заменить один символ другим. Найдите наименьшее число операций, превращающих первую строку во вторую.

Задача «Расстояние по Левенштейну» есть на CodeRun.

**Формат ввода.** Две строки из строчных латинских букв длиной от 0 до 2000 (строка может быть пустой).

**Формат вывода.** Одно число.

## Подсказки
- dp[i][j] — расстояние между префиксами a[:i] и b[:j].
- Храните только две строки таблицы, чтобы не тратить O(n·m) памяти.

## Разбор
`dp[i][j]` — расстояние между первыми i символами первой строки и первыми j второй. База: `dp[i][0] = i` (удалить всё), `dp[0][j] = j` (вставить всё). Если последние символы равны — `dp[i][j] = dp[i−1][j−1]`, иначе `1 + min` из удаления `dp[i−1][j]`, вставки `dp[i][j−1]` и замены `dp[i−1][j−1]`.

Таблица 2001 × 2001 = 4·10⁶ ячеек — в Python это много памяти и медленно; хватает двух строк: текущей и предыдущей.

Читайте ввод построчно: строка может быть пустой.

**Сложность:** O(n · m) времени, O(m) памяти.
