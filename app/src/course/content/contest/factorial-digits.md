Для числа n найдите, сколько цифр в десятичной записи n! = 1 · 2 · … · n и чему равна сумма этих цифр. По определению 0! = 1.

**Формат ввода.** Одно целое n (0 ≤ n ≤ 3000).

**Формат вывода.** Два числа через пробел: количество цифр и сумма цифр n!.

## Подсказки
- Большие целые в Python не переполняются, `math.factorial` посчитает 3000! точно.
- Решение `str(math.factorial(n))` проходит маленькие тесты, но падает на больших. Прочитайте текст ошибки: он подсказывает, что сделать.

## Разбор
`math.factorial(n)` считает точно, а цифры проще всего получить из строки. Но 3000! содержит 9131 цифру, а с Python 3.11 перевод в строку целых длиннее 4300 цифр по умолчанию запрещён: `str(...)` бросает `ValueError`, и решение получает RE.

Лимит снимается в начале программы: `sys.set_int_max_str_digits(0)`. После этого `s = str(math.factorial(n))`, ответ — `len(s)` и `sum(map(int, s))`.

Без снятия лимита можно отщеплять цифры `divmod(f, 10)` в цикле, но это O(L²) для числа из L цифр — каждое деление большого числа проходит по всей его длине. `str` работает быстрее.

**Сложность:** вычисление факториала и перевод в строку для чисел из тысяч цифр — доли секунды.
