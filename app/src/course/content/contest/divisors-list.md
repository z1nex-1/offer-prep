Выведите все натуральные делители числа n в порядке возрастания.

**Формат ввода.** Одно целое n (1 ≤ n ≤ 10¹²).

**Формат вывода.** В первой строке — количество делителей. Во второй — сами делители через пробел по возрастанию.

## Подсказки
- Перебор всех чисел от 1 до n при n = 10¹² не успеет. Если d — делитель, какое ещё число точно делитель?
- Одно из чисел пары `d` и `n // d` не больше √n.
- Осторожно с точными квадратами: корень не должен попасть в ответ дважды.

## Разбор
Делители идут парами `d` и `n // d`, и меньший в паре не больше √n. Перебираем `d`, пока `d * d <= n`: если `n % d == 0`, кладём `d` в список «маленьких», а `n // d` — в список «больших», если он не совпадает с `d`. Маленькие получаются по возрастанию, большие — по убыванию, поэтому ответ — `small + big[::-1]`, без сортировки.

Условие `d * d <= n` лучше, чем `d <= math.sqrt(n)`: оно в целых числах и не зависит от точности `float`.

**Сложность:** O(√n) — не больше 10⁶ итераций.
