Дан неориентированный граф из n вершин и m рёбер. Выведите количество компонент связности и размер наибольшей из них.

**Формат ввода.** Первая строка — n и m (1 ≤ n ≤ 10⁵, 0 ≤ m ≤ 2·10⁵). Далее m строк по два числа u v — ребро (1 ≤ u, v ≤ n, возможны петли и кратные рёбра).

**Формат вывода.** Два числа через пробел.

## Подсказки
- Запускайте обход из каждой ещё не посещённой вершины — каждый запуск находит одну компоненту.
- Обход пишите итеративно: при n = 10⁵ рекурсия упрётся в лимит.

## Разбор
Список смежности и массив посещённых. Для каждой непосещённой вершины запускаем итеративный DFS (или BFS) и считаем, сколько вершин он посетил, — это размер компоненты. Число запусков — число компонент.

Петли и кратные рёбра не мешают: посещённые вершины не добавляются повторно. Изолированная вершина — отдельная компонента размера 1.

Альтернатива — DSU: объединяем концы каждого ребра, потом считаем корни и размеры.

**Сложность:** O(n + m).
