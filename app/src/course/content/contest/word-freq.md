Дан текст. Выведите все различные слова текста вместе с числом их повторений: сначала самые частые, при равной частоте — в алфавитном порядке.

Словом считается последовательность непробельных символов. Регистр важен: `Кот` и `кот` — разные слова.

**Формат ввода.** Текст из нескольких строк, в сумме до 2·10⁵ слов. Слова разделены пробелами и переводами строк.

**Формат вывода.** Для каждого различного слова строка: слово и через пробел — сколько раз оно встретилось.

## Подсказки
- Сначала посчитайте частоты: `collections.Counter` или словарь.
- Сортировка по двум критериям — ключ-кортеж. Как сделать, чтобы частота шла по убыванию, а слово — по возрастанию?

## Разбор
Весь текст читаем `sys.stdin.read().split()` — так переводы строк не мешают. `Counter(words)` считает частоты за O(N).

Сортируем пары `(слово, частота)` по ключу `(-частота, слово)`: кортежи сравниваются по первому элементу, при равенстве — по второму. Минус перед частотой переворачивает порядок только для неё, слова остаются по возрастанию.

`Counter.most_common()` здесь не подходит: при равных частотах он оставляет порядок первого появления, а не алфавитный.

Строки сравниваются по кодам символов: заглавные латинские буквы идут раньше строчных, а латиница — раньше кириллицы.

**Сложность:** O(N + K log K), где N — число слов, K — число различных слов.
