Нейросеть-классификатор выдала для каждого из n объектов K логитов z₁, …, z_K. Вероятности классов — softmax: pₖ = e^(zₖ) / Σⱼ e^(zⱼ). Посчитайте среднюю кросс-энтропию −(1/n)·Σᵢ ln p(верный класс объекта i) и accuracy — долю объектов, у которых верный класс имеет наибольший логит (если максимальных логитов несколько, предсказанным считается класс с меньшим номером).

Логиты бывают большими по модулю — до 10⁴.

**Формат ввода.** Первая строка — n и K (1 ≤ n ≤ 10⁴, 2 ≤ K ≤ 10). Следующие n строк — K целых логитов и номер верного класса (от 1 до K).

**Формат вывода.** Два числа через пробел: кросс-энтропия и accuracy. Ответ принимается с абсолютной или относительной погрешностью 10⁻⁶.

## Подсказки
- `math.exp(10000)` — ошибка переполнения. Softmax не меняется, если вычесть из всех логитов одно и то же число.
- Кросс-энтропию удобно считать через log-softmax: ln pₖ = zₖ − m − ln Σⱼ e^(zⱼ − m), где m — максимальный логит.

## Разбор
Прямая формула `exp(z) / sum(exp(z))` падает на логитах порядка 1000: `exp` переполняется (в NumPy — даёт `inf` и `nan`). Решение — сдвиг на максимум m: e^(zₖ − m) не больше 1, а сумма не меньше 1, потому что одно из слагаемых — e⁰.

Для кросс-энтропии не нужно считать саму вероятность — логарифм сразу:

```python
m = max(z)
lse = m + log(sum(exp(v - m) for v in z))    # log-sum-exp
loss = lse - z[true]
```

Если вычислять p и потом `log(p)`, при очень уверенной ошибке p может округлиться до 0, и `log(0)` упадёт. Log-softmax считает ту же величину без этой проблемы — так устроены `torch.nn.CrossEntropyLoss` и `scipy.special.logsumexp`.

Accuracy — сравнение индекса первого максимума с верным классом.

**Сложность:** O(n·K).
