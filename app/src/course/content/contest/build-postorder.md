Бинарное дерево из n вершин содержит числа от 1 до n, каждое ровно один раз. Даны два его обхода: прямой (корень, левое поддерево, правое поддерево) и симметричный (левое поддерево, корень, правое поддерево). Восстановите дерево и выведите его обратный обход (левое поддерево, правое поддерево, корень).

**Формат ввода.** В первой строке — число n (1 ≤ n ≤ 10⁴). Во второй строке — прямой обход, в третьей — симметричный. Гарантируется, что обходы соответствуют одному дереву, а его высота не больше 500.

**Формат вывода.** n чисел через пробел — обратный обход.

## Подсказки
- Первый элемент прямого обхода — корень. Где он стоит в симметричном обходе?
- Всё, что левее корня в симметричном обходе, — левое поддерево. Его размер k говорит, какие k элементов прямого обхода после корня относятся к левому поддереву.
- Искать корень в симметричном обходе циклом — O(n) на каждую вершину. Заранее запомните позицию каждого числа в словаре.

## Разбор
Прямой обход начинается с корня. В симметричном обходе корень делит последовательность на левое поддерево (слева от него) и правое (справа). Если в левом поддереве k вершин, то в прямом обходе за корнем идут сначала k вершин левого поддерева, затем правое. Получается рекурсия по отрезкам обоих массивов:

```python
pos = {v: i for i, v in enumerate(inorder)}

def build(pre_lo, in_lo, size):
    if size == 0:
        return
    root = preorder[pre_lo]
    k = pos[root] - in_lo                    # размер левого поддерева
    build(pre_lo + 1, in_lo, k)              # левое
    build(pre_lo + 1 + k, pos[root] + 1, size - 1 - k)   # правое
    post.append(root)                        # корень — после поддеревьев
```

Само дерево строить не нужно: обратный обход получается прямо во время рекурсии — корень дописывается после обработки обоих поддеревьев.

Две типичные ошибки:

- **поиск корня `inorder.index(root)`** — O(n) на вызов, O(n²) в сумме; словарь позиций делает поиск O(1);
- **срезы `preorder[1:k + 1]`** — тоже копирование на каждом уровне; передавайте границы индексами.

Почему нужны именно два обхода с симметричным: прямой и обратный вместе не определяют дерево однозначно. Деревья «корень 1, левый ребёнок 2» и «корень 1, правый ребёнок 2» имеют одинаковые прямой (1 2) и обратный (2 1) обходы. Симметричный обход различает левое и правое.

Глубина рекурсии равна высоте дерева — в условии она не больше 500, так что стандартного предела в 1000 хватает. Для произвольных деревьев понадобился бы `sys.setrecursionlimit` или явный стек.

**Сложность:** O(n) времени и памяти.
