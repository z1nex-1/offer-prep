Дано дерево из n вершин, в каждой записано целое число. Дерево подвешено за вершину 1. Для каждой вершины найдите сумму чисел в её поддереве — в ней самой и во всех её потомках.

**Формат ввода.** В первой строке — число n (1 ≤ n ≤ 10⁵). Во второй строке — n целых чисел a₁, …, aₙ (|aᵢ| ≤ 10⁹). В следующих n − 1 строках — рёбра дерева: пары номеров вершин u v. Рёбра даны в произвольном порядке и без направления.

**Формат вывода.** n чисел через пробел: сумма в поддереве вершины 1, вершины 2, …, вершины n.

## Подсказки
- Рёбра не направлены — сначала нужно понять, кто чей родитель. Обойдите дерево от корня, запоминая, откуда пришли.
- Сумма поддерева вершины — её число плюс суммы поддеревьев детей. Значит, детей надо обработать раньше родителя.
- Запишите вершины в порядке обхода от корня. В обратном порядке каждый ребёнок идёт раньше своего родителя.

## Разбор
Задача на обратный (постфиксный) обход: ответ вершины собирается из ответов детей. Рекурсивно это три строки:

```python
def dfs(v, parent):
    total = a[v]
    for u in g[v]:
        if u != parent:
            total += dfs(u, v)
    res[v] = total
    return total
```

Но дерево может быть цепочкой из 10⁵ вершин, и рекурсия в Python упадёт. Надёжный приём без рекурсии — **порядок обхода + проход в обратном порядке**:

```python
parent = [0] * (n + 1)
parent[1] = -1
order = [1]
for v in order:
    for u in g[v]:
        if u != parent[v]:
            parent[u] = v
            order.append(u)

res = a[:]
for v in reversed(order):
    if parent[v] > 0:
        res[parent[v]] += res[v]
```

Первый цикл — обход в ширину от корня: он расставляет родителей, и в `order` каждая вершина стоит позже своего родителя. Во втором цикле порядок обратный, поэтому, когда мы прибавляем `res[v]` к родителю, сумма поддерева `v` уже окончательная: все потомки `v` стоят в `order` после неё и обработаны раньше.

Этот шаблон подходит для любой «динамики по поддеревьям»: размер поддерева, высота, число листьев, максимум — меняется только операция в строке с `res[parent[v]]`.

Отдельно — ввод. Чтение 10⁵ строк через `input()` в Python медленное; читайте всё сразу через `sys.stdin.buffer.read().split()`.

**Сложность:** O(n) времени и памяти.
