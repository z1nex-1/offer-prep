Обучите линейную регрессию a(x) = w₀ + w₁x₁ + … + w_d x_d градиентным спуском по MSE. Начальные веса — нули. На каждом из T шагов все веса обновляются одновременно:

```text
eᵢ = a(xᵢ) − yᵢ
w₀ ← w₀ − η · (2/n) · Σᵢ eᵢ
wⱼ ← wⱼ − η · (2/n) · Σᵢ eᵢ · xᵢⱼ      для j = 1..d
```

Ошибки eᵢ на шаге считаются по весам до обновления. Выведите веса после T шагов и MSE на обучающей выборке с этими весами.

**Формат ввода.** Первая строка — n, d, T и η (1 ≤ n ≤ 200, 1 ≤ d ≤ 3, 1 ≤ T ≤ 500, 0 < η ≤ 0.5). Следующие n строк — d признаков и y. Признаки — числа от −3 до 3, не больше двух знаков после точки, y — от −100 до 100. Гарантируется, что спуск не расходится.

**Формат вывода.** Первая строка — d + 1 весов w₀, …, w_d через пробел. Вторая — MSE. Ответ принимается с абсолютной или относительной погрешностью 10⁻⁶.

## Подсказки
- Сначала посчитайте весь вектор градиента по старым весам, потом обновите все веса.
- Свободный член удобно считать весом признака-константы 1.

## Разбор
Прямая реализация формулы. Главная ловушка — обновлять веса по одному внутри цикла по признакам так, что градиент следующего веса считается уже по изменённым весам: это другой алгоритм (покоординатный спуск), и ответ не совпадёт. Поэтому: посчитать ошибки eᵢ по текущим весам, накопить градиент по всем координатам, затем одним шагом обновить все веса.

С NumPy шаг — одна строка:

```python
X1 = np.hstack([np.ones((n, 1)), X])
w = np.zeros(d + 1)
for _ in range(T):
    w -= lr * 2 / n * X1.T @ (X1 @ w - y)
```

MSE после обучения — `np.mean((X1 @ w - y) ** 2)`. Если бы η был слишком большим, веса росли бы с каждым шагом — классическое расхождение градиентного спуска; в тестах этого нет.

**Сложность:** O(T · n · d).
