Даны n встреч, встреча i идёт в полуинтервале времени [sᵢ, eᵢ). Какое наименьшее число переговорных нужно, чтобы провести все встречи? Встреча может начаться в комнате ровно в момент окончания предыдущей.

**Формат ввода.** Первая строка — n (1 ≤ n ≤ 2·10⁵). Далее n строк: sᵢ eᵢ (0 ≤ sᵢ < eᵢ ≤ 10⁹).

**Формат вывода.** Одно число.

## Подсказки
- Отсортируйте встречи по началу.
- В min-куче — времена окончания занятых комнат: если самая ранняя освобождается к началу встречи, переиспользуйте её.

## Разбор
Сортируем встречи по началу и держим min-кучу времён окончания занятых комнат. Для очередной встречи: если корень кучи (самая рано освобождающаяся комната) `≤ s` — комната свободна, заменяем её время окончания на `e` (`heapreplace`); иначе нужна новая комната — `heappush`. Ответ — размер кучи.

Эквивалентно — максимум одновременно идущих встреч методом событий (урок об отрезках).

**Сложность:** O(n log n).
