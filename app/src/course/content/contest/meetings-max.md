Есть n заявок на переговорную: встреча i идёт с момента sᵢ до момента eᵢ (sᵢ < eᵢ). Встречи в переговорной не могут пересекаться, но следующая может начаться ровно в момент окончания предыдущей. Какое наибольшее число встреч можно провести?

**Формат ввода.** Первая строка — n (1 ≤ n ≤ 2·10⁵). Далее n строк по два целых числа sᵢ и eᵢ (0 ≤ sᵢ < eᵢ ≤ 10⁹).

**Формат вывода.** Одно число.

## Подсказки
- Жадно выбирайте встречу, которая заканчивается раньше всех.
- Сортировка по концу, затем один проход.

## Разбор
Классический жадный алгоритм: сортируем встречи по времени окончания и берём встречу, если она начинается не раньше окончания последней взятой.

Почему это оптимально (обменный аргумент): пусть в оптимальном наборе первая встреча — не та, что заканчивается раньше всех. Заменим её на самую рано заканчивающуюся — она кончается не позже, значит, ни с одной из остальных встреч набора не пересечётся. Размер набора не изменился. Повторяя рассуждение, получаем, что жадный ответ оптимален.

Сортировка по началу или длине ломается: одна длинная ранняя встреча перекрывает несколько коротких.

**Сложность:** O(n log n).
