Дан вложенный список целых чисел в привычной записи Python, но без пробелов: например, `[1,[2,[3,-4]],5]`. Элементом списка может быть число или другой список, в том числе пустой.

Глубина числа — это количество списков, внутри которых оно лежит. В примере у чисел 1 и 5 глубина 1, у числа 2 — глубина 2, у чисел 3 и −4 — глубина 3.

Найдите сумму всех чисел, умноженных на свою глубину. Для примера: 1·1 + 2·2 + 3·3 + (−4)·3 + 5·1 = 7.

**Формат ввода.** Одна строка длиной до 2·10⁵ символов — корректная запись списка. Числа по модулю не больше 10⁹, глубина вложенности не больше 100.

**Формат вывода.** Одно число — взвешенная сумма.

## Подсказки
- Список — рекурсивная структура: список состоит из элементов, каждый из которых — число или снова список. Функция разбора списка может вызывать сама себя.
- Передавайте в функцию позицию в строке и текущую глубину, а возвращайте позицию, на которой разбор закончился, и сумму.
- Можно и без рекурсии: идти по строке, увеличивать глубину на `[`, уменьшать на `]`, а числа умножать на текущую глубину.

## Разбор
Удобная рекурсия — функция `parse(i, depth)`, которая разбирает список, начинающийся с символа `[` на позиции `i`, и возвращает пару «позиция сразу после закрывающей скобки, взвешенная сумма»:

```python
def parse(i, depth):
    i += 1                              # пропускаем '['
    total = 0
    while s[i] != "]":
        if s[i] == "[":
            i, sub = parse(i, depth + 1)
            total += sub
        else:
            j = i + 1
            while s[j] not in ",]":
                j += 1
            total += int(s[i:j]) * depth
            i = j
        if s[i] == ",":
            i += 1
    return i + 1, total
```

Ответ — `parse(0, 1)[1]`. Функция доверяет себе же разбор вложенного списка и занимается только своим уровнем — классическое «доверяй рекурсии».

Здесь рекурсия — ещё и иллюстрация того, что её всегда можно заменить явным состоянием. Раз от вложенного списка нужна только глубина, достаточно счётчика: `[` увеличивает глубину, `]` уменьшает, число умножается на текущую глубину. Это решение короче и не упирается в ограничение глубины рекурсии, если бы вложенность была большой.

Ловушки: отрицательные числа (минус — часть числа, а не разделитель), пустые списки `[]` и строка из одного `[]`.

Встроенный `ast.literal_eval` тоже разберёт строку, но на большой вложенности он падает с ошибкой, а на контесте полезнее уметь писать разбор самому: задачи на разбор вложенных форматов (JSON, скобочные выражения) встречаются регулярно.

**Сложность:** O(L) времени, где L — длина строки; O(глубина) памяти.
