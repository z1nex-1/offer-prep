Дано число n. Найдите наибольшее целое r, для которого r² ≤ n. Решите бинпоиском: функции `math.isqrt` и возведения в степень 0.5 на секции могут не разрешить, а `n ** 0.5` на больших числах ошибается.

**Формат ввода.** Одно число n (0 ≤ n ≤ 10¹⁸).

**Формат вывода.** Одно число r.

## Подсказки
- Условие r² ≤ n монотонно: истинно для всех r до ответа и ложно после.
- Ищите последнее r, для которого условие истинно, в диапазоне [0, 10⁹].

## Разбор
Функция `r → r² ≤ n` монотонна, поэтому ищем последнее r с истинным условием. Шаблон «последнее истинное»: `lo = 0` (0² ≤ n всегда), `hi = 10⁹` (для n ≤ 10¹⁸ корень не больше 10⁹). Середина округляется **вверх** `(lo + hi + 1) // 2`, чтобы при `lo = mid` цикл не завис.

Почему не `int(n ** 0.5)`: для n близких к 10¹⁸ корень во float может отличаться на единицу (например, для n = (10⁹)² − 1 он округлится до 10⁹).

**Сложность:** O(log n).
