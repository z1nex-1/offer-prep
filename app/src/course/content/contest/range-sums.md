Дан массив из n чисел и q запросов. Каждый запрос — пара l, r (1 ≤ l ≤ r ≤ n): выведите сумму aₗ + … + aᵣ.

**Формат ввода.** Первая строка — n и q (1 ≤ n, q ≤ 10⁵). Вторая — n целых чисел по модулю не больше 10⁹. Далее q строк по два числа l и r.

**Формат вывода.** q чисел, каждое на отдельной строке.

## Подсказки
- Посчитайте префиксные суммы один раз.
- С массивом pref длины n + 1 и pref[0] = 0 сумма отрезка [l, r] при нумерации с единицы — pref[r] − pref[l − 1].

## Разбор
Суммировать каждый отрезок заново — O(n·q) = 10¹⁰. Префиксные суммы: `pref[i]` — сумма первых i элементов, `pref[0] = 0`. Тогда при нумерации с единицы сумма `[l, r]` равна `pref[r] - pref[l - 1]` — по одному вычитанию на запрос.

Ответы собираем в список и печатаем одним `join` — 10⁵ вызовов `print` заметно медленнее.

**Сложность:** O(n + q).
