Дан массив из n целых чисел (могут быть отрицательными) и число k. Сколько существует непустых отрезков подряд идущих элементов с суммой ровно k?

**Формат ввода.** Первая строка — n и k (1 ≤ n ≤ 2·10⁵, |k| ≤ 10¹⁴). Вторая — n целых чисел по модулю не больше 10⁹.

**Формат вывода.** Одно число.

## Подсказки
- Сумма отрезка — разность двух префиксных сумм.
- Для каждого конца отрезка нужно знать, сколько раз раньше встречался префикс `cur - k`. Не забудьте пустой префикс.

## Разбор
Пусть `pref` — префиксные суммы. Отрезок (l, r] имеет сумму k, если `pref[r] - pref[l] = k`. Идём слева направо с текущей суммой `cur` и словарём «значение префикса → сколько раз встречалось». Для каждого нового конца к ответу добавляется `cnt[cur - k]`, затем `cur` записывается в словарь. Начальное состояние `{0: 1}` соответствует пустому префиксу — без него потеряются отрезки, начинающиеся с первого элемента.

Скользящее окно здесь не работает: с отрицательными числами сумма окна не монотонна.

**Сложность:** O(n) в среднем.
