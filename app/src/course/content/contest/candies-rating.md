После олимпиады n школьников стоят в ряд, у каждого есть рейтинг. Учитель раздаёт конфеты: каждый получает хотя бы одну, а школьник, у которого рейтинг выше, чем у соседа в ряду, получает больше конфет, чем этот сосед. Какое наименьшее число конфет понадобится?

**Формат ввода.** В первой строке — n (1 ≤ n ≤ 5·10⁴). Во второй — n целых чисел rᵢ (0 ≤ rᵢ ≤ 10⁴), рейтинги в порядке ряда.

**Формат вывода.** Одно число — наименьшее количество конфет.

## Подсказки
- Условие «больше соседа» распадается на два: больше левого соседа и больше правого. Каждое по отдельности выполняется одним проходом.
- Слева направо: если рейтинг выше левого соседа, конфет на одну больше, чем у него. Справа налево — то же с правым соседом.
- Во втором проходе нельзя испортить первый — берите максимум из двух требований.

## Разбор
Первый проход слева направо: `c[i] = c[i − 1] + 1`, если `r[i] > r[i − 1]`, иначе 1. Второй проход справа налево: если `r[i] > r[i + 1]`, то `c[i] = max(c[i], c[i + 1] + 1)`. Ответ — сумма `c`.

Почему это минимум. После первого прохода `c[i]` равно длине строго возрастающего участка, который кончается в i: вдоль него конфеты обязаны расти хотя бы на единицу, поэтому меньше дать нельзя. Второй проход так же даёт длину убывающего участка, который начинается в i. Значит, итоговое `c[i]` — нижняя граница для любой правильной раздачи, а сам набор нижних границ условию удовлетворяет. Соседи с равным рейтингом ничего друг другу не должны: `1 2 2` — это `1 2 1`, всего 4.

Частые ошибки: один проход (на убывающем ряду `3 2 1` все получат по одной конфете); во втором проходе `c[i] = c[i + 1] + 1` без `max` — на вершине `1 3 4 5 2` пятёрка получит 2 вместо 4; равные соседи получают одинаково, хотя условие этого не требует.

**Сложность:** O(n).
