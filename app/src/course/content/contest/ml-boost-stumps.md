Реализуйте градиентный бустинг для регрессии с функцией потерь MSE на одном признаке. Базовые модели — решающие пни (деревья глубины 1).

1. Начальное предсказание F₀(x) — среднее всех y обучающей выборки.
2. На каждом из R раундов посчитайте остатки rᵢ = yᵢ − F(xᵢ) и обучите пень на остатках: порог t выбирается среди середин между соседними различными значениями x, в левом листе (x ≤ t) — среднее остатков его объектов, в правом (x > t) — среднее остатков правых. Выбирается порог с минимальной суммой квадратов ошибок пня на остатках. Затем F(x) ← F(x) + η · пень(x).

Выведите MSE итогового ансамбля на обучающей выборке и его предсказания для q точек-запросов. Гарантируется, что различных значений x хотя бы два, а на каждом раунде лучший порог единственный с запасом, так что погрешности вычислений на выбор порога не влияют.

**Формат ввода.** Первая строка — n, R и η (2 ≤ n ≤ 5000, 1 ≤ R ≤ 50, 0 < η ≤ 1). Следующие n строк — x и y (целые, |x| ≤ 10⁶, |y| ≤ 10⁴). Затем строка с q (1 ≤ q ≤ 1000) и q строк с x запросов (целые, |x| ≤ 10⁶).

**Формат вывода.** Первая строка — MSE на обучающей выборке. Затем q строк — предсказания для запросов. Ответ принимается с абсолютной или относительной погрешностью 10⁻⁶.

## Подсказки
- Для MSE антиградиент по предсказаниям — это остатки, поэтому каждый пень учится на остатках.
- Сумма квадратов ошибок пня равна Σ r² − S_L² / n_L − S_R² / n_R, где S — суммы остатков слева и справа. Минимизировать её — значит максимизировать S_L² / n_L + S_R² / n_R.
- Отсортируйте объекты по x один раз: на каждом раунде пороги перебираются одним проходом с префиксными суммами остатков.

## Разбор
Храним текущие предсказания F для обучающих объектов и список пней (t, левое значение, правое значение). Объекты сортируем по x один раз.

На раунде считаем остатки в отсортированном порядке, их общую сумму S и идём слева направо, накапливая S_L. На границе между различными x оцениваем S_L² / n_L + (S − S_L)² / (n − n_L) и запоминаем максимум — это минимум суммы квадратов ошибок пня. Значения листьев — средние остатков: S_L / n_L и S_R / n_R. Обновляем F с коэффициентом η.

Предсказание для запроса: F₀ плюс η, умноженное на сумму ответов всех пней (для каждого пня — левое значение, если x ≤ t, иначе правое).

Это ровно то, что делает градиентный бустинг в CatBoost или XGBoost, только с деревьями глубины 1 и без регуляризации. Заметьте: при η = 1 первый пень сразу подгоняет остатки, а при маленьком η ансамблю нужно больше раундов — и именно так он меньше переобучается.

**Сложность:** O(n log n + R · n + q · R).
