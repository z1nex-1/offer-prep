В ряд стоят n человек с номерами 1, 2, …, n слева направо. По одному они выходят из ряда, и оставшиеся смыкаются. Для каждого выходящего выведите, кто в момент выхода стоял от него слева и кто справа.

**Формат ввода.** В первой строке — n и q (1 ≤ q ≤ n ≤ 10⁵). Во второй — q различных номеров в порядке выхода.

**Формат вывода.** q строк: номер соседа слева и номер соседа справа. Если соседа с какой-то стороны нет, вместо номера выведите 0.

## Подсказки
- Искать человека в списке и удалять его — O(n) на запрос. Что нужно помнить о каждом человеке, чтобы удалить его за O(1)?
- Для каждого храните соседей слева и справа — двусвязный список на двух массивах.

## Разбор
Храним `left[x]` и `right[x]` — текущих соседей каждого. Вначале `left[x] = x − 1`, `right[x] = x + 1`, а номера 0 и n + 1 — фиктивные края. Когда x выходит, его соседи — ровно `left[x]` и `right[x]`; выводим их (n + 1 выводим как 0) и сшиваем ряд: `right[left[x]] = right[x]`, `left[right[x]] = left[x]`. Больше ничего менять не нужно: к x никто не обратится, потому что его уже нет среди ничьих соседей.

Частые ошибки: забыть сшить одну из сторон; выводить n + 1 вместо 0; решать через `list.index` и `pop` — каждый запрос O(n), всего O(n · q).

**Сложность:** O(n + q).
