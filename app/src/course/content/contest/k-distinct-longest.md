Дан массив из n целых чисел и число k. Найдите длину самого длинного отрезка подряд идущих элементов, в котором не больше k различных значений.

**Формат ввода.** Первая строка — n и k (1 ≤ k ≤ n ≤ 2·10⁵). Вторая — n целых чисел по модулю не больше 10⁹.

**Формат вывода.** Одно число.

## Подсказки
- Окно со словарём частот. Число различных — размер словаря.
- Пока различных больше k — сужайте окно слева, удаляя ключи с нулевой частотой.

## Разбор
Окно `[l, r]` и словарь частот его элементов. Добавляем `a[r]`; если различных стало больше k, сдвигаем `l`, уменьшая частоту `a[l]` и удаляя ключ, когда она обнулилась. После этого окно хорошее, его длина — кандидат.

Удалять ключи с нулевой частотой обязательно — иначе `len(cnt)` будет считать элементы, которых в окне уже нет.

**Сложность:** O(n) в среднем.
