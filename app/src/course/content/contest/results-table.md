Даны результаты n участников олимпиады: имя, число решённых задач и штраф. Упорядочьте таблицу: сначала по числу задач (больше — выше), при равенстве по штрафу (меньше — выше), при полном равенстве — по имени в лексикографическом порядке.

**Формат ввода.** Первая строка — n (1 ≤ n ≤ 10⁵). Далее n строк: имя (латинские буквы, без пробелов), число задач (0–15) и штраф (0–10⁶).

**Формат вывода.** Имена участников в порядке таблицы, каждое на своей строке.

## Подсказки
- Один вызов sorted с ключом-кортежем.
- Чтобы число задач шло по убыванию, поставьте перед ним минус.

## Разбор
Кортежи сравниваются лексикографически, поэтому ключ `(-solved, penalty, name)` задаёт ровно нужный порядок: сначала по задачам по убыванию (минус переворачивает порядок), потом по штрафу по возрастанию, потом по имени.

Альтернатива без минуса — несколько устойчивых сортировок от младшего критерия к старшему: по имени, потом по штрафу, потом по задачам с `reverse=True`. Устойчивость Timsort гарантирует правильный результат.

Сортировать `solved` как строки нельзя: `"10" < "9"`.

**Сложность:** O(n log n).
