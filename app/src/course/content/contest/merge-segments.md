Дано n отрезков [lᵢ, rᵢ] на прямой. Объедините пересекающиеся и касающиеся отрезки (например, [1, 3] и [3, 5] сливаются в [1, 5], а [1, 2] и [3, 4] — нет). Выведите получившиеся отрезки в порядке возрастания левого конца.

**Формат ввода.** Первая строка — n (1 ≤ n ≤ 10⁵). Далее n строк по два целых числа lᵢ ≤ rᵢ, по модулю не больше 10⁹.

**Формат вывода.** В первой строке — число отрезков k. Далее k строк по два числа.

## Подсказки
- Отсортируйте по левому концу.
- Новый отрезок может пересекаться только с последним отрезком ответа.

## Разбор
После сортировки по левому концу идём по отрезкам: если начало текущего не больше конца последнего отрезка ответа — расширяем его конец до `max`, иначе начинаем новый. Все более ранние отрезки ответа заканчиваются раньше, поэтому проверять их не нужно.

Частая ошибка — присваивать конец `res[-1][1] = r` вместо `max(...)`: вложенный отрезок [1, 10] и [2, 3] даст [1, 3].

**Сложность:** O(n log n).
