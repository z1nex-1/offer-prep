Цифровой корень числа получается так: складываем его цифры, у результата снова складываем цифры, и так, пока не останется одна цифра. Например, 9875 → 29 → 11 → 2.

Найдите цифровой корень числа, в записи которого может быть до 10⁵ цифр.

**Формат ввода.** Одна строка — неотрицательное целое число без ведущих нулей (число 0 записывается как `0`), от 1 до 10⁵ цифр.

**Формат вывода.** Одна цифра — цифровой корень.

## Подсказки
- Работайте с числом как со строкой: цифры — это её символы.
- После первого суммирования получится число не больше 9 · 10⁵ — дальше можно повторять в цикле.

## Разбор
Читаем строку и суммируем цифры: `sum(map(int, s))`. Получилось число не больше 900 000, и дальше повторяем то же самое, пока оно не станет однозначным — это пара итераций.

Можно было бы сделать `int(s)` и работать с числом: в Python это сработает, но перевод строки из 10⁵ цифр в число — лишняя работа (а в новых версиях Python по умолчанию есть ограничение на 4300 цифр при переводе строки в `int`, и такой код упадёт с `ValueError`).

Есть и формула: у положительного числа цифровой корень равен `1 + (n − 1) % 9`, потому что число и сумма его цифр дают одинаковый остаток при делении на 9. Для 0 ответ 0.

**Сложность:** O(L), где L — число цифр.
