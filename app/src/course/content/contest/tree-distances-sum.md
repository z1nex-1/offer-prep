Посёлки соединены n − 1 дорогами так, что из любого посёлка можно доехать в любой, и путь единственный. Все дороги одинаковой длины. Компания выбирает посёлок для склада: из склада машина ездит в каждый посёлок по отдельности, и нужно знать суммарный пробег. Для каждого посёлка v выведите сумму расстояний (в дорогах) от v до всех остальных посёлков.

**Формат ввода.** В первой строке — n (1 ≤ n ≤ 10⁵). Далее n − 1 строк с парами a b — дорогами между посёлками (1 ≤ a, b ≤ n).

**Формат вывода.** В одной строке n чисел: ответы для посёлков 1, 2, …, n.

## Подсказки
- Обход из каждой вершины — O(n²), для 10⁵ это 10¹⁰.
- Подвесьте дерево за вершину 1 и посчитайте размеры поддеревьев и ответ для корня.
- Как меняется ответ при переходе от вершины v к её ребёнку c? До вершин поддерева c стало на 1 ближе, до всех остальных — на 1 дальше.

## Разбор
Это классический приём **перекоренения** (rerooting): посчитать ответ для одного корня, а затем «передвигать» корень по рёбрам, пересчитывая ответ за O(1).

**Шаг 1.** Подвешиваем дерево за вершину 1 и находим порядок обхода — в нём родитель раньше ребёнка. Проходом в обратном порядке считаем размеры поддеревьев `size[v]`. Ответ для корня — сумма глубин всех вершин.

**Шаг 2.** Пусть ответ для v известен, c — ребёнок v. Если перенести склад из v в c, то до каждой из `size[c]` вершин поддерева c путь станет на 1 короче, а до остальных `n - size[c]` — на 1 длиннее:

```
ans[c] = ans[v] - size[c] + (n - size[c]) = ans[v] + n - 2 * size[c]
```

Проходом в прямом порядке обхода (родитель раньше ребёнка) получаем все ответы.

```python
order = [1]
parent[1] = 0
for v in order:                       # обход в ширину от корня
    for c in adj[v]:
        if c != parent[v]:
            parent[c] = v
            depth[c] = depth[v] + 1
            order.append(c)

size = [1] * (n + 1)
for v in reversed(order):             # дети раньше родителей
    if parent[v]:
        size[parent[v]] += size[v]

ans = [0] * (n + 1)
ans[1] = sum(depth)
for v in order[1:]:                   # родитель раньше ребёнка
    ans[v] = ans[parent[v]] + n - 2 * size[v]
```

Рекурсивный DFS для этой задачи опасен: на дереве-цепочке глубина 10⁵, и Python упадёт с переполнением стека даже с поднятым `setrecursionlimit`. Порядок обхода в ширину даёт то же самое без рекурсии.

Тот же приём решает много задач вида «посчитать что-то для каждой вершины как для корня»: самую удалённую вершину от каждой, число вершин на расстоянии не больше k и т. д. Схема одна: динамика по поддеревьям снизу вверх, затем проход сверху вниз, который добавляет вклад «остальной части дерева».

**Сложность:** O(n) времени и памяти.
