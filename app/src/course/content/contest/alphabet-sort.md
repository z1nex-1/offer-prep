У пришельцев те же 26 строчных латинских букв, но другой алфавитный порядок. Дан этот порядок и n слов. Выведите слова в словарном порядке пришельцев: слова сравниваются по первой различающейся букве, а если одно слово — начало другого, раньше идёт более короткое.

**Формат ввода.** В первой строке — 26 различных строчных латинских букв: алфавит пришельцев от первой буквы к последней. Во второй — n (1 ≤ n ≤ 10⁴). Далее n строк по одному слову из строчных латинских букв, длина слова от 1 до 20. Слова могут повторяться.

**Формат вывода.** Слова в словарном порядке пришельцев, по одному на строке.

## Подсказки
- Если заменить каждую букву её номером в алфавите пришельцев, слова станут списками чисел, а списки Python сравниваются ровно по словарному правилу.
- Словарь `pos` «буква → номер» стоит построить один раз, до сортировки.

## Разбор
Построим `pos = {c: i for i, c in enumerate(alphabet)}` и отсортируем слова с ключом `lambda w: [pos[c] for c in w]`. Списки сравниваются поэлементно, а если один — префикс другого, меньше короткий. Это и есть словарный порядок в новом алфавите. Ключ вычисляется один раз для каждого слова, поэтому стоимость — O(n · L) на ключи и O(n log n · L) на сравнения, где L — длина слова.

Другой способ — перевести слова в обычный алфавит: `table = str.maketrans(alphabet, 'abcdefghijklmnopqrstuvwxyz')` и ключ `w.translate(table)`. Строки-ключи сравниваются быстрее списков.

Ошибка, которую ловят тесты, — отсортировать слова обычным `sorted`: результат совпадёт с нужным, только если алфавит пришельцев случайно обычный.

**Сложность:** O(n · L · log n).
