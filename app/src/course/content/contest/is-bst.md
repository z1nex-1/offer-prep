Дано бинарное дерево из n вершин, корень — вершина 1. Проверьте, является ли оно бинарным деревом поиска: для каждой вершины все значения в её левом поддереве строго меньше значения вершины, а все значения в правом поддереве — строго больше.

**Формат ввода.** В первой строке — число n (1 ≤ n ≤ 10⁵). В следующих n строках — описание вершин 1, 2, …, n: значение (целое, по модулю не больше 10⁹), номер левого ребёнка и номер правого ребёнка. Номер 0 означает, что ребёнка нет. Гарантируется, что описание задаёт дерево с корнем 1.

**Формат вывода.** `YES`, если дерево — дерево поиска, иначе `NO`.

## Подсказки
- Проверить только, что левый ребёнок меньше вершины, а правый — больше, недостаточно. Придумайте дерево из трёх уровней, где это выполняется, но дерево не поисковое.
- Спускаясь от корня, передавайте допустимый интервал значений: в левом поддереве вершины со значением x всё должно быть меньше x.
- Другой путь: симметричный обход дерева поиска выдаёт строго возрастающую последовательность.

## Разбор
Классическая ошибка — сравнивать вершину только с детьми. Дерево «корень 5, левый ребёнок 3, у тройки правый ребёнок 7» проходит такую проверку, но 7 лежит в левом поддереве пятёрки, где всё должно быть меньше 5.

**Способ 1: интервалы.** Каждой вершине при спуске передаём границы (lo, hi), в которых обязано лежать её значение. Корню — (−∞, +∞). Левому ребёнку вершины x — (lo, x), правому — (x, hi):

```python
stack = [(1, float("-inf"), float("inf"))]
while stack:
    v, lo, hi = stack.pop()
    if not lo < val[v] < hi:
        return False
    if left[v]:
        stack.append((left[v], lo, val[v]))
    if right[v]:
        stack.append((right[v], val[v], hi))
return True
```

**Способ 2: симметричный обход.** Для дерева поиска порядок «левое поддерево, вершина, правое поддерево» даёт строго возрастающую последовательность, и наоборот. Достаточно обойти дерево и сравнить соседние значения.

Строгие неравенства важны: одинаковые значения в дереве поиска из условия недопустимы. Так же спрашивают и на собеседованиях, но это стоит уточнить у интервьюера — в некоторых определениях дубликаты разрешены с одной стороны.

Дерево может быть цепочкой из 10⁵ вершин, поэтому обход сделан явным стеком, а не рекурсией.

**Сложность:** O(n) времени и памяти.
