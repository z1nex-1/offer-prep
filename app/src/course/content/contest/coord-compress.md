Дан массив из n целых чисел. Замените каждое число его рангом: номером среди различных значений массива, упорядоченных по возрастанию. Самое маленькое значение получает ранг 1, следующее по величине различное значение — ранг 2, и так далее. Равные числа получают равные ранги.

**Формат ввода.** В первой строке — n (1 ≤ n ≤ 3·10⁴). Во второй — n целых чисел, по модулю не больше 10⁹.

**Формат вывода.** n рангов через пробел в исходном порядке.

## Подсказки
- Ранг числа — это его позиция в отсортированном списке **различных** значений.
- Поиск позиции через `list.index` внутри цикла — O(n) на каждое число. Постройте словарь «значение → ранг» один раз.

## Разбор
Отсортируем различные значения: `vals = sorted(set(a))`. Ранг значения `vals[i]` равен `i + 1`. Словарь `rank = {v: i + 1 for i, v in enumerate(vals)}` строится за O(n), после чего ответ — `rank[x]` для каждого x.

Две частые ошибки. Первая — сортировать `a` без `set`: тогда равные числа займут несколько позиций, и ранги «съедут». Вторая — искать ранг через `vals.index(x)` в цикле: это O(n) на поиск и O(n²) в сумме. Если словарь не нужен, можно искать бинарным поиском: `bisect_left(vals, x) + 1` — O(log n) на запрос.

Этот приём называется сжатием координат: значения до 10⁹ превращаются в числа от 1 до k, и их можно использовать как индексы массива.

**Сложность:** O(n log n) на сортировку, O(n) памяти.
