На пустой шахматной доске стоит одна фигура. Может ли она за один ход попасть из одной клетки в другую?

Фигуры ходят так: король — на одну клетку в любом направлении, ладья — на любое число клеток по горизонтали или вертикали, слон — на любое число клеток по диагонали, ферзь — как ладья или слон, конь — буквой «Г»: на две клетки в одном направлении и на одну в перпендикулярном.

**Формат ввода.** В первой строке — число запросов q (1 ≤ q ≤ 10⁴). В каждой из следующих q строк — название фигуры (`king`, `queen`, `rook`, `bishop` или `knight`) и две различные клетки в шахматной записи, например `knight g1 f3`.

**Формат вывода.** Для каждого запроса `YES` или `NO`.

## Подсказки
- Переведите клетку в два числа: столбец `ord(c[0]) - ord('a')` и строку `int(c[1])`.
- Всё решают модули разностей `dx = |x1 − x2|` и `dy = |y1 − y2|`. Выпишите условие для каждой фигуры.

## Разбор
Переводим клетки в координаты и считаем `dx` и `dy` — модули разностей по столбцу и строке. Клетки различны, поэтому хотя бы одно из них не ноль. Дальше таблица:

| Фигура | Условие |
|---|---|
| король | `max(dx, dy) == 1` |
| ладья | `dx == 0 or dy == 0` |
| слон | `dx == dy` |
| ферзь | ладья или слон |
| конь | `{dx, dy} == {1, 2}` |

Условия удобно положить в словарь функций или просто в цепочку `if`. Главное — не писать отдельные ветки для каждого направления: модули разностей убирают все симметричные случаи сразу.

**Сложность:** O(1) на запрос.
