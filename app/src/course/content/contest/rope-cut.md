Есть n верёвок длиной L₁, …, Lₙ сантиметров. Из них нужно нарезать не меньше k кусков одинаковой целой длины (остатки выбрасываются, связывать верёвки нельзя). Какой наибольшей длины могут быть куски? Если нельзя нарезать даже куски длиной 1, выведите 0.

**Формат ввода.** Первая строка — n и k (1 ≤ n ≤ 10⁵, 1 ≤ k ≤ 10⁹). Вторая — n длин от 1 до 10⁷.

**Формат вывода.** Одно число.

## Подсказки
- Из верёвки длины L получается L // x кусков длины x.
- Чем длиннее куски, тем их меньше — ищите наибольшее x бинпоиском.

## Разбор
Для длины x число кусков — `sum(L // x)`. Функция не возрастает по x, поэтому наибольшее x с `sum(L // x) >= k` ищется бинпоиском по ответу в [0, max(L)]. Значение 0 — «ничего не получится»: проверку для x = 0 не вызываем, она всегда считается истинной (иначе деление на ноль).

**Сложность:** O(n log max L).
