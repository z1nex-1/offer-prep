Массив из n неотрицательных чисел нужно разрезать на k непустых отрезков подряд идущих элементов так, чтобы наибольшая из сумм отрезков была как можно меньше. Выведите эту наименьшую возможную наибольшую сумму.

**Формат ввода.** Первая строка — n и k (1 ≤ k ≤ n ≤ 10⁵). Вторая — n чисел от 0 до 10⁹.

**Формат вывода.** Одно число.

## Подсказки
- Проверка «можно ли уложиться в S»: жадно набирайте элементы в отрезок, пока сумма не превысит S.
- Бинпоиск по S от max(a) до sum(a).

## Разбор
Зафиксируем S и спросим: можно ли разрезать массив так, чтобы все суммы были ≤ S? Жадно: набираем элементы в текущий отрезок, пока сумма не превысит S, затем начинаем новый. Если отрезков получилось не больше k — можно (лишние отрезки всегда можно получить, разрезав какой-то дальше, ведь элементы неотрицательны и n ≥ k).

Проверка монотонна по S, значит, минимальное S ищем бинпоиском в [max(a), sum(a)]: меньше max(a) нельзя — самый большой элемент не влезет ни в один отрезок.

**Сложность:** O(n log(sum)).
