Бинарное дерево записано по уровням — так, как его записывают в задачах на собеседованиях. Сначала идёт значение корня. Затем для каждой вершины, уже появившейся в записи, по порядку перечисляются её левый и правый ребёнок; отсутствующий ребёнок обозначается словом `null`. У отсутствующих вершин детей не перечисляют. Лишних `null` в конце записи может не быть.

Например, запись `1 2 3 null 5 null 4` задаёт корень 1 с детьми 2 и 3, у вершины 2 есть только правый ребёнок 5, у вершины 3 — только правый ребёнок 4.

Представьте, что вы смотрите на дерево справа. Выведите значения вершин, которые видны, сверху вниз: на каждом уровне видна самая правая вершина.

**Формат ввода.** Одна строка — запись дерева: до 10⁵ слов, каждое — целое число по модулю не больше 10⁹ или `null`. Корень существует.

**Формат вывода.** Значения видимых вершин через пробел.

## Подсказки
- Сначала восстановите дерево из записи: очередь вершин, каждой по порядку достаются два следующих слова.
- Затем обход в ширину по уровням: на каждом уровне нужна последняя вершина.
- Деревья можно не строить объектами: достаточно массивов `left` и `right` с номерами вершин.

## Разбор
Формат записи сам устроен как обход в ширину. Вершины получают детей в том порядке, в котором появились, поэтому восстанавливаем дерево очередью:

```python
vals = line.split()
left, right = {}, {}
queue = [0]                  # номера слов, ставших вершинами
pos = 1
for v in queue:
    if pos < len(vals):
        if vals[pos] != "null":
            left[v] = pos
            queue.append(pos)
        pos += 1
    if pos < len(vals):
        if vals[pos] != "null":
            right[v] = pos
            queue.append(pos)
        pos += 1
```

Вершину удобно обозначать номером её слова в записи. Дальше — обход по уровням, как в уроке «Деревья и обходы»: текущий уровень — список вершин, следующий уровень собирается из их детей, и в ответ идёт последняя вершина уровня.

```python
level = [0]
res = []
while level:
    res.append(vals[level[-1]])
    nxt = []
    for v in level:
        if v in left: nxt.append(left[v])
        if v in right: nxt.append(right[v])
    level = nxt
```

Частая ошибка — идти только по правым детям от корня. В примере `1 2 3 4` видна вершина 4, хотя она левый ребёнок левого ребёнка: на третьем уровне других вершин нет.

Вариант с обходом в глубину: идти сначала вправо и записывать вершину, если её глубина впервые достигла нового значения. Но дерево может быть цепочкой длины 10⁵ — нужен явный стек.

**Сложность:** O(n) времени и памяти.
