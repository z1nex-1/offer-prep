Дан набор из n целых чисел (среди них могут быть отрицательные и одинаковые) и число S. Сколько существует непустых подмножеств набора, сумма элементов которых равна S? Подмножества различаются номерами взятых элементов: если в наборе два одинаковых числа, то подмножества из первого и из второго считаются разными.

**Формат ввода.** В первой строке — числа n и S (1 ≤ n ≤ 18, |S| ≤ 10⁹). Во второй строке — n целых чисел, по модулю не больше 10⁸.

**Формат вывода.** Одно число — количество подходящих подмножеств.

## Подсказки
- n ≤ 18 — это намёк: подмножеств всего 2¹⁸ ≈ 260 тысяч, их можно перебрать все.
- Для каждого элемента два варианта: взять или не взять. Передавайте в рекурсию номер элемента и текущую сумму.
- Не забудьте, что пустое подмножество не считается — даже если S = 0.

## Разбор
Ограничение n ≤ 18 прямо говорит о полном переборе: 2ⁿ подмножеств — это 262 144 варианта.

Рекурсия `go(i, s, taken)`: рассмотрели первые i элементов, их выбранная часть даёт сумму `s`, взято `taken` элементов. Для элемента i два варианта — не брать или взять:

```python
def go(i, s, taken):
    if i == n:
        return 1 if s == S and taken > 0 else 0
    return go(i + 1, s, taken) + go(i + 1, s + a[i], taken + 1)
```

Отсечение «сумма уже больше S — дальше не идём» здесь **неверно**: числа бывают отрицательными, и сумма ещё может уменьшиться. Это частая ошибка — отсечения переносят из задачи с положительными числами, не проверив условие.

Пустое подмножество имеет сумму 0. Если S = 0, его нельзя засчитать — отсюда счётчик `taken`. Можно и проще: посчитать все подмножества с суммой S, а потом вычесть единицу, если S = 0.

Тот же перебор без рекурсии — по битовым маскам: `for mask in range(1, 1 << n)`, сумма элементов с установленными битами. Но так на каждую маску тратится O(n), итого O(2ⁿ · n), а рекурсия считает сумму по дороге и укладывается в O(2ⁿ).

Для n до 40 есть приём «встреча посередине»: разбить набор на две половины, перебрать суммы каждой (по 2²⁰) и для каждой суммы левой половины найти в словаре, сколько раз в правой встречается S минус она.

**Сложность:** O(2ⁿ) времени, O(n) памяти на стек рекурсии.
