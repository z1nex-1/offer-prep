Дано поле игры «Сапёр»: `*` — мина, `.` — пустая клетка. Для каждой пустой клетки напишите, сколько мин в соседних с ней клетках — по стороне или по углу, всего до восьми соседей.

**Формат ввода.** В первой строке — n и m (1 ≤ n, m ≤ 300). Далее n строк по m символов `*` или `.`.

**Формат вывода.** n строк по m символов: мина остаётся `*`, вместо пустой клетки — цифра от 0 до 8.

## Подсказки
- Заведите список восьми сдвигов `(di, dj)` и перебирайте соседей циклом, а не восемью `if`.
- Проверяйте границы поля до обращения к `grid[ni][nj]`. Помните, что индекс −1 в Python не вызывает ошибку.

## Разбор
Для каждой пустой клетки `(i, j)` перебираем восемь сдвигов, для каждого считаем соседа `(i + di, j + dj)` и, если он внутри поля и там мина, увеличиваем счётчик.

Главная ловушка — проверка границ. Если её забыть, у клеток последней строки или столбца будет `IndexError`, а у клеток первой строки или столбца — хуже: `grid[-1]` молча вернёт последнюю строку, и в ответ попадут чужие мины. Поэтому условие `0 <= ni < n and 0 <= nj < m` стоит первым.

Строки ответа собираем через `''.join(row)`, а все строки печатаем одним `print('\n'.join(...))`.

**Сложность:** O(n · m · 8) = O(n · m).
