Сколько чисел от 1 до n делятся хотя бы на одно из чисел a и b?

**Формат ввода.** Три целых числа n, a, b (1 ≤ n, a, b ≤ 10¹⁸) через пробел.

**Формат вывода.** Одно число — ответ.

## Подсказки
- Цикл до n при n = 10¹⁸ не закончится никогда. Сколько чисел от 1 до n делятся на a?
- Числа, которые делятся и на a, и на b, посчитаны дважды. На что они делятся?

## Разбор
Чисел от 1 до n, кратных a, ровно `n // a`. Кратных b — `n // b`. Сумма считает дважды числа, кратные обоим, — это числа, кратные наименьшему общему кратному `lcm(a, b) = a // gcd(a, b) * b`. Их вычитаем: ответ `n // a + n // b − n // lcm(a, b)`. Это формула включений-исключений.

НОК может быть до 10³⁶ — больше n, тогда `n // lcm` просто 0. В Python переполнения нет, но в C++ здесь пришлось бы быть осторожнее. Функция `math.lcm` есть с Python 3.9.

Частая ошибка — вычитать `n // (a * b)`: при a = 4, b = 6 общие кратные — числа, кратные 12, а не 24.

**Сложность:** O(log min(a, b)) на вычисление НОД.
