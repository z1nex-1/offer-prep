### [1] Что выведет код? @recursion
```python
def f(n):
    if n <= 1:
        return 1
    return n * f(n - 1)

print(f(5))
```
- [ ] `15`
- [x] `120`
- [ ] `5`
- [ ] `RecursionError`
> Это факториал: 5 · 4 · 3 · 2 · 1 = 120. База — n ≤ 1.


### [2] Что выведет код? @backtracking
```python
res = []
cur = []
def go(i):
    if i == 3:
        res.append(cur[:])
        return
    cur.append(i)
    go(i + 1)
    cur.pop()
    go(i + 1)

go(0)
print(len(res), res[0], res[-1])
```
- [ ] `8 [] [0, 1, 2]`
- [x] `8 [0, 1, 2] []`
- [ ] `3 [0] [2]`
- [ ] `6 [0, 1, 2] []`
> Сначала ветка «взять», поэтому первым получается полное подмножество, последним — пустое. Всего 2³ = 8.

### [2] Какая сложность у функции? @divide-conquer
```python
def g(a, lo, hi):
    if hi - lo <= 1:
        return a[lo]
    mid = (lo + hi) // 2
    return max(g(a, lo, mid), g(a, mid, hi))
```
- [ ] O(log n)
- [x] O(n)
- [ ] O(n log n)
- [ ] O(n²)
> T(n) = 2T(n/2) + O(1): число вызовов растёт к листьям, листьев n. Итого O(n) — как и у обычного прохода.

### [3] Нужно посчитать aⁿ mod m для n до 10¹⁸. Какое решение правильное и быстрое? @divide-conquer
- [ ] `a ** n % m`
- [x] `pow(a, n, m)` или рекурсия через aⁿ = (a^(n/2))²
- [ ] Цикл из n умножений с взятием остатка
- [ ] `math.pow(a, n) % m`
> `a ** n` строит число из миллиардов цифр, цикл делает 10¹⁸ шагов, `math.pow` работает с float и теряет точность. Быстрое возведение — O(log n).

### [3] Как посчитать n-е число Фибоначчи по модулю 10⁹ + 7 для n = 10¹⁸? @divide-conquer

- [ ] Только динамика

### [3] Что выведет код? @brute-force-contest
```python
a = [1, 2, 3, 4]
i = len(a) - 2
while i >= 0 and a[i] >= a[i + 1]:
    i -= 1
j = len(a) - 1
while a[j] <= a[i]:
    j -= 1
a[i], a[j] = a[j], a[i]
a[i + 1:] = reversed(a[i + 1:])
print(a)
```
- [ ] `[4, 3, 2, 1]`
- [x] `[1, 2, 4, 3]`
- [ ] `[2, 1, 3, 4]`
- [ ] `[1, 3, 2, 4]`
> Это алгоритм «следующая перестановка»: после `1 2 3 4` идёт `1 2 4 3`.
