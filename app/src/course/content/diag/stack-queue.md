### [2] Что выведет код? @stack-queue
```python
st = []
for t in "3 4 + 5 *".split():
    if t in "+*":
        b, a = st.pop(), st.pop()
        st.append(a + b if t == "+" else a * b)
    else:
        st.append(int(t))
print(st)
```
- [ ] `[23]`
- [x] `[35]`
- [ ] `[3, 20]`
- [ ] `[12]`
> (3 + 4) · 5 = 35.
