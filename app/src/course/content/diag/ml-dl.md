### [3] Почему в трансформерах используют LayerNorm, а не BatchNorm? @ml-dl-training
- [ ] BatchNorm нельзя дифференцировать
- [x] LayerNorm нормирует по признакам одного объекта: не зависит от размера батча и длины последовательностей и одинаково работает при обучении и применении
- [ ] LayerNorm не имеет параметров
- [ ] BatchNorm медленнее
> Статистики по батчу нестабильны при маленьких батчах и паддинге.

### [3] Зачем в attention делить Q·Kᵀ на √d_k? @ml-cnn-transformers
- [ ] Чтобы веса суммировались в 1
- [x] Дисперсия скалярного произведения растёт с d_k, softmax насыщается и градиенты исчезают
- [ ] Чтобы учесть позиции токенов
- [ ] Чтобы сократить память
> Нормировку в сумму 1 делает softmax.

### [3] Какова сложность self-attention по длине последовательности T и почему? @ml-cnn-transformers
- [ ] O(T): каждый токен обрабатывается один раз
- [x] O(T²): каждый запрос сравнивается с каждым ключом
- [ ] O(T log T)
- [ ] O(1)
> Поэтому длина контекста ограничена, а FlashAttention и разреженные варианты борются с памятью T × T.

### [3] В обратном проходе слоя z = Wh + b, a = f(z) известен δₐ = ∂L/∂a. Чему равен градиент по h? @ml-mlp-backprop
- [ ] δₐ · hᵀ
- [x] Wᵀ · (δₐ ⊙ f'(z))
