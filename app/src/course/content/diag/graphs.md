### [1] Какой обход находит кратчайший путь в невзвешенном графе? @graphs-basics
- [ ] DFS
- [x] BFS
- [ ] Любой
- [ ] Никакой
> BFS обходит вершины в порядке возрастания расстояния.

### [1] Какая сложность BFS на списке смежности? @graphs-basics
- [ ] O(V²)
- [x] O(V + E)
- [ ] O(E log V)
- [ ] O(V · E)
> Каждая вершина и каждое ребро обрабатываются константное число раз.

### [2] Как проверить, можно ли разбить граф на две группы, чтобы рёбра шли только между группами? @graphs-basics
- [ ] Посчитать степени вершин
- [x] Раскрасить обходом в два цвета и найти конфликт
- [ ] Топологической сортировкой
- [ ] Дейкстрой
> Это проверка двудольности; конфликт означает нечётный цикл.

### [2] Как найти порядок выполнения задач с зависимостями? @graphs-advanced
- [ ] BFS от первой задачи
- [x] Топологической сортировкой; если в порядок попали не все — есть цикл
- [ ] Сортировкой по номеру
- [ ] Дейкстрой
> Алгоритм Кана по входящим степеням.

### [2] Почему Дейкстра не работает с отрицательными весами? @graphs-advanced
- [ ] Куча не хранит отрицательные числа
- [x] Извлечённая вершина может позже улучшиться через отрицательное ребро, а алгоритм считает её расстояние окончательным
- [ ] Из-за переполнения
- [ ] Работает
> С отрицательными весами — Форд — Беллман.

### [3] Как отвечать на запрос «сколько компонент» после каждого добавленного ребра? @graphs-advanced
- [ ] Заново обходить граф после каждого ребра
- [x] DSU: объединение уменьшает число компонент, если концы были в разных множествах
- [ ] Топологической сортировкой
- [ ] BFS от каждой вершины
> Почти O(1) на ребро.

### [2] Как найти расстояние от каждой клетки до ближайшего из нескольких выходов? @graphs-contest
- [ ] BFS от каждой клетки
- [x] Один BFS, стартующий сразу из всех выходов
- [ ] DFS от выходов
- [ ] Дейкстра от каждой клетки
> Многоисточниковый BFS за O(V + E).

### [3] Переходы стоят 0 или 1. Какой алгоритм даст кратчайшие пути за O(V + E)? @graphs-contest
- [ ] Обычный BFS
- [x] 0-1 BFS с деком: вес 0 — в начало, вес 1 — в конец
- [ ] Флойд
- [ ] DFS
> Обычный BFS неверен, Дейкстра — медленнее.

### [3] Как найти минимальное остовное дерево? @graphs-contest
- [ ] BFS от любой вершины
- [x] Краскал: рёбра по возрастанию веса и DSU, чтобы не замыкать цикл
- [ ] Топологической сортировкой
- [ ] Взять n − 1 самых лёгких рёбер без проверки
> Без проверки на цикл лёгкие рёбра могут не соединить граф.
