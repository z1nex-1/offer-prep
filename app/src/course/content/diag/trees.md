### [2] Что выведет код? @trees
```python
class N:
    def __init__(self, v, l=None, r=None):
        self.v, self.l, self.r = v, l, r

def h(x):
    return 0 if x is None else 1 + max(h(x.l), h(x.r))

t = N(1, N(2, N(3)), N(4))
print(h(t))
```
- [ ] `2`
- [x] `3`
- [ ] `4`
- [ ] `1`
> Самый длинный путь от корня — 1 → 2 → 3, три вершины.
