### [1] Как получить max-кучу через heapq? @heap
- [ ] `heapq.maxheap`
- [x] Хранить числа с обратным знаком
- [ ] Передать `reverse=True`
- [ ] Никак
> `heappush(h, -x)` и `-heappop(h)`.

### [2] Что выведет код? @heap
```python
import heapq
h = []
for x in [4, 9, 1, 7, 3]:
    heapq.heappush(h, x)
    if len(h) > 2:
        heapq.heappop(h)
print(sorted(h))
```
- [ ] `[1, 3]`
- [x] `[7, 9]`
- [ ] `[4, 9]`
- [ ] `[3, 4]`
> min-куча размера 2 оставляет два наибольших.
