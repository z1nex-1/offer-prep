### [1] Как найти максимум массива за один проход, если числа могут быть отрицательными? @arrays-scan
- [ ] Начать с `best = 0`
- [x] Начать с первого элемента или `float("-inf")`
- [ ] Отсортировать и взять первый
- [ ] Начать с `best = -1`
> Ноль даст неверный ответ, если все числа отрицательные.

### [1] Что выведет код? @arrays-scan
```python
a = [1, 1, 0, 1, 1, 1]
best = cur = 0
for x in a:
    cur = cur + 1 if x == 1 else 0
    best = max(best, cur)
print(best)
```
- [ ] `5`
- [x] `3`
- [ ] `2`
- [ ] `6`
> Самая длинная серия единиц — 3.

### [2] Массив отсортирован. Как найти пару с суммой target за O(n) и O(1) памяти? @two-pointers
- [ ] Двойной цикл
- [x] Два указателя с концов
- [ ] Словарь
- [ ] Бинпоиск для каждого элемента
> Словарь — O(n) памяти, бинпоиск — O(n log n).

### [2] Что выведет код? @two-pointers
```python
a = [1, 2, 4, 7, 11]
l, r = 0, len(a) - 1
while l < r:
    s = a[l] + a[r]
    if s == 9:
        break
    if s < 9:
        l += 1
    else:
        r -= 1
print(l, r)
```
- [ ] `0 4`
- [x] `1 3`
- [ ] `2 3`
- [ ] `0 3`
> 2 + 7 = 9.

### [2] Как слить два отсортированных массива длины n и m? @two-pointers

### [2] Функция должна изменить переданный список `a` на месте. Какая строка это делает? @arrays-in-place
- [ ] `a = a[::-1]`
- [x] `a[:] = a[::-1]`
- [ ] `b = a; b = b[::-1]`
- [ ] `return a[::-1]`
> Присваивание срезу меняет содержимое того же объекта. `a = ...` лишь перепривязывает локальное имя к новому списку.

### [3] Как отсортировать массив из 0, 1 и 2 за один проход и O(1) памяти? @arrays-in-place
- [ ] Встречными указателями, как пару с суммой
- [x] Тремя указателями: ноль меняем с `a[lo]`, двойку — с `a[hi]`, не сдвигая текущий
- [ ] `sorted(a)`
- [ ] Это невозможно за один проход
> «Голландский флаг» Дейкстры: зоны нулей, единиц, непросмотренных и двоек. После обмена с `a[hi]` текущий элемент ещё не проверен, поэтому `mid` не двигается.
