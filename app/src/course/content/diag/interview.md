### [2] Что вернёт функция на `[1, 1, 2]`? @code-without-run
```python
def groups(a):
    res, cnt = [], 1
    for i in range(1, len(a)):
        if a[i] == a[i - 1]:
            cnt += 1
        else:
            res.append(cnt)
            cnt = 1
    return res
```
- [ ] `[2, 1]`
- [x] `[2]`
- [ ] `[1, 1, 1]`
- [ ] `[]`
> Последняя серия не добавлена после цикла.
