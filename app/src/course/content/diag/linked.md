### [2] Люди 1…n стоят в ряд и по одному выходят. Как для каждого выходящего за O(1) узнать соседей? @linked-arrays
- [ ] Искать в списке через `index` и удалять `pop`
- [x] Хранить `left[x]` и `right[x]` и при выходе сшивать соседей друг с другом
- [ ] Отсортировать номера
- [ ] Хранить множество оставшихся
> Двусвязный список на массивах: соседи x — ровно `left[x]` и `right[x]`, после выхода они смотрят друг на друга.

### [3] Текстовый редактор с курсором решён двумя стеками. Какая клавиша делает решение квадратичным? @linked-arrays
- [ ] Буква
- [ ] Стрелка влево
- [ ] Backspace
- [x] Home — перенос курсора в начало

### [2] Как удалить k-й с конца узел за один проход? @linked-rewire
- [ ] Развернуть список, удалить k-й, развернуть обратно
- [x] Два указателя с фиктивного узла, передний выпущен на k шагов вперёд
- [ ] Посчитать длину — это и есть один проход
- [ ] Рекурсией без возврата
> Когда передний дошёл до последнего узла, задний стоит прямо перед удаляемым; фиктивный узел покрывает удаление головы.

### [3] Как найти первый общий узел двух списков за O(1) памяти? @linked-rewire
- [ ] Сравнивать значения узлов попарно
- [x] Два указателя; дойдя до конца, каждый переходит в голову другого списка
- [ ] Отсортировать оба списка
- [ ] Развернуть оба списка и сравнить с конца
> Оба пройдут x + t + y узлов и встретятся в первом общем узле или одновременно в `None`.

### [3] Какую сортировку выбрать для односвязного списка? @linked-rewire
- [ ] Быструю сортировку с опорным элементом по случайному индексу
- [x] Слиянием: середина, две половины, слияние без новых узлов
- [ ] Пузырёк — он работает на месте
- [ ] Подсчётом — всегда
> Слияние не требует доступа по индексу и работает за O(n log n).
