### [1] Когда задачу стоит решать динамическим программированием? @dp-intro
- [ ] Когда нужно отсортировать данные
- [x] Когда ответ собирается из ответов на пересекающиеся подзадачи меньшего размера
- [ ] Когда в задаче есть граф
- [ ] Когда ограничения до 10⁹
> Динамика — это перебор, в котором каждая подзадача решается один раз и запоминается.

### [1] Что выведет код? @dp-intro
```python
dp = [0] * 7
dp[0] = 1
for i in range(1, 7):
    dp[i] = dp[i - 1] + (dp[i - 2] if i >= 2 else 0)
print(dp[6])
```
- [ ] `8`
- [x] `13`
- [ ] `21`
- [ ] `6`
> Лестница с шагами 1 и 2: 1, 1, 2, 3, 5, 8, 13.

### [2] Что выведет код? @dp-2d
```python
a, b = "abcb", "bcb"
n, m = len(a), len(b)
dp = [[0] * (m + 1) for _ in range(n + 1)]
for i in range(1, n + 1):
    for j in range(1, m + 1):
        if a[i - 1] == b[j - 1]:
            dp[i][j] = dp[i - 1][j - 1] + 1
        else:
            dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
print(dp[n][m])
```
- [ ] `2`
- [x] `3`
- [ ] `4`
- [ ] `1`
> Наибольшая общая подпоследовательность — `bcb`.
