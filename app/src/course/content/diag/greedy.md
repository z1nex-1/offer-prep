### [1] Что такое жадный алгоритм? @greedy
- [ ] Перебор всех вариантов
- [x] На каждом шаге локально лучший выбор без пересмотра
- [ ] Динамика с запоминанием
- [ ] Бинарный поиск
> Работает, только если локальный выбор не портит глобальный ответ.

### [2] Что выведет код? @greedy
```python
a = [2, 3, 1, 1, 4]
far = 0
ok = True
for i, x in enumerate(a):
    if i > far:
        ok = False
        break
    far = max(far, i + x)
print(ok, far)
```
- [ ] `False 4`
- [x] `True 8`
- [ ] `True 4`
- [ ] `True 5`
> Конец достижим; максимальная дальность 4 + 4 = 8.

### [1] Сколько точек нужно, чтобы задеть все отрезки `[1, 3]`, `[2, 4]`, `[5, 7]`, `[6, 8]`? @greedy-segments

### [2] Как покрыть отрезок `[0, L]` наименьшим числом данных кусков? @greedy-segments
- [ ] Брать самые длинные куски
- [x] Среди кусков, начинающихся не правее покрытой границы, брать тот, что заканчивается дальше всех
- [ ] Сортировать по правому концу и брать все подряд
- [ ] Брать куски по порядку ввода

### [3] Почему в задаче о заправках станции кладут в max-кучу, а не заправляются на каждой? @greedy-segments
- [ ] Так быстрее считать
- [x] Решение о заправке откладывается: когда топлива не хватает, «задним числом» берём самую большую из пройденных заправок
- [ ] Чтобы заправиться на самой дальней
- [ ] Куча не нужна
> Отложенная жадность: выбор делается тогда, когда без него уже нельзя, и из лучших доступных вариантов.

### [1] Как удалить k цифр из числа, чтобы осталось наименьшее? @greedy-order
- [ ] Удалить k самых больших цифр
- [x] Идти слева направо со стеком: пока вершина больше текущей цифры и удаления остались — снимать вершину
- [ ] Удалить k первых цифр
- [ ] Удалить k последних цифр
> Старшие разряды важнее: цифру удаляют, если справа от неё стоит меньшая.

### [2] Задания с длительностью t и весом w, минимизируем сумму `w · время окончания`. Когда a раньше b? @greedy-order
- [ ] Если `t_a < t_b`
- [ ] Если `w_a > w_b`
- [x] Если `t_a · w_b < t_b · w_a`
- [ ] Если `t_a + w_a < t_b + w_b`
> Обмен соседей: сравниваем вклад двух порядков. Произведения вместо деления — без ошибок float.

### [3] Заправки по кругу: стартовали с s, бак впервые ушёл в минус после заправки i. Какой следующий кандидат на старт? @greedy-order
- [ ] s + 1
- [x] i + 1
- [ ] i
- [ ] Любая заправка
> Любая заправка между s и i при старте с неё дойдёт до i с не большим запасом и тоже провалится — их можно пропустить.
