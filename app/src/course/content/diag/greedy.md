### [2] Как выбрать максимум непересекающихся встреч? @greedy
- [ ] Самые короткие
- [ ] По раннему началу
- [x] По раннему окончанию
- [ ] Самые длинные
> Обменный аргумент доказывает корректность.

### [2] Что выведет код? @greedy
```python
a = [2, 3, 1, 1, 4]
far = 0
ok = True
for i, x in enumerate(a):
    if i > far:
        ok = False
        break
    far = max(far, i + x)
print(ok, far)
```
- [ ] `False 4`
- [x] `True 8`
- [ ] `True 4`
- [ ] `True 5`
> Конец достижим; максимальная дальность 4 + 4 = 8.
