### [3] Для проверки анаграмм кандидат написал `return set(a) == set(b)`. На каком примере это решение ошибается? @solve-method
- [ ] `"abc"` и `"cab"`
- [ ] `""` и `""`
- [x] `"aab"` и `"abb"`
- [ ] `"ab"` и `"ba"`
> Множества букв совпадают, а количество каждой буквы — нет. Нужно сравнивать частоты, например `Counter(a) == Counter(b)`.

### [2] Во входе: в первой строке n, дальше n строк по одному числу. Как надёжнее всего прочитать числа? @first-submit
- [ ] `list(map(int, input().split()))`
- [x] `data = sys.stdin.read().split()`, затем `n = int(data[0])` и `data[1:1 + n]`
- [ ] `input()` один раз и `split(",")`

> `read().split()` режет весь вход и по пробелам, и по переводам строк, поэтому не зависит от того, как числа разбиты по строкам.
