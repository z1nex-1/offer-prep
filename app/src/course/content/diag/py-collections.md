### [3] Что выведет код? @py-functions
```python
x = 10
def f():
    x = 20
    def g():
        nonlocal x
        x += 1
        return x
    return g() + x

print(f(), x)
```
- [ ] `42 11`
- [x] `42 10`
- [ ] `41 10`
- [ ] Ошибку
> `nonlocal` меняет `x` функции `f`: 21 + 21 = 42. Глобальный `x` не тронут.

### [2] Что выведет код? @py-matrix
```python
a = [[1, 2], [3, 4], [5, 6]]
t = [list(c) for c in zip(*a)]
print(len(t), len(t[0]))
```
- [ ] `3 2`
- [x] `2 3`
- [ ] `2 2`
- [ ] `6 1`
> Транспонирование меняет размер n × m на m × n: из матрицы 3 × 2 получилась 2 × 3.

### [3] Почему в игре «Жизнь» нельзя обновлять клетки поля на месте, в том же списке? @py-matrix
- [ ] Строки в Python неизменяемы
- [x] Соседи, обработанные раньше на этом шаге, уже будут новыми, и результат зависит от порядка обхода
- [ ] Это медленнее, чем создавать новое поле
- [ ] Будет IndexError на границе
> Правила применяются ко всем клеткам одновременно, по состоянию до шага. Новое поле строят по старому и заменяют целиком.
