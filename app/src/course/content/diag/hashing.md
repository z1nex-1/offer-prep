### [1] Как быстро проверить, встречалось ли уже число, при проходе массива? @hash-patterns
- [ ] Список и `in`
- [x] Множество и `in`
- [ ] Отсортировать массив на каждом шаге
- [ ] Строка с числами
> Проверка во множестве — O(1) в среднем.

### [1] Две строки — анаграммы. Какая проверка правильная? @hash-patterns
- [ ] `set(a) == set(b)`
- [x] `Counter(a) == Counter(b)`
- [ ] `len(a) == len(b)`
- [ ] Все символы `a` есть в `b`
> Нужны частоты, а не только наличие символов.

### [2] Что выведет код? @hash-patterns
```python
a = [2, 7, 11, 15]
seen = {}
for i, x in enumerate(a):
    if 9 - x in seen:
        print(seen[9 - x], i)
    seen[x] = i
```
- [ ] `1 0`
- [x] `0 1`
- [ ] `0 3`
- [ ] Ничего
> Классика two sum за один проход.

### [3] Как посчитать количество подмассивов с суммой k (числа любого знака)? @hash-patterns
- [ ] Скользящее окно
- [x] Префиксные суммы и словарь «сумма префикса → сколько раз»
- [ ] Сортировка и два указателя
- [ ] Только перебор O(n²)
> Окно не работает с отрицательными числами.

### [3] Что выведет код? @hash-patterns
```python
cnt = {0: 1}
cur = res = 0
for x in [1, 2, 3]:
    cur += x
    res += cnt.get(cur - 3, 0)
    cnt[cur] = cnt.get(cur, 0) + 1
print(res)
```
- [ ] `1`
- [x] `2`
- [ ] `3`
- [ ] `0`
> Подмассивы с суммой 3: `[1, 2]` и `[3]`.

### [1] Какой ключ правильно группирует рёбра неориентированного графа, чтобы `(u, v)` и `(v, u)` считались одним ребром? @hash-keys
- [ ] `(u, v)`
- [x] `(min(u, v), max(u, v))`
- [ ] `[u, v]`
- [ ] `str(u) + str(v)`
> Упорядоченный кортеж одинаков для обеих записей ребра. Список нехешируем, а склейка строк зависит от порядка и путает `(1, 23)` с `(12, 3)`.

### [2] Почему наклон `dy / dx` во `float` — плохой ключ для группировки точек по прямым? @hash-keys
- [ ] `float` нельзя класть в словарь
- [x] Вертикальные прямые дают деление на ноль, а близкие дроби при больших координатах совпадают после округления
- [ ] Словарь с `float` работает за O(n)
- [ ] Это хороший ключ
> Надёжный ключ — вектор `(dx, dy)`, сокращённый на НОД, со знаком, приведённым к одному виду.

### [3] Шаблон `ab`, слова `dog dog`. Какое решение ошибочно ответит «следует шаблону»? @hash-keys
- [ ] Сравнение шаблонов «номер первого появления»
- [ ] Два словаря: буква → слово и слово → буква
- [x] Один словарь «буква → слово»
- [ ] Проверка всех пар i, j: `p[i] == p[j]` тогда и только тогда, когда `w[i] == w[j]`
> Один словарь не видит, что разные буквы отображаются в одно слово. Нужна проверка в обе стороны.
