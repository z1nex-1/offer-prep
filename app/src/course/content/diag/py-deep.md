### [1] Что выведет код? @py-objects
```python
a = [1, 2]
b = a
b.append(3)
print(a)
```
- [ ] `[1, 2]`
- [x] `[1, 2, 3]`
- [ ] `[3]`
- [ ] Ошибку
> `b = a` не копирует список: оба имени указывают на один объект.

### [2] Для чего правильно использовать `is`? @py-objects
- [ ] Для сравнения строк
- [ ] Для сравнения чисел
- [x] Для сравнения с `None` и другими синглтонами
- [ ] Для сравнения списков по содержимому
> `is` сравнивает идентичность объектов, значения сравнивают через `==`.

### [3] Что выведет код? @py-objects
```python
import copy
a = [[0], [0]]
b = copy.copy(a)
b[0].append(1)
b[1] = [9]
print(a)
```
- [ ] `[[0], [0]]`
- [x] `[[0, 1], [0]]`
- [ ] `[[0, 1], [9]]`
- [ ] `[[0], [9]]`
> Поверхностная копия разделяет вложенные списки, но замена элемента копии не трогает оригинал.

### [1] Что такое замыкание? @py-closures
- [ ] Функция без аргументов
- [x] Функция, которая запоминает переменные объемлющей области после её завершения
- [ ] Закрытый метод класса
- [ ] Функция, которая вызывает сама себя
> На замыканиях построены декораторы и фабрики функций.

### [2] Что выведет код? @py-closures

### [3] Зачем в декораторе `functools.wraps`? @py-closures
- [ ] Чтобы декоратор принимал аргументы
- [x] Чтобы обёртка сохранила имя, документацию и другие атрибуты исходной функции
- [ ] Чтобы кэшировать результат
- [ ] Без него декоратор не работает
> Без `wraps` все декорированные функции называются `wrapper`.

### [2] Что выведет код? @py-oop
```python
class A:
    x = []
a1, a2 = A(), A()
a1.x.append(1)
a2.x = [7]
print(A.x, a1.x)
```
- [ ] `[] [1]`
- [x] `[1] [1]`
- [ ] `[7] [7]`
- [ ] `[1] [7]`
> `append` меняет общий атрибут класса; присваивание `a2.x` создаёт атрибут только у `a2`.

### [3] Что произойдёт, если определить в классе `__eq__`, но не `__hash__`? @py-oop
- [ ] Хеш будет по `id`
- [x] Экземпляры станут нехешируемыми
- [ ] Хеш будет по полям автоматически
- [ ] Ошибка при определении класса
> Python ставит `__hash__ = None`, чтобы не нарушить правило «равные — равные хеши».
