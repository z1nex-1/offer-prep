### [1] Что выведет код? @strings-python
```python
print('10' < '9', 'ab' < 'abc')
```
- [ ] `False True`
- [x] `True True`
- [ ] `False False`
- [ ] `True False`
> Строки сравниваются посимвольно по кодам: `'1' < '9'`, а префикс меньше более длинной строки.

### [1] Как правильно собрать длинную строку из многих кусков? @strings-python
- [ ] `res += part` в цикле
- [x] Сложить куски в список и вызвать `''.join(parts)`
- [ ] `res = res + part` в цикле
- [ ] `str(parts)`
> Строки неизменяемы; `join` копирует каждый символ один раз.

### [2] Как за O(n) проверить, что две строки — анаграммы? @strings-python
- [ ] `sorted(a) == sorted(b)`
- [ ] `set(a) == set(b)`
- [x] Сравнить частоты символов: `Counter(a) == Counter(b)`
- [ ] `a[::-1] == b`
> Сортировка — O(n log n), а множества не учитывают количество одинаковых букв.

### [2] Что вернёт `'  a  b '.split()`? @strings-python
- [x] `['a', 'b']`
- [ ] `['', '', 'a', '', 'b', '']`
- [ ] `['a', '', 'b']`
- [ ] `['  a', 'b ']`
> Без аргумента `split` режет по любым пробельным символам и выбрасывает пустые куски.

### [2] Как найти самую длинную подстроку-палиндром за O(n²) и O(1) памяти? @strings-algo
- [ ] Перебрать все подстроки и проверить каждую
- [x] Расширяться от каждого из 2n − 1 центров, пока символы по краям совпадают
- [ ] Сравнить строку с её разворотом
- [ ] Отсортировать символы
> Перебор с проверкой — O(n³); сравнение с разворотом находит общую подстроку, но не обязательно палиндром.

### [2] Зачем нужны префиксные полиномиальные хеши строки? @strings-algo
- [ ] Чтобы сортировать строки быстрее
- [x] Чтобы сравнивать любые две подстроки за O(1) после O(n) предподсчёта
- [ ] Чтобы шифровать строку
- [ ] Чтобы найти палиндромы за O(1)
> Хеш подстроки `s[l:r]` — `(h[r] − h[l]·P^(r−l)) mod M`.

### [3] Как по префикс-функции найти длину самого короткого периода строки длины n? @strings-algo
- [ ] `pi[n − 1]`
- [x] `n − pi[n − 1]`
- [ ] `max(pi)`
- [ ] `n // pi[n − 1]`
> Наибольший префикс, равный суффиксу, длины pi[n − 1] означает сдвиг на n − pi[n − 1], при котором строка совпадает сама с собой.

### [2] Окно `[l, r]` должно содержать все различные символы строки. Почему здесь работают два указателя? @strings-algo
- [ ] Потому что строка отсортирована
- [x] Если окно содержит все символы, то и любое окно, которое его содержит, — тоже
- [ ] Потому что символов не больше 26
- [ ] Два указателя работают для любой задачи о подстроках
> Монотонность: расширение не портит хорошее окно, поэтому левая граница только растёт.

### [2] Что выведет `json.dumps({"ok": True, "v": None})`? @strings-parsing
- [ ] `{'ok': True, 'v': None}`
- [x] `{"ok": true, "v": null}`
- [ ] `{"ok": "True", "v": "None"}`
- [ ] `{"ok":true,"v":null}`
> JSON пишет `true` и `null`, ключи в двойных кавычках, разделители по умолчанию `', '` и `': '`.

### [2] Какой вызов проверяет, что строка целиком — время `HH:MM`? @strings-parsing
- [ ] `re.match(r'\d\d:\d\d', s)`
- [ ] `re.search(r'\d\d:\d\d', s)`
- [x] `re.fullmatch(r'\d\d:\d\d', s)`
- [ ] `s.count(':') == 1`
> `match` пропустит `12:30abc`, `search` — ещё и `abc12:30`.

### [2] Почему CSV нельзя всегда разбирать через `line.split(',')`? @strings-parsing
- [ ] Это медленно

- [ ] CSV всегда разделён точкой с запятой
> Модуль `csv` учитывает кавычки и удвоенные кавычки внутри поля.

### [3] В логе 10⁵ строк, нужно посчитать число запросов и ошибок 5xx по каждому эндпоинту. Как хранить статистику? @strings-parsing
- [ ] Список всех строк и подсчёт перебором для каждого эндпоинта
- [x] Словарь: ключ — эндпоинт (например, кортеж метода и пути), значение — счётчики
- [ ] Отсортировать строки лога как строки
- [ ] Отдельную переменную на каждый эндпоинт
> Один проход и O(1) на строку; перебор по эндпоинтам был бы O(n·k).
