### [1] Как быстро отвечать на много запросов суммы на отрезке неизменного массива? @prefix-sums
- [ ] Считать каждый раз циклом
- [x] Префиксные суммы: O(1) на запрос после O(n) предподсчёта
- [ ] Сортировка
- [ ] Куча
> `pref[r + 1] - pref[l]`.

### [1] Что выведет код? @prefix-sums
```python
a = [5, 1, 3, 2]
p = [0]
for x in a:
    p.append(p[-1] + x)
print(p[3] - p[1])
```
- [ ] `6`
- [x] `4`
- [ ] `9`
- [ ] `3`
> Сумма a[1] + a[2] = 1 + 3.

### [3] Как посчитать число подмассивов ровно с k различными числами? @sliding-window
- [ ] Одним окном
- [x] «Не больше k» минус «не больше k − 1»
- [ ] Только перебором
- [ ] Префиксными суммами
> Свойство «не больше k» монотонно.

### [3] Что выведет код? @prefix-sums
```python
g = [[1, 2], [3, 4]]
P = [[0] * 3 for _ in range(3)]
for i in range(2):
    for j in range(2):
        P[i + 1][j + 1] = g[i][j] + P[i][j + 1] + P[i + 1][j] - P[i][j]
print(P[2][2], P[2][2] - P[1][2])
```
- [ ] `10 3`
- [x] `10 7`
- [ ] `10 4`
- [ ] `7 3`
> Сумма всей матрицы 10, минус первая строка (3) — вторая строка 7.

### [1] Счётчик запросов записывает накопленное значение раз в секунду: 0, 3, 7, 2, 5 (между 7 и 2 был сброс). Сколько запросов пришло в секунду с показанием 2? @time-windows
- [ ] −5
- [x] 2
- [ ] 0
- [ ] 7
> После сброса счётчик начал с нуля, значит, за эту секунду пришло столько, сколько он показал.

### [2] Лог заказов (время, сумма). Как найти наибольшую выручку за любые k секунд? @time-windows
- [ ] Окно из k подряд идущих заказов
- [x] Отсортировать по времени и двигать левый указатель, пока заказ старше T − k + 1
- [ ] Разбить смену на куски по k секунд
- [ ] Взять k самых дорогих заказов
> Окно задаётся временем, а не числом заказов: за k секунд может прийти сколько угодно заказов.

### [3] Как посчитать длительность интервала с 22:30 до 01:15 в минутах? @time-windows
- [ ] `abs((1 * 60 + 15) - (22 * 60 + 30))`
- [x] `((1 * 60 + 15) - (22 * 60 + 30)) % 1440`
- [ ] `(22 - 1) * 60 + 30 - 15`
- [ ] 21 час 15 минут
> 165 минут. Интервал идёт через полночь, остаток по модулю суток делает разность неотрицательной.
