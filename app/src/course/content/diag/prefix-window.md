### [1] Как быстро отвечать на много запросов суммы на отрезке неизменного массива? @prefix-sums
- [ ] Считать каждый раз циклом
- [x] Префиксные суммы: O(1) на запрос после O(n) предподсчёта
- [ ] Сортировка
- [ ] Куча
> `pref[r + 1] - pref[l]`.

### [1] Что выведет код? @prefix-sums
```python
a = [5, 1, 3, 2]
p = [0]
for x in a:
    p.append(p[-1] + x)
print(p[3] - p[1])
```
- [ ] `6`
- [x] `4`
- [ ] `9`
- [ ] `3`
> Сумма a[1] + a[2] = 1 + 3.

### [3] Почему скользящее окно не годится для «самого короткого подмассива с суммой ≥ s», если есть отрицательные числа? @sliding-window
- [ ] Годится

### [3] Как посчитать число подмассивов ровно с k различными числами? @sliding-window
- [ ] Одним окном
- [x] «Не больше k» минус «не больше k − 1»
- [ ] Только перебором
- [ ] Префиксными суммами
> Свойство «не больше k» монотонно.

### [3] Что выведет код? @prefix-sums
```python
g = [[1, 2], [3, 4]]
P = [[0] * 3 for _ in range(3)]
for i in range(2):
    for j in range(2):
        P[i + 1][j + 1] = g[i][j] + P[i][j + 1] + P[i + 1][j] - P[i][j]
print(P[2][2], P[2][2] - P[1][2])
```
- [ ] `10 3`
- [x] `10 7`
- [ ] `10 4`
- [ ] `7 3`
> Сумма всей матрицы 10, минус первая строка (3) — вторая строка 7.
